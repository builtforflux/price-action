# 概率清单

集中保存课程中的数值概率、相关频率、计算示例及未采用项。按事件合并重复和多空镜像，条件不同则分列；同一数字不能相加或互相验证。

范围为已汇总的市场与交易概率及其补充项。逐讲重复、个案胜负记录和更细的来源差异沿 [D007 来源分项](../audits/reference_absorption/details/D007.md)追溯；本表不宣称穷尽原课所有数字。回撤比例、仓位比例、费率等非概率参数不在本表范围。

**采用状态：当前没有已校准、可直接用于交易决策的数值概率规则。**“Core 已收录”只表示保留为来源经验；“仅清单”表示未进入核心摘要；“隔离”表示条件、分母或来源仍有问题。系统采用情况以 [Governance](../trading_system/governance.md)及负责页为准。

表内期限写在条件中。未写明的期限或产品、周期，表示该摘要不足以确定，须回查来源，不补成统一窗口。物理页码对应各讲所属 PDF；时段数字沿原 Session 理解。

## 如何使用

- 市场概率、交易概率和出现频率分别理解；先确定事件，再看数字。
- 事前与事件发生后的条件概率分开；不将少数分支发生后的判断继续固定在旧概率。
- 目标与失败可能之外还有未决或到期，不擅自补成互斥全集；来源明确二分的，仍保留其原语境。
- 相同概率可用于不同事件，多条描述也可能来自同一事实；不相加、不重复计票。
- [Core](../trading_system/core_summary.md)保留常用关系与场景；来源条件有分歧时回查逐讲材料，采用规则按 [Governance](../trading_system/governance.md)处理。
