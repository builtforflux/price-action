# Al Brooks Trading Course 01–52

本目录按课程编号保存 01–52 的逐讲 Markdown 材料分析。带 A、B、C 等后缀的文件对应同一课程编号下的原始分讲；编号文件共 191 份，按名称自然排序形成完整课程顺序。

这里保存的是课程证据地图和仓库分析，不是课程正文转录，也不直接许可交易动作。术语定义和缩写回到[核心术语表](../glossary.md)及其[常用缩写](../glossary.md#常用缩写)，来源身份和版本指纹回到[正式来源台账](../official_sources.md)，完整交易计划回到[策略手册](../../strategy/README.md)。

每份逐讲材料的五个固定部分承担不同证据职责：

| 部分 | 默认职责 |
| --- | --- |
| 内容结构 | 按物理 PDF 页码记录原课主题和页面顺序 |
| 核心思想 | 对带页码课程材料作条件化归纳；除非明确标为直接引述，否则属于仓库整理 |
| 重复与递进 | 比较跨页、跨讲和牛熊镜像的信息增量，属于仓库分析 |
| 可能矛盾或边界 | 保存数学冲突、适用条件和不可外推范围，属于仓库分析 |
| 翻译或抽取问题 | 登记 OCR、图文顺序、翻译、原页笔误和仍未完成的视觉核对 |

`p` 和“物理页”均指来源台账登记版本的物理 PDF 页码。课程转述、仓库归纳、来源冲突和未决问题分别按[来源台账的证据归因](../official_sources.md#证据归因)理解；逐讲中的“应、不得、可以入场”等措辞若未明确标为仓库规则，只是在转述或限制课程案例，不构成策略许可。
