## 怎样处理内容冲突

1. Brooks 概念或术语冲突，先回到正式来源和 `core/README.md` 注册的对应 Definition 页；术语表不是平行权威。
2. 参考材料与 Core 的权威定义冲突时，以 Core 为准。

来源支持价格行为关系，仓库负责把这些关系整理成可读的知识结构，不应把仓库归纳写成 Brooks 官方穷尽分类。
