## 证据使用顺序

```text
正式来源与具体页码
> 逐讲材料中的页级分析
> 边界与冲突、重复矩阵
> 概念索引、术语表和覆盖映射等派生导航
```

派生文件帮助定位证据，不能覆盖具体来源条件。引用课程数字时必须保留目标事件、周期、时间范围和判断时点；数学、分母或翻译不清的内容留在隔离台账。

## 系统与证据的关系

1. Reference 说明 Brooks 材料实际包含什么、出现在哪里及其限制。
2. `trading_system/` 负责选择、归并和条件化，并决定哪些关系可以运行。
3. Reference 中不能改变结构、目标、路径、概率、风险、执行或复盘的内容不进入运行系统。
4. 若新证据与现有系统冲突，先保留证据和适用条件，再明确系统是否更新；不能静默用来源片段覆盖完整运行契约。
