# 参考资料

> **定位：来源、证据、别名、冲突和核验状态**

本目录回答“资料实际说了什么、出现在哪里、在什么条件下成立、怎样被核验、与其他资料有何重复或冲突”。Reference 不定义看盘和交易方法，也不直接决定交易；当前方法由 [`trading_system/`](../trading_system/README.md) 独立负责。系统可以选择、归并或拒绝 Reference 中的 Claim，但不能反向用现有结构证明来源已经支持该设计。

## 权威边界

| 负责文件 | 唯一职责 | 不负责 |
| --- | --- | --- |
| [正式来源台账](official_sources.md) | 来源身份、版本语境与指纹、访问状态、稳定 Source ID、原文锚点和来源级冲突 | 课程页界、具体方法或交易决定 |
| [机器可读课程目录](course/course_catalog.json) | 191 个分讲的物理页界和原始 bookmark 标签（`start_title`） | 原 PDF bookmark 的目标页异常、来源身份或版本语境、逐页视觉核验、课程命题真伪 |
| [课程覆盖清单](course/coverage_manifest.md) | 每份分析是否存在、逐页视觉验收和局部核验状态 | 重新定义页界或证明原课已被完整复原 |
| [逐讲课程材料](course/README.md) | 带页码的课程提取、条件化归纳、重复、边界和抽取问题 | 自动成为系统规则 |
| [边界与冲突](course/boundaries_and_conflicts.md) | 数学、分母、语义、翻译和适用条件冲突 | 静默选择一个版本覆盖其他来源 |
| [课程知识与方法关系](course/course_to_method_map.md) | 知识层、01–52 证据增量、六类场景归并、条件证据及其可能影响的方法环节 | 制定运行规则、对象设计、来源身份或当次交易许可 |
| [`trading_system/`](../trading_system/README.md) | 市场判断、交易方案、风险、执行和复盘方法 | 改写来源或把仓库综合归因于 Brooks |

`course_catalog.json` 只负责分讲页界和 bookmark 标签（`start_title`）；其中 `sources`、指纹和 Source ID 字段只是正式来源台账的机器可读镜像，不取得来源身份或版本语境的权威。目录也不保存原 PDF bookmark 实际指向的目标页。bookmark 目标页与已核页界不一致时，该差异是来源级异常，由正式来源台账保存，并由逐讲记录和覆盖核验提供证据，不能反向改写目录页界。[完整课程索引](course/lesson_index.md)及覆盖清单中的页范围是目录的派生视图；Source ID 含义回到正式来源台账，描述性标题来自逐讲文件。视觉核验状态由覆盖清单独立拥有，不能从页界连续性推断。

## 证据使用顺序

```text
正式来源与具体页码
> 逐讲材料中的页级分析
> 边界与冲突、重复矩阵
> 概念索引、术语表、覆盖映射和其他派生导航
```

派生文件帮助定位证据，不能覆盖具体来源条件。引用课程数字时必须保留目标事件、周期、时间范围、horizon 和判断时点；数学、分母、翻译、图文关系或来源口径不清的内容留在隔离台账。

证据归因与核验状态是两个不同维度：Direct support、Context support、Repository synthesis 等说明命题怎样归因；来源身份已核、文本已读、页面已视觉核对、跨来源确认或仍未决，说明证据被核到什么程度。缺少逐页视觉验收时，不能把依赖图形、箭头、订单线或逐帧关系的提取升级为已确认事实。

## Claim 的使用边界

1. Reference 保存 Claim 的来源锚点、条件、目标事件、适用周期、horizon、判断时点、冲突和核验状态。
2. 只有会改变可观察事实解释、位置、结构/状态判断、现实结果路径、交易风险、订单/仓位处理或复盘结论的 Claim，才需要进入系统。
3. 历史产品参数、固定点数、特定平台行为和案例仍留作证据；实际交易应从当前 Broker 文档、账户界面和成交对账获得实时值，不能把旧案例参数复制为常数。
4. 数学错误、分母不清、翻译冲突、图形未核或不可观察因果叙事不得进入运行规则；必要时可作为反例、解释模型或待核项保存。
5. 若新证据与现有方法冲突，先保留来源及适用条件，再明确是否更新；不得静默用来源片段覆盖完整方法，也不得用当前结构消解来源冲突。

Reference 中的内容一律是证据；整理状态本身不许可数值判断或交易。未解决的数学、分母、翻译、图文与时序冲突继续隔离；来源和 Claim 边界由本页与[正式来源台账](official_sources.md)负责，具体冲突回到[边界与冲突](course/boundaries_and_conflicts.md)。
