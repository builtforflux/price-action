# 仓位管理：规模、加减仓与退出

按持仓状态与新信息整理 reference 中的管理动作，供后续吸收。条目归并属于仓库综合；课程参数、算例与冲突见[参数与核算](parameters.md)，来源范围及吸收位置见[来源与吸收映射](coverage.md)。

## 管理链路

交易前提与持有目标 → 保护止损与风险预算 → 首仓及预定分层 → 持有 / 加仓 / 减仓 / 平仓 → 余仓保护与订单核对

市场背景、账户盈亏与管理动作分别记录。同一笔交易可依次经历多个条目；多头与空头的方向镜像合并，改变条件、数量或退出方式的分支保留。

## 核算口径

| 术语 | 含义 |
| --- | --- |
| 首仓 | 本笔交易首次成交形成的仓位 |
| 加仓 | 仍有持仓时，增加同方向数量 |
| 减仓 / 平仓 | 减少部分数量 / 将本笔余仓降至零 |
| 重新入场 | 原交易平仓后，按新信号建立新交易 |
| 入场笔数 / 数量 | 成交批次 / 每批持仓单位；一笔可以包含多个单位 |
| 初始风险距离 | 入场价至初始保护止损的距离；金额另计数量、点值与成本 |
| 当前回吐风险 | 当前价至有效止损所对应的余仓权益回撤 |
| Actual Risk（课程） | 有利运动确认后，回看入场后回调所得的最小历史存活止损距原入场的距离 |
| 整笔止损结果 | 已实现盈亏、余仓在止损处退出的盈亏与成本之和 |
| 首笔保本 | 首笔在入场价附近退出；其他分笔单独计算 |
| 组合毛保本 / 净保本 | 全部相关分笔毛盈亏合计为零 / 扣除成本后合计为零 |
| 近似保本 | 入场或组合成本附近的小利、小亏退出 |

浮盈 / 浮亏以实际持仓成本判断；顺势 / 逆势以所选市场运动判断。回调加仓时，首仓仍可浮盈。Actual Risk 保留观察截止时点，初始定量使用当时已知的止损距离。

来源：[34A p2697–2707](../../reference/course/34A.md)、[35A p2735–2739](../../reference/course/35A.md)、[35B p2757](../../reference/course/35B.md)、[33G p2676–2679](../../reference/course/33G.md)、[36A p2792–2796](../../reference/course/36A.md)。

## 规模与保护

### PM01 按止损距离确定首仓

- **条件：**交易前提、结构止损、目标与可承受金额已明确。
- **动作：**以入场至止损的每单位损失反推数量；宽止损配小仓位。金额承受能力与执行状态共同约束规模。
- **后续：**较晚确认、大突破或高周期止损使距离扩大时，重算数量与剩余目标空间。
- **来源：**[30C p2352–2354](../../reference/course/30C.md)、[33A p2579–2583](../../reference/course/33A.md)、[33F p2663–2669](../../reference/course/33F.md)、[36B p2808](../../reference/course/36B.md)。

### PM02 预留分层风险

- **条件：**首笔入场前已选择分层参与，具备逐层核算与主动退出能力。
- **动作：**确定最大追加次数、各层位置或信号、数量、共同止损、组合退出及期限；首仓为后层预留损失预算。
- **后续：**每次追加前核算全部可能成交层的总风险；下一层条件未出现时沿用现有持仓方案。
- **来源：**[35A p2739](../../reference/course/35A.md)、[35B p2756–2764](../../reference/course/35B.md)、[35C p2770–2771](../../reference/course/35C.md)、[51D p1344–1346](../../reference/course/51D.md)、[52A p1369–1371](../../reference/course/52A.md)。

### 保护止损的结构参照

| 持有前提 | 参照 | 管理含义 |
| --- | --- | --- |
| 信号构成新走势段起点 | 信号 K 线 / 完整反转结构外 | 信号起点失效时退出 |
| 强突破或趋势波段 | 最近强突破段起点 / 主要 HL、LH 外 | 容纳该尺度的正常回调 |
| 强势段维持浅回撤 | 所选强势段中点外 | 较深回撤触发退出；恢复后可重新入场 |
| 宽通道 / 区间内反复测试 | 相关通道或区间外 / 具明确测量依据的投射外 | 用较小数量容纳较大摆动，并保留主动退出分支 |

参照按持有前提选择，同图可以有多个合理方案。已有持仓的止损调整见 PM12–PM14；来源中不同宽窄止损的备选案例分别保留。

来源：[33B p2590–2596](../../reference/course/33B.md)、[33C p2602–2618](../../reference/course/33C.md)、[33E p2645–2654](../../reference/course/33E.md)、[33F p2659–2667](../../reference/course/33F.md)。

## 加仓

### PM03 强突破持续时顺势追加

- **条件：**原方向强突破与跟随持续，出现新的顺势入场机会。
- **动作：**在后续顺势信号或强趋势收盘追加；逐层比较新入场至共同止损、目标的距离，并重算整仓风险。
- **后续：**首仓可持有波段，后层短线兑现；强趋势持续时也可保留追加仓。动能转弱后按 PM08 降低规模。
- **来源：**[35A p2735、2745–2749](../../reference/course/35A.md)、[38D p93–99](../../reference/course/38D.md)、[41D p338–345](../../reference/course/41D.md)。

### PM04 原前提有效时在回调中追加

- **条件：**原趋势或第二段预期仍有效，相关结构守住，回调到计划区域或形成恢复信号。35A 多头例要求回调弱、没有连续强空头 K 线，且尚未转为 Always In Short。
- **动作：**在预定回撤区域限价追加，或在同向反转 K 线外侧突破追加；距离与数量按原分层计划执行。
- **后续：**恢复强可保留波段；恢复偏弱可在首笔价或组合成本附近减仓、退出；原前提失效转 PM15。
- **来源：**[33C p2609](../../reference/course/33C.md)、[35A p2750–2751](../../reference/course/35A.md)、[35B p2756–2763](../../reference/course/35B.md)、[52A p1369–1372](../../reference/course/52A.md)。

### PM05 区间或宽通道边缘分层

- **条件：**价格处于区间边缘，或已有上下段重叠、回调穿回突破点的宽通道边缘；预计向内回摆，仍有可用回摆空间。
- **动作：**上沿高处分层卖出、下沿低处分层买入；可用边缘限价或向内反转信号。止损、层距、总量与组合退出一起确定。
- **后续：**回摆至首笔价、加权成本或区间内部时按计划减仓、退出；向外强突破与跟随使回摆前提失效时停止追加并退出。
- **来源：**[45D p649–659](../../reference/course/45D.md)、[46D p762–767](../../reference/course/46D.md)、[47C p856、860–866](../../reference/course/47C.md)、[47D p872–878、887–888](../../reference/course/47D.md)。

窄通道中的逆势分层单列为受限来源案例：43C、44C 展示了有限回摆收益与共同止损风险累积的交换，详见参数 N16–N17；其背景与 PM05 的双向宽幅摆动分别保存。

## 减仓与目标调整

### PM06 当前回吐风险增大

- **条件：**趋势继续，当前价距有效结构止损越来越远，现有数量对应的权益回撤扩大。
- **动作：**减仓以降低当前回吐风险；已有新结构时，也可按 PM12 追踪止损。
- **后续：**按余量、当前价和有效止损重算；初始风险距离保持原记录。
- **来源：**[36A p2792–2793、2796](../../reference/course/36A.md)；[来源台账 SRC-POSITION-SIZE](../../reference/official_sources.md)。

### PM07 目标兑现与分批退出

- **条件：**价格到达预定退出目标；部分退出方案另有余仓持有依据。
- **动作：**按预定数量部分或全部止盈；保留部分参与第二段、测量移动或趋势延伸。比例明确按原始总量或当时余量计算。
- **后续：**风险倍数目标过近而强趋势仍有空间时，可保留余仓至结构目标；更新余仓保护与下一退出条件。数量模板见 N09–N11。
- **来源：**[21D p1862–1863](../../reference/course/21D.md)、[22B p1900](../../reference/course/22B.md)、[31D p2492](../../reference/course/31D.md)、[34B p2714–2720](../../reference/course/34B.md)、[36B p2804–2807](../../reference/course/36B.md)、[39D p162–163](../../reference/course/39D.md)。

### PM08 加仓后的动能转弱

- **条件：**连续追加后仓位较大，强突破转成较平通道或区间，重叠、十字星、第三推增加。
- **动作：**将大仓降回常态规模，或按转弱程度全部退出；先处理依赖持续动能的追加仓。
- **后续：**首仓波段仍有依据时保留并跟踪；原持有前提失效时退出余仓。
- **来源：**[35A p2745–2748](../../reference/course/35A.md)。

### PM09 高潮与目标区域的反向信号

- **条件：**已有趋势利润，接近测量目标或重要区域，出现连续高潮、末端旗形、楔形或可信反向信号。
- **动作：**停止追加，部分止盈或全部退出；目标区反转增强时处理余仓。
- **后续：**趋势仍强时可保留部分。止盈与建立反向仓位分别判断。
- **来源：**[13B p837、845–848](../../reference/course/13B.md)、[35A p2749](../../reference/course/35A.md)、[36B p2811–2812、2816](../../reference/course/36B.md)、[39D p162–164](../../reference/course/39D.md)。

### PM10 趋势转为区间

- **条件：**原计划追随突破或趋势，随后回调延长、双向重叠增加；原方向仍可能恢复。
- **动作：**将直接延伸目标调整为区间另一侧、小利或近似保本；数量随新目标和回摆风险重评。
- **后续：**原计划包含区间摆动时可继续管理；强反向突破及跟随使持有前提失效时转 PM15。
- **来源：**[31D p2478–2480](../../reference/course/31D.md)、[33D p2623–2628、2637–2638](../../reference/course/33D.md)、[40B p196–199](../../reference/course/40B.md)、[52B p1378–1381](../../reference/course/52B.md)。

### PM11 分层仓位回到退出区域

- **条件：**计划内多笔已成交，价格恢复至首笔入场或组合成本附近。
- **动作：**首笔价退出方案分别记录首笔保本与后层盈亏；组合成本方案按实际数量加权并计成本。可按恢复力度部分或全部退出。
- **后续：**强恢复支持余仓波段；恢复受阻则接受当时可实现结果，限价未成交转 PM17。
- **来源：**[35A p2737–2738、2743](../../reference/course/35A.md)、[35B p2757、2761](../../reference/course/35B.md)、[47C p863–866](../../reference/course/47C.md)、[52A p1370](../../reference/course/52A.md)。

## 持有与止损调整

### PM12 正常回调与结构追踪

- **条件：**原方向波段前提有效，关键结构守住；新的强突破与跟随可进一步确认主要回调点。
- **动作：**普通回调期间依有效结构止损持有；新强突破创新高 / 新低后，可将止损移至所确认主要 HL 下方 / LH 上方。
- **后续：**弱新高低仍按原结构管理；较近保护与较宽保护分别对应不同回调容忍度。
- **来源：**[31A p2422–2423、2430](../../reference/course/31A.md)、[33C p2606、2612、2615–2618](../../reference/course/33C.md)、[39C p146–148](../../reference/course/39C.md)。

### PM13 突破测试后恢复，再次测试

- **条件：**突破入场已经历首次回调测试，随后强势恢复；原入场附近及关键结构再次面临测试。
- **动作：**首轮测试用原结构止损容纳回撤；强恢复后可移至近似保本或新结构外，管理再次测试。
- **后续：**再次测试守住则继续跟踪；跌破多头关键低点 / 上破空头关键高点时退出或重评区间。
- **来源：**[33G p2680–2686](../../reference/course/33G.md)、[38B p72](../../reference/course/38B.md)、[39C p147–148](../../reference/course/39C.md)。

### PM14 临近短线目标后反转

- **条件：**短线已接近目标但退出尚未成交，剩余回报缩小，同时出现反转证据。
- **动作：**可将止损移至近似保本或新反向结构外，或在旧极值测试、反转信号处止盈。
- **后续：**比较当前价至目标与止损的距离；目标完成比例见 N12，具体动作仍保留反转条件。
- **来源：**[33G p2678–2679](../../reference/course/33G.md)、[36A p2794](../../reference/course/36A.md)。

## 平仓与重新入场

### PM15 持有前提失效

- **条件：**合理反向信号或强反向动量使原持有前提失效；包括目标反复落空后的反转。
- **动作：**主动平仓并停止追加；执行当时的盈利、减亏或亏损退出方案。
- **后续：**空仓后重新判断。结构反向信号、强反向动量与保护止损是来源中的三种退出依据。
- **来源：**[33D p2630–2640](../../reference/course/33D.md)、[34A p2709](../../reference/course/34A.md)、[36A p2789–2790、2796–2798](../../reference/course/36A.md)、[36B p2803](../../reference/course/36B.md)、[52A p1357–1365](../../reference/course/52A.md)。

### PM16 保护止损触发

- **条件：**预置保护止损满足触发条件。
- **动作：**执行所保护数量的退出，核对实际成交价、数量与余仓；跳空等成交偏差纳入结果。
- **后续：**剩余订单按实际持仓处理；新的交易机会转 PM18。
- **来源：**[32A p2503–2509、2514–2516](../../reference/course/32A.md)、[33A p2565–2566](../../reference/course/33A.md)、[51C p1319–1321](../../reference/course/51C.md)。

### PM17 退出限价未成交

- **条件：**计划获利或保本退出仅触价、部分成交或未成交，随后反向运动增强。
- **动作：**按实际余仓调整退出限价、采用反向信号退出或市价退出；原保护持续覆盖余仓。
- **后续：**手动退出后核对并处理原 bracket / OCO，避免残留订单形成新仓位。
- **来源：**[32A p2511–2516、2520–2522](../../reference/course/32A.md)、[40D p223–225](../../reference/course/40D.md)、[51B p1304](../../reference/course/51B.md)、[52B p1385–1388](../../reference/course/52B.md)。

### PM18 平仓后重新入场

- **条件：**原仓已退出，原背景重新获得支持，或反向突破形成新交易依据；相应独立信号出现。
- **动作：**重新确定入场、止损、数量与目标；仍有旧余仓时，新增部分按加仓核算。
- **后续：**保留原交易结果，新交易单独跟踪；宽止损持有与先退后入作为备选方案比较。
- **来源：**[33B p2588–2590、2597](../../reference/course/33B.md)、[33F p2661、2670](../../reference/course/33F.md)、[38A p59](../../reference/course/38A.md)、[51C p1319](../../reference/course/51C.md)、[52B p1381](../../reference/course/52B.md)。

## 时间与执行状态

### PM19 剩余时段缩短

- **条件：**日内交易临近时段结束，分层回摆或波段目标所需时间减少。
- **动作：**重评未用加仓层与目标；晚段反转交易要求较快推进，按日内计划退出余仓。
- **后续：**区别尾盘才启动的新通道与较早建立的持续趋势；日内来源的最终平仓按其实际时段理解。
- **来源：**[38D p97、101](../../reference/course/38D.md)、[41A p275、279](../../reference/course/41A.md)、[48I p1039–1042](../../reference/course/48I.md)。

### PM20 执行承受能力下降

- **条件：**持仓金额、困惑或沮丧已干扰原计划执行。
- **动作：**来源允许近似保本退出；后续交易缩小至可稳定执行的规模。
- **后续：**把执行状态与市场前提分别记录；原保护止损持续生效。
- **来源：**[30C p2352–2354](../../reference/course/30C.md)、[33A p2579](../../reference/course/33A.md)、[33G p2677](../../reference/course/33G.md)、[52B p1392](../../reference/course/52B.md)。

## 逐笔记录

| 对象 | 必要信息 |
| --- | --- |
| 判断 | 最后可见 K 线、周期、主运动、交易前提、目标、剩余时段 |
| 持仓 | 方向、每笔实际入场价与数量、已实现盈亏、当前余量 |
| 加仓 | 位置或信号、预计成交价、数量、剩余次数、共同止损、停止追加条件 |
| 减仓 | 原始总量或当时余量、拟退出数量、目标余量、余仓依据 |
| 保护 | 有效止损、拟调整参照、当前回吐风险、整笔止损结果 |
| 退出 | 目标或触发条件、委托价、实际成交、未成交余量、相关订单状态 |

这些字段是跨讲核算所需的综合整理。图示目标、文字方案、实际到价与账户成交分别留证；案例中的替代方案各自核算。
