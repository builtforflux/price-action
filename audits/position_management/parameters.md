# 仓位管理：参数与核算

管理条件见[仓位管理](README.md)。以下区分课程参数、假设算例、仓库算术与来源冲突；保留各自的数量、风险分母、判断时点和成本口径。课程概率沿用 reference 编号，均未作当前市场校准。

## 风险与数量

以下为同一线性产品、同方向持仓的核算归纳。数量采用产品允许的单位；点值及损益币种统一后计算。期权与跨产品组合另建损益模型。

| 符号 | 含义 |
| --- | --- |
| `B` | 本笔计划损失预算 |
| `E_i / q_i` | 第 i 笔入场价 / 数量 |
| `S / C / F` | 有效止损价 / 当前价 / 拟退出价 |
| `v` | 每单位持仓、每价格单位对应的账户币金额 |
| `D` | 多头为 +1，空头为 −1 |
| `K` | 对应账本中的全部适用成本 |

```text
初始单笔数量上限
=（B - 固定成本预留）÷（入场至初始止损距离 × v + 每单位成本预留）

计划分层止损损失
= Σ[q_i × D × (E_i-S) × v] + K
（全部计划入场均在止损有利侧时；分别计算已成交与仍可能成交层）

当前回吐风险
= max(0, Q × D × (C-S) × v)
（Q 为当前实际余量，另计未来执行成本）
```

首层风险占比与首层数量占比分开；入场距离不同，即使等量，各层承担的损失也不同。初始止损已移到某层盈利侧后，整笔结果用下节的有向损益计算。数量按允许步长向下取整。

来源：[30C p2353–2354](../../reference/course/30C.md)、[33A p2579–2583](../../reference/course/33A.md)、[35A p2739、2745](../../reference/course/35A.md)、[36A p2792–2796](../../reference/course/36A.md)。成本与逐笔合计为仓库核算补全。

## 均价与分段退出

本节 `q_i` 仅指第 i 笔当前未退出的实际数量；已退出数量计入已实现结果，待成交层单独用于计划核算。

```text
当前余仓数量 Q = Σq_i
当前余仓加权成本 Ē = Σ(q_i × E_i) / Q
余仓在 F 全退的毛结果 = Q × D × (F-Ē) × v

整笔在 F 结束的净结果
= 已退出分笔毛结果 + 余仓在 F 全退的毛结果 - 全部适用成本

整笔止损净结果 = 上式取 F=S
整笔止损净损失 = max(0, -整笔止损净结果)
```

两笔等量、均未退出时，两价中点为余仓毛保本价。回首笔价全退时，首笔毛保本、较优价格的追加仓获利；已部分退出时，整笔净保本还须计入已实现结果。价格中的点差、滑点与另收费用按实际计价口径核算，已计部分只扣一次。

减仓比例以原始总量为分母时，`50% → 25% → 25%` 对应原量的三次退出；以余量为分母时，连续减半对应原量的 `50% → 25% → 12.5%…`，两种写法分别记录。

来源：[03E p254–264](../../reference/course/03E.md)、[35A p2737–2738、2743](../../reference/course/35A.md)、[35B p2757](../../reference/course/35B.md)、[36B p2807](../../reference/course/36B.md)。公式为按这些关系展开的仓库算术。

## 冲突与交易结果数字

二元毛保本算术为 `p_BE = L / (W+L)`，假定每次结果仅为固定毛利 `W` 或固定毛亏 `L`。分批、提前退出及保留波段会改变结果分布；算术门槛与来源声称的实际胜率分别保存。

表中 `tick-units / point-units / pip-units` 表示价格变动乘持仓单位后的加总。它们与单笔止损的价格距离分别计量。
