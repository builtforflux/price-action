# 概率分析与速查

先确定要预测什么，再看来源给出的概率。下表按事件归组，保留 P001–P079 与 X001–X044 的编号、条件、数值和状态；X043–X044 补入趋势起点强突破的出现频率。分组是检索与比较的起点，同组条目不自动拥有共同分母，也不构成独立样本。

所有市场数值仍是 reference 的课程说法，尚未作当前市场校准。这里不对场景按胜率排名，不把同时适用的条目相乘或相加。完整背景、候选路径与失效条件见[场景正文](scenarios.md)。

## 怎样比较

| 分析问题 | 可以做的比较 | 需要补足或保留的区别 |
| --- | --- | --- |
| 区间不同位置哪边更有利 | P013、P020 可按相同等距事件对照位置条件 | 起点、等距大小、周期和期限须一致；目前没有统一样本统计 |
| 早期参与与确认后参与 | P045、P046 可分析价格、风险和确认程度的交换 | 前者明确至少2R，后者是波段利润；不能直接解释为同一交易胜率提高20个百分点 |
| 通道边缘与外侧突破后的反转 | P011、P027 均涉及约5根内的反转启动 | 判断起点、边缘测试与已向外突破不同；5根不约束到达对侧 |
| 突破往哪边、能否到目标 | P017 对应方向，P018 对应先达目标／此前反转 | 两个50/50不是同一个事件，也未给可以相乘的条件独立性 |
| 波段、区间与强反向趋势 | P029、P030 可分析结果层级及包含关系 | 不把60%、40%、20%拼成互斥树，也不反推“波段后成趋势”的条件概率 |

只要目标、期限、判断起点或结果定义缺失，就先做条件与方向的定性分析。表中“未统一记录”表示当前整理未提供统一时间口径；不能擅自补成下一根、当日或二十根。无结果、失效、未到目标和交易亏损分别保留。

## 数值以外的条件与未决项

52B 对合理入场后立即反转的回测，给出1–3根、二十根内和二十根后的不同表述；测试本身还指距入场价1–2 ticks/pips。它们是时间与距离口径，不能填成概率或硬截止期限，完整冲突见 [B08](scenarios.md#b08-回测突破点强收盘或信号区域随后检验能否恢复)。

NYSE TICK 的首次极值、后期重复极值、背离与零轴偏置只有定性预期；±700／±1,000是来源时期的广度水平，不能换成概率。见 [M01](scenarios.md#m01-市场广度支持重复极值与背离)。

固定盈亏对应的毛期望与保本概率在 [G04](scenarios.md#g04-概率回报与算例)：40%/2R与60%/1R、80%赚1亏3、赚4亏32、再赚1或回吐10、赚6亏14各自保留假设。计算出的保本值不计入观察到的胜率。

尚无充分来源的“前九十分钟80%测试支撑阻力”和“unlikely必定低于40%”保留在 [G06](scenarios.md#g06-保留原说法但尚不足以采用的概率)；不填入行情分支。
