# 场景条件详表

本稿是对本地 reference 的条件化整合，不是 Brooks 原有的六分法。六类可以交叉出现；先确定所观察的周期和运动尺度，再判断当前事件。概率、根数、时长、倍数和产品点数不在这里变成通用阈值。

- 场景共用条件
  - <a id="C-1"></a>周期与尺度：区分图表周期、当前局部运动和主要结构；局部反转可以仍是更大趋势的回调。
  - <a id="C-2"></a>重要区域与空间：预先标出旧极值、突破区域、EMA20、比例区域、趋势线、通道边界、日周月开高低收和测量区域；到达附近后重新评价剩余空间。
  - <a id="C-3"></a>推进、保留、恢复：比较运动推进多远、回调交还多少，以及原方向恢复的力度、速度和所达位置；同时观察突破后的跟随。
  - <a id="C-4"></a>判断不清：趋势与区间不清时先保留双向路径；已知是趋势、只是强弱不清时，不据此宣布区间化。短期噪声中可回看最近尚未被推翻的主导突破。
  - <a id="C-5"></a>期限：使用当前市场实际存在的交易时段；开盘、盘中、尾盘和更高周期临近收盘会改变预期实现的时间；相同形态不能直接沿用相同期限。

- 趋势延续
  - <a id="S1-1"></a>强突破：突破后有跟随、进展保留且前方有空间，可研究回调后的第二段；跟随不足或深度回入时降低延续预期。
  - <a id="S1-2"></a>意外突破：原先较不支持的方向突然突破，按新发生的强弱和跟随更新；缺乏跟随时仍可能只是原趋势的旗形，不能因意外就认定成功。
  - <a id="S1-3"></a>第二段的尺度：第二段可以短小、横向或不创新极值；低周期两小段可能仍属外层第一段，强第二段也可能继续引出更多推进。
  - <a id="S1-4"></a>突破转通道：出现有意义的回调后，观察是否转为通道推进；被强势恢复迅速覆盖的微小停顿，不必单独判为阶段转换。
  - <a id="S1-5"></a>紧密通道与小回调趋势：首次反向运动通常先按回调观察；已有清楚的主要反转结构、宽幅顶部或底部，或强反向突破时，重新评价。
  - <a id="S1-6"></a>宽幅通道：保留整体方向倾向，同时承认内部反向波段；根据所在边缘、最近一段强弱和剩余空间分别判断。
  - <a id="S1-7"></a>阶梯推进：分别观察创新高或新低的增量、回调深度和恢复速度；增量缩小只表示推进减弱，不能单独确认反转。
  - <a id="S1-8"></a>区间逐级推进：突破后形成新区间，观察能否主要保持在旧区间之外；允许局部重叠，回入后再看恢复、横盘或反向发展。
  - <a id="S1-9"></a>延续失败后再恢复：第一次延续尝试失败，反向运动也未能推进，随后原方向重新突破并获得跟随，更新延续预期。

- 回调恢复
  - <a id="S2-1"></a>首次回调：强趋势的首次停顿可能很小、信号外观不理想；比较回调前趋势强度和实际反向压力，不因信号弱就否定恢复，也不强求深回调。
  - <a id="S2-2"></a>普通回调：比较此前回调的幅度、时间和恢复情况；浅回调不等于一定恢复，较深回调也不直接等于主要趋势破坏。
  - <a id="S2-3"></a>强回调：回调自身形成强突破或紧密通道时，可能还有反向第二段；首次顺势恢复可能失败。
  - <a id="S2-4"></a>两段或多段回调：观察反向推进是否衰减、原方向能否恢复；第二段、第二次测试和第二次信号分别记录，次数本身不能替代强弱判断。
  - <a id="S2-5"></a>首次回测 EMA20：长期位于 EMA20 一侧、较长时间未触及后，首次回到均线附近，观察原方向恢复；区分接近、触及和穿越。
  - <a id="S2-6"></a>首次收于 EMA20 反侧：与首次触线分开记录，观察能否重新回到原侧并恢复；不能仅凭一次反侧收盘宣布反转。
  - <a id="S2-7"></a>整根 K 线位于 EMA20 反侧：反侧力量增强；原方向仍可能恢复并测试旧极值，但需比较能否到达、突破并保留进展，也可能先转入区间。
  - <a id="S2-8"></a>回测突破区域：回到突破点、原整理边缘或相关信号区域时，观察能否守住并恢复；未精确触及、短暂穿越后收回，需结合实际推进判断。
  - <a id="S2-9"></a>比例区域回调：回到此前运动中部等比例区域时，观察原方向恢复；比例只是位置参照，是否破坏趋势仍取决于相关主要结构。
  - <a id="S2-10"></a>反复回测原突破或强收盘区域：首次返回可属正常回调；恢复后再次返回、恢复越来越弱或不到原极值，增加原方向受损依据。
  - <a id="S2-11"></a>回调扩大或拖延：深度、时长和重叠明显增加时，比较继续恢复、转入区间和形成反向趋势，不沿用最初的小回调预期。
  - <a id="S2-12"></a>最后旗形候选：趋势后段整理接近重要区域，反向压力增强，观察延续是否失败；可先创新极值，也可在没有明显新突破时失败。

- 区域测试
  - <a id="S3-1"></a>到达重要区域：快速推进可能是向目标的加速，重点看到达后的延伸、停顿或拒绝；到达目标不自动结束趋势。
  - <a id="S3-2"></a>边缘拒绝：区间或宽幅通道边缘无法继续向外推进，随后向内发展，先评估向内空间，再根据中部表现评价能否到达对侧。
  - <a id="S3-3"></a>边缘突破：观察界外延伸、进展保留和回测后的恢复；仅有越界或一根强 K 线，不足以确认界外被接受。
  - <a id="S3-4"></a>未确认的边缘反向尝试：价格到达或略过边缘，拒绝尚未形成；这是提前押注边缘有效的阶段，后续须验证向内推进。
  - <a id="S3-5"></a>不到边缘便反向：可能反映提前行动，也可能只是局部停顿；观察后续能否离开该区域，不强求精确触线。
  - <a id="S3-6"></a>第二段陷阱：第二段到达边缘或目标附近，看似强势却无法继续，随后回入并反向发展；保留所处区间或通道背景。
  - <a id="S3-7"></a>突破失败后的回测：失败方向的原突破或强收盘区域可能成为反向阻碍；若重新越过并保持，原失败预期也需更新。
  - <a id="S3-8"></a>目标附近推进失败：接近目标却无法到达，或到达后迅速反向，重新评价继续推进的依据；目标触及、目标完成和订单成交分别记录。
  - <a id="S3-9"></a>已到中部或空间不足：重新评价当前机会；原先位于边缘的条件不能随价格移动而自动保留。

- 区间演化
  - <a id="S4-1"></a>多次突破失败：双向推进反复被收回、缺少跟随时，保留区间预期；区间中的单段强势不能单独证明新趋势。
  - <a id="S4-2"></a>向一侧持续施压：推进更远、回调更浅、受阻后仍能恢复，增强该侧突破依据；仍需验证界外保留。
  - <a id="S4-3"></a>双向强势或双向弱势：大涨后大跌等相互抵消的强推进，和小实体、差跟随的弱重叠，都可支持区间解释；前者波动和反向运动更大，不混为同一种强弱。
  - <a id="S4-4"></a>成熟突破状态：双向测试后方向仍未确定，研究向上或向下突破及其成败；不将普通区间的突破失败倾向直接沿用到此状态，也不由轻微方向倾向推定突破成功。
  - <a id="S4-5"></a>紧密区间：重叠密集、空间有限时，观察突破及跟随；若内部已有持续的单向推进，不能只凭区间外形忽略它。
  - <a id="S4-6"></a>短暂整理与成熟区间：短整理可以保留此前趋势倾向；整理延长、双向交易增强后，原方向优势可能减弱。
  - <a id="S4-7"></a>压缩与扩张：三角形、扩张结构或边界逐步变化，均观察两侧实际推进；外形和第三次、第五次测试不直接决定突破方向。
  - <a id="S4-8"></a>突破失败：先看向内推进能走多远，不直接推定到达对侧；若向内运动也失败，再观察重新向外突破。
  - <a id="S4-9"></a>区间转趋势：越界后持续跟随、回调保留进展，并出现新的顺向推进，再提高趋势预期；强突破可以改变此前区间判断。
  - <a id="S4-10"></a>趋势或通道转区间：原方向恢复受限，反向波段加深，双向重叠增加；仍有倾斜时，可同时保留宽幅通道视角。

- 异常运动与修正
  - <a id="S5-1"></a>异常加速：相对此前运动突然放大，接近目标或通道外侧，出现巨大 K 线或连续强推进，观察后续能否继续保留进展。
  - <a id="S5-2"></a>异常持久：长期单向运行、缺少明显回调，即使 K 线较小也需观察修正；持久本身不构成立即反转信号。
  - <a id="S5-3"></a>趋势末端跟随失败：最后一段强收盘后失望、恢复不到相关强收盘区域，再出现强反向推进，增加原趋势方退出的解释；末端趋势 K 线与后来的反向“放弃 K 线”是不同事件。
  - <a id="S5-4"></a>连续高潮或抛物线推进：多次加速后，观察新增进展、反向压力与后续跟随；三推结构也可能继续突破，不能按次数宣布结束。
  - <a id="S5-5"></a>时间修正：推进停止、重叠增加，但价格回撤有限；原趋势可能在横盘后恢复。
  - <a id="S5-6"></a>价格修正：明显交还进展、反向运动持续，观察高潮起点、相关通道内部等区域的反应；较大修正不必发展成新趋势。
  - <a id="S5-7"></a>修正后的恢复或再次高潮：观察修正是否已发生、原方向恢复是否获得跟随；后来的新高潮是新事件，不把所有停顿拼成固定次数。
  - <a id="S5-8"></a>顺势突破通道线：保持并延伸时研究更强趋势；失败回入时先看通道内部，再根据通道宽紧和修正力度评价更远位置。
  - <a id="S5-9"></a>缺口保持并继续延伸：支持测量解释；失去跟随、交还相关突破进展时，增加衰竭依据。推进耗尽也可能先表现为横盘，不能要求所有缺口先闭合。
  - <a id="S5-10"></a>反向突破趋势线后的修正：原通道强而紧时，可能主要横向修正；原通道较弱时，更需观察通道起点的测试。通道起点、通道对侧和最初急速段起点分开。
  - <a id="S5-11"></a>高潮后的反向运动：先区分局部修正、转入区间和主要反转；原方向可能仍有最后一段，也可能在充分反向证据下直接转向。

- 趋势受损与反转
  - <a id="S6-1"></a>受损层级：先分清趋势线被突破、局部运动受损和主要结构破坏；一条线被穿越不等于整个趋势反转。
  - <a id="S6-2"></a>典型反转过程：反向推进 → 原方向恢复或测试旧极值 → 恢复失败 → 再次反向推进；这是常见路径，不是必须出现的固定步骤。
  - <a id="S6-3"></a>首次反向推进强：可在随后测试旧极值附近研究早期反转；仍需区分候选与已经形成的反向趋势。
  - <a id="S6-4"></a>首次反向推进弱：等待更强反向推进或后续原方向恢复失败；紧密趋势中的弱反向信号尤其不能单独确认反转。
  - <a id="S6-5"></a>测试旧极值：允许不到、持平或越过旧极值；比较测试力度、反向跟随和进展保留，不能仅用新高或新低判定成功失败。
  - <a id="S6-6"></a>双重测试、楔形与头肩结构：作为恢复失败的具体组织形式；相关中间摆动极值或颈线的突破可增加证据，名称本身不能确认反转。
  - <a id="S6-7"></a>强反向突破：反向推进和跟随足够强时，及时更新方向判断，不必等待标准形态全部出现；V 形变化也不能被分类排除。
  - <a id="S6-8"></a>成熟通道的小突破失败：通道后段、突破规模小且缺少跟随时，失败可增加反向发展依据；不能把这一条件用于所有小突破。
  - <a id="S6-9"></a>楔形向原趋势方向突破：按突破后的新事实比较加速延续与失败反向，不再沿用突破前的反转倾向；突破失败也可构成再次顶部或底部测试。
  - <a id="S6-10"></a>原方向重新强势推进：反转尝试失败后，更新或放弃反转预期；若只是再次转为重叠，保留区间分支。
  - <a id="S6-11"></a>反向波段形成：继续区分局部反转、区间的一段和新趋势；反向通道可以在旧趋势最终极值之前开始形成。

- 时段条件（叠加于上述场景）
  - <a id="T-1"></a>开盘强推进：仍需验证跟随和重要区域反应；不能直接套用盘中成熟趋势的延续预期。
  - <a id="T-2"></a>开盘反转与跳空：结合昨日高低、收盘区域、开盘价和 EMA20，观察延续或拒绝；跳空方向不决定当天方向。
  - <a id="T-3"></a>高周期背景：高周期处于区间时，早期强推进更需留意回归；高周期处于趋势时，早期逆向测试可能失败并恢复原方向，当天强证据仍可改变这一倾向。
  - <a id="T-4"></a>初始运动幅度：初始运动已经很大时，失败后更可能形成宽区间；较小初始运动失败后，可形成更大的反向波段。巨大反向趋势的例外仍保留，幅度不能机械分档。
  - <a id="T-5"></a>昨日高潮：今天可能先延续再修正，也可能较早修正；若整理昨日已经开始，应从实际开始处判断，不能每日重置。
  - <a id="T-6"></a>开盘区间：区分早期双向突破状态和用于观察突破的开盘范围；第一段或第二次信号均可能失败。
  - <a id="T-7"></a>盘中转换：早期趋势开始深回调或长期整理后，重新判断通道、区间和新突破，不沿用开盘标签。
  - <a id="T-8"></a>尾盘新通道：较晚才形成的通道可能只是区间的一段，随后再次反向；与较早启动并持续至尾盘的小回调趋势分开。
  - <a id="T-9"></a>尾盘目标与回归：强推进可能测试开盘价、日内极值或其他收盘相关水平；到达后可能停顿或回归，且剩余时间可能不足以完成原目标。

## 术语边界

- 推进、保留、恢复是共用判断；同一事实的多个形态名称不重复计证据。回调可以仅是暂停，并可在最终极值形成前开始。
- H1/H2、L1/L2、双顶底、楔形、三角形、头肩和圆弧可出现在不同场景；必须按位置、前序运动、尺度和跟随确定其功能。
- 缺口要声明比较对象；微缺口、开收盘缺口、突破回调缺口和均线缺口不混用。闭合只更新原有分离证据，不独立确认反转。

- EMA20 是 20 周期指数均线；“20-gap-bar”中的 20 描述一段未触均线的 K 线序列，不是第 20 根自动触发。此稿使用“长期未触及”作主描述，具体来源数量留在来源记录。
- 跟随：突破后继续支持该方向的价格行为。恢复：回调后原方向重新推进，并不保证到达旧极值。
- 回入：回到边界内的事实。拒绝：向外尝试受阻并出现向内发展。接受：界外推进、保留与回测表现共同支持的判断，没有统一根数阈值。
- 第二段、第二次测试、第二次信号、第二次入场不是同一计数。信号未触发与触发后失败也要分开。
- 最后旗形、测量缺口、衰竭缺口在实时观察中可能只是候选；不同来源的追认口径保留在冲突记录。
- 多空通常可镜像理解，但不据此改写来源案例的信号颜色、次数、订单或成交事实。
