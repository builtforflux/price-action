# 场景

六类场景可同时适用，共用判断和时段条件一并考虑。

- 共用判断
  - <a id="C-1"></a><a id="C-2"></a><a id="C-5"></a>背景：确定周期、尺度、重要区域、剩余空间与时间。
  - <a id="C-3"></a>强弱：比较推进幅度、进展保留和回调后的恢复，结合后续跟随判断。
  - <a id="C-4"></a>不清：区分方向不清与趋势强弱不清；回看尚未被推翻的主导突破，保留竞争路径。

- 趋势延续
  - <a id="S1-1"></a><a id="S1-2"></a>突破推进：有跟随、能保留进展，支持继续；意外突破也按新表现更新，缺少跟随则保留失败分支。
  - <a id="S1-3"></a>第二段：可短小、横向或不创新极值；按同一尺度分段，强第二段仍可继续延伸。
  - <a id="S1-4"></a><a id="S1-5"></a><a id="S2-1"></a>紧密推进：首次回调可能很小，先看顺势恢复；有意义的回调可使突破转为通道，明显反向证据则重新判断。
  - <a id="S1-6"></a>宽幅通道：保留整体倾向，同时观察内部反向波段。
  - <a id="S1-7"></a><a id="S1-8"></a>逐级推进：阶梯看新增进展、回调与恢复；新区间看能否保持外移，允许局部重叠。
  - <a id="S1-9"></a>失败后恢复：延续尝试失败，但反向也走不远，原方向重新突破并获得跟随。

- 回调恢复
  - <a id="S2-2"></a><a id="S2-4"></a>普通回调：比较此前回调的深度、时间和恢复；多段回调看反向推进是否衰减。
  - <a id="S2-3"></a>强回调：回调自身可能还有第二段，首次顺势恢复可能失败。
  - <a id="S2-5"></a>首次回测 EMA20：长期未触及后首次回到均线附近，观察原方向恢复。
  - <a id="S2-6"></a>首次收于 EMA20 反侧：观察能否返回原侧并恢复，与首次触线分开判断。
  - <a id="S2-7"></a>整根 K 线位于 EMA20 反侧：反方增强；原方向仍可能测试旧极值，再看延续或区间化。
  - <a id="S2-8"></a><a id="S2-9"></a>回测关键区域：突破点、原整理边缘或比例区域附近，观察能否守住并恢复。
  - <a id="S2-10"></a><a id="S2-11"></a>回调恶化：回调加深、拖长，或反复返回且恢复减弱，增加区间化或反向发展的依据。
  - <a id="S2-12"></a>最后旗形候选：趋势后段整理、反向压力增强，观察延续是否失败；不要求先创新极值。

- 区域测试
  - <a id="S3-1"></a><a id="S3-8"></a><a id="S3-9"></a>接近目标：到达、未达便反向或到达后停顿，都需重估方向与剩余空间。
  - <a id="S3-4"></a><a id="S3-5"></a>拒绝未确认：到达、略过或尚未触及边缘便反向，观察能否真正向内推进。
  - <a id="S3-2"></a>边缘拒绝：向内发展后先看中部，再依实际表现评价对侧。
  - <a id="S3-3"></a>边缘突破：看界外延伸、进展保留与回测能否守住。
  - <a id="S3-6"></a>第二段陷阱：第二段到达边缘或目标后无法延续，随后回入并反向发展。
  - <a id="S3-7"></a>失败后的回测：原突破或强收盘区域可能转为反向阻碍；重新越过并保持则更新判断。

- 区间演化
  - <a id="S4-1"></a><a id="S4-3"></a>双向震荡：推进反复被收回，保留区间预期；区分大幅双向运动与弱势重叠。
  - <a id="S4-2"></a>单侧施压：推进更远、回调更浅、受阻后仍能恢复，突破依据增强。
  - <a id="S4-5"></a><a id="S4-7"></a>压缩或扩张：观察两侧边界与内部推进；紧密区间尤其受空间限制，形状不直接决定方向。
  - <a id="S4-4"></a><a id="S4-6"></a>整理成熟：短整理仍可保留原趋势倾向；双向测试充分后，重新比较突破方向及成败。
  - <a id="S4-8"></a>突破失败：先看向内空间；向内也失败，再看重新突破。
  - <a id="S4-9"></a><a id="S4-10"></a>状态转换：界外推进得到保留，支持转为趋势；恢复受限、反向加深、重叠增加，支持转为区间。

- 异常运动与修正
  - <a id="S5-1"></a><a id="S5-2"></a><a id="S5-4"></a>异常推进：突然加速、连续高潮或长期缺少回调，观察延续能力与修正压力。
  - <a id="S5-3"></a>末端失望：强收盘后缺少跟随，恢复不到相关区域，再出现强反向推进。
  - <a id="S5-5"></a><a id="S5-6"></a>修正方式：横盘且回撤有限，偏时间修正；明显交还进展，偏价格修正。
  - <a id="S5-8"></a>顺势突破通道线：保持并延伸则研究更强趋势；失败回入则先看通道内部。
  - <a id="S5-10"></a>反向突破趋势线：强紧通道可能主要横向修正；较弱通道更需观察通道起点。
  - <a id="S5-9"></a>缺口演化：保持并延伸支持测量解释；跟随消失、进展交还增加衰竭依据，耗尽也可先表现为横盘。
  - <a id="S5-7"></a><a id="S5-11"></a>修正后发展：比较原方向恢复、转入区间与反向发展；后来的新突破或新高潮重新判断。

- 趋势受损与反转
  - <a id="S6-1"></a>受损层级：区分趋势线突破、局部运动受损与主要结构破坏。
  - <a id="S6-2"></a><a id="S6-5"></a><a id="S6-6"></a>恢复失败：反向推进后测试旧极值，原方向恢复失败，再次反向推进；测试可不到、持平或越过。
  - <a id="S6-3"></a><a id="S6-4"></a><a id="S6-7"></a>反向强弱：首次反向强，可研究随后测试中的早期反转；反向弱，等待更多证据；强突破可直接改变方向判断。
  - <a id="S6-8"></a>末段突破失败：成熟通道中小突破缺少跟随，失败后更需留意反向发展。
  - <a id="S6-9"></a><a id="S6-10"></a>反转失败：原方向重新突破，按延续或再次失败更新；楔形也不例外。
  - <a id="S6-11"></a>反向波段形成：继续区分局部反转、区间的一段和新趋势；新通道可在旧极值前开始。

- 时段修正
  - <a id="T-1"></a><a id="T-2"></a><a id="T-6"></a>开盘：结合跳空、昨日区域与开盘范围，观察最初推进的延续或反转；强第一段与第二次信号均可能失败。
  - <a id="T-3"></a><a id="T-4"></a>开盘背景：高周期趋势与区间分别影响恢复或回归倾向；初始运动很大时，反向发展更容易形成宽区间。
  - <a id="T-5"></a>昨日高潮：可能先延续再修正，也可能较早修正；已经开始的整理不重新计时。
  - <a id="T-7"></a>盘中：深回调或长期整理出现后，重新判断状态。
  - <a id="T-8"></a><a id="T-9"></a>尾盘：区分持续至今的趋势与刚形成的区间段；接近磁铁或剩余时间不足时，重估延伸与回归。

形态用于描述结构，按所在场景解释；次数不代替强弱。第二段、第二次测试与第二次信号分别计数。
