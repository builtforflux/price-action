# 来源覆盖对照

结论：以上一版为基准，确有条件遗漏或过度压缩；本轮补齐后，按已复核 reference 产物中的市场场景及其条件化变体检查，均能在六类场景、共用条件和时段条件中找到对应，未发现尚未覆盖的独立市场场景。此结论限定于当前 reference 产物的场景内容，不表示穷尽所有未来市场走势，也不把交易管理和全部数值例子改写成场景。

正文随后进一步合并为 39 条场景、3 条共用判断和 5 条时段修正；原 76 个条件锚点全部保留，细节见[条件详表](scenario_details.md)。以下数量记录来源条件，不代表当前正文条数。

## 来源冲突和暂不定案

- 缺口关闭与方向推进耗尽不是同一时点；缺口类别不能用一条统一的闭合规则替换来源语境。
- 20-gap-bar 的经验序列与 EMA20 的参数分开；不设第 20 根自动事件。
- 25B 的失败双重测试／颈线表述、48D 同图不同阶段的突破状态命名、50E 复制残留等，不补造原文未能确认的事件次序。
- 无样本概率、TBTL 时长、ADR 比例、三分之一或三分之二区域、根数和 tick/pip 目标，均留在原语境；不是可跨市场直接执行的规则。
- 原始图文、翻译、分母或算术冲突统一回溯[来源边界与冲突](../../reference/course/boundaries_and_conflicts.md)和[来源台账](../../reference/official_sources.md)。本稿没有替这些冲突作最终裁决。

本轮参考本地[术语表](../../reference/glossary.md)和[来源台账](../../reference/official_sources.md)已登记的锚点；未把已登记链接等同于已重读整篇来源。传统 island、gap reversal 等保留其定义，并按突破、区域测试或反转解释，不因形态名字另增必然路径；gap reversal 不要求填完实际缺口。书籍 Ch19／Ch26 的原版精确页码与措辞仍待复核，不列为完整原书覆盖。

## 本轮补齐的条件

- 意外突破后重新判断，以及没有跟随时仍属原趋势旗形。
- 第二段可短小、横向或不创新极值，强第二段后还能继续。
- 强趋势首次回调外观不理想，仍须按背景判断。
- 比例区域回调与主要结构失效分开。
- 目标附近未达、到达后反向与真实成交分开。
- 双向强势与双向弱势，以及成熟突破状态的独立条件。
- 趋势末端跟随失败、恢复不到强收盘区及随后强反向推进。
- 反向破趋势线后的强弱通道修正，以及通道起点与对侧区别。
- 成熟通道小突破失败、楔形向原趋势方向突破后的条件更新。
- 高周期背景、初始运动幅度，以及较晚才出现的新通道。
- 当前判断不清时分层处理，不把趋势强弱不清统一当作区间。

## 覆盖结论的使用

“覆盖”指 reference 已整理出的市场情境、正常路径与改变路径的条件，在完整场景稿中有语义对应；不要求每个形态名各占一条。条件需要连同共用条件和时段条件一起阅读。数值经验、精确几何、订单／仓位、产品与心理内容仍由 reference 保留，不算遗漏的市场场景。
