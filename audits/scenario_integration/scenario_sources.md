## 来源侧交叉检查

逐讲思想组见[来源索引](inventory.md)。以下按 reference 自身的概念族反向检查，防止只从整合稿找支持。

| reference 场景族 | 完整稿落点 |
| --- | --- |
| Breakout、Spike、Surprise、跟随及失败的失败 | 趋势延续；区间演化 |
| First Pullback、微通道、小回调、紧／宽通道、阶梯、新区间 | 趋势延续；回调恢复 |
| EMA 首次测试、反侧收盘、MAG、突破回测、比例区域、重复恢复 | 回调恢复 |
| 边缘拒绝、接受、不到、越过、真空、第二段陷阱、目标附近失败 | 区域测试 |
| 普通／紧密区间、BOM、双向强弱、压力累积、压缩／扩张、区间化 | 区间演化 |
| Climax、Parabolic Wedge、Final Trend Bar、Give-up、时间／价格修正、通道突破、缺口成败 | 异常运动与修正；趋势受损与反转 |
| Minor／Major、旧极值测试、双顶底、楔形、Final Flag、H&S、圆弧、V 形、失败重置 | 回调恢复；趋势受损与反转 |
| Opening Trend／Range／Reversal／Gap、昨日高潮、日中转换、尾盘磁铁及期限 | 时段条件 |

信号、计数、位置构造、交易管理、产品与辅助信息的边界见[覆盖对照](coverage.md)。上述检查未发现需要另增第七个市场场景大类、或仍无落点的独立市场场景。
