# 价格行为交易方法

## 唯一入口

[从交易系统开始](trading_system/README.md)。在不确定的市场中，识别并参与一段值得持有、能够承担的运动。知识从可见事实、比较关系和条件预期进入选择；参与前匹配价格、保护与允许的过程，后续按实质变化调整，用连续结果检验成本后的经济价值。实际参与须具备有依据的条件路径和完整交易方案。

使用系统直接依据运行正文；必要的判断依据与行动规则必须在负责页完整表达。背景、位置或当前尝试的预期不清楚时，按问题查阅场景导航；场景名称不决定交易许可。

## 权威边界

Trading System 定义从市场事实、条件路径、交易方案、账户执行到复盘的运行规则。[Reference](reference/README.md)只保存来源、原始锚点、重复、冲突、核验状态和研究候选；它不直接决定交易。

| 准备使用的内容 | 使用条件 |
| --- | --- |
| 经验概率或统计规则 | 经治理流程验证、发布且仍适用，才可用于生产判断 |
| 价格、数量、成本计算或事前风险限制 | 按各自计算与限制规则使用 |
| 教学比例、形态重合或单笔结果 | 不得换算为当前胜率或盈利能力 |

当前仓库没有生产级校准概率；详细边界见[复盘与治理](trading_system/governance.md)。

## 核心边界

- Market 持续判断位置、预期、实际进展和相关路径；远端目标依据不足时，可以先保留过程判断与下一观察。Trade 仍须依据条件路径构造完整交易方案并决定仓位怎样处理；Account 检查并执行订单授权，以平台记录核对实际仓位。
- 同一事实共享记录；不同关系增加的位置、次序、进展和跟随信息共同进入判断。重复命名本身不增加证据或预算；场景帮助判断，连续用例检验事实怎样改变动作及执行交接。
- 条件路径支持事前方案比较；参与和持仓管理明确正常不利表现、改变动作的事实及当前价格交换。加仓先比较新增风险的补偿，再检查整笔与账户限制。
- 只有实际成交改变仓位。实际仓位归零且所有相关订单不再可能成交后，本笔交易才结束；市场、交易、账户和执行结果分别复盘。

训练默认在 TradingView 随机选择历史起点，逐步向前模拟完整交易；从过程中识别机会，结束后再复习具体片段。日常练习的记录按反馈需要安排，正式检验按事前确定的范围保留证据；实际授权与平台记录仍完整核对。执行熟练度与方法的经济表现分别检验，增加数量需要成本后表现的支持，具体见[训练与实盘运行](practice/README.md)。

课程知识与当前方法的对应关系见[课程知识与方法关系](reference/course/course_to_method_map.md)；数字、数学和来源限制见[边界与冲突](reference/course/boundaries_and_conflicts.md)。
