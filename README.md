# Al Brooks 价格行为交易方法

## 唯一入口

[从交易系统开始](trading_system/README.md)。该页先用六个问题说明完整闭环，再按 Market、Trade、Account 和复盘的职责链接到详细规则。

使用 `trading_system/` 不需要先阅读 `reference/`，也不需要先选择场景。只有已经看清背景、位置和当前尝试，却仍不会组织双向路径时，才从交易系统按需进入场景导航。

## 权威边界

Trading System 定义从市场事实、双向路径、交易方案、账户执行到复盘的运行规则。[Reference](reference/README.md)只保存来源、原始锚点、重复、冲突、核验状态和研究候选；它不直接决定交易。

数值知识必须先经治理流程发布且仍然适用，运行时才能使用。当前仓库没有生产级校准概率；不得把教学比例、形态重合或单笔结果写成当前胜率或盈利能力。详细边界见[复盘与治理](trading_system/governance.md)。

## 核心边界

- Market 判断位置、预期、实际进展和双向路径；Trade 构造交易方案并决定仓位怎样处理；Account 检查并执行订单授权，以平台记录核对实际仓位。
- 名称共享底层事实，不增加证据、概率、仓位或最大计划损失；场景只提供候选知识，examples 只验收环节交接。
- 路径完整后仍须检查入场、止损、出场、期限、成本和数量；完整方案较有利且账户检查通过时，才可建仓或加仓。
- 只有实际成交改变仓位。实际仓位归零且所有相关订单不再可能成交后，本笔交易才结束；市场、交易、账户和执行结果分别复盘。

课程知识与当前方法的对应关系见[课程知识与方法关系](reference/course/course_to_method_map.md)；数字、数学和来源限制见[边界与冲突](reference/course/boundaries_and_conflicts.md)。
