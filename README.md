# 价格行为交易方法

## 唯一入口

[从交易系统开始](trading_system/README.md)。这套方法以多空博弈理解市场，围绕当前机会、动作选择、管理变化和连续过程复盘组织交易。入口页给出盘中决策主线，各页补充所需的判断、计算和执行规则。

使用 `trading_system/` 不需要先阅读 `reference/`。背景、位置或当前尝试的预期不清楚时，按问题查阅场景导航；场景名称不决定交易许可。

## 权威边界

Trading System 定义从市场事实、条件路径、交易方案、账户执行到复盘的运行规则。[Reference](reference/README.md)只保存来源、原始锚点、重复、冲突、核验状态和研究候选；它不直接决定交易。

经验概率和统计规则经治理流程验证、发布且仍然适用后，才可用于生产判断。价格、数量、成本计算和事前风险限制按各自规则使用。当前仓库没有生产级校准概率；不得把教学比例、形态重合或单笔结果写成当前胜率或盈利能力。详细边界见[复盘与治理](trading_system/governance.md)。

## 核心边界

- Market 持续判断位置、预期、实际进展和相关路径；Trade 构造交易方案并决定仓位怎样处理；Account 检查并执行订单授权，以平台记录核对实际仓位。
- 同一事实共享记录；不同关系增加的位置、次序、进展和跟随信息共同进入判断。重复命名本身不增加证据或预算；场景帮助判断，连续用例检验事实怎样改变动作及执行交接。
- 条件路径支持事前方案比较；参与和持仓管理明确正常不利表现、改变动作的事实及当前价格交换。加仓先比较新增风险的补偿，再检查整笔与账户限制。
- 只有实际成交改变仓位。实际仓位归零且所有相关订单不再可能成交后，本笔交易才结束；市场、交易、账户和执行结果分别复盘。

Less is more 以必要判断能否稳定执行衡量。执行熟练度与方法的经济表现分别检验，增加数量需要成本后表现的支持，具体见[训练与实盘运行](practice/README.md)。
