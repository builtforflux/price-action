# Al Brooks 价格行为交易方法

## 唯一入口

[从交易系统开始](trading_system/README.md)。该页先给出一张盘中最小运行卡，再按 Market、Trade、Account 和复盘的职责链接到详细规则。

使用 `trading_system/` 不需要先阅读 `reference/`，也不需要先选择场景。只有已经看清背景、位置和当前尝试，却仍不会组织双向路径时，才从交易系统按需进入场景导航。

## 权威边界

Trading System 拥有从市场事实、双向路径、交易表达、账户执行到复盘的运行语义。[Reference](reference/README.md)只保存来源、原始锚点、重复、冲突、核验状态和研究候选；它不直接决定交易。

数值知识必须先经治理流程发布且仍然适用，运行时才能使用。当前仓库没有生产级校准概率；不得把教学比例、形态重合或单笔结果写成当前胜率或盈利能力。详细边界见[复盘与治理](trading_system/governance.md)。

## 必须守住的边界

- Market 只组织市场事实、判断和双向路径；Trade 只构造具体交易；Account 只核对账户限制、执行动作和平台权威事实。
- 路径完整不等于值得交易；只有具体表达较有利且账户检查通过，才可提交新增风险。
- Pattern、H/L、Wedge、Double Test、Flag、Triangle、MTR 等重合名称共享事实，不重复增加证据、概率或风险预算。
- 场景只是按需导航，不拥有第二套状态、路径或逐 K 流程；examples 只验证负责页面中的规则。
- 图表触价、订单触发、实际成交和仓位变化不能互换；只有成交改变仓位。
- 风险关闭条件：实际仓位为零，且所有本交易相关订单均已确认完成、取消或不再可能成交。状态未知、待撤单确认或存在未处理迟到成交时，不得关闭风险或开始同品种新交易。市场、交易、账户和执行结果分别复盘。
