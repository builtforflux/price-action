# Opening Reversal（开盘反转）

> **状态：Strategy / Application（覆盖层页，不建立新家族）**

## 覆盖内容

session 早段的初始方向在已知支撑、阻力或旧价格区域附近失去接受，随后形成反向路径。它可能与 double top/bottom、wedge 或 failed breakout 重叠，但名称本身不构成交易许可。

## 叠加规则

- 反向路径的 premise 必须来自现有家族：早段区间边缘的失败按 [区间 fade](../range/README.md)；旧极值测试失败并出现反方控制按 [反转情景](../reversal/README.md)（MTR 或逆势修正 scalp）；
- 相同结构若到较晚阶段才出现，只称普通 reversal 或 MTR，不能继续借用 Opening Reversal 的早段语境；
- "多早"必须随品种、session 和 bar interval 校准，本层不设硬分钟数；
- Opening gap 只说明开盘重新定价，不预设当天方向；gap 与 gap reversal 的边界见 [缺口](../../core/04_patterns/07_gaps.md)。

## 失效

- 初始方向重新获得接受并延续；
- 早段候选没有形成反向接受。
