# BTC/STC 决策协议：构造分支走查与覆盖表

> **状态：Strategy / Playback（构造分支走查，非价格回放）**
>
> 对 [BTC/STC 决策协议](buy_sell_the_close.md) 的分支逐例走查。**方法限制**：本记录是「构造案例/分支单元测试」——案例预置了「方程成立」「障碍实质」等关键判断，且引用的课程页标注「视觉核验未建立逐页验收」，因此结果具有构造性，**不能作为价格回放验收**。「试点验收通过」必须另加真实图表、逐根时序、当时可见信息与独立裁决记录。本记录在价格回放验收通过后、批量补齐 21 页协议前可归档/删除。

**来源性质约定**：`[课程实例]` = 课程原文直接描述该场景；`[人工边界测试]` = 规则来自协议操作化或 core 定义，课程页为相邻但不同的场景，仅作行为参照，不承担动作授权。

## 案例走查

### 1. 正例：早期版（[人工边界测试]；41A p263、49A p1072 提供相邻价格行为语境——原文描述连续强 K 与跟进，不直接描述「首根收盘、无独立 follow-through」）

**构造**：强多头突破，首根大阳线收在旧边界外，实体明显大于近期、收盘近高点、少重叠；**最近 magnet 为前高（明确最近）**；无清楚的第二腿/量度结构（仅粗略目标方向，swing 方程无法评估）；尚无独立 follow-through。

**走查**：Must-have 五条全满足；严格口径五条全满足；版本选择 → 早期版；stop = 完整 breakout leg 外；管理版本：无可行 swing 计划（swing 方程无法评估）+ scalp 方程成立 → Scalp；target = 最近 magnet（前高）。

**结果**：早期版 + 完整 leg stop + Scalp + 前高 —— 唯一 ✓（若构造未提供距离顺序与各自方程，则按协议应输出「管理版本无法唯一选择 → WATCH/NO_TRADE」，本案例已补充构造使之可裁决）

### 2. 正例：确认版（[课程实例] 41A p263–265、41D p333）

**构造**：连续大多头实体、收近高点、空头旗形向上突破、强跟进；清楚量度结构、近端无实质障碍。

**走查**：版本选择 → 确认版；stop 按确认时重算完整 breakout leg；管理版本：可行 Swing → Swing；target = 量度结构目标。

**结果**：确认版 + 重算 leg stop + Swing + 结构目标 —— 唯一 ✓

### 3. 近似反例：大 K 但质量不足（[课程实例] 42A p351、41C p314）

**构造**：突破 K 实体大但影线长、高度重叠、收盘未稳定留在边界外（多头镜像）。

**走查**：严格口径第 3/4 条无法明确确认 → WATCH。

**结果**：WATCH ✓

### 4. 管理例：正常回调进入 channel（[课程实例] 49A p1072；[人工边界测试] core 01_trends）

**构造**：突破后约 90% 概率先回调形成通道；首回调未破坏突破 leg。

**走查**：转入 channel → 停止机械 BTC、不自动退出；新入场转趋势/pullback；已有仓位按原锁定计划管理。

**结果**：不退出 ✓

### 5. 失效例：旧区域重新接受（[人工边界测试]；40E p243 支持强空头突破确认，不直接描述「重新接受旧区域并获跟进」，该动作链来自协议第 1 条）

**构造**：真正强空头突破后价格回到旧区域并获反向跟进。

**走查**：Premise invalidation 第 1 条 → 全部主动退出；stop 归零前继续有效。

**结果**：全部退出 ✓

### 6. 过期例：尚未入场（[人工边界测试]；41A p265 提供相邻回调语境）

**构造（区分两种时点）**：

- **6a. 仅错过早期收盘时点**：首根强 bar 收盘时未入场，随后出现连续强收盘——早期版过期，但**确认版仍可能成立**（重新评估确认版，不直接转 breakout-pullback）；
- **6b. 已经出现可识别回踩**：无须触及突破点——core 中 pullback 可以是反色 K、doji、inside bar、停顿或较小周期回调；若已形成回踩后的新触发语境，离开 BTC/STC 卡并转 breakout-pullback 重新评估。

**走查**：Entry expiry 按 6a/6b 分别裁决。

**结果**：6a → 确认版仍可评估；6b → 本卡不可用，转 breakout-pullback ✓

### 7. 管理例：Scalp（[人工边界测试] 41B p288 为相邻场景）

**构造**：近端 magnet（前高）可形成合理方程；无清楚 swing 结构（无法评估 swing 计划）。

**走查**：无可行 swing + scalp 可行 → Scalp；target = 最近 magnet。

**结果**：Scalp + 最近 magnet ✓

### 8. 管理例：Swing（[课程实例] 41D p333–337）

**构造**：强空头突破后（空头侧），量度目标清楚、路径无实质近端障碍。

**走查**：可行 Swing → Swing；target = 量度结构目标；stop = 空头腿顶部。

**结果**：Swing + 结构目标 ✓

### 9. 管理例：预写分仓（[人工边界测试] 41A p261 为多空对称构造；41B p289 是成交后 Low 2 加仓，非入场前拆分，仅作行为参照）

**构造**：近端 magnet（前高）构成实质障碍并显著降低远端到达概率但未使 swing 方程转负；两套方程均成立；数量/target/管理入场前拆分。

**走查**：两子计划可行 + 实质障碍未否定 swing → 预写分仓；runner 继续依赖同一 BTC premise。

**结果**：预写分仓 ✓

### 10. 管理例：swing 方程被否定（[人工边界测试] 47B p819 障碍语境；41C p316 为结果路径描述）

**构造**：清楚第二腿结构存在，但近端障碍使 swing 方程不成立；到近端 magnet 的 scalp 方程成立。

**走查**：按「有没有可行 swing 计划」→ 无可行 swing → Scalp；41C 的降级按「原计划结束 + 新计划」处理（管理版本不临场切换）。

**结果**：Scalp ✓（并确认管理降级边界）

### 11. 削弱例：momentum 削弱（[人工边界测试] 削弱组合为协议操作化；41C p316 为相邻加仓/降级场景）

**构造**：顺势 K 线持续缩小 + 关键顺势收盘失去跟进 + 反方 K 线增加但无强反向突破；旧区域尚未重新接受。

**走查**：完整削弱组合三条件同时成立 → 允许预写分支减仓；不触发全部退出。

**结果**：预写分支减仓 ✓

### 12. 正常波动例：无跟进反向 signal（[人工边界测试]；40C p211 支持跟进差、上影卖盘及后续 HL 语境，但不等于明确发生「普通反向 signal 已触发且无跟进」）

**构造**：跟进不佳时上影表示卖盘，但无强反向突破与跟进；单根普通反向 signal 无跟进。

**走查**：不单独构成 premise 失效；削弱组合不完整 → 正常波动，不退出。

**结果**：不退出 ✓

### 13. 失效例：全部退出（[课程实例] 40E p243）

**构造**：强反向突破 + 跟进（第 2b 条）。

**走查**：Premise invalidation 第 2b 条 → 全部退出而非只减仓。

**结果**：全部退出 ✓

### 14. 失效例：异常强单根反向 K（[人工边界测试] 规则直接来自 core [三层退出保护](../../core/06_trade_plan_and_management/00_trade_plan.md) 与课程 52A；40C p208 为相邻 give-up 语境）

**构造**：一根异常强反向趋势 K 线本身否定原接受结构（实体异常大、收盘反侧、吞没突破 leg），无后续跟进。

**走查**：Premise invalidation 第 2a 条（不要求后续跟进）→ 全部退出。

**结果**：全部退出 ✓

### 15–17. Must-have 失败例（[人工边界测试]）

15. **stop 不可定义**（突破 leg 无清晰边界）→ 本卡不可用；
16. **target 不现实**（前方障碍封死 / 无 magnet）→ 本卡不可用；
17. **方程不可评估**（概率/成本无法赋值）→ 本卡不可用。

结果：均为「本卡不可用 → WATCH/NO_TRADE」✓

### 18. Candidate rejection：目标空间封死（[人工边界测试] 47B p819）

**构造**：价格已接近前高且前方整数位/前高密集障碍，现实 target 与 stop 之间无方程空间。

**走查**：Candidate rejection → 本卡不可用。

**结果**：本卡不可用 ✓

### 19. 失效例：Always In 翻转否定 premise（第 3 条，[人工边界测试] core 00_trade_plan）

**构造**：同一管理周期 Always In 明确翻转（如连续反向强 K 使 Always In 从 Long 翻 Short），且该翻转否定原突破延续 premise。

**走查**：Premise invalidation 第 3 条 → 全部退出。

**结果**：全部退出 ✓

### 20. 削弱替代条件（[人工边界测试]，验证三个 OR 子条件各自成立）

20a. 仅「顺势 K 线持续缩小」+ 其余两条件 → 削弱组合成立；
20b. 仅「关键顺势收盘失去跟进」+ 其余两条件 → 成立；
20c. 仅「影线与重叠增加」+ 其余两条件 → 成立。

结果：三者任一均触发削弱组合 → 允许预写分支减仓 ✓

### 21. 空头镜像包（最小，覆盖最易产生方向性措辞的分支；[课程实例] 21a 基于 41D p333–337，其余为人工边界测试）

**21a. 确认版 + 第 1 类失效**：强空头突破、连续强空头收盘、跟进（stop = 重算完整空头 leg 外）——前半段为 [课程实例]（41D p333–337）；随后价格明确回到旧区域上方并获反向跟进 → 第 1 条镜像 → 全部退出——后半段为 [人工边界测试]（课程页未直接描述该动作链）✓

**21b. 早期版镜像**：首根足够强空头 bar 收盘、无独立 follow-through，严格口径五条（空头侧措辞）全满足 → 早期版 + 完整空头 leg stop + 管理版本选择 ✓

**21c. 异常强单根反向 K 镜像**：空头持仓中一根异常强多头趋势 K 本身否定接受结构（第 2a 条镜像）→ 全部退出 ✓

**21d. 正常回调进入 channel 镜像**：空头侧突破后正常反弹进入 channel → 不退出，按原计划管理；新入场转趋势/pullback ✓

**结果**：空头确认版/早期版/第 2a 失效/channel 管理镜像样本通过——不声称全部构造样本均已逐一做空头镜像

### 22. 无可行管理版本（[人工边界测试]）

**构造**：Scalp 与 Swing 方程均不可行（近端 magnet 太近无空间、远端结构被障碍封死）。

**走查**：管理版本选择「其余」分支 → WATCH/NO_TRADE。

**结果**：WATCH/NO_TRADE ✓

### 23. Candidate rejection：快速回到旧区域（[人工边界测试]）

**构造（入场前）**：突破后尚未入场，价格已快速回到旧区域。

**走查**：Candidate rejection 分支 ① ——拒绝候选，**不触发任何持仓退出**（尚无持仓）。

**结果**：本卡不可用 ✓

### 24. Candidate rejection：强反向收盘并获跟进（[人工边界测试]）

**构造（入场前）**：突破后尚未入场，出现强反向收盘并获得跟进。

**走查**：Candidate rejection 分支 ② ——拒绝候选，不触发持仓退出。

**结果**：本卡不可用 ✓

### 25. 跨 premise 禁借反例（[人工边界测试]）

**构造**：交易者试图在 BTC 早期版计划中借用 breakout-pullback 的回踩 swing stop，或引用 MTR 的约 40% 概率。

**走查**：协议第 7 块拒绝——BTC 仓位必须用本卡自己的完整 leg stop 与方程；借用参数需先结束本计划、建立新 premise 计划。

**结果**：借参被拒绝 ✓

## 结论（降级）

- **30 个独立分支样本（23 组）构造走查通过**：协议各块在预置判断下产生唯一且可观察的结果；覆盖表显示**主要正向终端与已列 OR 分支**已有构造案例（含 Candidate rejection 三分支、Entry expiry 两时点、空头最小镜像包、跨 premise 禁借反例）；
- **尚不构成「试点验收通过」**：本记录为构造走查（含人工边界测试），课程页视觉核验未建立；「试点验收通过」需要真实图表、逐根时序、当时可见信息与独立裁决记录；
- 边界确认 2 条（非缺陷）：① 管理版本成交后不临场切换，41C 降级按「原计划结束 + 新计划」；② Must-have 第 5 条与严格口径第 5 条轻微冗余，保留。
