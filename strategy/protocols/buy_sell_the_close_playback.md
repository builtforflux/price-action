# BTC/STC 决策协议：试点验收回放

> **状态：Strategy / Playback（试点验收记录）**
>
> 对 [BTC/STC 决策协议](buy_sell_the_close.md) 的 14 个验收案例逐一走查。案例构造来自课程原文；无真实 OHLC 处只核对协议各块是否产生**唯一且可观察**的结果，不宣布数值方程成立。本记录在批量补齐 21 页协议后可归档/删除。

## 1. 正例：早期版（41A p263、49A p1072）

**构造**：强多头突破，首根大阳线收在旧边界外，实体明显大于近期、收盘近高点、少重叠；前方有可定义测量目标；尚无独立 follow-through。

**走查**：Must-have 五条全满足（清楚边界 ✓ 完成 K 收外 ✓ 可定义 leg stop ✓ 现实 target ✓ 方程可评估 ✓）；严格口径五条全满足；版本选择 → 早期版；stop = 完整 breakout leg 外；管理版本：无可行 swing 结构（仅首根收盘、第二腿未确认）→ Scalp；target = 最近 magnet（前高/测量目标）。

**结果**：早期版 + 完整 leg stop + Scalp + 最近 magnet —— 唯一且可观察 ✓

## 2. 正例：确认版（41A p263–265、41D p333）

**构造**：连续大多头实体、收近高点、空头旗形向上突破、强跟进（Always In Long 已确立）。

**走查**：版本选择 → 确认版；stop 按确认时重算完整 breakout leg（不继承早期收盘价）；管理版本：清楚第二腿/量度结构且近端无实质障碍 → Swing；target = 量度结构目标。

**结果**：确认版 + 重算 leg stop + Swing + 结构目标 —— 唯一 ✓

## 3. 近似反例：大 K 但质量不足（42A p351、41C p314）

**构造**：突破 K 实体大但影线长、与相邻 K 高度重叠、收盘未稳定留在边界外（近似 42A「弱突破：K 不大、影线/重叠明显、跟进差」的多头镜像）。

**走查**：严格口径第 3 条（方向优势）与第 4 条（未落回双边状态）无法明确确认 → 按协议「无法确认任一项 → WATCH」。

**结果**：WATCH —— 不构成早期版 ✓

## 4. 管理例：正常回调进入 channel（49A p1072、core 01_trends）

**构造**：突破后约 90% 概率先回调，再形成通道或交易区间（49A 场景 1）；首回调未破坏突破 leg。

**走查**：第 6 块「转入 channel」→ 停止机械 BTC、重新判断，**不自动退出**；新入场转趋势/pullback 策略；已有仓位按原锁定计划管理。

**结果**：不退出，原计划继续 ✓

## 5. 失效例：旧区域重新接受（40E p243）

**构造**：高潮背景后出现真正强空头突破，价格回到旧区域并获反向跟进。

**走查**：Premise invalidation 第 1 条成立 → 全部依赖 BTC premise 的仓位主动退出；stop 在归零前继续有效。

**结果**：全部退出 ✓

## 6. 过期例：尚未入场已出现回踩（41A p265）

**构造**：突破获接受后出现首次回踩，交易者尚未入场。

**走查**：Entry expiry → 早期/确认收盘版本均已过期；本卡不可用；转入 breakout-pullback 重新评估。

**结果**：转 breakout-pullback，不追认早期价 ✓

## 7. 管理例：Scalp（41B p288）

**构造**：近端 magnet（前高）可形成合理方程；远端第二腿/量度结构不清楚（无法确认 swing 计划）。

**走查**：没有可行 swing 计划 + scalp 方程成立 → Scalp；target = 最近 magnet；退出 = 到达 magnet 或 premise invalidation。

**结果**：Scalp + 最近 magnet ✓

## 8. 管理例：Swing（41D p333–337）

**构造**：强空头突破后（空头侧镜像），量度目标清楚、路径无实质近端障碍。

**走查**：有可行 swing 计划且近端不构成实质障碍 → Swing；target = 量度结构目标；stop = 空头腿顶部（同一失效点）。

**结果**：Swing + 结构目标 ✓

## 9. 管理例：预写分仓（41B p289、41A p261）

**构造**：近端 magnet（前高）显著影响远端测量目标到达概率，但未使 swing 方程转负；两套方程均成立；41B 提供数量拆分先例（低 2 点加仓、首笔保本第二笔获利）。

**走查**：两子计划可行 + 近端构成实质障碍但未否定 swing → 预写分仓；每份数量/target/触发入场前写明；runner 继续依赖同一 BTC premise。

**结果**：预写分仓 ✓

## 10. 管理例：swing 方程被否定（47B p819、41C p316）

**构造**：清楚第二腿结构存在，但路径上近端 magnet 与障碍使 swing 方程不成立（stop 过远/reward 被压缩）；到近端 magnet 的 scalp 方程成立。

**走查**：按「有没有可行 swing 计划」判据 → 没有可行 swing → Scalp（不被错误排除）；41C「深回调令 swing 预期降为区间 scalp」是结果路径描述，可执行处理 = 原计划结束 + 新计划（管理版本不临场切换）。

**结果**：Scalp ✓（并确认管理降级边界：成交后不临场切换管理版本，降级 = 原计划结束 + 新计划）

## 11. 削弱例：momentum 削弱（41C p316）

**构造**：BTC 突破失败后更低位置存在加仓语境：顺势 K 线持续缩小、关键顺势收盘失去跟进、反方 K 线增加但未形成强反向突破；旧区域尚未重新接受。

**走查**：完整削弱组合三条件同时成立 → 允许预写分支减仓；premise 未失效，不触发全部退出。

**结果**：预写分支减仓 ✓

## 12. 正常波动例：无跟进反向 signal（40C p211）

**构造**：跟进不佳时上影表示高位卖盘，但未形成强反向突破与跟进；单个普通反向 signal 触发后无跟进。

**走查**：不单独构成 premise 失效；削弱组合不完整（无顺势 K 缩小/跟进丢失）→ 正常波动，不退出。

**结果**：不退出 ✓

## 13. 失效例：全部退出（40E p243）

**构造**：真正强空头突破出现（第 2b 条：强反向突破 + 跟进）。

**走查**：Premise invalidation 第 2b 条成立 → **全部退出而非只减仓**。

**结果**：全部退出 ✓

## 14. 失效例：异常强单根反向 K（40C p208、core 三层退出保护）

**构造**：一根异常强反向趋势 K 线本身否定原接受结构（实体异常大、收盘反侧、吞没突破 leg 结构），尚无后续跟进。

**走查**：Premise invalidation 第 2a 条成立（不要求后续跟进）→ 全部退出。

**结果**：全部退出 ✓

## 验收结论

- **14/14 案例通过**：协议各块均产生唯一且可观察的结果，未发现 P0/P1 协议缺陷；
- 边界确认 2 条（非缺陷）：① 管理版本成交后不临场切换，41C 的 swing→scalp 降级按「原计划结束 + 新计划」处理；② Must-have 第 5 条与严格口径第 5 条同为「方程可评估」，属轻微冗余，保留（一个管资格、一个管持续条件）；
- 协议状态可更新为「试点验收通过」，可进入批量补齐阶段。
