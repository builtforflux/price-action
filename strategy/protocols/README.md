# 策略决策协议（Strategy Decision Protocol）

> **状态：Strategy / Index（模板与约定）**
>
> 本目录把策略页从「知识结构清晰」提升到「执行协议清晰」：为每个策略页补充**版本选择与参数绑定的条件规则**。它不是订单执行层——不处理订单、成交、撤单、平台保护与异常（那些属于账户/平台事实，超出本仓库范围）。

## 命名与历史说明

- 本目录称「策略决策协议」，不称「执行协议」，避免与旧 `execution/` 层的订单执行职责混淆。
- 仓库历史：`eb7403f` 移除了旧 `strategy/` + `execution/` 层并收敛为 core/reference。旧层包含人工固定基线（固定窗口、单目标、全量退出等），其细节可从旧提交内容查证；但**移除原因未在提交说明中记录**，此处对旧层问题的描述（如「机械基线泛滥」）属于合理推断，不是已证实的历史事实。

## 职责声明

决策协议把策略页已有概念**操作化为可观察的选择条件**；它**可以收紧仓库候选资格**（如「首根足够强」的严格口径），但**不得**扩大 core / strategy 的 premise、重定义概念、增加未经授权的概率或订单执行规则。

## 设计原则

1. **条件规则，不是固定参数**：
   - 补：`如果证据组合 X → 使用版本 A；如果证据组合 Y → 使用版本 B；否则 → WATCH/NO_TRADE`；
   - 不补：`必须第 N 根 / 必须回撤 X% / 必须达到 1R`。
2. **条件规则必须由可观察事实组成**——不能把「看情况」改写成「如果足够强」而不定义「足够强」的最低证据组合。
3. **四种角色必须分开**，不能用一个 Disqualifier 承担四种职责：

| 角色 | 含义 | 时机 |
| --- | --- | --- |
| Candidate rejection / entry expiry | 尚未入场时，该版本不再允许采用（如首根收盘时点已过） | 入场前 |
| Premise invalidation | 原交易理由被可观察事实否定 | 入场前后均可 |
| Active exit | 持仓在 protective stop 触发前主动退出 | 持仓中 |
| Protective stop | 实际在场的保护锚点 | 持仓中 |

例：「已经回测突破点」可能是早期收盘版本已过期（entry expiry），不表示突破延续 premise 失效，也不表示已有持仓必须退出。

## 模板（每页 7 块）

| 块 | 内容 | 验收问题 |
| --- | --- | --- |
| 1. Must-have | 全部成立才进入本卡的事实清单（可观察） | 哪些事实必须全部成立 |
| 2. 反证 / Candidate rejection | 任一出现即本卡不可用；与 entry expiry、premise invalidation、active exit 分开记录 | 任意出现什么就禁止 |
| 3. 版本选择 | 多 entry 版本的唯一选择条件（if-then 链，else → WATCH/NO_TRADE） | 采用哪个唯一 entry 版本 |
| 4. Entry-Stop 绑定 | 每版 entry 绑定的唯一 active stop；注明不得借用的其他版本 stop | stop 是哪个 |
| 5. 目标优先级 | 首要 target 的选取顺序（magnet 距离/结构依据） | 首要 target 是哪个 |
| 6. 管理分支 | Premise 失效 vs Active exit vs 正常波动三组证据；scalp→swing 与部分退出触发条件 | scalp/swing、主动退出 vs 正常波动 |
| 7. 跨 premise 禁借 | 选择本 premise 后禁止借用其他候选/其他版本的概率、entry、stop、target | 选择后禁止借用什么 |

## 多候选（PSEL）全局规则

选定 premise 后，entry、stop、target、概率、仓位和管理**全部来自该 premise 的同一版本**。未选候选不提供交易许可或参数；市场中的可观察事实仍可继续监控，但**只有当前计划预写为「削弱/失效/退出证据」的事实才能改变本仓管理**。

一句话：**保留市场事实，不保留其他候选的规则。**

**选择必须给出理由**：写明主导命题、计划持有方式（scalp / swing / 预写分仓）和该命题比其他候选更直接解释当前风险的理由；两个候选都通过且无法给出不依赖结果的选择理由 → WATCH / NO_TRADE；不允许以「喜欢这个形态」或更漂亮的 R 作为唯一理由。

## 验收标准

按模板逐块填写后，任何一块出现「看情况 / 任选一个 / 根据强度决定」而没有继续说明判断依据，该页就未达到决策协议级清晰度。
