# 失败再失败后的原方向延续（Failed Failure）

> **状态：Strategy / Application**
>
> 本文把突破延续命题实例化为"失败尝试本身也失败"后的再次突破；它不生成具体订单参数。

## 交易命题

第一次突破尝试失败并快速回到旧区域，随后反向尝试也失败，原突破方向再次触发并获得强跟进。此时第一次 failed breakout 转成 breakout pullback，逆向交易者反而可能被困；failed failure 往往比第一次尝试更可靠。

## 情景判定

- 事件顺序必须保留：突破 → 失败回到旧区域 → 反向尝试失败 → 原方向再次获得接受；
- 再次突破获得跟进（强收盘、少重叠、旧区域未快速收回）；
- 前方仍有目标空间。

定义见 [接受、失望与失败证据](../../core/03_acceptance_and_order_logic/01_acceptance_and_failure.md#failed-failure运动尝试) 与 [交易区间](../../core/01_market_cycle/02_trading_ranges.md#区间突破)。

## 触发类别

第二次原方向触发（stop entry 越过再次突破后的 signal bar 极值）。

## 失效与 Stop 锚点

- 反向尝试获得接受并建立持续控制；
- 再次突破缺少跟进并重新回到旧区域。

Stop 锚点类别：反方收回尝试的完整极值外——只有在能否定当前接受结构时才构成 stop。

## 目标与管理

直接预期：第二腿是条件性倾向（强 surprise 后市场往往还会尝试第二腿，不保证直线延伸）；measured move 仅在当时存在清楚且固定的量度结构时加入。管理：scalp 或 swing 取决于突破强度与量度结构；正常回踩允许，再次回到旧区域并获接受时按 premise 变化退出。名称本身不替代 context、follow-through 和目标空间。

## 常见误读

- 突破失败后机械反手，而不建立新的反向 Setup；
- 把 failed breakout 直接当成反向信号；
- 忽略 failed failure 中被困的逆向交易者压力。
