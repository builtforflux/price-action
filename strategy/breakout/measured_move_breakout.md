# 量度目标突破（Measured Move）

> **状态：Strategy / Application（目标构造页，不是独立入场策略）**
>
> 本文说明量度目标如何构造与检查；它不是独立入场策略——premise、触发、stop 与 management 来自承载它的突破/趋势/反转策略页。

## 交易命题

强突破后，用已经形成的清楚结构估算下一段运动可能测试的区域：区间/形态高度、breakout height 或 Leg 1 = Leg 2。Measured move 用结构估算区域，不是用固定点数预测未来。

## 目标构造

| 构造 | 投射方式 |
| --- | --- |
| 区间 / 形态高度 | H = 上边界 - 下边界；向上突破目标 = 上边界 + H，向下镜像 |
| Breakout height | Δ = breakout 结束价 - breakout 起始价；目标 = 突破结束价 + Δ（必须先固定起止价格） |
| Leg 1 = Leg 2 | 第二腿起点 C，目标 = C + (B - A) |
| Micro measuring gap | 强趋势 K 线前后两根 K 线的完整范围不重叠；该几何事实出现时即可确认 |
| Measuring gap | 最终带来 measured move 的 breakout；实时只能称 candidate measuring gap，达到结果后才能确认 |

定义见 [支撑阻力与目标](../../core/02_context/01_support_resistance_targets.md#量度目标)。

## 使用边界

- 量度对象必须在当时可见并固定；
- Measured move 是目标候选，不是保证到达；
- 若到量度目标前已有更近的前高前低、区间中轴、均线或大周期关键位，先评估这些障碍是否压缩风险回报；
- 没有清晰测量结构时，不需要为交易强行构造投射。

## 失效与状态变化

- 量度端点或原投射结构被明确否定（突破 leg 或旗形高度被反向接受）时，量度结构失效；
- 当前阶段转为 channel、trading range 或 climax / transition 只改变目标到达概率与管理，不自动取消已固定的量度结构；
- 突破延续 premise 自身的失效条件见 [突破延续 Setup](../../core/05_setups/02_breakout_continuation.md) 与 [收盘跟随](buy_sell_the_close.md)。

## 常见误读

- 把任意大 K 线都当成投射基准；
- 事后改用另一根 K 线的 close 或 high/low 重选端点；
- 忽略近端障碍只选与当前 Setup 无关的远端投射。
