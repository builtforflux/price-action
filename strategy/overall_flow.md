# 价格行为交易总流程

```text
新 K 线与账户事实
→ 记录价格事实
→ 更新活动结构
→ 明确当前正在测试的问题
→ 建立同周期的结果路径
→ 用新证据更新路径
→ 评价触发
→ 匹配条件概率并收敛候选
→ 建立当前交易计划
→ 执行 / 观察 / 不交易
→ 持仓更新或退出
→ 新 K 线重新开始
```

系统以价格事实、活动结构、当前测试和结果路径组织交易。人和程序使用同一批价格、距离、时间、风险和实际结果。

## 总流程

### ⓪ 固定运行边界

- 交易周期、外层周期和观察窗口
- 当前 Session、剩余交易时间和是否允许跨 Session
- 当前持仓、挂单、实际保护状态和风险预算

### ① 记录原始价格事实

K 线：
- 方向、开高低收、实体、总振幅、上下影线
- 与前一根 K 线、突破区域和附近价格区域的重叠
- 高点、低点以及相对前高前低的变化

可直接记录：
- 实体占比：`abs(close - open) / (high - low)`
- 收盘位置：`(close - low) / (high - low)`；`0.5` 是本根中点
- 上影占比：`(high - max(open, close)) / (high - low)`
- 下影占比：`(min(open, close) - low) / (high - low)`
- 相对大小：本根总振幅和实体相对附近 K 线扩大、相近还是缩小
- 重叠程度：共享价格范围相对本根或正在比较结构的大小

若 `high = low`，直接记录为零波幅 K 线，不计算比例。Signal-bar 角色和质量在步骤 ⑥ 结合结构与位置评价。

价格事件：
- Push / Leg、Pullback / Pause
- Approach、Test、Breakout Attempt
- Follow-through、Acceptance、Failure、Re-entry

参照区域：
- 前高前低、swing high / low
- 突破点、区间边界和中部
- 趋势线、通道线和 20EMA
- gap 边界、旧结构起点和 measured-move 区域

### ② 更新活动结构

```text
活动结构

外层背景
- 周期：
- 方向：多头控制 / 空头控制 / 双方平衡
- 分离与重叠：扩大 / 保持 / 缩小 / 反复重叠
- 演化阶段：Breakout / Spike / Tight Channel /
              Broad Channel 或 Trending Trading Range / Trading Range
- Breakout Mode：方向未决 / 不适用

直接交易结构
- 周期：
- 当前上涨腿或下跌腿：
- 当前回调、暂停或小交易区间：
- 当前突破区域或突破后的第一次测试：
- 当前双测试、三次尝试、区间边缘或通道边界：

结构边界
- 起点：
- 上边界：
- 下边界：
- 中部或测试点：
- 当前价格位置：
- 当前阶段及其与外层结构的关系：
```

任何 Rising Channel 都同时是当前周期的 Bull Trend 和较长演化上的 Bear Flag；Falling Channel 完全镜像。这些角色合并为同一个结构证据。Broad Channel、Staircase 和 Trending Trading Range 也可能是同一段方向移动的不同观察视图。

一笔候选以一个当前测试作为组织中心，使 entry、invalidation 和第一现实目标属于同一条价格路径。局部结构通常组织触发，外层趋势、通道或区间提供背景、合理的更宽失效边界和较长目标；所有输入共同服务于同一条路径。

必要边界无法识别时，不建立交易计划。

### ③ 明确当前正在测试的问题

当前测试回答：

> 当前价格正在测试什么？这次测试成功或失败分别意味着什么？

```text
当前测试

- 外层背景：
- 直接交易结构：
- 参照区域：
- 接近方向：
- 当前位于参照区域内部 / 外部 / 边缘：
- 观察周期：
- 预计时间范围：
- 正在判断：参照区域继续发挥作用 / 被有效突破或原结构失效
```

| 当前结构 | 正在测试的问题 |
| --- | --- |
| 趋势回调 | 原方向恢复，还是回调扩大并破坏原结构？ |
| 交易区间边缘 | 边缘拒绝价格，还是边界外获得接受？ |
| 突破后的回踩 | 突破点或 gap 守住，还是重新进入旧结构？ |
| 通道边界 | 产生内部反应，还是形成有效外部突破？ |
| 第二腿到达旧结构边缘 | 在外部延续，还是形成第二腿陷阱？ |
| 旧高低、EMA 或量度区域 | 被接受穿越，还是遭到拒绝？ |

同一价格区域可能同时被称为前高、区间边缘、双顶区域或 measured-move 目标。若它们来自同一位置和同一次测试，只形成一个位置证据；真正不同的周期、结构来源或反应事实才增加新信息。

如果当前没有明确参照区域、测试方向或可观察结果，就继续观察。

### ④ 为当前测试建立结果路径

```text
结果路径

路径一
- 预期价格运动：
- 增强证据：
- 削弱证据：
- 失效条件：
- 候选目标：
- 当前触发：
- 当前状态：不存在 / 观察 / 可以建立计划 / 失效
- 正在等待：

路径二
- 预期价格运动：
- 增强证据：
- 削弱证据：
- 失效条件：
- 候选目标：
- 当前触发：
- 当前状态：不存在 / 观察 / 可以建立计划 / 失效
- 正在等待：
```

不同结构中的具体表达：

| 当前测试 | 一种结果 | 另一种结果 |
| --- | --- | --- |
| 趋势中的回调 | 原趋势恢复并测试旧极值 | 回调扩大、结构被破坏或进入区间 |
| 交易区间边缘 | 边缘拒绝并返回区间 | 边界外获得接受并启动突破路径 |
| 突破后的回踩 | 突破点守住并恢复突破方向 | gap 关闭、重新进入并形成失败突破 |
| 通道边界 | 从边界反应并继续通道内部运动 | 有效突破边界并转入新的结构路径 |
| 第二腿到达区间边缘 | 获得外部接受并继续 | 外部接受失败，形成第二腿陷阱并返回区间 |

上涨通道内部的短期多头恢复和通道生命周期中的长期反向突破可以同时存在，并分别记录时间范围。长期概率保持为背景，直到出现相同时间范围的当前触发。

```text
每条结果路径独立经历：

不存在
↓ 出现明确结构、参照区域和当前测试
观察
├─ 测试仍未完成 → 继续观察，并保留正在等待的事实
├─ 必要证据和触发完整 → 可以建立计划
└─ 结构或结果路径被否定 → 失效

可以建立计划
├─ 交易方程成立 → 执行
├─ 等待新的 entry 或价格后仍可能改善方程 → 返回观察
├─ 空间、时间、风险或成本已经否定方程 → 不交易
└─ 路径失效 → 不交易
```

### ⑤ 用价格事实更新结果路径

| 观察事实 | 当前含义 | 对结果路径的更新 |
| --- | --- | --- |
| 突破创造分离，完整 gap 保持 | 原方向控制和突破接受较强 | 增强原方向路径 |
| 完整 gap 关闭，但实体 gap 保持并很快恢复 | 原方向减弱但未失败 | 原路径仍成立，继续观察跟随 |
| gap 缩小、被补或回调穿回突破点 | 原方向保持分离的能力下降 | 削弱原路径，增加通道化或区间化 |
| 局部小区间连续重叠 | 新旧公平价格尚未完全分离 | Broad Channel / Trending Trading Range 属性增强 |
| 双方反复接受同一价格区域 | 双方趋于平衡 | Trading Range 属性增强 |
| gap 关闭后反方获得跟随 | 原突破已被实质否定 | 原突破路径失效或重新分类 |

```text
Gap 观察
- 分隔的两个参照对象：
- 类型：完整范围 / 实体 / 微型 / EMA 或结构分离
- 状态：新形成 / 保持 / 部分回补 / 完全回补
- 回补后的跟随：
```

完整 gap、实体 gap、微 gap、均线分离和突破接受若来自同一次分离，只构成一个证据簇。

| K 线与反应事实 | 压力与控制判断 |
| --- | --- |
| 实体扩大、收盘靠近方向端点、反向影线较少、连续性好 | 对应方向压力增强 |
| 突破有跟随、回调浅且恢复快 | 对应方向控制得到确认 |
| 实体缩小、影线增加、重叠增加 | 对应方向压力减弱 |
| 突破缺少跟随或快速返回 | 对应方向控制受到否定 |

Buying / Selling Pressure、Breakout Quality、Acceptance 和 Control 共同引用上述来源事实，合并为相应的价格反应证据簇。

| 同一回调或测试中的次序 | 向上恢复 | 向下恢复 | 空间表现 |
| --- | --- | --- | --- |
| 第一次尝试 | H1 | L1 | 第一次恢复尝试 |
| 第一次失败或出现新的反向推进后 | H2 | L2 | Double Bottom / Double Top |
| 再次失败或出现第三次反向推进后 | H3 | L3 | Wedge Bottom / Wedge Top |

双测试不要求两个极值完全相等；Higher Low、Lower Low、Lower High 或 Higher High 只要仍属于同一结构中的第二次测试，都可以承担相应 H2 / L2 角色。计数只在同一周期、同一回调或测试中延续。原方向已经形成新的明确走势腿、当前测试被否定、活动结构被替换或观察周期改变时，重新开始相应计数。H/L、Double Test、Wedge 和 Flag 若描述同一事件链，只形成一个结构证据。

边界反应：

```text
Approach
→ Test
→ Breakout Attempt
→ Follow-through / No Follow-through
→ Acceptance / Failure
```

新证据到来后，每条路径更新为：增强、仍成立但减弱、失效或继续等待。判断随来源事实改变；新的更具体结构可以替代旧路径。

### ⑥ 出现交易机会时评价触发

只有已经明确结构、位置和准备交易的结果路径后，才评价 signal bar。

| 检查 | 较好的多头 Signal Bar | 较好的空头 Signal Bar |
| --- | --- | --- |
| Context 与位置 | 所在结构和位置支持买入 | 所在结构和位置支持卖出 |
| 收盘位置 | 至少收在本根上半部；上三分之一或近高更强 | 至少收在本根下半部；下三分之一或近低更强 |
| 反向影线 | 上影较短 | 下影较短 |
| 实体 | 多头实体相对较大，占本根范围较多 | 空头实体相对较大，占本根范围较多 |
| 反转拒绝 | 明显下影可以表示低位拒绝 | 明显上影可以表示高位拒绝 |
| 相对大小 | 相对附近 K 线有足够力度，但不能大到使合理 stop 过远或已经像末端高潮 | 镜像处理 |

Signal-bar 质量由外观、结构和位置共同决定；强趋势背景可以补偿较弱的顺势 signal bar。

| 承担风险的时点 | 入场前必须完成 | 成交后继续验证 |
| --- | --- | --- |
| Signal trigger 入场 | entry condition 清楚、未过期；结构和路径仍有效 | 是否立即退回 signal bar；entry bar、follow-through 和 acceptance |
| 等待确认后入场 | entry bar、follow-through 或计划要求的 acceptance 已出现 | 新价格下的原路径是否继续成立 |

计划明确 Acceptance 位于入场前还是成交后。提前承担风险与等待确认属于两个决策时点；等待确认的计划按确认后的价格重新计算 entry、stop、target 和交易方程。

### ⑦ 匹配条件概率并收敛多候选

```text
概率判断
- 已经成立的市场状态和条件：
- 预测的目标事件：
- 观察周期：
- 时间范围：
- 适用的近似概率：
- 哪个新事实会替代当前判断：
```

同一目标事件和时间范围内，更新后更具体的条件替代较早的一般判断；目标或时间范围不同的概率可以同时成立。例如上涨通道当前仍可能恢复旧高，同时在完整通道生命周期中更可能最终跌破趋势线。

| 已经成立的条件 | 预测的目标事件 | 近似概率 | 适用范围 |
| --- | --- | --- | --- |
| 已确认趋势中的反转尝试 | 不发展成完整相反趋势 | 约 80% | 趋势惯性的结构判断 |
| 已确认交易区间中的突破尝试 | 不获得持续外部接受 | 约 80% | 区间惯性的结构判断 |
| 成熟中性 Breakout Mode | 最终向上或向下突破方向 | 接近 50 / 50 | 突破方向先验 |
| Tight Channel 第一次逆势尝试 | 先成为 minor reversal | 约 70% | 第一次反转的近期结果 |
| 清楚倾斜的方向通道 | 最终先反向突破趋势线并通常区间化 | 约 75% | 完整通道生命周期 |
| 通道向原趋势方向突破外轨 | 最高适用周期约 5 根内失败 | 约 75% | 已发生同向外轨突破后的结果 |
| 倾斜 Wedge 完成 | 先向楔形反方向 / 原方向突破 | 约 75 / 25 | 突破方向 |
| Strong Breakout 并获得跟随 | 至少尝试第二腿 | 约 60% | 第二腿事件 |
| 早期 MTR / 强反向突破和跟随 | 完成反向 swing objective | 约 40% / 60% | 各自决策时点的 swing 结果 |

这些数字描述表中对应的结构事件。Trader's Equation 使用条件、entry、stop、target 和持有时间完全一致的估计。完整适用范围和隔离项见[规则与冲突台账](rules_and_conflicts.md)。

| 当前具体交易 | 近似概率语言 | 风险回报含义 |
| --- | --- | --- |
| 较早、尚未获得强确认但条件已经可定义 | 约 40% | 需要较大潜在回报补偿 |
| 双方接近平衡 | 接近 50% | 需要明显更大回报，或等待新证据 |
| 条件、触发和目标具有清楚方向优势 | 约 60% | 约 1R 也可能使方程成立，仍须计算成本 |

70%–80% 的结构概率只有在当前交易评价的目标事件与原规则完全相同时才能直接使用。无法说明为什么当前交易属于哪个概率范围时，继续观察，不以理由数量制造百分比。

| 理由关系 | 处理 |
| --- | --- |
| H2、Double Bottom、Second Entry 等来自同一事件链 | 合并为一个结构理由 |
| 同一突破同时产生 pressure、acceptance 和 control 标签 | 合并为一个价格反应证据簇 |
| 背景与控制、位置与测试、触发与响应、目标空间来自不同事实 | 可以相互补充 |
| 独立同向证据增加 | 路径支持通常增强；概率仍由匹配的条件规则提供 |
| 出现强反方事实 | 可以覆盖多个弱支持理由 |

承担风险前至少能指出两个来源独立的支持事实。条件规则提供概率，理由负责更新路径支持程度。

| 候选之间的关系 | 处理 |
| --- | --- |
| 当前测试、方向、trigger、invalidation 和持有时间相同，只是名称或目标不同 | 合并为一份候选，用多个目标表达 |
| 同一方向，但触发、失效边界或持有时间不同 | 保留为不同候选，每个候选保留完整的 entry、stop 和 target |
| 方向相反或依赖不同结构 | 分别评价 |
| 只有长期结构预期，没有当前触发 | 只保留为观察背景 |
| 无法比较独立证据、反方事实、第一目标、风险、时间和交易方程 | 继续观察或不交易 |

Scale-in 的全部内容必须在第一笔 entry 前确定；当前结果路径失效时，取消剩余层。

| 目标层次 | 定义 |
| --- | --- |
| 候选目标 | 结构可量度后事前计算，只用于判断空间 |
| 第一现实目标 | entry 后最近的旧极值、区间位置或其他现实 magnet |
| 主要结构目标 | 当前结果路径直接生成的结构投射 |
| 延伸目标 | 只有新突破和跟随继续支持原路径时才启用 |

Protective stop 位于真正否定当前路径、同时能够容纳正常波动的位置。合理 stop 太远时，选择缩小仓位、等待更好的 entry 或放弃交易。

使用同一组 entry、stop 和实际准备兑现的目标检查：

```text
到达目标的概率 × Reward
>
先触发 Stop 的概率 × Risk + 成本
```

存在部分退出、scratch 或主动退出时，交易方程覆盖计划中的各项实际结果。

### ⑨ 唯一决策

| 决策 | 必须满足 | 输出 |
| --- | --- | --- |
| 执行 | 路径有效；入场前证据完整；entry、invalidation、stop、目标、仓位和时间明确；交易方程成立 | 当前交易计划进入执行 |
| 观察 | 当前测试仍可能成立，但缺少触发、跟随、清楚边界或足够证据 | 写明正在等待什么 |
| 不交易 | 路径失效，或空间、时间、风险、成本使交易不值得承担 | 写明不交易原因 |

观察或不交易都不建立订单。新 K 线到来后返回步骤 ①。

### ⑩ 执行与初始保护

```text
当前交易计划
├─ 预挂 stop / limit order
│  → 提交订单
│  → 等待市场触发或成交
│
├─ 等待图表条件后下单
│  ├─ 条件未发生 → 继续等待
│  └─ 条件发生且计划仍有效 → 提交订单
│
└─ 条件失效或过期
   → 取消计划和未成交订单

订单等待成交
├─ 回执不明 → 核对账户，不重复下单
├─ 路径失效或订单过期 → 撤单并确认
├─ 未成交 → 继续等待
└─ 实际成交或部分成交
   ↓
确认数量、均价和剩余订单
   ↓
确认 Active Protective Stop 覆盖全部实际仓位
├─ 已确认 → 持仓
└─ 未确认 → 执行预写异常处理
```

没有实际成交就没有持仓；没有保护确认就不能假定风险已经受控。首次成交后冻结当时的原始计划，持仓中的更新另行记录，不覆盖入场时事实。

### ⑪ 新 K 线驱动持仓更新

每根新 K 线都返回步骤 ①，重新更新价格事实、活动结构、当前测试、结果路径、概率和目标。

```text
持仓中
├─ 原路径增强
│  → 按计划持有
│  → 新主要结构成立后可降低风险或保留延伸目标
│
├─ 原路径仍成立但减弱
│  → 按事前规则保持、减仓或收缩目标
│  → 不自动反向
│
├─ 原路径失效
│  → 主动退出
│  → 仓位归零前 Protective Stop 继续有效
│
├─ 强相反路径获得接受
│  → 退出原交易
│  → 如需反向，重新建立完整计划
│
├─ 目标到达
│  → 按计划减仓或退出
│
├─ Protective Stop 触发
│  → 退出
│
└─ 时间或账户约束触发
   → 按计划减仓或退出
```

Trailing stop 只能降低开放风险：多头 stop 只能上移，空头 stop 只能下移；必须先形成能够容纳正常回调的新结构，并确认新保护已经生效。

## 结构怎样生成目标

| 活动结构与结果路径 | 主要结构目标 |
| --- | --- |
| Double Bottom / H2 向上突破并接受 | `neckline + double-bottom height` |
| Double Bottom / H2 向下突破并接受 | `bottom - double-bottom height` |
| Double Top / L2 向下突破并接受 | `neckline - double-top height` |
| Double Top / L2 向上突破并接受 | `top + double-top height` |
| Trading Range 向上突破并接受 | `upper boundary + range height` |
| Trading Range 向下突破并接受 | `lower boundary - range height` |
| 从 `C` 开始第二腿 | `C ± first-leg length` |
| Rising Channel 反向跌破趋势线并接受 | 通道起点；通常先预期更大区间 |
| Falling Channel 反向突破趋势线并接受 | 通道起点；通常先预期更大区间 |
| Failed Breakout 返回原结构 | 最近内部目标，再看中部或另一侧 |
| Trading-range Second-leg Trap | 先返回区间，再看中部或另一侧 |
| Measuring Gap 保持 | 按 gap 来源投射 measured move |

```text
double-bottom height = neckline - bottom area
double-top height    = top area - neckline
range height         = upper boundary - lower boundary
Leg 1 = Leg 2        = second-leg start ± first-leg length
```

目标按实际路径排序。多个 measured move 落在相近区域会形成更明显的 magnet；同一结构的不同量度合并为一个方向理由。Gap-based target 与区间高度、双测试或 Leg 1 = Leg 2 分别维护各自来源和有效性。

## 概念在流程中的唯一职责

| 概念 | 在总流程中的职责 |
| --- | --- |
| 实体、影线、收盘和重叠 | 原始价格事实 |
| Gap、EMA 分离和局部区间重叠 | 判断价格能否保持分离 |
| Buying / Selling Pressure | 汇总一段价格事实，归入来源证据簇 |
| Spike、Channel、Trading Range | 描述活动结构和市场演化阶段 |
| H1/H2/H3、L1/L2/L3 | 记录同一回调或测试中的尝试次数 |
| Double Test、Wedge | 尝试次数的空间表现 |
| Flag | 结构在外层趋势中的角色 |
| Breakout、Follow-through、Failure | 更新当前测试的结果路径 |
| Signal Bar、Entry Bar | 组织触发并观察触发后的反应 |
| Support / Resistance | 当前测试的参照区域和路径障碍 |
| Measured Move | 从已固定结构生成候选目标 |
| Protective Stop | 限制当前计划的最坏风险 |
| Trailing Stop | 新结构形成后降低开放风险 |
| Trader's Equation | 判断当前风险交换是否值得承担 |

最终统一关系：

> K 线形成分离、重叠、压力和测试；测试发生在活动结构与具体位置中；新价格选择成功、失败或尚未完成的结果路径；被选中的路径统一生成 entry、invalidation、stop、目标和管理；每根新 K 线继续验证这条路径，直到目标到达、路径失效或保护触发。
