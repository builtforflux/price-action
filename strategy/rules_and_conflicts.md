# 规则、条件关系与冲突台账

> **状态：Strategy / Discussion**
>
> 本页集中保存条件概率、概念关系、适用范围和冲突。实时运行以[价格行为交易总流程](overall_flow.md)为入口，本页提供规则条件与来源边界。

## 分类

| 状态 | 含义 | 能否进入运行 |
| --- | --- | --- |
| 可同时成立 | 规则描述不同对象、周期或职责 | 可以，但必须保留各自条件 |
| 条件更新 | 同一路径在不同观察时点使用不同先验，新条件覆盖旧条件 | 可以，按状态转换使用 |
| 同源视图 | 多个名称来自同一组价格事实 | 只保留一份证据，不重复计票 |
| 隔离 | 分母、目标、数学或来源口径不清 | 不可以，只保留供讨论 |
| 待讨论 | 流程语义尚未决定 | 不可以，先讨论 |

## 一、可以直接串联的概念

### 1. 从价格事实到当前交易计划

```text
K 线事实
→ Push / Pullback / Test / Breakout
→ Separation / Overlap / Follow-through / Failure
→ Pressure / Control / Acceptance
→ 活动结构与边界
→ 尝试次数和形态名称
→ 当前测试与同周期结果路径
→ 条件概率和目标路径
→ Entry / Invalidation / Stop / Target / Management
```

| 概念 | 底层来源 | 在闭环中的唯一职责 | 分类 |
| --- | --- | --- | --- |
| Buying / Selling Pressure | 实体、收盘、影线、连续性、跟随、回调质量 | 汇总一段窗口内哪一方更主动 | 可同时成立 |
| Breakout Quality | 越界幅度、收盘、重叠、跟随、回踩 | 判断新价格是否获得接受 | 可同时成立 |
| Support / Resistance | 前高低、区间边界、突破点、线条、EMA、gap、量度位 | 提供 Approach / Test 的参照区域和路径障碍 | 可同时成立 |
| Gap | 两个价格范围、实体、结构或 EMA 关系是否保持分离 | 更新 pressure、接受和趋势阶段 | 可同时成立 |
| H1/H2/H3、L1/L2/L3 | 同一活动结构中的方向尝试次数 | 记录第几次恢复或反转尝试 | 可同时成立 |
| Double Bottom / Top | 对近似价格区域的第二次测试 | H2 / L2 的空间视图 | 同源视图 |
| Wedge | 三次同方向推进或测试 | H3 / L3 的空间视图 | 同源视图 |
| Flag | 暂停、回调、通道或局部区间在外层趋势中的角色 | 说明结构属于哪一外层方向命题 | 同源视图，不能与组成结构重复计票 |
| Measured Move | 已固定结构的距离投射 | 生成目标候选，不提供入场许可 | 可同时成立 |
| Failed Breakout / Trap | 越界未获接受、重新进入及被困交易者压力 | 使原突破路径失效并启用返回路径 | 条件更新 |
| Protective Stop | 当前交易计划的最坏风险保护 | 在主动判断或执行失败时限制风险 | 可同时成立 |
| Trailing Stop | 新结构形成后向降低风险方向调整保护 | 收缩开放风险，不扩大原风险 | 条件更新 |

### 2. 同一价格的多种视图

以下关系不冲突，但必须绑定周期和当前讨论的活动结构：

```text
第二次向上尝试
= H2（触发计数）
= Double Bottom（空间测试）
= 可能是 Bull Flag（外层 Context 角色）

第三次向下尝试
= L3（触发计数）
= Wedge Top（三推空间结构）
= 可能是 Bull Trend 中的反转尝试

Rising Channel
= 当前周期的 Bull Trend
+ 长期演化上的 Bear Flag

局部 Bull Flag
可以同时位于外层 Rising Channel / Bear Flag 内
```

同一事实的多个标签只产生一个结构证据。不同周期、不同结构边界或新的独立反应事实，才可能形成另一条证据。

### 3. 分离、重叠与市场周期

```text
强突破创造价格分离
→ 回调检验分离
→ Gap 保持：原方向控制保持
→ Gap 缩小：控制减弱
→ 回调穿回突破点：Staircase
→ 局部区间连续重叠：Broad Channel / Trending Trading Range
→ 双方反复接受同一区域：Trading Range
→ 新区间成功突破：重新进入 Breakout Phase
```

完整 gap、实体 gap、微 gap、EMA 分离和突破接受若来自同一突破，只构成一个“价格分离”证据簇。

### 4. Gap 的条件演化

| 观察事实 | 当前解释 | 后续更新 |
| --- | --- | --- |
| 结构 gap 保持、跟随良好 | 原方向 pressure 和接受较强 | 保留延续与第二腿路径 |
| 完整 gap 关闭、实体 gap 保持 | 原方向减弱但未失败 | 继续观察跟随和回踩 |
| 所有 gap 快速关闭 | 原突破出现失望 | 降低延续路径，增加区间/失败路径 |
| 关闭后反方获得跟随 | 原突破路径失效 | 启用返回或反向路径 |
| 候选 measuring gap 保持 | 可保留 gap-based target | 仍须结合其他障碍 |
| 候选 measuring gap 关闭 | 取消或降低该 gap 投射 | 不自动取消区间高度或 Leg 1 = Leg 2 |
| 长期未触 EMA 后首次测试立即恢复 | 原趋势第一次 EMA 测试成功 | 第一现实目标通常仍是旧极值 |
| 整根 K 线来到 EMA 反侧 | 严格 MAG Bar，反方压力显著增加 | 常仍可能最后测试旧极值，再判断较大修正 |

`20 Gap Bar Buy/Sell` 与严格 `Moving Average Gap Bar` 不是同一事件：前者是长期未触 EMA 后的首次测试，后者是整根 K 线位于 EMA 反侧。

## 二、条件概率清单

以下百分比对应明确的条件、目标事件和时间范围。镜像方向使用相同规则。

### 运行取舍

概率规则按用途分层：

| 用途 | 规则 | 处理 |
| --- | --- | --- |
| 核心结构先验 | 趋势惯性、区间突破失败、区间边缘、趋势回调、第一次逆势尝试、通道、TTR 重叠、Wedge、强突破和 MTR | 条件、目标事件和周期匹配时启用；更具体的新事实覆盖旧规则 |
| 特定覆盖条件 | 三种明确 Climax 条件、开盘区间获得接受后的突破 | 只在原条件和原目标完整匹配时使用；不与核心规则叠加计票 |
| 语言、数学和背景 | likely / unlikely、普通 40–60 思维、40% 与 60% 的回报交换、市场阶段占比、Endless Pullback、MAG、Opening / Session 时间统计 | 用于解释概率语言、风险交换、状态重分类或时段背景，不作为新的订单胜率 |
| 合并或隔离 | 普通 Flag 统一 40%、广义 MTR 80/20、Exceptional opening breakout 独立 70% | 分别归入实际结构规则、趋势惯性和特别强突破 measured move |

适用关系：

- 广义反转失败使用“趋势中的反转尝试约 80% 不发展成完整相反趋势”；MTR `80 / 20` 与其合并。
- Exceptional opening breakout 的 measured move 使用“特别强突破约 60%–70% 到达已固定量度目标”；Opening 提供 Session 条件。
- MAG 作为 MTR 背景证据；具体交易使用早期反转约 `40%` 或强反向突破后的约 `60%`。
- Endless Pullback 发展到约 20 根时，市场重分类为 Transition / Breakout Mode，并使用当前平衡状态规则。
- 普通 Flag 按当前实际的 Trend、Channel、Wedge 或 Trading Range 结构匹配概率。
- 三条 Climax 规则分别保留各自条件和目标；条件不完整时记录“修正倾向增强”。
- Opening 的极值时间、swing 启动时间和支撑阻力测试归入 Session context。

### 1. 概率语言与交易数学

| 条件或措辞 | 目标事件 | 概率或风险交换 | 用途 / 限制 |
| --- | --- | --- | --- |
| Brooks 使用 likely / probably | 原句明确定义的事件 | 约 `60%+` | 只是 Brooks 教学语言的近似阈值 |
| Brooks 使用 unlikely | 原句明确定义的事件 | 约 `40%-` | 目标事件仍须明确 |
| 普通、没有压倒性证据的判断 | 当前明确 objective | 常在 `40%–60%` | 不制造更精确的数字 |
| 具体交易估计约 `40%` | 计划目标先于 stop | 常需约 `2R` 作基线 | 只是风险交换，不是固定目标 |
| 具体交易估计约 `60%` | 计划目标先于 stop | 约 `1R` 可能成立 | 仍须计成本和实际 stop |

### 2. 市场状态与区间

| 条件 | 目标事件 / 时间范围 | 概率 | 用途 / 限制 |
| --- | --- | --- | --- |
| 观察市场阶段 | 强 breakout phase 与 channel / range 行为占比 | 约 `10 / 90` | 状态频率，不是交易胜率 |
| 已确认趋势中的反转尝试 | 未发展成完整相反趋势 | 约 `80%` | 表达趋势惯性 |
| 已确认交易区间中的突破尝试 | 未获得持续外部接受 | 约 `80%` | 表达区间惯性 |
| 成熟中性区间 / Breakout Mode | 最终向上或向下突破方向 | 约 `50 / 50` | 方向先验，不是订单方程 |
| 成熟区间上/下三分之一附近 | 先向区间内部移动等距目标 | 约 `60%` | 中部更接近 `50 / 50` |
| Endless Pullback 发展到约 20 根 | 原趋势恢复或反向突破 | 接近 `50 / 50` | 用于重分类为 Transition / BOM；根数不是机械阈值 |

### 3. 趋势、旗形和通道

| 条件 | 目标事件 / 时间范围 | 概率 | 用途 / 限制 |
| --- | --- | --- | --- |
| 已确认趋势、合理回调、结构 stop | 测试旧极值或对应近端 objective | 典型约 `60%` | 目标必须具体 |
| 强趋势 / Tight Channel 的第一次逆势反转 | 先成为 minor reversal、pullback 或测试旧极值 | 约 `70%` | 不等于顺势 entry 胜率 |
| 普通 bull / bear flag | 向趋势反方向突破 | 约 `40%` | Flag 范围过宽；保留来源，不进入运行 |
| 清楚倾斜的方向通道 | 最终先反向突破趋势线并区间化 | 约 `75%` | 长期结构事件 |
| 测试已识别通道边界 | 从边界反应/测试另一侧，与持续外部突破 | 约 `70 / 30` | 局部路径事件 |
| 通道向原趋势方向突破外轨 | 最高适用周期约 5 根内失败 | 约 `75%` | 强跟随后更新为新突破 |
| Trending Trading Range 形成新区间 | 回测并与前一区间重叠 | 约 `60%` | 描述重叠事件 |

### 4. Wedge、突破和反转

| 条件 | 目标事件 / 时间范围 | 概率 | 用途 / 限制 |
| --- | --- | --- | --- |
| 倾斜 Wedge / 三推完成，尚无低先验方向突破 | 先向楔形反方向突破，与向原方向突破 | 约 `75 / 25` | 只描述突破方向 |
| Wedge 已向原先约 25% 的方向突破 | 延续到腿 / MM，与失败反转 | 约 `50 / 50` | 新条件出现后替换旧 75 / 25 |
| 强突破并获得跟随 | 至少尝试第二腿 | 约 `60%` | 第二腿可短小或横向 |
| 特别强、连续、低重叠的突破 | 到达已固定 breakout-height measured move | 约 `60%–70%` | 普通突破不能借用 |
| 趋势线破坏、旧极值测试失败，但尚无强反向突破跟随 | 完成反向 swing objective | 约 `40%` | 当前风险承担时点的条件估计 |
| 强反向突破和跟随已建立控制 | 完成反向 swing objective | 约 `60%` | 新事实出现后重新估计 |
| 筛选较少的广义反转尝试 | 未形成完整 opposite trend / 形成完整 opposite trend | 约 `80 / 20` | 与趋势惯性重复，不进入运行 |

### 5. 高潮、TBTL 和 Gap 覆盖条件

| 条件 | 目标事件 | 概率 | 用途 / 限制 |
| --- | --- | --- | --- |
| 极端 microchannel / 高潮推进 | TBTL 横向至反向修正 / 继续形成新 swing | 约 `70 / 30` | 特定覆盖条件 |
| 区间顶部高潮突破、长上影、差跟随 | TBTL 横向至下 / 继续成为 measuring move | 约 `60 / 40` | 特定覆盖条件 |
| 成熟通道、重复 climaxes 或末段推进 | correction / trading range 与继续原趋势 | 约 `75 / 25` | correction 不等于 opposite trend |
| MAG 背景中的 MTR 尝试 | swing reversal / flag 或 trading range | 约 `40 / 60` | 只作 MTR 背景，不与 MTR 数值叠加 |

### 6. Opening / Session 覆盖条件

| 条件 | 目标事件 | 概率 | 用途 / 限制 |
| --- | --- | --- | --- |
| 第一根 / 前 7 根 / 第一小时 / 前 90 分钟 | 已形成当日一个极值 | 约 `20 / 50 / 70 / 90%` | 窗口嵌套，不相加 |
| 初始 opening swing 已形成 | 初始 swing 发生反转 | 约 `50%` | 仍需具体 trigger |
| 前两小时 / 日中 / 最后两小时 | 启动当日 major swing | 约 `90 / 50 / 80%` | 窗口可重叠，不是互斥分布 |
| 约 18 根 opening range 后出现获接受突破 | 对侧极值保持不被测试 | 约 `90%` | 普通越界不适用 |
| 开盘前 90 分钟 | 测试事前标出的 support / resistance | 约 `80%` | 不得事后挑价位 |
| Exceptional opening breakout | 到达已固定 measured move | 约 `70%` | 并入特别强突破的 60%–70%，只保留 Session 来源 |

## 三、表面冲突：条件不同，可以自洽

| 看起来冲突的规则 | 为什么不冲突 | 正确切换 |
| --- | --- | --- |
| 趋势反转约 80% 失败；MTR 条件早期约 40%；强反向突破跟随后约 60% | 分别是广义结构惯性和两个不同观察时点的 swing objective | 趋势惯性 → 结构筛选 → 早期或确认时点分别使用 40% / 60% |
| 区间突破约 80% 失败；强突破约 60% 有第二腿；特别强突破约 60–70% 到 MM | 观察时点和突破质量不同 | 普通 attempt 使用 80%；获得接受后切换 60%；exceptional 条件完整后才用 60–70% |
| 通道最终约 75% 反向突破；当前顺势回调约 60% 测试旧极值 | 长期通道生命周期与短期内部腿不同 | 两条路径可以同时存在，分别保存 horizon |
| 通道边界约 70/30；通道最终反向突破约 75%；同向外轨突破约 75% 失败 | 局部边界反应、长期演化、已经发生同向突破后的失败是三个事件 | 不合并百分比，按当前事件选规则 |
| Tight Channel 第一次逆势约 70% 只是 minor；通道最终约 75% 反向突破 | 第一次信号的近期结果与通道最终寿命不同 | 第一次反转先按 minor；强反向突破获得接受后再更新 |
| Wedge 突破前 75/25；低概率方向突破后 50/50 | 25% 事件已经发生，条件分母改变 | 突破后重置规则，不继续使用旧 75/25 |
| 普通 flag 约 40% 反向突破；趋势反转约 80% 失败 | 一个评价宽泛 flag 边界方向，一个评价是否形成完整反向趋势；但 Flag 范围不足以稳定匹配 | 运行时舍弃统一 Flag 40%，改用实际 Channel、Wedge、Trend 或 Range 结构规则 |
| Directional Broad Channel 约 75% 反向突破；Trading Range 突破约 80% 失败 | 倾斜通道与成熟平坦区间不是同一状态 | 先判定活动结构；结构变平后改用区间规则 |
| 市场约 10% breakout、90% channel/range；普通交易约 40–60% | 前者是状态占比，后者是条件交易结果估计 | 不把状态频率代入 Trader's Equation |
| Opening 的 20/50/70/90 与 major-swing 90/50/80 | 事件不同且窗口重叠 | 只在明确 session objective 中使用，不相加 |

## 四、真实冲突或信息不足：隔离

以下数字保留为隔离资料：

| 说法 | 问题 | 状态 |
| --- | --- | --- |
| “下一次反转约 40% 成为主要反转” | 分母和 major 的结果口径不明确 | 隔离 |
| 任意 protective stop 被触发后约 50% 是 trap | 范围过宽，缺少结构和时间窗 | 隔离 |
| Surprise 后 scale-in 约 80% 回到 breakeven | 未定义最大风险、加仓次数、时间和成本 | 隔离 |
| Scale-in 胜率递进 `60 / 80 / 90` | 材料内部与完整总风险数学冲突 | 隔离 |
| “80% 胜率且 3R”作为一般规则 | 与课程常见概率—回报交换不一致，缺少条件 | 隔离 |
| Elite scalper 约 90% 胜率 | 能力上限修辞，无可复核样本 | 隔离 |
| 约 90% K 线双方都能经管理获利 | 结果和管理分母不可验证 | 隔离 |
| “风险大于回报时约 60% 会亏” | 未定义具体 risk/reward 和结果事件 | 隔离 |
| 用事后 Actual Risk / MAE 证明入场概率或 2R | 循环推理，不能作为事前输入 | 隔离 |
| “概率永远不超过 60%” | 与多项特定结构 70–90% 事件冲突，只能视为普通交易修辞 | 隔离 |
| 期权对冲可能占卖压约 50% | 缺少数据且不是价格可直接观察事实 | 隔离 |
| 无明确条件的 TBTL `60 / 70 / 75` | 三个数字可能使用不同结构和分母 | 丢失原条件时隔离 |

更完整的课程原始冲突记录见[边界与冲突](../reference/course/boundaries_and_conflicts.md)。

## 五、运行边界

[价格行为交易总流程](overall_flow.md)拥有实时观察、结果路径、交易计划和持仓管理。本文只提供条件概率、概念关系与冲突边界。

可运行的概率规则同时写明：

- 当前 market state 与 condition event；
- target event；
- timeframe 与 horizon；
- 增强、削弱、替代和失效条件；
- 与同源 Pattern / Reason 的合并关系；
- 与同一决策时点 Entry、Stop、Target 和 Management 的对应关系。

隔离项保留来源和问题，待讨论项保留待确定的语义。
