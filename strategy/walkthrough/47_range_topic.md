## 方法

与 [49A 走查](49A_day_case.md) 相同：按时间点拆分；Trader's Equation 只记录「具备计算条件」；每个 STRATEGY 时间点固定六列；无 OHLC 时结论只能是「字段可定义」。

## 场景 1：成熟宽区间（47A–B，p799–839）

**T1（区间确认）**：上下腿至少各两腿、充满嵌套两腿结构、约 10–20 根 AIL swing、K 线级证据（小实体、显著影线、重叠）→ 基础状态 trading range（成熟）→ R16–R19 家族。候选集合按边缘证据。

**T2（上下三分之一区）**：上三分之一优先卖、下三分之一优先买（47A p801）；下半部限价买/上半部限价卖（BLSHS，47B p834–839）→ R16（边缘确认 fade，stop-entry 等向下反转/向上反转）或 R17（限价探针）或 R18（边缘第二次信号）。候选集合 {R16, R17, R18}，按入场方式二次判定。

六要素（R16 → [边缘确认 fade](../range/edge_fade_confirmed.md)）：premise=成熟区间边缘突破失败回归；触发=重新入区后反向触发；失效=区间外强 breakout+跟进；stop=失败极值外（容许 overshoot）；target=区间内部价值区；管理=scalp 默认。六项「字段可定义」。R17（[限价探针](../range/edge_fade_limit_scalein.md)）与 R18（[边缘第二次信号](../range/edge_second_signal.md)）同族，「字段可定义」。

**T3（中部）**：中间三分之一无优势（47A p801、47B p836）→ R23（NO_TRADE）。

语境先验核对：80% 突破失败（47B p819–820）、平衡市场约 50% 结果概率（47B p823）与 [区间 README 语境先验](../range/README.md) 一致 ✓。

## 场景 2：第二腿陷阱（47C，p844–858）

**T1（强第二腿上涨）**：看似形成测量缺口并继续测量移动，却很快反转（47C p845–847）→ 检查点「强区间腿与第二腿陷阱」，不按 R20 突破延续逻辑。

**T2（专家反向 / 初学者第二信号）**：专家在强第二腿上涨后前高上方限价卖、弱买信号上方卖，或等阴线/连续低收确认（47C p851）→ R17（限价探针，区间语境）或 R19（真空 fade）；初学者等第二次反转信号（微型双顶/双底）或强反向突破（47C p857–858）→ R18。候选集合 {R17, R19} 或 {R18}，按入场方式与经验层级二次判定。

六要素（R19 → [失败突破回归](../range/failed_breakout_return.md)）：premise=越界后缺乏跟进重新入区；触发=反向触发或真空 fade；失效=突破获接受（回踩守住边界外）；stop=失败极值外；target=内部价值区；管理=scalp。六项「字段可定义」。

## 场景 3：紧密区间 LOM（47B p838–839、47D p883–885）

**T1（紧区间确认）**：空间不足以支撑多数 stop-entry scalp（47D p884）→ R24 语境（等待脱离）或 NO_TRADE（多数交易者）；专家若参与：下半部买空头强势、上半部卖多头强势，宽止损、加仓、小目标（47D p885）→ R17（限价探针，已登记的专家变体边界）。候选集合 {R17}（专家）或 NO_TRADE（多数）。

**T2（平均波动小于成本与合理目标）**：最好不交易（47D p884）→ NO_TRADE。

## 场景 4：区间突破切换趋势（47D p887–888）

**T1（强突破 + 跟进）**：区间策略持续到强突破并有跟进为止；此后停止逆向限价思维，按新趋势和测量移动处理（47D p887）→ R20（收盘跟随确认版，无回踩）/ R21（突破回踩，回踩守住）。

六要素（R20 → [收盘跟随](../breakout/buy_sell_the_close.md) 确认版）：六项「字段可定义」。R21 同族。

- **累积式突破（47D p888）**：突破可由一串较小趋势 K 线逐渐形成（微型通道/连续更高低点），不一定是单根大 K——R20 确认版（连续强收盘或 follow-through）覆盖该形态，无需新行；登记为可发现性说明。

## 场景 5：区间日尾盘回测开盘价（47D p880–881）

**T1（尾盘，开盘价位于区间中间三分之一）**：交易区间日常在尾盘回测开盘价 → 目标=开盘价 magnet（[支撑阻力与目标](../../core/02_context/01_support_resistance_targets.md) 的 opening price magnet），叠加 [尾盘时间风险](../session/late_session_time_risk.md) 覆盖层（R28 语境：剩余时间不足时新 swing 降级，已持仓位按原管理处理）。

登记为检查点：区间日尾盘回测开盘价是 opening price 作为 magnet 的应用，不产生独立叶子（问题 W-11）。
