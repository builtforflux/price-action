# 回放验证：49A 日内案例

> **状态：Strategy / Walkthrough（验证记录，不新增定义）**
>
> 案例来源：`reference/course/49A.md`（PDF 物理页 1070–1091）。本文件沿课程描述的单日状态切换走查矩阵与流程。

## 方法（含限制声明）

- **按时间点拆分**：每个场景按新增证据拆成 T1/T2/T3 子场景；**每个时间点重新运行一次流程**，候选集合只包含该时刻同时成立的候选。先后发生的风险承担时点（首根收盘 → follow-through → 首次回调）不并入同一次 PSEL。
- **Trader's Equation 验证边界**：本案例材料为文本，无真实 OHLC；因此只记录各候选「具备计算条件」（可见 entry 类别、active protective stop 锚点类别、现实 target 类别可定义），**不宣布方程成立**，也不宣布「PSEL 收敛正常」——具体 risk/reward 数值需真实行情数据。
- **兜底终端的证明力限制**：WATCH（R35 等）与 NO_TRADE 兜底能保证任何输入都有终端，但这只证明控制流有出口，**不能证明语义覆盖完整**；语义覆盖由「行映射是否语义正确」判断（见问题清单）。

## 场景 1：强开盘反转进入多头趋势（p1072–1073）

**行情片段**：开盘初始方向反转，随后两根以上大阳线连续收在高位、重叠很少；约 70% 至少完成一倍测量移动；可在强跟进收盘、市价、下一根开盘或约 50% 回调处入场；急速突破后约 90% 会先回调。

**T1（首根强阳线收盘）**：基础状态 trend（spike）；结构进度=首根足够强 breakout bar 收盘、无独立 follow-through。命中 R36（STRATEGY 早期版）。候选集合 {R36}。六要素（[收盘跟随](../breakout/buy_sell_the_close.md) 早期版）：premise=强突破首根收盘承担风险；触发=收盘参与；失效=价格回到旧区域获反向跟进；stop=完整 breakout leg 外；target=第二腿/量度类别；管理=scalp/swing 由强度决定——六项「字段可定义」。

**T2（第二根大阳线收高，follow-through 出现）**：命中 R03（STRATEGY 确认版，无回踩）。候选集合 {R03}。R36 不再是该时刻候选（早期版时点已过，若此前未入场则不能继承早期价格）。六要素（[收盘跟随](../breakout/buy_sell_the_close.md) 确认版）：六项「字段可定义」（与 T1 同页确认版分支）。

**T3（首次回调出现）**：约 90% 先回调；若回调浅且控制仍有效，命中 R01（STRATEGY 首次小回调）。R46 为覆盖行（开盘趋势）叠加于 R01，不产生独立候选（问题 W-01）。候选集合 {R01}。六要素（[第一次小回调](../trend/first_small_pullback.md)）：premise=强趋势首次浅回调恢复；触发=回调末端顺势 signal stop entry；失效=主要结构被反向突破；stop=完整回调极值外；target=最近趋势极值；管理=scalp/swing——六项「字段可定义」。

**裁决**：三个时间点各自候选集合唯一，**PSEL 的方程门尚未验证**（无 OHLC，不宣布唯一叶子）；R46 不参与计数（修复后）。

## 场景 2：强开盘后转为交易区间（p1074–1075）

**行情片段**：昨日强收盘无买入跟进，连续空头 K 线构成「大涨—大跌—大混乱」；交易区间或三角形更可能；多头后续在空头突破失败、大 H2、更高低点处押注趋势恢复。

**T1（大涨大跌大混乱，区间形成中）**：状态不清 → 命中 R35（WATCH fallback；R35 已含「区间形成中/未成熟」别名，见问题 W-02）。候选集合 {R35}。

**T2（区间成熟 + 空头突破失败 / 大 H2）**：命中 R16（边缘确认 fade）/ R18（边缘第二次信号）。候选集合 {R16, R18}；各自方程具备计算条件，多候选时按交易者明确选择的 premise 收敛（本走查以 R16 为例：确认型 stop entry，先看失败确认）。

六要素（R16 → [边缘确认 fade](../range/edge_fade_confirmed.md)）：premise=成熟区间边缘突破失败回归；触发=重新入区后的反向触发（stop entry）；失效=区间外强 breakout+跟进；stop=失败极值外（容许 overshoot）；target=区间内部价值区；管理=scalp 默认。六项「字段可定义」。

## 场景 3：抛物线楔形与连续高潮（p1076–1079）

**行情片段**：连续买入高潮、第三腿衰竭形成抛物线楔形顶；随后空头趋势或区间向下腿；向下突破失败形成双底/三角形恢复；连续卖出高潮后预期至少十根两腿横盘到上涨。

**T1（连续买入高潮、无反向证据）**：命中 R06（WATCH：不逆势）。候选集合 {R06}。

**T2a（楔形三推 + 合格逆势触发，完整 MTR 链未成立）**：命中 R32（STRATEGY 三推楔形反转）。候选集合 {R32}。

六要素（R32 → [三推楔形反转](../reversal/wedge_reversal.md)）：premise=趋势后期三推逆势修正 scalp；触发=反向 signal 等候选证据；失效=强趋势继续第二腿/结构极值被反向接受；stop=三推结构极值外；target=两腿修正（TBTL 仅预写 runner）；管理=scalp 默认。六项「字段可定义」。

**T2b（完整链成立 + 反向触发）**：命中 R30（MTR 早期版，约 40%）。候选集合 {R30}。六要素（[MTR 早期与确认两版本](../reversal/mtr_early_and_confirmed.md) 早期版）：premise=旧趋势失去控制、旧极值测试失败、反方建立 swing；触发=测试失败后的反向 signal stop entry；失效=旧极值被重新接受/原趋势强 breakout 恢复；stop=旧极值测试或完整反转结构外；target=反向两腿 + swing；管理=swing 两版独立计划。六项「字段可定义」。R31 需后续独立时间点（强反向 breakout + follow-through 出现时）再运行，不与 R30 并列。

**T3（向下突破失败形成双底/三角形）**：命中 R26（压缩结构双向候选）。候选集合 {R26}。

**关于「连续卖出高潮后约十根两腿」**：该 TBTL 语境已由 R07 与 [高潮后修正](../reversal/climax_correction.md) 的「TBTL 条件性持有」覆盖，不构成策略缺口；具体课程概率（49A p1079；49D p1161–1163 的约 60% TBTL 属 H4 背景）应归 reference 冲突台账核验后处理，不直接写入矩阵（问题 W-03）。

## 场景 4：强控制中的专家限价卖出（p1080）

**行情片段**：空头明确控制市场时，熟练交易者在前高附近限价卖出，押注弱多头突破和楔形顶部失败；课程标注不是多数交易者的默认方式。

**方向分类修正**：相对 Always In Short，高位限价卖出是**顺势卖出**（仅对局部多头反弹逆向），不是 countertrend（问题 W-04 重构）。

**落点**：标准矩阵无独立行 → 对标准交易者裁决 NO_TRADE（无候选）；该行为登记为「强趋势中的顺势限价卖出（专家入场变体，reference-only 边界）」，见矩阵检查点登记表与 [风险与心理纪律](../../core/06_trade_plan_and_management/03_risk_psychology.md) 的小仓宽 stop 早期参与边界。不新建专家 countertrend 家族。

## 场景 5：跳空高开后区间腿 vs 小回调趋势（p1081–1086）

**T1（缺口保持、回调小、空头无法盈利）**：小回调多头趋势 → 命中 R01（首次小回调）或 R08（趋势延续，若回调已非首次）。**文本不足以区分首次/非首次回调**：课程摘要只确认「小回调趋势」，未确认是趋势建立后的第一次回调；保留 {R01, R08} 未裁决，视觉核验后按「是否首次」定行，不任意选例代替事实。六要素（两页同族）：premise=小回调趋势恢复；触发=回调末端顺势 signal stop entry；失效=主要结构被反向突破；stop=完整回调极值外；target=最近趋势极值；管理=scalp/swing——六项「字段可定义」。

**T2a（昨日高点上方失败突破后首根强空头收盘，无独立 follow-through）**：命中空头侧 R36（早期版）。候选集合 {R36}。六要素（[收盘跟随](../breakout/buy_sell_the_close.md) 早期版，空头侧）：六项「字段可定义」（同场景 1 T1 镜像）。

**T2b（连续空头收低，follow-through 出现）**：命中空头侧 R03（确认版）。候选集合 {R03}。六要素（同页确认版，空头侧）：六项「字段可定义」。R36 时点已过，不能与 R03 并列。

**T3（到均线处出现楔形多头旗形 / H2 / 双底）**：弱反向尝试 → 命中 R12/R32（逆势修正，链未成立）或趋势恢复候选（R01/R08）。候选集合按该时刻证据具体化（本走查以 R32 为例：楔形三推 + 逆势触发，六要素同上）。

**裁决**：按时间点拆分后每个阶段都有落点（R27 → 空头 R03/R36 → minor scalp 或趋势恢复），不构成 P1 缺口；仅登记「组合推导可发现性」提示（问题 W-05，P2）。

## 场景 6：多头趋势后期的衰竭突破（p1087–1089）

**T1（>20 根后全段最大阳线突破通道）**：高潮候选，无反向证据 → 命中 R06（WATCH：不逆势）；首次回落仍可能被买入测试最高收盘 → 同时刻 R01 候选（目标=最高收盘测试）。候选集合 {R01}（STRATEGY），R06 为等待型 WATCH 不否决。

**T2（测试最高收盘失败 + 强空头证据）**：拆成独立证据分支——链未成立 + 合格逆势触发 → R32（六要素同上）；完整链成立 + 反向触发 → R30（六要素同上）；测试失败但尚无触发 → R44（WATCH：等待反向触发）。若课程文本不足以判断触发是否成立，明确落 WATCH/待视觉核验，不并列为 {R32/R30}。
