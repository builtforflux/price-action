# 回放验证：48 时段专题

> **状态：Strategy / Walkthrough（验证记录，不新增定义）**
>
> 案例来源：`reference/course/48A–48K.md`（开盘/中段/尾盘）。走查开盘场景分支（R26/R27/R41/R45/R46）与尾盘时间风险（R28）的交叉验证。

## 方法

与 [49A 走查](49A_day_case.md) 相同：按时间点拆分；Trader's Equation 只记录「具备计算条件」；每个 STRATEGY 时间点固定六列；无 OHLC 时结论只能是「字段可定义」。

## 场景 1：开盘三条路径（48A–B）

**T1（开盘）**：直接延续 / 双向试探后突破 / 测试关键位后反转——三路径需在进展中更新，非开盘前预判（48B）。命中 OPEN 分支：

- 双向试探后突破 → R26（BOM/压缩双向候选，等表态）；
- 离开 opening-range 边界并获接受 → R41（开盘区间突破）；
- 测试关键位后反转（早段时间窗口 + 关键位置测试 + 反转证据）→ R27（Opening Reversal，WATCH 直到底层 premise 可判定）；
- 开盘即趋势 → R46 覆盖行（叠加于 R01/R03）。

候选集合按路径收敛。六要素（R41 → [开盘区间突破](../breakout/opening_range_breakout.md)）：premise=离开明确声明的 opening-range 边界并获接受；触发=越界事件 + 接受证据（收盘/跟进/未快速收回）；失效=快速回到开盘范围获反向接受；stop=突破 leg 结构外；target=开盘量度或前高前低；管理=scalp/swing 依强度与剩余时间。六项「字段可定义」。

**T2（H/L 计数，48B）**：重复突破尝试组织为第一/二/三次入场；更高次数对应双顶/双底、三角形或楔形 → R08/R18（第二次信号）相关行，六要素同族「字段可定义」。

## 场景 2：Opening BOM 成熟判定（48D）

**T1（BOM 确认）**：测试开盘首根两侧、短期多空概率接近 → R26 + R45（Opening BOM 覆盖层）。开盘区间需足够时间和高度才有稳定测量意义；太短太紧的区间更像 LOM（48D）→ R26 语境 + R17（限价探针）。

**T2（首破）**：首破可信度低、突破方向只提供条件概率（原区间另一侧较可能保持，48D）→ R26 等表态；获接受后转 R20/R21。

first-18 heuristic 边界（48D）：第 18 根是近似窗口不是神奇数字——与 [时段覆盖层](../session/README.md) 声明一致 ✓。

## 场景 3：昨日高低点测试与 Opening Reversal 时间边界（48E）

**T1（测试昨日高低点）**：首次越界≠突破成功≠必然反转 → R27（需早段时间窗口 + 位置测试 + 反转证据组合）；相同图形太晚只能称普通反转或 MTR（48E）→ 不能借用 Opening Reversal 早段语境。

**T2（第二次反转信号）**：两次尝试突破关键位仍未获持续跟进 → R18/R08（第二次信号）或 R27 升级路径。

## 场景 4：日中状态转换（48G–48H）

**T1（开盘趋势 → 日中区间）**：趋势进入足够长区间后原趋势先验衰减 → R15（转换证据）/ R35（状态重判）；区间腿反转可从一根普通中等 K 线开始（48G）→ R16–R19 家族。

**T2（区间 → 强突破）**：强突破与跟进出现后反转思维停止（48H）→ R20/R21（突破家族）；主要趋势反转或强反向突破出现前顺势优先 → R30/R31（若链成立）。

## 场景 5：尾盘（48H–48K）

**T1（尾盘关键位测试）**：三类结果（围绕关键位小区间 / 向上突破收高 / 向下突破收低）由反应和跟进确认（48H）→ R28 覆盖层（时间约束）+ 突破/区间按证据分类。强 K 线在区间背景关键磁点附近可能只是真空和陷阱 → 检查点「强区间腿与第二腿陷阱」。

**T2（尾盘 BTC/STC）**：有限时间快速到达支撑阻力的高潮过程，磁点到达后理由消失（48J）→ R28 + climax 语境（R06/R07 检查）；识别延迟消耗有效窗口 → 严格限制入场次数与持仓时间（R28 语义）。

**T3（弱通道尾盘形成）**：最后一小时反转后形成的通道更像临时区间腿，不按趋势延续（48I）→ R35/区间行，叠加 R28。

**T4（高周期磁点）**：日/周/月关键位提供目标，低周期突破/反转/跟进提供入场（48K）→ Trade Plan 层多周期分工（与 W-08 同类，登记可发现性说明）。开盘价既是均衡参照也是尾盘回测位置（48K）→ W-11 已登记。
