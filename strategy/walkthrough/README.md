> 本目录用课程真实案例沿「矩阵行命中 → 候选集合 → PSEL 裁决 → 策略页六要素」完整走查，验证覆盖矩阵与决策流程图在真实行情片段上能否收敛为唯一叶子、六要素是否可执行。它不新增定义，不修改矩阵；发现的问题登记在各案例文件的问题清单，并在文末汇总。

## 记录规则

- 只使用案例中明确描述的可观察事实；推断与案例原文分开标注；
- **按时间点拆分**：每个场景按新增证据拆成 T1/T2/T3 子场景，每个时间点重新运行一次流程；先后发生的风险承担时点不并入同一次 PSEL；
- 每个时间点记录：行情片段 → 判定字段 → 命中行 → 候选集合 → 所选页六要素「具备计算条件」检查；
- **Trader's Equation 验证边界**：无真实 OHLC 时只记录「具备计算条件」（entry/stop/target 类别可定义），不宣布方程成立；
- **兜底终端限制**：WATCH/NO_TRADE 兜底只证明控制流有终端，不证明语义覆盖完整；语义覆盖由行映射正确性判断；
- 问题分两级：`P1`（矩阵/流程结构缺陷）、`P2`（可发现性/登记类），修复后在本目录标记状态。
