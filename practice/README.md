# 训练与实盘运行

默认练习是在 TradingView 回放中随机选择历史起点，只使用当时可见信息，逐步向前模拟完整交易；记录当场疑问，结束后复盘。本页安排回放、模拟与实盘的准备、记录和检验。[Trading System](../trading_system/README.md)定义完整交易链路，练习直接使用这些规则。

## 一、共同运行原则

回放、模拟和实盘中的每笔交易，都按[核心闭环](../trading_system/README.md#核心闭环)完成市场判断、机会与方案评价、账户检查、执行核对和后续管理，并按实际结果复盘。学习重点与记录详略可以不同，必要的判断和执行要求不因练习目的而省略。

完整思考可以沿用已经核实且仍有效的背景、参数和方案，只更新受影响部分；未使用的参与或管理方式无需全部展开。本次依据、是否值得、允许过程、改判条件和执行安排仍须明确。关键依据不足时，等待或放弃。

识别机会、等待、错过和没有交易都是练习内容，不要求先找到某种形态才开始。可以事前限定参与范围，但不能据此挑出后来出现该类机会的日期。正式检验沿用同一连续过程，另在开始前固定验证对象、取样、速度、暂停条件和必要证据；结论限于覆盖范围。

针对具体片段的复习在连续练习后进行，保留原记录并标为已知材料。它帮助理解问题，不代替未知窗口中的完整交易练习。

- 每根 K 完成 → 观察新事实，更新受影响内容；可靠判断、共享事实和未变管理沿用。
- 日历换日、上线或值守结束 → 按市场自身时间结构接续判断，不自动重置。
- 竞争解释或参与方式会影响当前选择 → 展开比较；其余不必展开。

## 二、运行闭环

### 1. 低频准备

首次使用或产品、账户、数据源、版本变化时完成准备；每次练习核实这些设置仍适用：

- 产品、数据源、主周期、K 线构造和会改变判断的外层周期；
- tick、数量步长、合约价值、费用、滑点和数据或维护边界；
- 若使用 `R`，固定 `1R` 的计算时点、全仓计划损失口径和成本处理；建仓后不因移动止损或事后路径改写该分母；
- 账户硬限制及 [Account 低频平台检查](../trading_system/account.md#五低频平台检查)；
- 系统版本、生效时间、适用产品及本次学习重点或验证对象。

参数、惯例与版本共享引用，变化时更新。成交与成本依据按运行方式选用：回放可用事前固定假设；实时模拟和实盘以平台记录为准。

可固定一个机会族、一种参与方式和简单管理基准，初期据此练习，熟练后也可继续采用。连续窗口中遇到范围外机会，仍观察并明确不参与原因，不必构造所有方案。扩大参与范围或增加管理方式时，按本次验证目的与原基准比较，计入成本、回撤和运行负荷；具体按[批次复盘](#批次复盘)处理。

比较不同方式时，先判断材料用途：

| 条件 | 动作与证据边界 |
| --- | --- |
| 尚未读取未来，准备检验效果 | 固定对照方案；使用各自当时价格，计入未成交、重入、成本与运行负荷 |
| 已看过后续 | 用于学习或设计；经济检验另取未知窗口 |
| 按事前完整规则复算已知窗口 | 结果另记“规则回放” |

### 2. 盘中运行导航

盘中按[核心闭环及事件导航](../trading_system/README.md#核心闭环)接续当前判断与执行。遇到判断困难时按本次暂停规则查运行文档，留下当场疑问，结束后回到相应规则页复核；记录按[最小记录](#五最小记录)，不重复转写运行卡。

## 三、历史回放

### 取样

先固定品种、主周期、可用历史日期范围、计划交易时段和本次窗口长度，再从范围内随机抽取起点。固定值守者只在值守时段内抽取。按日期与时间抽取，不先浏览走势图寻找“适合练习”的位置，也不根据后来有无机会、行情是否顺畅更换起点。

起点应有足够的此前数据建立背景，并有覆盖预定窗口的后续数据；数据可用性等排除条件事前确定。抽到明显记得后续的片段，或设置回放时意外看到了未来，记录暴露范围并标为已知；另按原抽取规则取未知窗口，不把重播结果计入未知练习或正式检验证据。正式计划内的受影响窗口保留记录并报告证据缺口，不静默剔除。

### 在 TradingView 中连续回放

1. **建立回放起点**：按抽到的时间进入回放，确认判断所用图表只展示截至该时点的信息；不先看完整走势再退回起点。补充周期或历史时，也只能使用截至回放时点已可见的数据，不能读取高周期 K 后来才形成的最终值。
2. **建立初始判断**：用起点及此前可见内容识别状态、位置和双方成果。起点可能处在一段运动中间；依据不足就继续观察，不要求恰好从形态起点开始，也不补做起点前的交易。
3. **逐步向前**：初期逐根推进，每次先形成当前判断与决定，再看下一根。机会在过程中识别；有完整且合格的方案才按设定的成交规则模拟参与，无机会则等待。不能跳到下一处已知信号，也不回退重做或改写先前决定。
4. **完成交易链路**：参与、保护、持有、调整、退出和订单核对沿同一套规则执行。回放中的成交与费用采用事前固定假设，并保留模拟记录；图表触价不直接作为真实 Broker 成交证据。
5. **按窗口结束**：不因没交易或短期亏损提前换样本、延长窗口。到预定结束点停止新建仓；若仍有仓位或可能成交的订单，按有效方案继续管理至本笔结束，并单列窗口后的延续处理。
6. **复盘并保留片段**：从自己的当时记录中找出疑问、遗漏或处理困难的位置，再回看相关过程。下一次检查是否学会，使用新的未知窗口。

同根 K 含止盈与止损、无法确定先后时，记“先后未知”；若采用保守代替规则，须事前固定并一致用于全部样本。不能用后来已知的走势补造盘中顺序或早先成交。

### 速度与进度

| 情况 | 怎样推进 |
| --- | --- |
| 连续练习需要查规则 | 可暂停，熟练后逐步减少暂停；回退学习的部分按已知材料处理 |
| 正式检验 | 遵守事前速度与暂停条件；暂停部分不作实时节奏证据 |
| 加速回放 | 只压缩等待，不缩短路径、交易或数据可靠性期限 |

连续练习与正式检验按预定窗口推进。不设每日笔数门槛或目标区间；零笔、少量或大量交易都如实保留，不为凑数延长训练、挑行情或降低标准。笔数不能代替观察时间、机会覆盖或学习效果。

### 练习后的片段复习

案例从刚完成的连续过程及其记录中产生：选出当时看不懂、判断有分歧或执行困难的位置，回查 Market、场景、Trade、Account 中的相关依据，并按 Governance 定位偏差或规则缺口。不要求事先正确识别形态，也不为找到同类案例去筛选下一次练习日期。

可以回退、暂停和比较不同解释，但保留首次判断，将复习明确标为“已知／学习”。对照的是当时依据与条件，不用后来涨跌倒推正确答案。不同范围的片段不拼成一份完整交易成绩，复习结果也不覆盖原样本。

下一次仍随机选取未知历史起点，连续向前。此前的问题可以成为关注重点；若没有再次遇到相应机会，就如实保留，不挑行情补足。方法效果按[批次复盘](#批次复盘)检验。

## 四、实时模拟与实盘

### 实时模拟

实时模拟不再压缩时间，用于验收：

- 等待下一可靠事实时能否保持空仓；
- 订单提交、撤单、替换、部分成交、止损覆盖和残余订单核对；
- 数据、连接或平台记录不清时的安全动作；
- 个人值守结束前的未成交订单和已有仓位处理。

模拟成交用于验收执行流程，不证明真实滑点、排队、拒单或平台能力。

### 实盘

实盘不设最低交易笔数。市场产生的合格方案可以是 `0` 笔或多笔；数量目标不得降低路径、交易或账户标准。

实盘开始前确定值守开始、停止新建仓、值守结束，以及届时对未成交订单、实际仓位和平台实际止损的确定性处理。离开时仍保留仓位，须有建仓前已验证的无人值守方案；不得临时决定。

从实时模拟进入实盘时，先限定可承担的学习损失、观察期限、复核时点及停止或退回条件：

- 最小可执行数量仍超过学习预算 → 继续模拟。
- 可以承担最小数量的学习风险 → 按[晋级条件](#晋级与退回)以最小可执行数量开始实盘；这不表示方法已证明盈利。

最小实盘检验：

- 真实成交、费用、滑点和订单限制是否与方案相容；
- 实际资金是否导致追价、提前退出、放宽止损、计划外加仓或报复交易；
- 账户硬限制、实际仓位和平台实际止损能否持续正确核对。

| 触发条件 | 动作与下一步 |
| --- | --- |
| 达到学习损失或期限边界 | 停止新增风险，终止未成交的建仓、加仓授权；由 Account 撤单、核对迟到成交，按既定退出和保护方案处理余仓，再复核是否退回模拟 |
| 任一情况：违反账户硬限制；止损覆盖或平台记录无法可靠核对；实际成本或执行明显破坏方案 | 停止新风险，按 Account 处理已有风险，回到上一已验收数量或模拟 |
| 准备增加数量 | 同时通过[执行能力与经济表现验收](#晋级与退回)；不得靠加量弥补学习亏损 |

## 五、最小记录

交易的必要判断与执行始终完整，留痕按下表取用；已有参数、惯例和可靠记录直接引用。记录简短不表示可以省略思考，片段复习只保留所研究范围的证据，不替换原交易记录。

| 何时 | 留什么 |
| --- | --- |
| 日常练习 | 学习重点、关键改判及当场困惑与错误；用时间点、图上标记、短语或语音，不逐次转写完整卡 |
| 完整检查 | 看结果前选定少量过程或抽取规则，保留当时判断与后续；自选难例只能补充 |
| 正式检验 | 按事前验证对象保存必要证据；计划内缺失单列，不事后剔除 |
| 实际平台执行 | 完整保留授权及变更、订单、成交、仓位和保护记录 |

无完整记录表示无法据此复核，不推定未思考、合规或违规；比率分母与覆盖说明见[每日复盘](#每日复盘)。

### 观察窗口记录

- 进入窗口或完整重判 → 建立依据。
- 新事实影响判断 → 更新受影响内容；方向未变也处理回撤加深、恢复变慢等变化。

需留痕的事件可写：

```text
时间 | 新事实 | 改变的判断 | 当前动作
```

### 每笔交易记录

完整评价一笔交易时汇总一行，链接当时判断、方案变更与执行记录；普通练习只补需反馈的关键差异：

```text
ID | 产品 | 时间 | 方向 | 入场 | 止损 | 计划出场 | 期限 | 计划 R | 实际 R | 退出结果 | 执行合规 | 最早偏差
```

结果仍按[Governance](../trading_system/governance.md#一复盘时分开四个结果)分开：

```text
Market：待定 / 实现 / 失效 / 到期 / 先后未知；停止采用和未继续评价另记
Trade：止盈 / 止损 / 主动平仓 / 到期 / scratch / 分批出场 / 无成交
Account：实际成交 / 费用 / 滑点 / 持有成本 / 净结果
Process：判断 / 方案 / 风险 / 仓位 / 执行是否合规，以及最早偏差
```

窗口记录连接相关退出、重入、未成交和未参与机会：

- 评价经济表现 → 保留整段成本与决定。
- 记录未参与 → 只记当时理由和可见条件；无事前对照方案，不补算假想收益。
- 需要截图或长复盘 → 只展开少数有反馈价值的样本。

### 路径后续评价范围

已记录的预测不改写；后续处理按条件执行：

| 路径情况 | 处理 |
| --- | --- |
| 当前采用 | 随新事实及时核对，不以是否交易为前提 |
| 正式检验计划内对象 | 按事前覆盖继续结算；缺失如实报告 |
| 事前选定追踪结果的预测 | 继续结算 |
| 其余已不影响动作、尚无结果的旧路径 | 保留原条件及停止采用的时间、原因，可标“未继续评价” |

“未继续评价”不是市场结果或数据先后未知，不计实现率。正式检验仍按事前覆盖结算，不能借此剔除计划内样本。

## 六、复盘、批次与晋级

### 每日复盘

- 日常练习 → 总结学到什么、最常见偏差和下次重点；有相应记录的内容按需汇总。
- 正式检验 → 按事前评价范围报告。

汇总内容：

```text
交易笔数 / 等待 / 放弃 / 无成交
成本后净结果 / 净 R / 费用 / 权益回撤 / 最大连续损失
授权前方案完整率 / 执行合规率
最常见的最早偏差
```

| 记录情况 | 怎样评价 |
| --- | --- |
| 样本能够复核 | 可计入完整率、合规率；同时报告抽取范围、覆盖量及缺失 |
| 无完整记录 | 不进入这些比率的分母，不据此判定合规或违规 |
| 正式计划内记录缺失 | 报告证据不足；不得剔除后将剩余比率当成完整验收结果 |

每天只选少数有信息增量的连续过程深度复盘。按实际出现且有证据的类别选取：合规盈利、合规亏损、获利但违规、重复偏差或无法解释。

复盘退出与重入时，检查减少的风险、整段成本，以及错失或多余操作是否来自可修正决定。赚钱不自动证明判断和执行正确，亏损也不自动证明市场判断错误。

### 批次复盘

开始前按目的准备：

| 目的 | 准备与后续 |
| --- | --- |
| 日常练习 | 汇总连续窗口中的重复偏差，确定复习问题与下次关注点；下一窗口仍按原范围随机抽取，不要求经济结论 |
| 正式验收或方法效果比较 | 固定验证对象、系统版本、能力范围、连续窗口长度与取样范围、必要证据及先后未知处理 |
| 涉及经济表现 | 另固定管理基准、成本假设、风险收益目标、评价与停止条件 |

正式批次按预定窗口完成：不因笔数、短期盈亏或期望结论增删样本；触发停止条件的批次也保留并说明。

验证对象按 [Governance 方法变更](../trading_system/governance.md#三方法变更)选定：

- 整套裁量 → 固定执行者及选择惯例，包括同类条件下的参与、持有、调整和例外依据；只评价该执行者、版本与范围的整体表现。
- 单项新增判断 → 固定采用与不采用它的完整方案，使其余选择和风险条件可比；不能分离影响时，只评价整体方案。

探索与检验分开：

- 形成或修改惯例、比较方案 → 可复习已完成窗口中的片段，记录改变及依据；这些已知材料用于探索，不与固定方案后的未知窗口混算同一版本证据。
- 检验固定方法 → 另取执行者未知的连续窗口，按事前范围取样；按既定惯例响应新事实仍属正常裁量。
- 涉及账户与执行 → 始终遵守当时有效的安全边界。

汇总结果时：

- 同一行情多次进出 → 按完整窗口或相关过程汇总成本后结果、回撤与机会处理，再比较窗口差异；笔数与连续时段共同报告，重入不算独立证据。
- 少数行情贡献大部分收益、未覆盖计划时段或成本假设不可靠 → 降低对结果的信心。
- 用旧样本修改了方法 → 另取固定方法后的新窗口检验；旧样本不能单独支持加量。

批次结束后按 [Governance 的复核顺序](../trading_system/governance.md#一复盘时分开四个结果)定位最早偏差或证据缺口，再选择处理：

| 问题 | 处理 |
| --- | --- |
| 规则清楚，但未遵守 | 通过训练纠正执行偏差 |
| 信息难调用、记录重复或表达无助于选择 | 检查表达、组织或记录义务，按 Governance 验证调整 |
| 同类条件下反复出现判断、参与或管理问题 | 按 Governance 比较方法调整 |

涉及规则、组织或记录义务的修改均按 Governance 选择验证；新版本只影响生效后的判断，不改写旧样本。

### 晋级与退回

```text
历史回放
→ 实时模拟
→ 最小可执行数量实盘
→ 事前定义的分级数量
```

晋级使用正式检验证据：批次开始前写明评价基准、证据需求、不确定性及停止或退回条件；已知片段的复习和记录未覆盖的过程不能替代验收。

**历史回放、实时模拟准备进入下一阶段 → 核对执行能力。** 进入最小实盘还须满足上述有限学习条件：

- 当时判断、交易方案和记录可以复核；
- 不通过偷看、事后改写、挑选样本或重复名称美化结果；
- 授权前方案完整率和执行合规率稳定，且没有账户硬限制违反；
- 订单、实际仓位和平台实际止损可以持续核对；
- 实际成本、执行能力和运行负荷不会破坏方案或仓位安全。

**准备增加数量 → 执行能力之外，再核对经济表现。** 证据须来自固定版本、事前约定的连续窗口：

| 检查项 | 需要满足 |
| --- | --- |
| 成本后表现 | 计入真实费用、滑点、持有成本及整段退出重入后，净表现支持增加风险 |
| 可承担损失 | 回撤、损失持续时间及各窗口表现符合事前范围；少数有利行情依赖已纳入不确定性评价 |
| 新增管理 | 相比事前简单基准，按风险收益目标有所改善，并计入新增成本与负担；未用复杂操作时直接评价基准 |
| 用部分净收益换取低回撤或稳定执行 | 改善足以支持取舍，仍满足净表现与风险底线 |
| 适用范围 | 成本与成交差异、窗口依赖及未覆盖行情明确；增加后的数量与执行条件仍相容 |

不设通用胜率、固定笔数或收益阈值；基准与风险限额在看见批次结果前确定。一次盈利或若干合规批次不替代经济验收；模拟收益只提供候选证据，真实成本和执行学习仍须完成。

按结果决定下一步；增加后继续按同一边界复核，不直接外推旧数量表现：

| 条件 | 动作 |
| --- | --- |
| 持续成本后净亏、回撤超出预定范围或证据不足 | 不增加数量 |
| 任一安全边界不成立、稳定执行明显退化或触及事前经济停止条件 | 停止新增风险，安全处理已有订单与仓位，退回上一已验收数量或模拟 |
| 证据不足，但未触及停止条件 | 保持当前数量，按事前计划继续取样 |
