# 市场判断：从当前表现到预期与机会

## 一、市场判断的主线

结合市场状态、重要位置和尺度，比较双方能否推进、保住进展并在回调后恢复，据此形成后续预期。新事实出现后，对照原预期，更新受影响的判断，并明确下一观察。

市场状态提供此前延续、回调或双向波动的背景，重要位置提供当前运动的参照；当前运动也可能改变状态判断和区域作用。首次分析从可见事实建立判断，后续沿用仍有效的依据，检查当前问题是否已经改变。

| 概念 | 用途 |
| --- | --- |
| 市场判断 | 解释当前表现及其在趋势或区间中的意义 |
| 预期 | 说明接下来期待什么、允许怎样的回调或停顿，以及改判条件和复查时间 |
| 条件路径 | 将需要评价的预期明确为目标、成立、完成、失效条件和期限，用于比较空间与核对结果 |
| 交易前提 | 本次参与或持仓依赖的具体表现，由 [Trade](trade.md#33-交易前提路径失效与保护性止损)确定 |

预期尚无明确目标时，可以继续观察；实际授权前须有完整条件路径。局部恢复偏弱可以削弱预期，同时仍处于本笔允许的回调范围；是否改变动作由 Trade 核对交易前提和当前交换。入场、退出或目标完成后，市场判断继续；原预测按原条件评价，当前认识随新事实更新。

## 二、运行卡

首次或重建判断按本卡；已有可靠判断时，先按[普通更新](#42-普通更新)核对新事实与原结果，再接续本卡受影响部分。背景不清时查[场景](scenarios.md)，参与构造按[交易交接](#五交给交易决策)进入 Trade。留痕按[最小记录](../practice/README.md#五最小记录)，已有依据直接引用。

### 1. 市场判断

1. **确认观察范围**：品种、图表周期、K 线构造、数据来源和最新可靠时间。数据不足按[数据规则](#33-数据可靠性)限制结论。
2. **确定当前问题**：识别市场状态、重要位置和当前运动，回看运动起点及仍起作用的区域。已有判断时，检查位置或结构变化是否改变了所研究的问题。当前图不能解释时，补充相关历史或周期；仍不清楚则说明缺项。
3. **形成当前判断**：结合位置与尺度，比较双方本次及此前相关尝试的推进、保留和恢复，说明各自做成了什么、未能做成什么；已有预期时说明新事实符合或偏离了什么。据此解释延续、转向或平衡的依据及主要反证。

区域注明价格带、来源、周期和当前作用；未注明周期时继承主周期。按此前反应与当前作用选择，距离最近的线未必最重要。

### 2. 预期与机会

1. **形成预期**：采用较有依据且未被反证否定的解释，说明为什么期待后续走势，允许怎样的回调或停顿，什么表现会削弱或否定预期，以及最迟何时复查。需要评价的局部测试事前确定成功与失败条件。
2. **保留必要分歧**：不同解释有依据且会改变判断或机会时，比较它们期待的后续，找[区分条件](#36-区域互动与预期更新)。双方都缺少持续性或事实暂时无法区分时，说明等待什么；新平衡或结构改变当前问题时，重选相关解释，不强定方向。
3. **寻找参与位置与条件**：根据当前运动和区域，研究现在或下一处哪里可能参与。未来条件仍是假设；一种后续表现可能形成机会时，也可先研究条件机会。
4. **需要比较空间时展开路径**：补齐有依据的目标、沿途障碍、成立、完成、失效与期限，只展开会改变选择的路径。目标等依据不足时保留缺项，不为补齐方案而外推。

有机会想法即可交 [Trade](trade.md)继续研究，实际授权仍需完整路径与交易方案。

当前判断、机会或等待条件、下一观察及复查时间已明确，即可结束本轮市场分析。保存下一轮所需的判断与条件；需要留痕时记录判断时间、当时最晚可见数据和变化部分。持仓、订单与执行查询继续按 Trade、Account 管理。

## 三、判断规则

按当前问题查用，综合表中适用的依据，无需逐项遍历。围绕位置、推进、保留与恢复，解释相关事实怎样支持或改变预期，保留有用的尺度和事件次序差异。确定结果前核对对象、尺度与原条件；条件不明记为不足，不能当成“不成立”。

回撤加深或恢复受阻时，查[回撤与恢复](#回撤与恢复怎样改变原判断)；到达重要边界时，查[区域作用是否改变](#边界处是否改变此前作用)。沿当前问题对照[预期差别](#由表现更新预期)，接续机会。背景怎样改变正常表现见[场景](scenarios.md)；几何、计数或测量不清时查[判定参考](#六术语与判定参考)。

### 3.1 事实、关系与判断

| 使用的内容 | 怎样表达 |
| --- | --- |
| 价格、时间、成交资料、修订及确定性计算 | 作为源事实，保留来源 |
| 区域、Swing、线、Gap、重叠、越界、回试 | 作为选定尺度和参照后的可复核关系；保留运动与锚点的选择依据 |
| 控制、阶段、相对优势 | 作为对事实关系的概括，说明实际比较了什么；名称本身不是新事实 |
| 未来的发展 | 作为预期，说明当前依据与尚待发生的条件 |
| 交易者身份、持仓或动机 | 标为推断，不冒充可见事实 |

使用 Trapped、Disappointment 或 Pain Trade 时，列出可见的事前预期、失败、跟随和空间依据；交易者身份、持仓与动机仍属推断。

**怎样从知识形成判断：**先说明比较了什么，再说明它为什么影响当前预期。不同知识提供的依据各有边界：

| 所用知识 | 提供的关系 | 怎样进入判断 |
| --- | --- | --- |
| K 线、位移、重叠与 Gap | 某次运动推进多少、哪些进展仍被保留 | 与此前相关运动及对方尝试比较；单次强推进不独立证明持续能力 |
| 回调、测试与恢复 | 反向挑战收回了什么，原方向能否继续 | 对照原来容许的幅度、时间与恢复要求，区分正常过程、受损和失败 |
| 突破、拒绝与接受 | 价格是否改变原区域的限制，改变能否维持 | 在当前尺度研究界内或界外发展；已完成的局部事件不替代更大路径结果 |
| 形态与计数 | 同一过程中的几何、尝试次序或结构关系 | 保留独有信息；名称重合不增加证据票数 |
| 比例、测量与时间经验 | 候选位置、运动尺度或条件性参照 | 计算可复核不代表目标可达；经验适用性按背景核对 |

这些关系组织观察，不证明特定订单流或参与者动机。预期所增加的未来主张须有自己的条件依据；当前无法区分的解释可以保留。形成参与选择后，再由后续事实与连续结果检验哪些判断有贡献，见 [Governance](governance.md#四知识进入方法前先拆清楚)。

**多个理由怎样合并：**

- 只是给同一事实重复命名 → 共享一次事实，不增加证据票数。
- 补充了位置、次序、进展或跟随信息 → 保留该增量；相关关系也可能有用，无需先证明统计独立。
- 新事实改变了某项比较 → 更新引用它的预期、路径或边界，保留各自条件与后果。
- 使用 Volume、DOM、新闻或情绪资料 → 说明它提示的流动性、尾部风险；用于方向判断时，仍须连到价格进展与当前预期。

标签或理由的数量不能换算为概率。名称的独有几何、次序和重置条件见[术语与判定参考](#六术语与判定参考)。

### 3.2 观察边界与多周期

观察边界指定图表、K 线构造和当时可见历史；窗口覆盖当前互动、尝试起点、重要结构，以及所用路径的目标、失效和期限。

图表注明使用成交价、Bid、Ask 或中间价；其触价事件与订单触发、成交的对应由 [Account](account.md#五低频平台检查)核实。引用高周期 EMA 时，使用该周期价格序列按指定参数计算的值；低周期长周期 EMA 只能作为注明算法的近似，不能仅按周期倍数换算就当成同一条均线。高周期尚未完成时的 EMA 是临时值，保留当时时点，不以最终值回填。

**使用什么事实：**默认使用完成 K；事先允许的盘中价格事件已发生 → 注明时点。未完成 K 的形态仍标为暂时事实。

**补充哪些背景：**符合当前问题的分别使用。

- Session 改变流动性、目标可达性或期限 → 展开相应时间结构；连续交易产品按自身结构处理。
- 外层周期影响本次判断 → 指明它改变哪项正常回撤、目标、失效、空间或期限。
- 低周期提供更细的参与事实 → 保留低周期范围，不改写高周期已记录的结果条件。

高周期影线保留价格曾到达并在收盘前离开极值的信息，但 OHLC 不包含极值先后、途中反复或完整低周期结构。需要这些过程区分解释时，查看当时可得的低周期数据；未查看时只保留可能解释，不把影线直接记成已观察的低周期失败突破或三推。

使用事先允许的形成中突破事件时，比较价格是否持续停留在推进端、回吐后能否迅速恢复，还是反复失去进展。单次深回吐与多次较浅回吐分别记录，不能从最终影线反推路径；采用比例时固定当时范围与测量时点，不用最终 K 线高度回算早先强弱。

区域、运动和路径各自绑定周期。不同周期不能共享目标、失效或期限 → 分别说明；Trade 明确采用哪一判断，其他周期作为支持或约束。

### 3.3 数据可靠性

先核对来源与事件；有以下情况时处理相应部分：

- **来源修订** → 保留原记录，从最早受影响处重判，注明修订改变了什么；可用范围仍按下表核对。
- **未完成 K，且该事件未获事先允许** → 等待完成后再使用该事实。

再判断数据对当前问题的影响：

| 数据情况 | 处理 |
| --- | --- |
| 可靠 | 正常判断 |
| 缺失区间能证明不影响当前问题 | 写明限制，使用仍可靠的事实 |
| 缺失影响必要事实，或影响无法判断 | 标明受影响结论不可用，保留最后可靠判断与时间，等待数据恢复或既定复查时点 |

数据不可用时，Market 不以猜测形成新结论；向 Trade 提供受影响范围和最后可靠时间，由 Trade 按方案的可靠性期限处理订单与持仓。

### 3.4 市场结构与持续能力

强弱与快慢均相对此前相关运动判断，并结合当前位置和后续表现。“控制”概括某方向持续延伸、回调后继续的能力。以下是比较依据，不能命中单项就确定状态。

双向比较核对双方尝试的成果：推进显示已取得的运动，保留显示进展未被收回，恢复显示回调后仍能继续。对手尚未出现有意义尝试，与对手尝试后失败提供的信息不同；是否算未能做成，仍对照事前预期和允许的波动。无需先等完整对抗序列才形成判断，已完成事件按当前背景评价。

己方受损不直接证明对方有持续能力；对方未成功也不独立证明己方值得参与。不同方向的运动按各自位置、尺度和目标研究，实际参与由 Trade 用当前价格比较。交易者身份、持仓与动机按[事实与推断](#31-事实关系与判断)处理。

#### 当前市场状态

| 已有表现 | 当前判断 | 接着核对 |
| --- | --- | --- |
| 价格持续创新高（或新低），回调后继续原方向运动，逆向运动有限 | 该侧仍在控制 | 下一次正常回调后能否继续恢复 |
| 价格反复涨跌，突破边界后难以在外延续 | 双边平衡 | 边缘能否继续拒绝，或出现外部接受 |
| 原趋势受损，反向运动尚不能持续 | 转换未完成 | 原趋势能否恢复，反向运动能否延伸并在回调后继续 |
| 事实不足或解释冲突 | 保留具体不确定之处 | 哪项后续表现能区分解释 |

趋势与区间可以在不同尺度共存。Always In 概括清楚的方向判断。改称 Breakout/Spike、Tight Channel、Broad Channel 或 Trending Trading Range 时，说明宽度、回撤、重叠及恢复能力实际改变了什么。

需要分清方向偏向与目标远近的影响时，可比较从同一现价向上、向下等距离哪个更可能先到；距离与观察期限须明确，更换尺度后重新判断。实际参与仍用所选目标、保护和成本，不把等距方向判断当成该方案的盈利概率。

#### 逆向运动是否已经具有持续空间

空间比较先固定对象：通道看逆向回调幅度，区间看总高度及内部摆动，再与同尺度的近期平均棒幅比较。Trade 另从实际或计划入场计算至目标的剩余空间，核对保护与成本；等待确认可能消耗原有空间。几何上较宽不保证当前交易合算，限价改善入场也不保证空间足够。

| 比较结果 | 对预期的影响 |
| --- | --- |
| 逆势越过信号边界后反复走不远，原方向很快恢复 | 更支持紧密通道中的延续 |
| 逆向运动在幅度、时间上更能持续，并提供较大空间 | 更支持双向交易；重新评价原方向回调与恢复预期 |
| 历史逆向机会有空间 | 只作为当前预期的依据；Trade 仍按当前入场、目标、止损和成本比较 |

成熟区间的依据是双方都曾形成有意义的方向运动，却反复无法持续离开共同区域，边界在返回和再测试中继续发挥作用。局部强上涨、强下跌可以与整体平衡并存；单向推进中的多次小回调不等于同尺度的成熟双边过程，不按固定段数或棒数确认。

#### 哪些事实足以改变结构判断

成熟趋势仍可发展，稳定区间也可包含局部新失衡。当前运动按[区域互动](#36-区域互动与预期更新)继续判断；采用下列结构概括时，核对相应依据。

| 准备采用的判断 | 核对依据 |
| --- | --- |
| 趋势成熟 | 结合此前持续扩展或长期缺少实质回调、接近旧极值/目标/通道外侧，以及异常延伸、恢复变慢或双向化；成熟程度仍为定性判断 |
| 区间成熟 | 本次到达前已有可识别边界、双方反复测试，且缺少持续外部接受 |
| 主要结构破坏 | 事前所依赖的主要 HL/LH、趋势段或有效边界被越过，且界外进展被保住 |
| 只有影线、趋势线穿越或普通反色 K | 通常先视为受损，不能单凭它宣告主要结构破坏或控制转移 |
| 已有反向 Swing | 承认反向运动；持续控制转移仍须核对反方后续延伸与正常回调 |
| 强背景与足够强的完成事件共同支持改变控制判断 | 可以及时更新，无需统一等待固定根数 |
| 事实较弱或相互冲突 | 等待能补足判断的跟随 |

#### 主要与次要回调点

主要 HL/LH 绑定所选趋势段与尺度，结合该点的结构位置、随后引出的突破力度、极值推进和回调边界判断。常见确认过程是多头回调形成 HL 后，恢复以强突破越过此前相关高点并保住进展；空头以强突破创新低确认此前 LH，完全镜像。确认时记录所依赖的突破与跟随，强完成事件足以满足条件时不另等固定根数。

| 后续事实 | 该回调点怎样使用 |
| --- | --- |
| 强突破确认新的主要 HL/LH | 可作为后续趋势恢复、失效及 Trade 结构止损的参照；确认前不回填其主要地位 |
| 只是普通新高、新低，突破较弱或很快交还进展 | 保留局部回调点，尚不因创新极值而升级为主要点；原入场区仍可能被正常复测 |
| 尚未创新极值，但已强势突破相关旗形等重要结构并保住进展 | 结合该点作为强趋势段起点及后续回调边界的作用判断，不因未立即创新极值就降为次要 |
| 只有趋势段内部局部起伏，缺少上述强突破与结构作用 | 保留次要层级；越过它可以削弱局部恢复，但不能单独证明主要趋势已破坏 |

已有主要趋势起点及旧主要 Swing 仍按当前作用保留，新主要点不使其他尺度的结构自动失效。Trade 若改用较近的局部点保护，须另说明对应的交易前提与正常回调风险，不能把它改名为主要点来支持收紧止损。

#### 结构不清时的保守处理

数据可靠但分类仍有歧义时，先确定不清楚的是哪一层；只约束所讨论尺度上的参与，不把临时假设记成已确认结构。

| 已知与未明部分 | 当前采用的预期与参与边界 |
| --- | --- |
| 连趋势还是区间都不清楚 | 先按区间行为研究双向反应，不借用清楚强趋势的单向延续预期；边界未建立时，不凭混乱假定成熟区间或边缘机会 |
| 已确认趋势，但突破还是通道不清楚 | 暂按突破的单边性处理，新参与只考虑顺势或等待，不预设逆向运动已有可交易空间 |
| 已确认方向通道，但紧密还是宽幅不清楚 | 暂按紧密通道处理，新参与只考虑顺势或等待；不能仅因可能是宽通道而提前采用逆势方案 |
| 已有双边空间，但宽通道还是区间不清楚 | 按双边行为研究边缘向内的机会，先看有依据的内部目标；保留通道倾斜、主要 Swing 和外层方向，不把双向可动等同双向同强 |

新的回撤、恢复和跟随足以明确双边空间，或支持旧控制受损后的反向发展 → 更新相应判断与参与边界，再由 Trade 比较当时方案。单次逆向信号或更近止损不解除原有歧义。可预先研究解除歧义后的条件机会，未发生的事实仍是假设，不能据此新增风险。已有仓位仍按交易前提和当前交换管理；数据不足则先按数据可靠性规则处理。

### 3.5 重要区域图与路径作用

重要区域是共同的位置底图。从当前趋势或区间的位置出发，在以下来源中寻找与当前问题有关的区域：

- 前高低、主要 Swing、区间边界与中部、旧突破点；
- Gap、趋势线、通道线和固定参数的 EMA；
- 端点固定的比例区域和测量投射；
- 重要开高低收、整数区域和其他可观察价格带。

文中 EMA 默认指当前所述图表周期的 EMA20（20 周期指数移动平均线）；引用其他周期的 EMA 时，注明来源周期。

来源只产生候选区域。同一价格带可以有多个来源；实际引用时说明其当前作用：

| 作用 | 对当前判断的意义 |
| --- | --- |
| 支撑 / 阻力 | 某侧可能恢复或受阻，接受性突破后可能交换作用 |
| 磁吸 | 当前事实支持前往测试，到达后的表现另行判断 |
| 障碍 / 检查点 | 说明到达或穿越该处时，什么表现会改变延续预期 |
| 路径目标 | 用于评价这条路径的市场结果 |
| 失效参照 | 用于定义否定路径的事实；具体交易止损由 Trade 选择 |

| 区域与当前问题的关系 | 是否展开 |
| --- | --- |
| 当前互动或路径直接引用 | 展示其价格带与实际作用 |
| 是最近的实质障碍 | 优先说明如何通过、受阻将改变什么 |
| 更远，但会改变目标可达性或管理选择 | 补充相应约束 |
| 只是图上可画出的线，对当前选择无影响 | 暂不展示 |

区域作用可直接写成条件，如“需穿越并保住；重新回入会削弱延伸”，无需逐项填写分类。

选择参照时，说明它组织了哪次相关运动、此前怎样产生反应、本次哪些表现会改变其作用。多个候选会导致不同目标或保护方案时，保留这个分歧交 Trade 比较；只因某一画法能给出更大回报，不足以采用它。区域是否用作目标按[目标选择](#路径怎样选择目标区域)判断，是否用作保护按 [Trade 的前提与止损规则](trade.md#33-交易前提路径失效与保护性止损)判断。

需要把区域采用为市场目标时，按[路径的目标选择](#路径怎样选择目标区域)评价可达性、近端障碍和结果条件。观察一个区域本身不要求先建立完整路径。

### 3.6 区域互动与预期更新

先定位本次互动，再比较此前相关推进、回撤和恢复，以及原有区域是否仍在限制双方。预期必须在结果前确定；首次看见已发生事件只能解释背景，不能补记事前预测。

#### 这段运动在当前位置意味着什么

| 位置与运动 | 当前问题 |
| --- | --- |
| 区间内部局部上涨，距离上沿仍有空间 | 局部推进能否持续，回调后哪里可能恢复 |
| 局部上涨接近反复拒绝价格的上沿 | 本次到达能否改变边缘行为；不能把内部上涨直接外推为界外延伸 |
| 一段下行处于较大上涨中 | 是允许的回调，还是已破坏上涨所依赖的恢复能力 |
| 一段下行处于区间或旧控制受损之后 | 分别检验区间向下段或反转尝试的依据 |

运动方向与外层作用分别表达，可以同时成立；按各自尺度的条件更新。

#### 当前运动的强弱

| 表现 | 对当前判断的意义 |
| --- | --- |
| 实体相对周围有意义、收近方向端点、影线和重叠较少，且实际位移较大 | 该方向推进较强；继续看后续能否延伸 |
| 影线和重叠增加，价格反复涨跌、净位移有限 | 更多双向交易；比较原方向能否恢复 |
| 巨大 K 出现在成熟趋势、目标附近，或已消耗剩余空间 | 同时考虑高潮与修正，不能只据大小提高延续预期 |
| 多根较小 K 累计向同一方向移动，回吐有限 | 也可建立失衡，不能因单根小而忽略累积进展 |

比较信号时，把本根或组合的开收盘、极值与此前收盘和相关高低点对照：向反侧尝试后收回多少、收盘保留多少推进、越过的是局部价格还是重要边界。影线越界后收回与收盘越界分别记录；后续重新回入还是继续延伸，决定这次进展是否保住。强跟随可以补强最初较弱的信号，但只改变当下判断，不补作早先参与时已有的事实。

单根强 K、首次越界或新 Gap 只说明已发生的变化。后续延伸、保持在界外或回调后继续，增加延续依据；背景与已完成事件足以支持判断时，无需统一等待额外根数。Buying/Selling Pressure 概括买卖压力，相对优势比较两个方向；单次强运动尚不能证明持续控制。

**使用关系和参与事件：**

- 趋势 K、Gap、Microchannel、浅回调、极值推进来自同一运动 → 共享事实，保留各自比较对象；关系变化只更新引用它的结论。
- Signal Bar 已形成 → 只得到候选参与边界；越界、收盘、跟随、回试守住各按实际发生的事件判断。Trade 选择所需事实或可执行条件。
- 反向 Signal 尚未触发便被原方向突破 → 分别保留反向候选未触发与原方向越过其边界的事实；已经反向触发、随后失去进展并被原方向突破 → 另有触发后未能持续的事实。结合信号所在位置、原方向突破力度与保留情况评价延续依据；未触发不等于没有信息，已触发也不预设为更强的失败证据。
- 要用双方机会比较持续能力 → 使用当时可见的同一窗口、可比周期与目标尺度，比较机会的位置、质量和实际后续。
- 一侧机会反复取得并保住进展，对手反复缺少跟随 → 可支持该侧持续能力；尚未发生的跟随仍是预期。
- 只是多画箭头或多设计参与方式 → 不增加方向概率。

#### 第二段预期与分段尺度

强突破取得并保住进展、反向尝试缺少持续能力，且前方仍有空间 → 可以研究回调后的同向第二段。先明确运动的方向、起止与周期；第一段的强度不保证第二段出现或达到等距目标。第二段预期本身不附带“约十根”的要求，也不要求本笔持有到第二段。

| 已有表现或分段问题 | 怎样形成后续预期 |
| --- | --- |
| 两个局部小段仅以短暂停顿分隔，整体紧密推进，较大尺度尚无有意义回调 | 可同属复杂第一段，之后仍可研究较大尺度的第二段 |
| 回调后出现新的同向运动 | 第二段可短、横向、不创新极值或快速失败，不必与第一段等长 |
| 深回调后原方向恢复，但第二段以较弱通道推进、重叠增加 | 仍可比较旧极值与等距目标；该段结束后转区间的依据增加，不能直接外推第三段。目标可达性与到达后的继续能力分别判断 |
| 第二段又形成强突破并保住进展 | 可继续延伸；结构改变时按[推动重计](#a-结构视图怎样共享事实)处理，两段不是趋势上限 |
| 分段尚不能确定 | 保留会改变预期的候选与锚点，由后续回撤、恢复或新突破辨别 |

外层趋势中的[强回调](scenarios.md#强回调自身也可能有第二段)也按自身方向判断。局部 [H2/L2](#d-hl-次序与重置)是触发次序，不代表较大修正完成两段；[测量锚点](#从哪些锚点投射候选区域)按原尺度固定，不为扩大目标而重选。

#### TBTL 与运动尺度

TBTL（Ten Bars, Two Legs）是约十根 K、两段运动的时间与结构经验。背景支持有意义的[修正](scenarios.md#七趋势异常加速或持续过久)、[反转 Swing](scenarios.md#八趋势受损后尝试反转)或[突破 Swing](scenarios.md#三趋势继续推进)，且需要估计这段运动的持续时间与分段时，可用作尺度预期。普通第二段预期不自动采用这一参照；打算做 Swing 也不能代替市场依据。

| 当前需要明确什么 | 使用方式 |
| --- | --- |
| 方向、结构与起点 | 绑定所研究运动的起点；修正尚未开始时保留为预期。突破 Swing 从新突破段起点观察，[顺势通道突破持续成功](scenarios.md#通道突破的方向与目标)也按此处理，不从后来首次回调重新起算 |
| 周期 | 使用仍清楚表达同一形态的最高相关周期，不无限向上找无关结构；低周期可看参与细节，其两小段不代替较大尺度的结构 |
| 完成了什么 | 时间、相应尺度的段数、价格目标和风险倍数分别核对，不要求同时达到 |

运动可更短、更长或继续扩大；约十根、两段不是统一最低等待、到期点或入场条件，也不证明运动已结束或原趋势将恢复。后续按[回撤与恢复](#回撤与恢复怎样改变原判断)判断；原趋势恢复后再有新高潮，另建预期，旧结果按[路径更新](#38-首次建立与路径变化)保留。

本笔的目标、允许回调和期限由 [Trade](trade.md#33-交易前提路径失效与保护性止损)确定。仅取局部目标时，较大运动尚未完成不自动妨碍入场或延后退出；若本笔依赖快速恢复，较长修正预期可能损害其前提。原方案容许的修正仍按原条件管理，已有交易、路径和安全期限继续生效。

#### 回撤与恢复怎样改变原判断

对照原预期中的区域、允许的回调幅度与时间、恢复条件。与此前相关回调相比，本次是否更深、更久，原方向是否更难继续，逆向运动是否更能持续？趋势名称未变，预期也可能需要调整。

建立正常预期时，选取同一尺度、仍适用于当前背景的此前回调，比较幅度、耗时、保留区域与恢复表现；位置、结构或剩余时段已改变时，不直接沿用旧范围。参照稀少或差异过大时明确不确定性，保留待观察条件。当前回调尚未结束，不能用它后来形成的极值或总时长补作事前允许范围。

回撤比例绑定所选趋势段。相同结构保护与旧极值目标下，更深回调可改善参与价格，也可能伴随更强反向推进、更弱恢复依据。短促下探后拒绝、持续紧密反向推进和长时间横盘，即使深度相同，含义也不同；比例描述位置，参与仍比较实际推进与恢复。

| 当时表现 | 原判断怎样变化，接着看什么 |
| --- | --- |
| 横向停顿但保住关键区域，或回到原区域仍符合允许的回试条件 | 如实区分横盘与回入；仍符合原条件时，按原期限观察恢复 |
| 回撤加深、延长，恢复变慢或反复受阻，已偏离原正常预期但未完成失败条件 | 削弱受影响的延伸或恢复预期；主要结构尚未破坏也要处理这项变化 |
| 回调停止，原方向恢复并保住进展 | 恢复依据增强；结合剩余空间研究旧极值或下一障碍，更远目标按路径规则评价 |
| 突破先取得有意义进展，首次回调短浅、反向跟随弱，仍保留突破区域 | 支持突破后的延续；回调出现较晚只是辅助，仍核对实际保留与恢复 |
| 突破尚未取得足够进展就回调，反向推进强、持续延长或回入突破区域 | 削弱立即延续，比较正常测试与双边化；不能仅因触及某笔入场价就判突破失败 |
| 一次恢复或本次突破先满足失败条件 | 按原条件记录该次失败；整段方向路径另判，本次失败仍可能处在更大趋势的回调内 |
| 原方向回吐，但反向运动也未持续 | 原延续变弱，可考虑通道化或双边化；反向未持续，仍不能证明原方向已恢复 |
| 反向运动未被收回，原方向再次恢复失败 | 反向段或内部轮转依据增强；用其自身空间和条件研究机会，不能由旧侧失败直接推出持续控制转移 |
| 对手随后继续延伸，并能在自己的正常回调后恢复 | 核对该尺度的控制变化；强背景与足够强的完成事件可以及时支持改变，无需固定等待根数 |
| 双方都推进有力，或双方都缺少推进 | 都可能相对平衡；分别判断波动、回撤、空间与突破预期，有稳定边界才采用相应边缘预期 |

这些影响可以同时存在。局部反向段、外层主要结构和各条路径按自身尺度与条件评价；原方向仍可在后续修复，稳定边界也可能继续改变。结构确认见[持续能力](#34-市场结构与持续能力)，特定背景带来的正常预期见[回调](scenarios.md#四趋势中出现回调)、[异常修正](scenarios.md#七趋势异常加速或持续过久)和[旧控制受损](scenarios.md#八趋势受损后尝试反转)。

突破后的首次回试可以穿过入场价；恢复后又返回同一突破或公共收盘区域，要比较这次离开是否取得并保住更多进展。反复无法离开、恢复跟随变差，会增加区间化依据；后续仍有强进展则不能按“第二次回测”自动退出。公共突破价、最高或最低趋势收盘与个人成本价分别标明。

末端收盘附近，原方向多次尝试却几乎不再扩展、反向进展逐渐保留时，可研究转向另一侧测试。先取该反向运动有依据的内部区域与空间，不由“两次失败”直接推出到达对侧或反向趋势。市场未到目标与目标已触及但订单未成交也分开：前者用于评价推进，后者先由 Account 核对执行。

#### 边界处是否改变此前作用

到达前先说明这一区域此前怎样限制价格，以及本次为何可能前往它；到达后比较向内返回与界外延伸。区间内部的局部强运动支持向边界推进，但不能直接外推为边界外的持续发展。

| 本次互动 | 对区域作用与后续预期的影响 |
| --- | --- |
| 接近但未触及 | 位置测试未完成；仍可按当时空间研究前往该处的运动 |
| 触及或轻微越界 | 只完成位置或越界事实；停止恢复、拒绝和外部接受各按已发生条件判断 |
| 在外保持、继续扩展或回试守住，完成事前要求 | 外部延伸依据增强；原向内预期是否失效，仍核对其自身条件 |
| 触及边缘后直接向内推进，或外部尝试失败后向内取得进展 | 支持边缘拒绝与内部发展；不要求先有向外恢复失败，内部目标仍需处理障碍 |
| 回入旧区域后，向外恢复失败并继续向内取得进展 | 进一步支持拒绝或内部发展；不能直接认定到达对侧 |
| 回入不能持续，随后重新在外保住进展并恢复 | 原拒绝解释受损，重新评价外部延伸；已完成的历史测试仍保留 |
| 穿越 EMA、趋势线或比例参照，但仍符合原先允许的复测与恢复条件 | 按该参照的事前作用继续观察，不能仅凭穿越就判其受损或主要结构破坏 |

界外收盘、接受和目标完成分别有条件；同一根 K 可以满足多个条件，也可能只完成其中一项。只短暂保住外部进展时，承认尚未交还，继续观察能否保持与恢复。成熟边缘、内部压缩和宽通道怎样改变预期，分别查[边缘与轮转](scenarios.md#五价格到达区间或宽通道边缘)及[平衡中的方向发展](scenarios.md#六区间反复测试边界)。

#### 第二段预期怎样受损或失败

第二段接近或到达限制延续的区域时，比较真实延续与陷阱风险。在 Trading Range 或 Broad Channel 中，局部第二段很强，但尚未改变主要边缘或外层结构的约束，也可能只是向限制区的高潮推进；不必等反向发展才开始考虑风险。清楚趋势早期的强第二段则更支持延续，仍需核对空间与跟随。

判断陷阱已发生时，按以下次序核对：

1. 第一段足以建立第二段预期。
2. 第二段实际出现，并到达限制延续的边缘、磁点、测量区或成熟通道外侧。
3. 应有跟随缺失。
4. 随后旧区域重新获得接受或反方向恢复。

第二段尚未出现，或已到限制区域但后续未明，都不能记为已发生的陷阱；第一段后的首次反转也不是第二段陷阱。已有跟随不足或恢复失败，仍按其自身条件更新局部测试、交易前提和方向路径，不以完整陷阱次序作为处理异常的前提。

#### 由表现更新预期

有影响当前选择的分歧时，先明确各解释对后续的不同期待，再对照新事实。例如，界外延伸期待回调后保住外部并恢复，边缘拒绝期待向内推进；若曾越界，再看回入后能否重新站回外部。只展开有实质差别的比较：

| 新事实与原预期的关系 | 处理 |
| --- | --- |
| 相比竞争解释，更符合某种预期的发展 | 说明增加支持的是哪项差别，以及仍缺什么 |
| 只是与某解释相容 | 不据此宣称支持增加；继续比较各解释原本期待什么 |
| 两个解释都允许该事实 | 比较它在各自预期下的意义，不能直接判定毫无区分作用 |
| 事前期待立即推进，跟随迟迟未出现 | 削弱立即推进预期，核对异常与失效条件 |
| 停顿仍在事前允许范围内 | 按原期限继续观察恢复，不提前判失败 |
| 新事实不足以改变判断 | 沿用原解释，保留尚未解决的问题 |
| 双方都未完成所期待的发展，或形成新的平衡 | 保留各自已知成果与不足；原问题仍适用则继续观察，结构或区域作用改变时重选问题 |

预期差只指实际表现与事前条件预期的差别，不证明其他参与者持有同样预期。

#### 测试结果与区域接受

测试绑定一次尝试和区域。需要评价结果时，事前确定成功表现、失败条件和观察期限。

先按[共同的结果规则](#测试与路径怎样评价结果)核对该次测试，再更新当前接受判断。测试结果说明完成的是收盘、延伸、保持、回试或恢复中的哪项要求；它不替代整段路径结果。

“接受”概括价格在指定区域内或边界外保持并发展的表现。使用时明确区域、尺度和所需条件：收盘、延伸、保持或回试。哪些条件须同时满足，由事前要求确定。

| 情况 | 接受与其他判断怎样接续 |
| --- | --- |
| 已完成界外收盘，但尚缺所要求的保持或回试 | 收盘测试完成，接受仍待所缺条件 |
| 当前背景中的强完成事件已满足接受条件 | 可以判断接受，不统一等待固定根数 |
| 已完成的测试之后又交还进展 | 保留原测试结果，更新当前接受与持续能力 |
| 局部测试失败 | 方向路径按自身条件核对；失败突破仍可能成为原趋势回调，原目标未必失效 |
| 准备改采对方路径 | 单独核对对方事实与结果条件，不能从本次失败直接生成 |
| 同一事件同时支持测试、接受、路径或控制判断 | 分别核对各自条件，共享同一组证据 |
| 主问题改变 | 更新当前采用的解释，保留已确定的历史结果 |

记录与后续评价按本次练习或检验的范围保留。

### 3.7 条件路径与目标

条件路径用于回答“什么条件下，预期在多久内到哪里，什么表现使预期失效”。它将市场预期变成可评价的结果；本笔怎样入场和退出由 Trade 决定。

**何时展开：**

- 只需理解当前过程，尚无有依据的目标 → 保留过程判断与下一观察。
- 需要回答什么条件下能到哪里 → 检查双方支持与反方事实，展开有依据的路径。

**展开多少：**

- 只有一条路径会改变当前选择 → 只保留这一条，无需另造相反故事。
- 不同条件下的竞争路径会改变判断或选择 → 保留相应分歧与区分条件。

#### 路径怎样选择目标区域

1. **核对可达性依据**：候选区域的来源、周期，以及当前运动为什么有空间和时间前往它。只有异常单根延伸或测量公式 → 依据不足，保留候选。
2. **先处理近端实质障碍**：
   - 有依据合理通过 → 说明怎样穿越、受阻会怎样。
   - 还依赖未来突破或跟随 → 远端目标保留为条件预期，明确尚待发生的条件。
   - 已知障碍无法合理通过 → 改看近端有依据的目标，或等待新事实。
3. **确定结果事件**：有当前依据且障碍已得到处理 → 明确完成要求触及、穿越还是界外接受；未来条件仍保持为条件。一条被评价路径只对应一个结果事件。

更远目标改变原完成结果 → 另记新预期。途中区域可作障碍、检查点或 Trade 出场位置。比例端点在计算前固定，EMA 参数在使用前固定；变更时注明生效时间并保留旧判断依据。

#### 怎样明确路径条件

一条供评价的路径写清：

- 当前依据，以及仍待发生的关键假设；
- 目标区域与完成条件；
- 沿途实质障碍，以及正常与异常表现的影响；
- 失效参照与条件；
- 有效期限，以及剩余空间和时间为何支持该预期。

多种参与方式引用相同的市场预期、目标、成立次序、完成、失效与期限 → 共享同一路径，参与位置、时点和额外确认交 Trade 比较。只得到相同目标价格，不足以合并路径。

**事件条件怎样使用：**

1. 事前写清成立条件、途中预期、完成与失效的先后关系。要求先成立、再到达目标 → 从成立后评价完成；成立前触及只保留为价格事实。
2. 评价结果时核对实际次序：同一事件足以证明所需顺序或同时条件 → 可以记录实现；数据不能证明 → 保留未知，不补写事件顺序。

缺少有依据的目标、失效或期限 → 保留过程判断、缺项与下一观察；已有假设但事实冲突 → 明确待辨别问题及复查时机，可等待下一次区域互动或可靠数据，不必预知唯一精确事件。研究和实际参与分别按[交易交接](#五交给交易决策)处理。

Trade 选用额外参与确认，只改变参与要求，不改写市场预测的起算条件；触价不能替代收盘或跟随。相关事实、空间或时间改变 → 重新评价当前路径。

### 3.8 首次建立与路径变化

首次记录可评价路径时，固定依据、目标、成立顺序、完成、失效及期限。若等待成立与目标发展需分别限时，在此时写清两段期限。

**当前采用什么：**

- 结果事件未变 → 新事实增强、削弱或维持原预期时，更新预期及依据；只是精化同一事件的边界时，保留精化依据。
- 调整目标、条件或期限会改变原事件结果 → 另记新路径及生效时间，保留旧条件。
- 不再采用已记录路径 → 保留停止采用的时间、理由、原条件与期限；后续评价按[路径后续评价范围](../practice/README.md#路径后续评价范围)处理。

旧区域仍有当前作用 → 可用于新目标、支撑阻力或回试；新预期须有当前依据、完成、失效与期限。

**哪些原预测继续评价：**

当前仍在采用的路径随新事实核对结果，不以是否交易为前提。停止采用后的追踪义务按[路径后续评价范围](../practice/README.md#路径后续评价范围)确定；已纳入评价的预测仍按原条件用可靠后续数据结算，保留还原结果所需事实。

#### 测试与路径怎样评价结果

需要评价的测试和路径各自绑定原条件。测试评价一次尝试的成功、失败或截至期限的表现；路径评价目标实现、失效或到期。它们共用以下核对顺序，各自结算：

1. 已有确定结果 → 保留原结果，后续事件不改写。
2. 尚未结算 → 按原成立、完成、失效与期限条件核对：
   - 必要数据缺失 → 标明结果无法可靠评价。
   - 数据粒度不能确定所需先后 → 保留“先后未知”及已知事实。
   - 所需事实与先后可知 → 完成条件、失败条件、期限结束中最先发生者决定结果；到期只评价截至期限的表现，不用后续事实补足。
   - 结果尚未发生且仍在期限内 → 待定。

成立条件在原期限内始终未发生 → 到期并注明未成立，不自动判方向失败。方向失败看原失效条件，盈亏看真实成交与成本；新路径可在旧交易结束前形成，旧市场结果也不自行决定仓位动作。来源修订按[数据规则](#33-数据可靠性)保留原记录并重判。

## 四、每次市场唤醒

### 4.1 唤醒来源

新完成 K、事先允许的盘中事件、观察或路径期限、数据恢复与修订，以及首次分析或接管，都可以触发更新。

### 4.2 普通更新

1. **核对新事实与原结果**：确认数据可靠性和当时可见时间，优先核对当前路径是否完成、失效或到期，再核对相关测试。各按原条件与事件先后结算，保留已确定的结果。
2. **确定当前问题**：核对原观察范围、运动和区域是否仍适用。范围失效时按[完整重判](#43-完整重判)重建；范围仍适用但主要问题改变时，重选相关运动与位置。仍有效的背景和其他尺度判断继续沿用。
3. **接续运行卡**：对照原先期待的表现和允许的波动，按[回撤与恢复](#回撤与恢复怎样改变原判断)、[边界表现](#边界处是否改变此前作用)及[预期差别](#由表现更新预期)，更新当前判断与后续预期。符合预期也要接续已完成的变化；没有实质变化则沿用。仍不明确时保留缺项与有影响的分歧。
4. **明确下一观察与影响**：按更新后的预期检查机会或等待条件；需要比较空间时补充路径，影响持有依据时交 Trade 重评。判断、机会或等待条件、下一观察及复查时点明确后，结束本轮市场分析。

例如，原区域仍有效但恢复变慢，可以继续原问题并调整预期；上涨接近反复受阻的区间上沿时，需要比较突破与返回，不能仅凭触线就切换判断。其他尺度仍有效的判断继续保留。

持仓、订单与查询按 Trade、Account 继续处理；停用路径按[路径变化](#38-首次建立与路径变化)保留原条件，记录范围按 Practice 执行。

### 4.3 完整重判

出现以下任一情况时，从对应起点重建受影响的判断：

| 触发条件 | 重判起点 |
| --- | --- |
| 品种、周期或 K 线构造改变 | 重新确定观察边界 |
| 数据修订影响基础判断 | 从最早受影响处重判 |
| 接管时旧判断可靠性不足 | 重新核实边界、事实与当前问题 |
| 主问题、结构或多周期关系使旧边界不再适用 | 重选观察范围，再建立当前判断 |

重判保留此前可见事实与历史路径的原条件；已有可靠部分直接引用。重建后接续机会或等待条件，无需重做未受影响的部分。

## 五、交给交易决策

向 Trade 提供观察范围与可靠性、当前市场判断、预期与机会、相关路径及本次变化。区域和事件直接引用。

**研究机会：**

- 只有机会想法，路径尚不完整 → 研究哪里、什么条件下可能参与，补足影响选择的缺项。
- 条件路径完整，部分条件尚未发生 → 可预构造和比较方案，明确实际参与采用哪些条件。

**实际授权：**须有依据的目标、失效、期限及完整交易方案，再按所选参与条件评价。市场事实已确认不等于授权或真实成交。

**继续管理：**目标完成、局部失败或出现新路径 → Trade 结合实际仓位、订单和风险决定下一动作。

市场判断持续比较双方，不因已有仓位而缩窄。市场事实、参与授权和真实成交分别记录。

## 六、术语与判定参考

本节保存几何定义、结构视图、次序和判定依据，按问题查阅。确定性计算、参照选择和对后续的解释各有不同依据；每次分析只取当前需要的关系，不逐项填写术语。

### A. 结构视图怎样共享事实

同一组 Swing 可以同时形成 H2、Double Bottom、Bull Flag 或 MTR 组件。价格事实只登记一次，各视图只保留独有作用。

| 结构视图 | 共享事实 | 独有作用 |
| --- | --- | --- |
| ii / iii | 连续 inside bars | 压缩范围和边界 |
| ioi | inside–outside–inside | 双边扩张后的再压缩 |
| oo | 连续 outside bars | 双边扩张和不稳定边界 |
| Triangle | 双方反复测试 | 两侧有效边界和成熟度 |
| Expanding Triangle | 双方交替测试并扩张极值 | 扩张边界和测试次序 |
| Double Bottom / Top | 两次运动测试同一区域 | 重复测试区、Neckline 和高度候选 |
| Wedge | 三次可区分的同向推动或测试 | 推动次序、斜率和延伸质量 |
| Flag | 外层方向中的局部结构 | 局部结构对延续或反转的作用 |
| Final Flag | 当前趋势段中的延续结构，可小至一根 K，也可位于区间内的局部趋势 | 结合位置与双方表现预期延续失败；实时候选与事后最后一个旗形分开 |
| H1/H2…、L1/L2… | 同周期、同恢复对象内的尝试 | 尝试次序、信号边界和重置点 |
| H&S | 三个相关极值及其间回撤形成的肩部、头部与 Neckline | 在旧控制受损时可表达 MTR 组件关系；区间中的同类几何按实际边界互动解释 |
| MTR | 成熟趋势后的反向发展 | 从 minor reversal 到控制转移的阶段 |

头肩顶的头部 HH 与随后右肩 LH，可表达旧高再测试后恢复能力减弱；头肩底以 LL 后 HL 镜像处理。反转依据仍来自此前反向压力、恢复失败与后续进展。肩部或头部内的小 MTR、楔形只补充相应尺度的过程，不因嵌套名称增加独立证据。

推动计数绑定所研究运动与尺度。强突破改变原结构后，按新趋势段重新计数，不将突破前后的推动机械拼成同一衰竭结构；普通新极值或段间时长差异本身不自动重置，外层结构按自身尺度保留。

Wedge 的推动之间须有可区分的暂停、回调或反转；连续扩大极值不逐棒计推。三推可以沿倾斜通道发展，收敛不是必要条件；推动增量缩小、回吐增加属于另行观察的质量变化，不能从三推名称中直接读出。Parabolic Wedge 指紧密运动中的连续高潮型三推，回调浅、推进段之间可不重叠，斜率可能增加；它与推进衰减的三推分别描述，异常程度按[高潮背景](scenarios.md#七趋势异常加速或持续过久)判断，不要求每推都比前推更陡。

Triangle 的上升、下降描述边界斜率：上升三角形下边抬高、上边近水平，下降三角形镜像；收缩与扩张描述两边距离变化。按交替 Swing 识别时，注明各侧测试与段数；五个交替段可使一侧出现三推，不等于五次反转。ii/iii 等微型压缩仍按自身几何使用，不由名称推定已有成熟双向边界。

Outside、ii/ioi 等用于参与判断时，先说明此前运动、所在位置与当前跟随：

| 背景与实际表现 | 边界怎样使用 |
| --- | --- |
| 顺势回调在相关支撑阻力或突破点附近停止，原方向恢复 | 研究恢复触发或回试；末棒同向、收近端点可补充局部支持，不要求完美外观 |
| Outside 完成有意义的反向收复，后续取得并保住进展 | 研究该方向突破或回试；大范围同时可能扩大保护距离 |
| 区间或旗形中，信号所指方向缺少延续依据，另一方向有返回或恢复空间 | 可研究反做边界的 Limit 方案；弱信号本身不证明反做值得，提前承接仍承担失败尚未确认的风险 |
| 小压缩处于长期横盘内部，缺少明确运动或空间 | 名称与末棒颜色不提供足够参与依据，等待有效突破或其他实质变化 |

小压缩末棒反色、收盘回吐或后续失望，会削弱立即延续的依据，但不单独确认反转。EMA 位置用于比较回调是否仍守住原方向关系，不能以均线上下代替推进与恢复。订单方式与实际价格交 [Trade](trade.md#32-确认程度与订单条件)评价。

嵌套结构分别保留外层推动与内层过程。外层第三推动中的小楔形，可进一步显示推进增强或受阻、回吐多少、恢复是否顺畅；这些具体关系才是信息增量。内层仍紧密推进时，保留其持续性，三推本身不提供衰减证据。内层反转按本层条件判断；它是否改变外层预期，取决于所处位置及对外层推进、保留或恢复的影响，不必等外层结构已经破坏才考虑。

名称只用共享事实和独有作用更新市场组织、重要区域或当前互动，不直接生成路径、概率或交易。

### B. 区间、比例与候选区域投射

区间边界取当前反复组织价格的两个区域。只有一次影线或轻微越界时，保留原边界，继续核对界外进展。

设下沿为 `L`、上沿为 `U`、高度为 `R`：

```text
R = U - L
中部 = L + R / 2
底部三分之一区域 = L 到 L + R / 3
顶部三分之一区域 = U - R / 3 到 U
```

当前段从 `A` 到 `B` 的半程为 `A + (B - A) / 2`。

比例区域按参与对象取分母：区间轮转取所研究区间的上下沿，趋势回调取所依赖趋势段的起止范围。宽通道内一段运动的中部不等于整个通道中部。半程、三分之一或两分之三区域用于定位候选价格，恢复依据、实际保护与目标仍分别判断。

#### 从哪些锚点投射候选区域

先明确所测对象与周期，固定当时可见的端点，再计算候选。以下投射都把一段距离从指定位置延伸出去；取点规则不同，不能交换距离与起点。半程、中部和三分之一区域只是内部位置计算，不提供投射方向。

测量新突破段时，以开启该段的清楚突破起点为候选，不必追溯到此前反向运动的绝对极值；测量整个趋势段时才使用该整体的端点。第一段之后已形成清楚区间，可用进入区间处结束第一段、离开区间处开始第二段，内部同向摆动仍属区间。区间起止尚不清楚时保留分段候选；后续明确了边界，只更新当前分段，不回改旧投射结果。起点、所测距离、投射位置与期限须对应同一研究对象。

| 测量对象 | 固定的锚点 | 候选构造 |
| --- | --- | --- |
| 第一段的等距延伸（Leg 1 = Leg 2） | 第一段起止 `A → B`，第二段起点 `C` | `C + (B - A)` |
| 区间、完整突破或更大趋势段的范围 | 区间用已识别的下沿 `L`、上沿 `U`；完整突破或趋势段用该对象的最低 `L`、最高 `U`。各取自己的正高度 `U - L` | 向上 `U + (U - L)`；向下 `L - (U - L)` |
| Double Bottom | 底部区域 `L`，两次测试之间的 Neckline `N` | `N + (N - L)` |
| Double Top | 顶部区域 `U`，两次测试之间的 Neckline `N` | `N - (U - N)` |
| 突破实体 | 首根强 K 开盘 `A`，末根强突破 K 收盘 `B`，有向位移 `d = B - A` | 顺向 `B + d`；原突破失败后反向 `A - d` |
| 测量 Gap 中点 | 所研究运动起点 `S`；两个明确参照边界的中点 `M` | `M + (M - S) = 2M - S` |
| 突破点对称投射 | 所研究运动起点 `S`；该运动引用的旧突破点 `P` | `P + (P - S) = 2P - S` |
| 区间中点对称投射 | 区间前所研究运动起点 `S`；区间中点 `M = (L + U) / 2` | `2M - S` |

中点投射将起点到中点的有向距离延伸一次。Gap 的中点来自所引用的前高与后低（空头镜像）等明确边界，不替换为突破 K 的实体中点；端点相接或重叠时，如实记录几何关系，不称为正宽度分离。所用运动起点与参照必须支持同一方向和尺度；锚点不清时保留候选，不为了目标更远更换起点。

旧突破点与 Gap 中点是不同的对称中心，使用时明确选取哪个参照及其结构作用。开放或重叠本身不决定采用哪一个；两者均合理时保留候选，不能因原目标未达便换中心改写结果。

区间中点法不同于从区间边界投射完整高度。它是两段测量的辅助候选；边界不清时不优先采用，也不因同时画出两种测量而增加证据权重。上述构造只确定候选位置，采用为路径目标仍按[目标选择](#路径怎样选择目标区域)核对当前依据、障碍与期限。

Double Test 与 Neckline 的资格按[两次测试](#c-double-test-与-neckline)核对；实体和完整突破的取点细节见下节。各行即使得到相同价位，也不证明测量依据相同或各自预期已成立。

采用候选时，统一按[目标选择](#路径怎样选择目标区域)处理可达依据、近端障碍、剩余空间与时间；有依据的远端可以预先作为条件预期，不要求先完成每个近端目标。50%、三分之一或测量值本身不生成反转判断或入场。

首次提出某候选时价格已走过该处，只保留为历史事实，不补记事前预测或成交；已有预测按原条件结算。更远目标改变原结果事件时，按[路径变化](#38-首次建立与路径变化)另记新预期，当前按剩余空间研究机会。

#### 突破高度与失败后的反向投射

先固定所测突破段的周期、首尾 K 和价格端点。连续强突破的实体跨度，取首根强趋势 K 的开盘 `A` 至末根强突破 K 的收盘 `B`，有向位移 `d = B - A`；这是首开到末收的净位移，不是逐根实体长度相加。所选段的方向与净位移不相容，或首尾不能明确时，不使用这项实体投射。

候选按[上表](#从哪些锚点投射候选区域)构造。影线计入完整突破自己的高低范围；采用更大原趋势段时，重新明确该段起止与高低点，不能只扩大距离而沿用另一基准的起点。多头实体投射从末收向上延伸，失败后从首开向下延伸；空头完全镜像。订单的触发边界和真实成交价由 Trade、Account 分别确定，不拿它们替代投射起点。

| 当前事实 | 目标怎样使用 |
| --- | --- |
| 强突破取得并保住进展 | 比较实体及完整突破的顺向候选、已有区域与近端障碍；不是所有突破都能支持同样远的目标 |
| 原突破只有小回调或暂时缺少跟随 | 可预研究失败后的反向候选，不能据此认定失败或采用已确认的反向测量预期 |
| 原突破被反向强势突破，并获跟随、满足失败条件 | 用原先固定的实体或完整范围构造反向候选；仍需反向路径自己的依据、障碍、失效和期限 |
| 多个尺度给出同向目标 | 按实际距离先评价近端；实体、完整突破和更大趋势段各保留基准，不把三个目标都当作必达 |
| 强势穿过近端目标并继续保住进展 | 更远候选有可见锚点及当前跟随支持时，按共同目标规则评价延伸 |

### C. Double Test 与 Neckline

Double Bottom / Top 的两次测试：

- 不要求精确同价；
- 必须是两次可区分的运动；
- 必须指向同一有意义区域；
- 中间必须有可见的反向 Swing。

Micro Double Top / Bottom 表示所选周期内紧凑的重复测试，仍须辨认两次运动及其间反向过程，不设统一棒数。其确认作用取决于外层位置与当前预期，微型测试本身不确认大尺度反转；单根 K 隐含的低周期测试未查看时只作推断。

Double Bottom 的 Neckline 是两次底部测试之间最高的相关反向 Swing high 区域；Double Top 镜像为最低的相关 Swing low 区域。

头肩结构另有两个肩头之间的反向拐点：头肩顶可分别取左肩至头部之间的低点水平、头部至右肩之间的低点水平，或连接两低点的斜线作颈线参照；头肩底镜像取两高点。各线位置接近时合看一个区域，相距较远时按运动方向先看近端，再看后续阻碍；越过一条不代表全部通过。斜线使用对应时点的价位，采用投射时固定所用参照，不把几种颈线当成独立证据。

| 已发生什么 | 可以判断什么 |
| --- | --- |
| Double Test 已形成，Neckline 尚未突破 | 可研究高度投射条件目标，尚未确认突破 |
| Neckline 突破后获得跟随或回试守住 | 增加投射可达性的依据，仍须检查近端障碍与期限 |
| Double Test 已形成，但 H2/L2 次序未完成 | 保留 Double Test；second entry 单独按其自身次序判断 |

### D. H/L 次序与重置

多头次序：

1. 在选定的多头回调或区间底部恢复对象内，当前 K 的高点首次严格高于前一根 K 的高点，形成 H1 Trigger；前一根完成 K 提供信号边界，越界 K 为 Chart Entry Bar。
2. H1 后出现至少一根高点低于前一根高点的完成 K，才建立同一回调内下一次恢复的候选；它与 H1 可以相隔多根 K。
3. 此后首次出现当前高点严格高于前一根高点，形成 H2 Trigger。触发前，以当时最近完成 K 的高点更新候选边界；后续 H3、H4 按同一次序处理，并先检查是否需要重置。
4. 连续抬高高点属于同次向上尝试，不逐根增加编号。相等高点既不触发，也不单独构成第 2 项所需的较低高点。

空头镜像：熊旗或区间顶部恢复对象内，低点首次严格低于前一根低点形成 L1；之后出现较高低点，下一次严格跌破前低才形成 L2。相等低点不触发，也不单独建立新的反弹尝试。这里采用严格越前高低的计数，依据 [Brooks 官方术语表](https://www.brookstradingcourse.com/price-action-trading-terms-glossary/)；按段数概括的其他标法不替换此处触发记录。

例如，同一多头回调、尚无重置时，依次出现高点 `101、100、100.2、100.1、100.3`，第 3 根触发 H1，第 5 根触发 H2。若第 3 根改为 `100`，则第 4 根才触发 H1，第 5 根仍是同次尝试。Signal Bar 只定义市场边界，采用、提交与成交另行判断。

| 当前事实 | 次序与计数处理 |
| --- | --- |
| 第一次 chart entry opportunity 尚未触发 | 尚不满足严格 second entry 的前序要求 |
| 第一次机会已触发，第二次 setup 尚未越界 | 有 setup，尚无第二次 Trigger；是否真实成交不决定图表计数 |
| 出现 H3/L3 | 可以与 Wedge 共享推动事实 |
| 出现更高编号 | 先检查是否已是 Triangle、Trading Range 或新的 Pullback 对象 |

再次尝试的价值来自新增检验：原方向是否推进更少或更难保住，反方是否保留前次成果并更能恢复。编号只记录次序；若原方向每次都强势恢复，连续逆向失败也可支持原趋势，不能按次数单调增加反转概率。

计数绑定周期、恢复对象和重置点。按下列条件判断是否重置，并说明所影响的尺度：

| 变化 | 是否重置 |
| --- | --- |
| 旧控制已恢复 | 重置 |
| 新方向在相关区域取得并保住进展，满足事前接受条件 | 重置 |
| 成熟 Range 切断旧运动，或主要结构被替代 | 重置 |
| 观察边界改变 | 按新边界重新计数 |
| 仅局部触价或收盘测试完成，尚未满足上述变化 | 不据此重置，继续核对同一恢复对象 |

### E. K 线与运动事实

市场事实由来源直接提供的 OHLC、trade 或 volume、发生时间、最早可见时间和修订关系，以及下列确定性计算组成；不保存相对优势、控制、形态作用或路径。

设最高、最低、开盘和收盘为 `H`、`L`、`O`、`C`：

```text
总范围   = H - L
实体     = abs(C - O)
实体占比 = abs(C - O) / (H - L)
收盘位置 = (C - L) / (H - L)
上影占比 = [H - max(O, C)] / (H - L)
下影占比 = [min(O, C) - L] / (H - L)
```

`H = L` 时按零波幅 K 处理，不计算比例。几何关系只描述价格事实：

- Bull body：`C > O`；Bear body：`C < O`；
- Inside bar：high 不高于前高，low 不低于前低；
- Outside bar：high 不低于前高，low 不高于前低，且至少一端严格越过；
- Doji：实体相对周围很小或为零；
- Shaved：实体一端与极值严格相等；使用 tick 容差时须事先声明。

Trend bar 与 trading-range bar 是方向表达的连续谱，不按固定实体占比分类。Breakout、Reversal、Signal 是完成 K 或组合在当前区域互动中的作用；跟随指初始表现之后的价格表现。

实体颜色比较本根开盘与收盘，反转作用比较此前运动与当前响应。阴实体下探后收回也可能具有向上反转作用，阳实体上冲后回落也可能具有向下反转作用；是否足够支持参与，仍看位置、收回程度和后续表现，越过自身中点不单独构成信号。

| 准备作出的判断 | 需要核对 |
| --- | --- |
| 这根 K 或组合有 Reversal 作用 | 区域、当前段、范围、实体、收盘、影线，以及已经发生的进展与跟随 |
| 这是 Two-bar 或 multi-bar reversal | 多根是否共同形成反向表达；单一吞没几何不能替代 |
| 这根 K 用作 Signal | 它是否提供当前判断或方案所用的边界 |
| 单根已改变趋势或反转判断 | 当前背景与该事件是否已完成所需条件；尚缺条件时继续观察，参与由 Trade 评价 |
| 首根 K 越过 Signal 边界 | 只确认 Chart Entry Bar；平台触发与成交仍按 Account 记录核对 |
| 同一运动在高周期为单根、低周期为多根 | 共享一组事实，不跨周期重复增加证据 |

严格相邻双棒与来源中按两段相反运动称作的“两根反转”分开。后者可隔着停顿或多根 K，评价时纳入完整过程，不只挑两根方向相反的棒。跨周期聚合须包含所选时段全部 K 并遵守实际周期边界；尚未完成或未查看的高周期反转不当作已确认事实。

- Push / Leg：较大结构中的一段方向运动；
- Pullback：当前方向运动中的暂停或暂时反向；
- Pause：停止扩展极值或横向停顿；
- Actual pullback：所研究上涨中，本根低点严格低于前根低点；下跌中，本根高点严格高于前根高点，即出现当前周期的最小实际回调。无需高低点同时反向，也不要求反色实体；
- Implied pullback：当前周期暂停，但尚未出现上述实际回调；doji 或反色实体也可能属于这种情况。低周期可能已经展开回调，未查看时仍是推断。

严格 Microchannel 从选定起始 K 开始：多头序列每根低点不低于前根低点，空头序列每根高点不高于前根高点。起始 K 是比较基点，不要求它与序列外前根也满足条件；首根违反条件的 K 结束该严格序列，不计入其中。实体可反色，相等极值不结束序列。

使用允许少量小回调的宽泛“微通道”描述时，注明实际回调，不与严格序列计数混用。实际回调或严格微通道结束只改变本尺度的过程描述；趋势是否受损、恢复或转向，仍按[回撤与恢复](#回撤与恢复怎样改变原判断)判断。

第二段的尺度、延伸与失败按[第二段预期](#第二段预期与分段尺度)判断；它不等于等距投射、second signal、second entry 或第二次成交。

### F. Gap：分离事实、直接引用与后续结果

Gap 使用指定价格对象作参照，区分区间分离与参照价差。比较区间时，正宽度表示所比较的区间不重叠，端点相接记为零宽度；negative / overlap gap 表示重叠。区间不重叠不证明其中从未成交，例如非相邻实体之间的空间可能被影线或中间 K 交易过。使用时必须写明方向、周期和比较对象：

- 相邻 K 完整高低范围之间的分离；
- 两个相关实体区间之间的 body gap，参照 K 可相邻或非相邻，分别记录所用 K；
- 隔一根 K 比较完整高低范围的 micro gap，端点恰好相接时记为零宽度接触，不与正宽度分离混同；
- 突破点与 Pullback 之间的开放、负值或重叠；
- 整根 K 未触及指定 EMA 的 moving-average gap bar；
- 事先固定 Session 的 session gap；
- 本根开盘相对前收盘的单根 opening gap。

收盘至参照的 Gap 价差，取突破或高潮末端收盘到前棒极值、旧突破点等参照的距离。固定收盘时点与参照价；该距离可能跨过已经交易的价格，不记为未成交空白。后续“回补”明确是重新触及该参照，还是完成所要求的回入、接受；不能用另一类 Gap 的关闭条件代替。测量中点的构造见[候选区域投射](#从哪些锚点投射候选区域)。

几何名称不能互换，也不直接决定强弱。关系事实保留锚点及当前关系：新形成、保持、收窄、轻微重叠、完全关闭，或关闭后重新接受旧区域。长期未触 EMA 后的首次测试与单根 moving-average gap bar 是不同对象，均不自动生成入场。

**哪些 Gap 需要跟踪：**

| 引用情况 | 处理 |
| --- | --- |
| 当前预期、接受/失败或路径结果引用某 Gap | 进入运行卡；标明比较对象、周期与当前关系，事前明确保持、收窄、重叠、关闭各改变什么 |
| 同一 Gap 被多个结论引用 | 事实保存一次，各结论按自身条件更新；不同周期或问题分别标明影响 |
| 同一运动留下多个被当前结论引用的 Gap | 分别核对各自是否关闭，不以其中一个代替其他 Gap |
| body gap、micro gap、突破回调 Gap、微型通道与极值推进来自同一运动 | 按一组共享事实使用 |

保持、交还和恢复怎样改变预期，统一按[区域互动](#36-区域互动与预期更新)判断；Gap 提供具体参照。关闭对手的分离同时保住本侧进展，可以支持优势转移，持续控制仍按相应尺度核对。只关闭某一 Gap 时，先更新引用它的判断，不能代替对手的进展。

- **跟随减弱，但所引用 Gap 尚未关闭** → 依赖关闭的判断仍未决；运动停止或时间修正可独立成立。
- **比较测量与衰竭解释** → 按[异常延伸背景](scenarios.md#七趋势异常加速或持续过久)核对该分离、旧区域接受及随后恢复；Breakout、Measuring、Exhaustion 是结合背景与后续的解释，不能只凭几何确定。
- **采用 Gap 区间、中点或投射** → 按[区域作用](#35-重要区域图与路径作用)评价目标、障碍或检查点；未经采用仍为候选。

### G. 趋势线与通道线

多头趋势线连接两个相关向上反转低点；空头趋势线连接两个相关向下反转高点。优先使用强段起点、强反转或显著拐点，不用大量小线填满图表。

增加一个测试点时，核对此前是否已有可区分的离开与返回。连续贴线中的相邻极值可属于同一次测试，不因多根触线而增加测试次数；间隔很短但有清楚回调，也可能形成新测试。按所选尺度辨认过程，不用固定时间倍数判定，结构上分开也不代表统计独立。

通道候选来自把趋势线平行复制到另一侧显著极值，或直接连接另一侧两个相关反转点。

也可先连接多头通道外侧两个相关高点，再向下平移到两点之间的相关低点，使这段价格尽可能包含在通道内；空头从两个相关低点向上平移到其间高点。固定所用两点、平移接触点与当时范围，检查整段容纳情况，不只挑出有利于当前入场的线位。斜线位置随时间变化，触线不等于价格已经回到较早时点的线价。

| 新表现 | 线的处理 |
| --- | --- |
| 持续产生反应 | 保留 |
| 出现新主要极值或失败突破 | 建立重画候选，核对其当前作用 |
| 轻微 overshoot/undershoot，且无良好跟随 | 不自动判原线失效 |
| 强越界并获得良好跟随 | 不再作为当前边界 |
| 长期不再产生响应 | 休眠 |
| 原边界仍可用作回试区 | 更新作用后保留 |
| 需要同时使用多条线 | 保留周期、尺度、用途不同的线，或同一问题下会改变目标、保护或边界判断的合理候选；只重复同一区域的画法合并 |
