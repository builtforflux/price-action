# 市场判断：从观察到双向机会

## 一、唯一职责

Market 只回答四个问题：在哪里、应该怎样、实际怎样、可以去哪里。答案形成双向路径；交易由 [Trade](trade.md) 决定，账户和平台记录由 [Account](account.md) 核对。

```text
背景与位置
→ 合理预期
→ 实际进展与跟随
→ 测试结果与相对优势
→ 双向路径
```

当前事件先回答测试，再更新相对优势；优势持续到足以组织正常回调、预期和路径时，才改变控制或市场组织。已知背景、位置和当前尝试却仍缺预期或路径时，按需查询[场景导航](scenarios.md)，采用适用的候选事实后返回本页继续判断。

## 二、运行卡

盘中只维护这一张卡。首次判断、主问题变化或上次可靠判断已经不再适用时完整展开；普通事件只写新事实及其改变的答案，其他内容沿用上次可靠判断。

最小记录保留判断时间、当时最晚可见数据和来源，并在运行卡顶部写“本次新事实”。这里仅引用新增可见事实；对应段落只保存它改变的结论，不复制完整历史。不得用后来的事实改写当时已知内容。

### 1. 在哪里

先确定观察边界：

- 品种、数据来源、主周期与 K 线构造；
- 最新可靠完成 K；
- 当前窗口是否足以解释主问题。

数据、未完成事件、外层周期、Session 或流动性边界只有确实改变判断时才展开；记录受影响结论、最后可靠时间和下次检查。来源修订从最早受影响处重判。

再说明背景：

- 市场组织：单边控制 / 双边平衡 / 转换中 / 不清楚
- 控制方向：多头 / 空头 / 双方平衡 / 尚未确认
- 当前阶段：
  - 单边时：启动 / 发展 / 成熟 / 受损
  - 双边时：形成 / 成熟 / 决断中
  - 转换时：旧控制受损 / 新控制尚未接受
  - 不清楚时：阶段隐藏，控制方向为“尚未确认”

最后说明位置：区间底部 / 中部 / 顶部 / 区间外，或趋势、通道内当前真正起作用的区域。

只登记当前尝试或路径引用的重要区域：

- 区域：
- 价格带：
- 来源：
- 周期：未注明时继承主周期

区域只保存价格带、来源和周期；距离、期限及路径目标、障碍、检查点或失效等作用由引用它的尝试或路径保存。

### 2. 应该怎样

默认只展开一个主测试：哪一方正在什么区域尝试什么；它以何种方式到达，属于延续、回调、区间段还是反转尝试，目前处于接近、触及、反应、突破尝试还是等待跟随。

- 当前尝试与测试区域：
- 若当前解释成立，接下来应出现的表现：
- 预期时限：最迟何时应出现

### 3. 实际怎样

- 初始表现：哪次完成 K、组合或价格事件取得了什么，又回吐了什么
- 跟随：进展随后被延伸、保住、回试守住、恢复，还是被交还；对手是否取得并保住自己的进展
- 预期差：符合 / 暂无实质变化 / 弱于预期 / 否定预期
- 测试结果：接受 / 失败 / 未决
- 相对优势：在本周期、当前运动、测试区域和当前问题内，哪一方更能取得并保住进展；接近或不清楚时直接写明
- 下一观察：

接受条件和失败条件在测试开始前写明。测试对象、最终结果、期限和后续影响均独立时，可以展开第二测试；两个测试最终仍汇入现有双向路径。

### 4. 可以去哪里

没有实际仓位且本交易尚未提交订单时，同时维护向上、向下路径，每个方向一条。首次提交相关订单后维护所选路径；Account 确认[本笔交易结束](account.md#本笔交易结束)后恢复双向搜索。

- **路径完整**：显示当前测试、沿途障碍或检查点、唯一路径目标及完成条件、失效区域及条件、参与前条件、路径目标可达性、期限、最强支持与反方事实、本次变化和下一观察。
- **等待形成**：只显示尚缺事实、下一事件和最晚等待时间。
- **当前排除**：只显示路径目标、空间、时间或形成条件中的一个主因。
- **实现 / 失效 / 到期 / 替代**：本笔交易尚未结束时保留旧路径的最终结果，不建立新路径。

路径完整时，路径目标、关键区域、失效和本次变化使用本页后文的完整条件。

## 三、判断规则

### 3.1 一组事实，四个答案

价格、时间、成交资料、修订及确定性计算是源事实；区域、Swing、线、Gap、重叠、越界和回试是可复核关系。它们只登记一次，再进入实际回答的问题：

| 问题 | 只保存 |
| --- | --- |
| 在哪里 | 市场组织、阶段、重要区域和当前尝试 |
| 应该怎样 | 当前解释成立时应有的正常后续和期限 |
| 实际怎样 | 初始表现、跟随、预期差、测试结果和相对优势 |
| 可以去哪里 | 双向路径的区域作用、路径目标、完成、失效、期限和可达性 |

名称只保留独有的几何、次序、阶段或重置作用。新内容进入它实际改变的第一个答案；只有该答案改变后续结论时才继续更新。未被当前答案引用的关系留在结构视图或盘后证据中。

Volume、DOM、新闻或情绪资料只提示组织和尾部风险；方向结论仍由价格对当前测试、相对优势或路径的实际影响形成。

### 3.2 观察边界与多周期

观察边界说明本次判断适用于哪张图、哪种 K 线和哪段当时可见历史。

- 默认使用完成 K；事先允许的未完成价格事件标为暂时事实。
- 观察窗口覆盖当前互动区域、主测试起点、关键结构边界、最近有效转换，以及路径目标、失效和期限。
- 自定义 Session 在确实改变流动性、路径目标可达性或期限时进入判断；全天连续交易产品按自身时间结构处理。
- 每个重要区域、当前互动和路径绑定周期，未注明时继承主周期。
- 外层周期显示它对路径目标、正常回撤、失效、空间、期限或测试解释的实际影响；低周期提供入场事实。
- 无法共享路径目标、失效和期限的周期分别形成观察边界明确的判断。Trade 引用其中一条完整路径，其他周期作为外层事实。

### 3.3 数据可靠性

| 数据情况 | Market 结论 | 后续限制 |
| --- | --- | --- |
| 可靠 | 正常判断 | 继续运行 |
| 存在数据缺失区间但能证明不影响当前主问题 | 标明限制后继续 | 不把缺失区间解释成价格事实 |
| 数据缺失影响必要事实，或无法证明不影响 | 按不可用处理 | 不猜测缺失区间 |
| 不可用且没有相关订单或仓位 | 不形成新路径 | 记录下次检查和最晚等待时间 |
| 不可用且本笔交易尚未结束 | 保留最后可靠路径，只报告数据不可用 | Trade 按事前可靠性期限处理 |
| 来源已修订 | 保留旧事实并从最早受影响处重算 | 不静默覆盖历史判断 |
| 未完成 K 且未获允许 | 等待收盘 | 不输出基于该 K 的正式变化 |

市场判断只报告数据状态和最后可靠结论，不因数据缺失自行决定持有或平仓。

### 3.4 市场组织、控制与阶段

市场组织先分四类：

#### 单边控制

一侧能够持续扩展极值，并限制对手在正常回撤边界内活动。结构可以表现为 Breakout/Spike、Tight Channel、Broad Channel 或 Trending Trading Range。

#### 双边平衡

双方都能推动、反转和获利，没有一侧持续获得外部接受。结构可以表现为 Trading Range、Breakout Mode、Triangle 或其他双向边界。

#### 转换中

旧控制已经受损，但新方向尚未获得足以组织正常回撤、路径目标和后续路径的接受。

#### 不清楚

事实不足或解释冲突。当前阶段留空，控制方向为“尚未确认”；能够明确测试对象、下一事实和期限时等待形成，否则当前排除。新事实足以形成单边控制、双边平衡或转换中后，再按对应阶段判断。

阶段决定同一强度事实的意义：

- 启动阶段的强初始表现和良好跟随更可能建立新失衡；
- 发展阶段看正常回调后能否快速恢复；
- 成熟阶段的最大 K、加速和缺口必须同时检查高潮、路径目标和空间；
- 受损阶段关注旧控制能否恢复，以及反方向能否获得接受；
- 双边成熟后关注边缘反应，决断阶段关注哪一侧获得外部接受。

“成熟”不能只由持续时间、单根大 K 或事后结果命名。单边成熟至少要同时指出：原方向已经持续扩展或长期缺少改变主结构的回调；当前位置已接近事前路径目标、旧极值或通道外侧，并出现异常延伸、恢复变慢或双向化中的可见变化。双边成熟则要求有效边界在本次到达前已经可识别，双方围绕同一内部区域反复测试，且没有一侧持续获得外部接受。这里不使用固定根数或成熟度评分。

“主要结构破坏”也必须绑定事前参照：控制方向正常回调所依赖的主要 HL/LH、趋势段或有效边界不再约束价格，按观察边界允许的完成事实越界后又获得良好跟随。单次影线、只穿越一条趋势线或一根普通反色 K 只提示受损；结构破坏本身仍不等于反方向已经获得接受。

控制只有在持续能力发生变化时切换。原侧削弱但仍能在正常回调内恢复，且反方没有获得接受，控制不切换。单根普通反色 K 不足以确认转换。

Always In 只是清晰控制的来源别名，不表示账户持仓。Trapped、Disappointment 和 Pain Trade 等叙事必须还原为可见的预期、跟随、失败、接受和空间事实。

### 3.5 重要区域图与路径作用

重要区域是所有位置判断的共同底图。先确定价格当前处于区间底部、中部、顶部或区间外，或者趋势、通道内哪个区域正在实际起作用，再从以下可复核来源寻找候选区域：

- 前高低和主要 Swing；
- 区间边界、中部和突破点；
- Gap、趋势线和通道线；
- 端点固定的比例区域和测量投射；
- 盘前固定参数的 EMA；
- 重要开高低收、整数区域和其他可观察价格带。

这些来源只产生候选区域。只有当前互动或路径实际引用的区域才进入重要区域图；同一价格带只登记一次，并只保存价格带、来源和周期。

作用写在引用区域的互动或路径中，不是区域的永久属性：

| 作用 | 含义 |
| --- | --- |
| 支撑 / 阻力 | 某侧可能恢复或受阻；接受性突破后可以交换 |
| 磁吸 | 当前组织与价格表现支持前往测试，不保证到达后反转 |
| 障碍 | 可能阻止路径目标，进入可达性和最强反方事实 |
| 检查点 | 到达不结束路径，但正常或异常表现会改变判断 |
| 路径目标 | 该方向路径唯一要完成的市场结果 |
| 失效参照 | 帮助定义否定路径的市场事实，不等于 Trade 确定的全仓计划止损 |

运行卡只显示当前互动或路径引用的区域。到路径目标前所有会实质改变可达性或后续判断的区域都必须分类；普通情况只显示最近一个，多个区域分别改变不同结果时全部保留。未分类关键区域意味着路径尚未完整。

#### 路径怎样选择目标区域

当前路径只选择一个同时满足以下条件的目标区域：

1. 来源和周期可复核；
2. 当前组织、阶段、尝试和合理预期确实指向它；
3. 更近区域已归为障碍或检查点，并有正常与异常后果；
4. 该路径目标尚未被消耗，按当前组织能在期限内到达；
5. 完成条件可观察并已事前确定。

依赖跳过未决障碍、异常单根延伸或临时外移路径目标时，路径目标不可达。近端区域未处理时路径等待或排除。其他区域只用作测试、障碍、检查点、磁吸或失效参照；Trade 可以在较近区域出场，但不改变 Market 的结果事件。比例端点和 EMA 参数必须事前固定。

### 3.6 当前区域互动、价格表现与预期差

区域回答“在哪里”，价格表现回答“发生了什么”；两者通过当前尝试和合理预期结合。合理预期必须在结果出现前确定。运动方向与外层作用分开，同一段下行可以是多头回调，也可以是区间向下段。所有名称都还原为：

```text
谁在什么区域尝试什么
→ 若成功应怎样表现
→ 初始表现取得或交还了什么进展
→ 后续是否延伸、保住、回试守住或恢复
→ 对手是否取得并保住自己的进展
→ 预期差、相对优势、测试和路径怎样变化
```

现有判断按以下依赖生成，不维护平行评分或同义状态：

| 概念 | 从什么生成 |
| --- | --- |
| 初始表现 | 一次完成 K、组合或事件取得并交还了多少方向进展 |
| 跟随 | 后续是否延伸、保住、回试守住或恢复该进展，以及对手是否取得自己的进展 |
| 预期差 | 初始表现与跟随相对合理预期是符合、无实质变化、偏弱还是否定 |
| 相对优势 | 双方在同一周期、运动、区域与问题中取得并保住进展的直接比较 |
| 接受 / 失败 | 事前确定的测试最终条件是否完成 |
| 控制与组织 | 相对优势是否持续到足以组织正常回调、预期、路径目标和后续路径 |

**方向表达**属于初始表现，不是独立的“K 线质量”状态。实体相对周围有意义、收近尝试方向端点、影线较短、重叠和回吐较少且实际位移较大，通常表示取得较多方向进展，并交还较少进展；相反特征表示更多双向交易。它只有放回当前区域、阶段和合理预期中才有意义：巨大 K 位于成熟阶段、路径目标附近或消耗剩余空间时，仍可能是高潮或不合格入场；多根较小但持续推进的 K 也能建立失衡。

Buying/Selling Pressure 只是相对优势的来源语言，连续性只概括多次良好跟随，二者都不单独维护。单根巨大趋势 K 先记为强初始表现；接受或控制切换仍需要事前要求的跟随。Signal Bar 只有被当前路径用作参与理由或边界时才显示；若越界本身不足以完成唯一尚缺条件，就继续等待收盘、跟随、回试守住或持续接受。

同一运动的趋势 K、Gap、Microchannel、浅回调和极值推进共享事实。某项关系不再成立时，只重算直接引用它的结论；没有对手自己的进展和跟随时，优先检查原结论削弱、通道化或双边化，而不是自动反转。

#### 预期差与测试结果

接受与失败条件必须在最终结果发生前写清。测试结果只有三种：

- **接受**：事前要求的收盘或跟随已经发生；跟随条件可以具体表现为延伸、保持在外、回试守住或恢复；
- **失败**：尝试没有获得应有接受，旧区域或竞争方向重新获得接受并实质否定原路径目标；
- **未决**：接受和失败的边界明确，但任一最终结果尚未发生。

没有立即出现良好跟随通常先记为弱于预期，不单独确认失败。普通回调也不会自动确认失败。测试期限结束或主问题被替代后，旧测试结束。

市场事实、重要区域和阶段先转换为合理预期，再与实际价格表现比较。H2、Gap、Pressure、突破、第二段、EMA 测试等来源名称都通过这一步形成当前判断。

#### 预期路径失败

以下顺序用于识别第二段陷阱、强突破后跟随不足、恢复尝试失败和其他“先建立合理预期、随后异常失败”的共同机制：

1. 前一段事实足够强，合理建立明确的后续预期；
2. 预期中的第二段、恢复或再次尝试实际出现；
3. 它发生在会限制延续的区域，例如区间边缘、磁点、测量投射区域或成熟趋势末端；
4. 该尝试未获得本应出现的跟随或外部接受；
5. 旧区域或反方向随后获得接受，才确认原预期失败；
6. 原路径按事实削弱或失效，竞争路径仍须独立具备路径目标、空间、完成和失效条件。

第二段陷阱不是第一段后的首次反转，也不是“第二段一定失败”。在清楚趋势早期，同样强度的第二段更可能是真实延续；在双边边缘，它可能只是真空测试。

### 3.7 双向路径

每个方向用一条当前市场路径表达方向机会。

#### 路径完整

路径只有在以下内容全部明确时才完整：

- 当前测试、沿途作用、唯一路径目标和失效参照都引用同一张重要区域图；
- 唯一路径目标已登记来源和周期，并绑定可观察完成条件；
- 路径目标与当前组织、阶段和预期一致，且空间与时间支持其到达；
- 参与前市场条件；
- 到达前所有关键区域已有当前作用；其中会改变可达性或后续判断的区域已经归为障碍或检查点；
- 障碍与检查点的正常预期和异常后果；
- 失效参照引用已登记区域，并绑定失效条件、期限、剩余空间和时间；
- 最强支持事实和最强反方事实。

参与条件已经完成，或者一个精确、可观察的价格事实本身足以完成唯一尚缺条件时，路径才可交给 Trade。

要求收盘、跟随、回试守住或持续接受的条件，不能由单纯触价完成，必须继续等待。

#### 等待形成

必须同时存在：

- 真实的当前测试；
- 精确的下一事实；
- 明确的最晚等待时间。

等待形成保存真实测试、下一事实和最晚等待时间；下一事实完成后重新判断路径。

#### 当前排除

只显示一个主因：

- 没有可达的路径目标；
- 没有足够空间；
- 没有足够时间；
- 没有形成条件。

当前排除持续到路径目标、空间、时间或形成条件发生实质改变。

### 3.8 首次建立与路径变化

等待形成首次达到路径完整时，只记“首次建立”，不把建立本身称为增强。

路径首次完整时，当前路径目标、完成条件和有效期限共同确定一个市场结果事件。之后：

- 仍表示同一事前区域、不会改变该事件是否已经完成、失效或到期的边界精化，可以作为路径更新保留，并记录精化依据；
- 改变目标事件、完成条件或结果期限，属于实质换目标；旧路径先记为“替代”，新目标只能作为新路径“首次建立”，不能写成增强、削弱或对历史字段的覆盖；
- 原路径目标已经完成时，旧路径先记为“实现”；任何更远延伸都是新路径，不能把原路径目标向外移动；
- 本笔交易尚未结束时，旧路径得出最终结果后不得建立延伸路径；Trade 按原方案完成平仓和撤单，本笔交易结束后再恢复双向搜索。

障碍、检查点、支持事实或反方事实可以随新事实更新；只要目标事件、完成条件和期限未变，就不因此创建新路径。

已有完整路径先判断是否出现最终结果：

1. 实现；
2. 失效；
3. 到期；
4. 替代。

多个最终结果先后可知时采用最先发生者。当前数据粒度无法确认先后时，使用“替代”结束旧路径，复盘保留“先后未知”，不得选择对账户更有利的结果。

没有最终结果时才判断：

- 增强：实际价格表现继续符合或超过原预期；
- 未变：实际价格表现属于事前允许的正常波动；
- 削弱但仍有效：实际弱于预期，但失效条件尚未完成。

路径实现、失效、到期或替代后固定最终结果。若本笔交易尚未结束，只继续提供止损、期限或出场条件依赖的市场事实，不建立新路径。延伸或反向交易必须在本笔交易结束后重新建立路径。

## 四、每次市场唤醒

### 4.1 唤醒来源

- 新完成 K；
- 事先允许使用的未完成价格事件；
- 测试、路径或数据可靠性期限；
- 数据恢复、缺失区间确认或来源修订；
- 首次完整分析、接管或完整重判条件。

### 4.2 普通更新

普通新 K 只做六件事：

1. 写入本次新事实；
2. 更新受影响的价格关系、初始表现或实际跟随；
3. 用更新前已经确定的合理预期判断预期差和测试结果；
4. 更新相对优势；只有持续能力改变时，才进一步更新控制、阶段、市场组织或当前互动，并为下一事件建立新预期；
5. 更新受影响路径的结果或变化；
6. 写明下一观察。

没有后续变化时立即停止，不重新抄写市场组织、重要区域、当前互动和路径全文。

直接改变接受、失败、路径目标、失效或期限的新事实必须继续更新相关结论；其余事实更新直接对应的答案后停止。

### 4.3 完整重判

以下情况从观察边界重新建立：

- 品种、主周期或 K 线构造改变；
- 数据缺失区间或来源修订影响旧结论；
- 接管时无法证明旧判断仍可靠；
- 主测试被独立新问题替代；
- 市场组织、关键结构锚点或阶段发生替代；
- 多周期关系改变路径目标、失效、空间或期限；
- 原路径已有最终结果，且本笔交易已经结束。

## 五、交给交易决策

Market 向 [Trade](trade.md) 提供观察边界、数据可靠性、组织、重要区域、当前互动和方向路径。路径直接引用测试、沿途障碍或检查点、唯一路径目标、失效参照、参与条件、期限及所需价格边界。

没有相关订单或仓位时提供双向路径；提交相关订单后只提供所选路径、最强反方事实和本次变化，直到本笔交易结束。路径完整只允许 Trade 制定具体交易方案，不评价交易质量，也不直接决定加仓、减仓、平仓或账户结果。

## 六、稳定事实附录

本附录用于首次分析、复核和完整重判，不是每根 K 的检查表。

### A. 结构视图怎样共享事实

同一组 Swing 可以同时形成 H2、Double Bottom、Bull Flag 或 MTR 组件。价格事实只登记一次，各视图只保留独有作用。

| 结构视图 | 共享事实 | 独有作用 |
| --- | --- | --- |
| ii / iii | 连续 inside bars | 压缩范围和边界 |
| ioi | inside–outside–inside | 双边扩张后的再压缩 |
| oo | 连续 outside bars | 双边扩张和不稳定边界 |
| Triangle | 双方反复测试 | 两侧有效边界和成熟度 |
| Expanding Triangle | 双方交替测试并扩张极值 | 扩张边界和测试次序 |
| Double Bottom / Top | 两次运动测试同一区域 | 重复测试区、Neckline 和高度候选 |
| Wedge | 三次可区分的同向推动或测试 | 推动次序、斜率和延伸质量 |
| Flag | 外层方向中的局部结构 | 局部结构对延续或反转的作用 |
| Final Flag | 成熟趋势末端的局部平衡 | 实时候选与事后结果分开 |
| H1/H2…、L1/L2… | 同周期、同恢复对象内的尝试 | 尝试次序、信号边界和重置点 |
| H&S | 旧极值测试、结构破坏和右肩 HL/LH | MTR 组件关系，不建立独立流程 |
| MTR | 成熟趋势后的反向发展 | 从 minor reversal 到控制转移的阶段 |

名称只用共享事实和独有作用更新市场组织、重要区域或当前互动，不直接生成路径、概率或交易。

### B. 区间、比例与候选区域投射

区间边界取当前反复组织价格的两个区域。一次影线或轻微越界不会自动改写边界。

设下沿为 `L`、上沿为 `U`、高度为 `R`：

```text
R = U - L
中部 = L + R / 2
底部三分之一区域 = L 到 L + R / 3
顶部三分之一区域 = U - R / 3 到 U
```

当前段从 `A` 到 `B` 的半程为 `A + (B - A) / 2`。

常见投射：

```text
Leg 1 = Leg 2 投射：第二段起点 C + 第一段位移 (B - A)
Range 向上投射：上沿 + Range 高度
Range 向下投射：下沿 - Range 高度
Double Bottom 投射：Neckline + Neckline 到底部区域的高度
Double Top 投射：Neckline - 顶部区域到 Neckline 的高度
```

所有端点必须在判断时已经可见并固定。投射只产生候选重要区域；只有被当前路径选中后，它才用作路径目标或发挥其他作用。仍须检查更近障碍、剩余空间和时间。50%、三分之一和测量值本身不生成反转或入场。

### C. Double Test 与 Neckline

Double Bottom / Top 的两次测试：

- 不要求精确同价；
- 必须是两次可区分的运动；
- 必须指向同一有意义区域；
- 中间必须有可见的反向 Swing。

Double Bottom 的 Neckline 是两次底部测试之间最高的相关反向 Swing high 区域；Double Top 镜像为最低的相关 Swing low 区域。

高度投射成为可达的路径目标前，至少还需要 Neckline 突破后获得跟随或回试守住之一。Double Test 可以先于 H2/L2 形成，但不能证明 second entry 已触发。

### D. H/L 次序与重置

多头次序：

1. 第一次向上 Trigger 为 H1；
2. 再次回调后，完成 K 定义第二个边界，形成 H2 setup；
3. 越过该高点形成 H2 Trigger；
4. 首根越界 K 为 Chart Entry Bar。

空头完全镜像。严格 second entry 要求第一次 chart entry opportunity 已经触发。Signal Bar 只定义市场边界；是否采用、提交和成交属于后续环节。

H3/L3 可以与 Wedge 共享推动事实。出现更高编号时，应先检查是否已经成为 Triangle、Trading Range 或新的 Pullback 对象。

计数始终绑定周期、恢复对象和重置点。以下情况重置：

- 旧控制已经恢复；
- 新方向获得接受；
- 成熟 Range 切断旧运动；
- 主要结构被替代；
- 观察边界改变。

### E. K 线与运动事实

市场事实由来源直接提供的 OHLC、trade 或 volume、发生时间、最早可见时间和修订关系，以及下列确定性计算组成；不保存相对优势、控制、形态作用或路径。

设最高、最低、开盘和收盘为 `H`、`L`、`O`、`C`：

```text
总范围   = H - L
实体     = abs(C - O)
实体占比 = abs(C - O) / (H - L)
收盘位置 = (C - L) / (H - L)
上影占比 = [H - max(O, C)] / (H - L)
下影占比 = [min(O, C) - L] / (H - L)
```

`H = L` 时按零波幅 K 处理，不计算比例。几何关系只描述价格事实：

- Bull body：`C > O`；Bear body：`C < O`；
- Inside bar：high 不高于前高，low 不低于前低；
- Outside bar：high 不低于前高，low 不高于前低，且至少一端严格越过；
- Doji：实体相对周围很小或为零；
- Shaved：实体一端与极值严格相等；使用 tick 容差时须事先声明。

Trend bar 与 trading-range bar 是方向表达的连续谱，不是固定实体占比分类。Breakout、Reversal 和 Signal 是当前区域互动赋予完成 K 或组合的市场作用：Reversal 必须结合区域、当前段、范围、实体、收盘、影线和后续跟随；Two-bar 或 multi-bar reversal 由多根共同形成反向表达，不能被单一吞没几何替代；Signal 只有被当前路径用作参与理由或边界时才显示。跟随是初始表现之后的价格表现，不是另一种 K 线类型。单根 K 不建立趋势、确认反转或许可交易。

Chart Entry Bar 只是首根越过 Signal 边界的图表事实，不能证明平台订单已经触发或实际成交；实际执行仍以 Account 核对的平台记录为准。同一运动在高周期的单根表达与低周期的多根展开只是一组事实，不能跨周期重复增加证据。

- Push / Leg：较大结构中的一段方向运动；
- Pullback：当前方向运动中的暂停或暂时反向；
- Pause：停止扩展极值或横向停顿；
- Actual pullback：当前周期已出现反向高低点运动；
- Implied pullback：当前周期仅暂停，低周期可能已经展开回调。

第二段可以很短、横向、不创新极值或快速失败。它不等于等距投射、second signal、second entry 或第二次成交。

### F. Gap：分离事实、直接引用与后续结果

Gap 比较两个相关价格对象之间的分离或重新重叠程度。正 Gap 表示两者之间仍有未被重新交易的空间；negative / overlap gap 表示相关锚点已经轻微重叠。使用时必须写明方向、周期和比较对象：

- 相邻 K 完整高低范围之间的分离；
- 相邻实体区间之间的 body gap；
- 隔一根 K 比较的 micro gap；
- 突破点与 Pullback 之间的开放、负值或重叠；
- 整根 K 未触及指定 EMA 的 moving-average gap bar；
- 事先固定 Session 的 session gap；
- 本根开盘相对前收盘的单根 opening gap。

这些几何名称不能互换，也不直接决定强弱。关系事实只记录相关锚点和当前是新形成、保持、收窄、轻微重叠、完全关闭还是关闭后重新接受旧区域。长期未触 EMA 后的首次测试与单根 moving-average gap bar 不是同一对象，也不会自动生成入场。

同一次运动可以留下多个 Gap，它们可能在不同时间关闭。运行时逐项直接引用：

- 合理预期、价格表现、接受或失败条件、路径完成或失效条件需要某个 Gap 时，直接引用其比较对象、周期和当前关系，并事前写明保持、收窄、重叠或关闭会怎样改变该结论；
- 同一 Gap 被多个结论引用时，关系事实仍只保存一次，各结论分别按自己的条件重算；
- 当前结论引用的 Gap 进入运行卡；同一 Gap 在不同周期或问题中的影响由各自结论表达并标明周期；
- 来自同一运动的 body gap、micro gap、突破回调 Gap、微型通道和极值推进按一组共享事实使用。

Gap 只通过初始表现和跟随影响相对优势：一次新分离可以构成初始进展；随后保持、扩展、回试守住或普通回调后恢复，可以构成良好跟随；关闭对手分离只有在本侧同时取得并保住进展时，才支持优势转移。某段分离关闭只更新直接引用它的跟随、测试或路径；若对手没有自己的进展和良好跟随，结果优先是原结论削弱或失效以及通道化、双边化，不是自动反转。

Breakout Gap、Measuring Gap 和 Exhaustion Gap 是市场组织、阶段、区域与后续价格表现共同形成的解释，不是出现时即可确定的几何类型：

- 分离保持、继续获得同向跟随或回试守住，支持突破接受或测量解释；
- 分离关闭、重新接受旧区域并出现反向恢复，支持失败或衰竭解释；
- 跟随减弱但事前要求保持的分离尚未关闭时，仍是未决；
- Gap 区间、中点或投射只生成候选重要区域，被当前路径选择后才用作路径目标、障碍或检查点。

### G. 趋势线与通道线

多头趋势线连接两个相关向上反转低点；空头趋势线连接两个相关向下反转高点。优先使用强段起点、强反转或显著拐点，不用大量小线填满图表。

通道候选来自把趋势线平行复制到另一侧显著极值，或直接连接另一侧两个相关反转点：

- 持续产生反应时保留；
- 新主要极值或失败突破出现时建立重画候选；
- 轻微 overshoot/undershoot 且无良好跟随时不自动失效；
- 强越界并获得良好跟随后不再作为当前边界；
- 长期不再产生响应时休眠；
- 仍可作为回试区时改变作用后保留。

多条线只有在周期、尺度或用途不同的时候并存。
