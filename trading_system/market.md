# 市场判断：从观察到双向机会

## 一、唯一职责

本页把当时可见的市场事实整理成可复核的市场判断，并向交易决策交付向上和向下的现实路径。

市场判断只回答六个问题：

1. 当前观察边界是否可靠；
2. 市场现在怎样组织，处于什么阶段；
3. 价格位于哪里，上下还有多少现实空间和时间；
4. 当前哪一侧正在尝试什么；
5. 如果该侧有控制，市场接下来应怎样表现，实际又怎样表现；
6. 向上和向下分别有什么现实路径，本次新事实改变了什么。

唯一判断顺序是：

```text
观察边界
→ 背景与位置
→ 当前尝试
→ 合理预期与实际表现
→ 双向路径
→ 首次建立或本次变化
```

这是一条推理链，不是六张表。普通新 K 只更新发生变化的字段。

本页不负责：

- 决定交易、等待或放弃；
- 选择订单类型、入场价格或数量；
- 计算账户风险；
- 推断订单已经触发、成交、撤销或退出；
- 决定持有、加仓、减仓或离场。

图表越过一个价格，只能证明市场发生了越界，不能证明账户订单已经触发或成交。

当事实、背景、位置和当前尝试已经明确，但仍不知道怎样组织双向路径时，按需查询[常见市场场景](scenarios.md)。场景页不保存第二套状态，也不建立逐 K 生命周期。

## 二、运行卡

盘中只维护这一张卡。首次判断、主问题变化或可靠基线丢失时完整展开；普通新 K 只更新“本次新事实”“预期与实际”“路径变化”和“下一观察”。未变化的结果沿用上次可靠判断。

系统自动保存判断时间、当时最晚可见数据和来源修订历史。不得用后来的事实改写当时已知内容。

### 观察边界

正常时只显示：

- 品种、数据来源、主周期与 K 线构造；
- 最新可靠完成 K；
- 当前窗口是否足以解释主问题。

只有异常或确实影响判断时才展开：

- 数据问题：缺口、不可用范围、最后可靠时间、受影响结论和下次检查；
- 来源修订：从最早受影响处重判；
- 获准使用的未完成价格事件；
- 外层周期改变的目标、正常回撤、失效、空间或期限；
- Session、时区或流动性边界造成的实际影响。

- 市场组织：单边控制 / 双边平衡 / 转换中 / 不清楚
- 控制方向：多头 / 空头 / 双方平衡 / 尚未确认
- 结构视图，仅保留真正影响解释的结果：
- 当前阶段：
  - 单边时：启动 / 发展 / 成熟 / 受损
  - 双边时：形成 / 成熟 / 决断中

- 当前使用的重要区域，只登记有消费者的条目：
  - 区域：
  - 来源：
- 主区域：引用重要区域
- 上方最近活动区域与可用距离：引用重要区域，并显示当前价格到该区域的距离
- 下方最近活动区域与可用距离：引用重要区域，并显示当前价格到该区域的距离

解释证据不另建必填表。压力、形态、指标关系等只有改变控制、阶段、当前尝试、预期或路径时，才在“本次新事实”或对应依据中写明。一侧削弱不等于另一侧增强，反方向必须有自己的成立事实。

### 当前尝试、预期与实际

## 三、共同判断语法

### 3.1 四个层次只有一个事实来源

| 层次 | 唯一内容 | 不包含 |
| --- | --- | --- |
| 市场事实 | 来源直接提供的价格、时间、成交资料和修订 | 支撑、压力、形态或交易判断 |
| 结构视图 | 区域、Swing、线、Gap、H/L 次序和形态几何 | 独立路径、概率或订单 |
| 市场判断 | 组织、阶段、位置、尝试、预期与实际表现 | 账户动作 |
| 市场路径 | 某方向的目标、完成、失效、期限和现实性 | 订单触发、成交或持仓结果 |

同一事实只登记一次。结构名称只保留独有的几何、次序、阶段或重置职责，不复制证据、建立平行流程或增加概率。

任何新事实、形态、指标关系、行为解释或课程概念只能进入以下一个运行入口：

- 改变市场组织、控制或阶段：写入背景；
- 改变当前互动区域或某价格带的职责：写入位置；
- 提出或改变市场正在验证的问题：写入当前尝试；
- 改变成立条件下的正常后续表现，或提供对它的实际响应：写入预期与实际；
- 改变某方向的完成目标、参与条件、关键区域、失效、期限或现实性：写入路径。

一条知识可以支持多个结论，但事实只保存一次，每个结论仍由自己的条件完成。无法改变上述任一运行结果的内容只作为结构视图、证据或隔离项，不进入运行卡。

### 3.2 观察边界与多周期

观察边界说明本次判断适用于哪张图、哪种 K 线和哪段当时可见历史。

- 默认只使用完成 K。未完成 K 只有在方法事先允许的具体价格事件中才能参与，并标为暂时事实。
- 观察窗口不使用固定根数。它至少覆盖当前互动区域、主测试起点、关键结构边界、最近有效转换，以及路径的目标、失效和期限。
- 全天连续交易产品没有天然日内开盘。自定义 Session 只有真实改变流动性、目标可达性或期限时才进入判断。
- 每项位置、测试和路径都绑定周期；未注明时继承主周期，不得无声切换。
- 外层周期只有改变目标、正常回撤、失效、空间、期限或测试解释时才显示。
- 低周期可以提供入场事实，但不能静默改写高周期目标、失效或期限。
- 两个周期不能共享同一目标、失效和期限时，应建立观察边界明确的另一份判断，不能强行融合。

### 3.3 数据可靠性

| 数据情况 | 市场结果 | 下游边界 |
| --- | --- | --- |
| 可靠 | 正常判断 | 继续运行 |
| 有缺口但能证明不影响当前主问题 | 标明限制后继续 | 不把缺口解释成价格事实 |
| 有缺口且影响必要事实，或无法证明不影响 | 按不可用处理 | 不猜测缺失区间 |
| 不可用且没有活动风险 | 不形成新路径 | 记录下次检查和最晚等待时间 |
| 不可用且已有实际仓位或可能成交的订单 | 冻结最后可靠路径，只报告数据不可用 | Trade 按事前可靠性期限处理 |
| 来源已修订 | 保留旧事实并从最早受影响处重算 | 不静默覆盖历史判断 |
| 未完成 K 且未获允许 | 等待收盘 | 不输出基于该 K 的正式变化 |

市场判断只报告数据状态和最后可靠结论，不因数据缺失自行决定持有或退出。

### 3.4 市场组织、控制与阶段

市场组织先分四类：

#### 单边控制

一侧能够持续扩展极值，并限制对手在正常回撤边界内活动。结构可以表现为 Breakout/Spike、Tight Channel、Broad Channel 或 Trending Trading Range。

#### 双边平衡

双方都能推动、反转和获利，没有一侧持续获得外部接受。结构可以表现为 Trading Range、Breakout Mode、Triangle 或其他双向边界。

#### 转换中

旧控制已经受损，但新方向尚未获得足以组织正常回撤、目标和后续路径的接受。

#### 不清楚

事实不足或解释冲突。此时不显示当前阶段，控制方向为“尚未确认”，双向路径不能标为完整。能够明确测试对象、下一事实和期限时等待形成；否则当前排除。不能靠形态名称强行选择方向；新事实足以重组为单边控制、双边平衡或转换中后，再按对应阶段判断。

阶段决定同一强度事实的意义：

- 启动阶段的强 K 和跟进更可能建立新失衡；
- 发展阶段看正常回调后能否快速恢复；
- 成熟阶段的最大 K、加速和缺口必须同时检查高潮、目标和空间；
- 受损阶段关注旧控制能否恢复，以及反方向能否获得接受；
- 双边成熟后关注边缘反应，决断阶段关注哪一侧获得外部接受。

控制只有在持续能力发生变化时切换。原侧削弱但仍能在正常回调内恢复，且反方没有获得接受，控制不切换。单根普通反色 K 不足以确认转换。

Always In 只是清晰控制的别名，不表示账户持仓。Trapped、Disappointment 和 Pain Trade 等叙事必须还原为可见的预期、失败、跟进、接受和空间事实。

### 3.5 重要区域、位置与目标

位置先于形态和信号。Reversal Bar 不能修复错误位置、不足空间或已经结束的期限。

主区域只选一个：

- 区间底部、中部、顶部或区间外；
- 趋势或通道内当前真正活动的区域。

重要区域可以来自：

- 前高低和主要 Swing；
- 区间边界、中部和突破点；
- Gap、趋势线和通道线；
- 端点已固定的比例区域和测量目标；
- 盘前固定参数的 EMA；
- 重要开高低收、整数区域和其他可观察价格带。

这些名称先形成一张共享的重要区域图，只保存价格带和可复核来源，不分别建立支撑表、压力表、磁吸表、目标表或止损表。同一价格带只登记一次；接近同价且由同一结构推导的名称不重复增加证据。方向职责只写在真正消费该区域的当前测试或路径中，不在区域图预填两套解释。

区域职责不是区域的永久属性，而是相对方向、路径、阶段和当前位置的当前解释。同一区域可以同时承担多个职责，也可以对两个方向承担不同职责：

- **支撑 / 压力**：说明当前哪一侧可能在这里恢复或受阻；突破并接受后可以交换；
- **磁吸**：说明价格有现实理由前往测试，不表示到达后必然反转；
- **障碍**：可能阻止当前完成目标实现，必须进入目标可达性和最强反方事实；
- **检查点**：到达不结束路径，但其正常表现和异常后果会改变后续判断；
- **当前完成目标**：某条方向路径当前要完成的唯一市场结果；
- **失效参照**：帮助定义否定路径的市场事实，不等同于 Trade 的精确保护价。

运行卡只显示对当前双向判断有消费者的区域和职责，不要求每个区域填满所有角色。当前价格到完成目标之间，任何会实质改变目标可达性、正常预期或后续市场判断的区域都必须分类；普通情况只显示最近一个，只有多个区域分别改变不同结果时才全部保留。未分类的关键区域意味着路径尚未完整。

#### 现实目标怎样确定

候选目标必须来自判断时已经可见的区域，例如旧极值、区间中部或对侧、突破点、Gap、趋势或通道边界、EMA 测试区、第二段或端点固定的测量投射。然后按同一顺序筛选：

1. **结构来源**：说明为什么这个区域客观存在，不能只写“想赚到这里”；
2. **路径一致**：当前组织、阶段、尝试和正常预期确实指向该区域；
3. **沿途处理**：更近支撑、压力或磁吸区域已经归为障碍或检查点，并写明正常与异常后果；
4. **空间与时间**：从当前价格或可行参与区到目标仍有现实距离，期限足以容纳正常路径；
5. **事件明确**：到达、触及、收盘越过或持续接受等完成条件可以被观察并在事前冻结。

最远、理论回报最高或名称最多的候选不自动成为目标。优先选择当前路径能够现实解释、沿途区域能够完整处理的结果事件。更远投射不能绕过近端障碍来修复空间或回报风险；近端区域无法合理处理时，路径等待形成或当前排除。

每条路径只保留一个当前完成目标。其他区域不是并行目标：它们要么承担沿途职责，要么因为没有当前消费者而隐藏。Trade 可以把其中较近的障碍或检查点用于部分或全部兑现，但这不会改变 Market 的结果事件。

EMA 是可选参照。默认参数不等于永久真理；使用其他周期或参数时必须在观察前固定。比例位置必须写明所用区段和周期。

### 3.6 尝试、预期与实际表现

当前运动方向和外层作用必须分开。同一段下行可以是多头趋势回调，也可以是区间向下段。

每个主测试按同一顺序读取：

```text
谁在尝试什么
→ 在哪里尝试
→ 若成功应怎样表现
→ 实际怎样表现
→ 是否获得跟进或接受
→ 原路径和竞争路径怎样变化
```

测试结果只有三种：

- **接受**：事前要求的收盘、跟进、保持在外或回试守住已经发生；
- **失败**：尝试没有获得应有接受，旧区域或竞争方向重新获得接受并实质否定原目标；
- **未决**：接受和失败的边界明确，但任一终局尚未发生。

没有立即跟进通常先记为弱于预期，不单独确认失败。普通回调也不会自动确认失败。测试期限结束或主问题被替代后，旧测试关闭。

事实、位置和阶段只有在这一步被转换为“应怎样表现”时，才取得当前判断意义。H2、Gap、压力、突破、第二段、EMA 测试或其他名称都不能跳过正常预期，直接完成路径或交易。

#### 预期路径失败

以下顺序用于识别第二段陷阱、强突破坏跟进、恢复尝试失败和其他“先建立合理预期、随后异常失败”的共同机制：

1. 前一段事实足够强，合理建立明确的后续预期；
2. 预期中的第二段、恢复或再次尝试实际出现；
3. 它发生在会限制延续的位置，例如区间边缘、磁点、测量目标或成熟趋势末端；
4. 该尝试未获得本应出现的跟进或外部接受；
5. 旧区域或反方向随后获得接受，才确认原预期失败；
6. 原路径按事实削弱或失效，竞争路径仍须独立具备目标、空间、完成和失效条件。

第二段陷阱不是第一段后的首次反转，也不是“第二段一定失败”。在清楚趋势早期，同样强度的第二段更可能是真实延续；在双边边缘，它可能只是真空测试。

### 3.7 解释证据不建立平行状态

压力是一个典型例子：它描述一侧持续推进能力的变化：

- 增强：实体、收盘、极值推进、连续性、分离或对手失败共同提高持续能力；
- 未变：属于当前路径允许的普通波动；
- 削弱：跟进、空间、时间、分离或恢复能力下降；
- 尚未建立：只有局部响应，没有独立连续性和现实路径。

一侧削弱不等于另一侧增强。运行时不单独保存压力生命周期；只在它改变控制、正常预期、测试结果或路径时，在对应结论中写明方向和证据。

形态名称、行为叙事、指标关系和结构频率也遵守同一边界：它们只能改变已有判断的依据，不直接生成路径、订单、交易许可或风险预算。

### 3.8 双向路径

方向机会就是该方向当前唯一的市场路径，不建立 Opportunity 对象、编号或独立生命周期。

#### 路径完整

路径只有在以下内容全部明确时才完整：

- 唯一当前完成目标引用的重要区域、该区域已登记的结构来源及完成条件；
- 目标与当前组织、阶段和预期一致，且空间与时间支持其现实可达；
- 参与前市场条件；
- 到达前所有关键区域已有当前职责；其中会改变可达性或后续判断的区域已经归为障碍或检查点；
- 障碍与检查点的正常预期和异常后果；
- 失效参照（如有）、失效条件、期限、现实空间和时间；
- 最强支持事实和最强反方事实。

参与条件已经完成，或者唯一尚缺条件能由一个精确、可观察的价格事实原子性完成时，路径才可交给 Trade。

要求收盘、跟进、回试守住或持续接受的条件，不能由单纯触价完成，必须继续等待。

#### 等待形成

必须同时存在：

- 真实的当前测试；
- 精确的下一事实；
- 明确的最晚等待时间。

等待形成不是较弱的完整路径，也不能用预挂订单代替缺少的市场事实。

#### 当前排除

只显示一个主因：

- 没有现实目标；
- 没有足够空间；
- 没有足够时间；
- 没有形成条件。

形态名称、单根信号或账户容量都不能修复被排除的市场路径。

### 3.9 首次建立与路径变化

等待形成首次达到路径完整时，只记“首次建立”，不把建立本身称为增强。

路径首次完整时，当前完成目标、完成条件和有效期限共同冻结为一个市场结果事件。之后：

- 仍表示同一事前区域、不会改变该事件是否已经完成、失效或到期的边界精化，可以作为路径更新保留，并记录精化依据；
- 改变目标事件、完成条件或结果期限，属于实质换目标；旧路径先记为“替代”，新目标只能作为新路径“首次建立”，不能写成增强、削弱或对历史字段的覆盖；
- 原目标已经完成时，旧路径先记为“实现”；任何更远延伸都是新路径，不能把原目标向外移动；
- 有实际仓位或仍可能成交的订单时，旧路径终局后不得建立延伸路径；Trade 按原方案关闭风险，风险关闭后再恢复双向搜索。

障碍、检查点、支持事实或反方事实可以随新事实更新；只要目标事件、完成条件和期限未变，就不因此创建新路径。

已有完整路径先裁决终局：

1. 实现；
2. 失效；
3. 到期；
4. 替代。

多个终局事实先后可知时采用最先发生者。当前数据粒度无法确认先后时，运行上使用“替代”关闭旧路径，复盘保留“先后未知”，不得选择对账户更有利的结果。

没有终局时才判断：

- 增强：实际表现继续符合或超过原预期；
- 未变：实际表现属于事前允许的正常波动；
- 削弱但仍有效：实际弱于预期，但失效条件尚未完成。

路径实现、失效、到期或替代后冻结终局。若账户风险尚未关闭，只继续提供保护、期限或退出条件依赖的市场事实，不建立新路径。延伸或反向交易必须在风险关闭后重新建立路径。

## 四、每次市场唤醒

### 4.1 唤醒来源

- 新完成 K；
- 事先允许使用的未完成价格事件；
- 测试、路径或数据可靠性期限；
- 数据恢复、缺口确认或来源修订；
- 首次判断、接管或完整重看条件。

### 4.2 普通更新

普通新 K 只做四件事：

1. 写入本次新事实；
2. 比较合理预期与实际表现；
3. 更新受影响路径的结果或变化；
4. 写明下一观察。

没有下游变化时立即停止，不重新抄写背景、位置、测试和路径全文。

不能因为位置未变就忽略直接改变接受、失败、目标、失效或期限的新事实。所有新增事实归入唯一入口后，才允许停止传播。

### 4.3 完整重看

以下情况从观察边界重新建立：

- 品种、主周期或 K 线构造改变；
- 数据缺口或来源修订影响旧结论；
- 接管时无法证明旧判断仍可靠；
- 主测试被独立新问题替代；
- 市场组织、关键结构锚点或阶段发生替代；
- 多周期关系改变目标、失效、空间或期限；
- 原路径关闭且账户风险已经确认关闭。

## 五、交给交易决策

Market 只交付：

- 观察边界与数据可靠性；
- 背景、位置和现实空间；
- 当前测试、合理预期和实际表现；
- 完整的方向路径块，包括唯一当前完成目标、来源、现实性、完成条件、沿途区域职责、参与条件、失效和期限。

没有实际仓位和可能成交或状态未知的相关订单时交付双向路径。只有出现实际仓位或此类订单后，才只交付所选路径、最强反方事实和本次变化。

路径完整不表示应当交易。Trade 仍须检查具体入场、计划保护、现实退出、成本后的回报风险和期限；Account 只确认风险容量、实际订单、成交、仓位和有效保护。

市场路径变化不直接决定持仓动作：

- 增强不自动授权加仓；
- 未变不重写原方案；
- 削弱不自动决定减仓或退出；
- 失效只交付市场事实；
- 实现不证明账户已经退出。

## 六、稳定事实附录

本附录用于首次分析、复核和重建，不是每根 K 的检查表。

### A. 结构视图怎样共享事实

同一组 Swing 可以同时形成 H2、Double Bottom、Bull Flag 或 MTR 组件。价格事实只登记一次，各视图只保留独有职责。

| 结构视图 | 共享事实 | 独有职责 |
| --- | --- | --- |
| ii / iii | 连续 inside bars | 压缩范围和边界 |
| ioi | inside–outside–inside | 双边扩张后的再压缩 |
| oo | 连续 outside bars | 双边扩张和不稳定边界 |
| Triangle | 双方反复测试 | 两侧活动边界和成熟度 |
| Expanding Triangle | 双方交替测试并扩张极值 | 扩张边界和测试次序 |
| Double Bottom / Top | 两次运动测试同一区域 | 重复测试区、Neckline 和高度候选 |
| Wedge | 三次可区分的同向推动或测试 | 推动次序、斜率和延伸质量 |
| Flag | 外层方向中的局部结构 | 局部结构对延续或反转的作用 |
| H1/H2…、L1/L2… | 同周期、同恢复对象内的尝试 | 尝试次序、信号边界和重置点 |
| MTR | 成熟趋势后的反向发展 | 从 minor reversal 到控制转移的阶段 |

名称只把共享事实和独有职责写回背景、位置或当前测试，不直接生成路径、概率或交易。

### B. 区间、比例与目标投射

区间边界取当前反复组织价格的两个区域。一次影线或轻微越界不会自动改写边界。

设下沿为 `L`、上沿为 `U`、高度为 `R`：

```text
R = U - L
中部 = L + R / 2
底部三分之一区域 = L 到 L + R / 3
顶部三分之一区域 = U - R / 3 到 U
```

当前段从 `A` 到 `B` 的半程为 `A + (B - A) / 2`。

常见投射：

```text
Leg 1 = Leg 2：第二段起点 C + 第一段位移 (B - A)
Range 向上目标：上沿 + Range 高度
Range 向下目标：下沿 - Range 高度
Double Bottom：Neckline + Neckline 到底部区域的高度
Double Top：Neckline - 顶部区域到 Neckline 的高度
```

所有端点必须在判断时已经可见并冻结。投射只产生候选目标区，还要检查更近障碍、剩余空间和时间。50%、三分之一和测量值本身不生成反转或入场。

### C. Double Test 与 Neckline

Double Bottom / Top 的两次测试：

- 不要求精确同价；
- 必须是两次可区分的运动；
- 必须指向同一有意义区域；
- 中间必须有可见的反向 Swing。

Double Bottom 的 Neckline 是两次底部测试之间最高的相关反向 Swing high 区域；Double Top 镜像为最低的相关 Swing low 区域。

高度投射成为现实目标前，至少还需要 Neckline 突破、突破跟进或回试守住之一。Double Test 可以先于 H2/L2 形成，但不能证明 second entry 已触发。

### D. H/L 次序与重置

多头次序：

1. 第一次向上 Trigger 为 H1；
2. 再次回调后，完成 K 定义第二个边界，形成 H2 setup；
3. 越过该高点形成 H2 Trigger；
4. 越界 K 为 Chart Entry Bar。

空头完全镜像。严格 second entry 要求第一次 chart entry opportunity 已经触发。Signal Bar 只定义市场边界；是否采用、提交和成交属于后续职责。

H3/L3 可以与 Wedge 共享推动事实。出现更高编号时，应先检查是否已经成为 Triangle、Trading Range 或新的 Pullback 对象。

计数始终绑定周期、恢复对象和重置点。以下情况重置：

- 旧控制已经恢复；
- 新方向获得接受；
- 成熟 Range 切断旧运动；
- 主要结构被替代；
- 观察边界改变。

### E. K 线与运动事实

底层只保存来源直接提供的 OHLC、trade 或 volume、发生时间、最早可见时间和修订关系，不保存压力、控制、形态或路径。

设最高、最低、开盘和收盘为 `H`、`L`、`O`、`C`：

```text
总范围   = H - L
实体     = abs(C - O)
实体占比 = abs(C - O) / (H - L)
收盘位置 = (C - L) / (H - L)
上影占比 = [H - max(O, C)] / (H - L)
下影占比 = [min(O, C) - L] / (H - L)
```

`H = L` 时按零波幅 K 处理，不计算比例。

- Inside bar：high 不高于前高，low 不低于前低；
- Outside bar：high 不低于前高，low 不高于前低，且至少一端严格越过；
- Doji：实体相对周围很小或为零；
- Shaved：实体一端与极值严格相等；使用 tick 容差时须事先声明；
- Reversal Bar：必须是完成 K，并结合位置、当前段、范围、实体、收盘和影线判断；
- Two-bar 或 multi-bar reversal：多根共同形成反向压力，不能被单一吞没几何替代。

Trend bar 与 trading-range bar 是连续谱。单根 K 不建立趋势或确认反转。

- Push / Leg：较大结构中的一段方向运动；
- Pullback：当前方向运动中的暂停或暂时反向；
- Pause：停止扩展极值或横向停顿；
- Actual pullback：当前周期已出现反向高低点运动；
- Implied pullback：当前周期仅暂停，低周期可能已经展开回调。

第二段可以很短、横向、不创新极值或快速失败。它不等于等距投射、second signal、second entry 或第二次成交。

### F. Gap 事实边界

使用 Gap 必须说明比较对象：

- 相邻 K 完整高低范围之间的分离；
- 相邻实体区间之间的 body gap；
- 隔一根 K 比较的 micro gap；
- 突破点与 Pullback 之间的开放、负值或重叠；
- 整根 K 未触及指定 EMA 的 moving-average gap bar；
- 事先固定 Session 的 opening gap；
- 本根开盘相对前收盘的单根 opening gap。

这些名称不能互换。来自同一次运动的多种分离仍是一组事实，不能重复增加证据。长期未触 EMA 后的首次测试与单根 moving-average gap bar 不是同一对象，也不会自动生成入场。

Volume、DOM、新闻或情绪资料可以提示背景和尾部风险。只有价格实际表现改变测试或路径时，才改变市场结论。

### G. 趋势线与通道线

多头趋势线连接两个相关向上反转低点；空头趋势线连接两个相关向下反转高点。优先使用强段起点、强反转或显著拐点，不用大量小线填满图表。

通道候选来自把趋势线平行复制到另一侧显著极值，或直接连接另一侧两个相关反转点：

- 持续产生反应时保留；
- 新主要极值或失败突破出现时建立重画候选；
- 轻微 overshoot/undershoot 且无强跟进时不自动失效；
- 强越界并获得跟进后失去当前边界职责；
- 长期不再产生响应时休眠；
- 仍是现实回试区时改变职责后保留。

多条线只有在周期、尺度或用途不同的时候并存。
