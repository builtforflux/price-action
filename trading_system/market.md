# 市场判断：从观察到双向机会

## 一、唯一职责

本页把当时可见的市场事实整理成可复核的市场判断，并向交易决策交付向上和向下的现实路径。

市场判断只回答六个问题：

1. 当前观察边界是否可靠；
2. 市场现在怎样组织，处于什么阶段；
3. 哪些重要区域当前有作用，价格正在与哪个区域互动；
4. 当前哪一侧正在什么区域尝试什么，若当前解释成立，接下来应怎样表现；
5. 初始行为取得了什么进展，后续跟随怎样，实际与预期相差多少；
6. 这些结果怎样改变向上和向下路径的区域职责、现实空间、时间与终局。

Market 内部只按这一顺序判断：

```text
观察边界
→ 市场组织
→ 活动重要区域图
→ 当前区域互动
→ 合理预期
→ 实际价格表现：初始行为与跟随
→ 预期差与测试结果
→ 当前相对优势，以及控制、阶段或组织是否改变
→ 双向区域路径
→ 首次建立或本次变化
```

这是一条推理链，不是逐项评分或多张状态表。普通新 K 只更新它实际改变的字段。

市场组织概括当前互动开始前仍有效的累计结果；合理预期必须在新事实发生前依据这份背景冻结。新事实先作为实际跟随与既有预期比较，再更新当前相对优势；只有优势持续到足以组织正常回调、预期和路径时，才更新控制、阶段或市场组织，并为下一事件建立新的合理预期。不另存压力、连续性或第二份控制基线。

本页不负责：

- 决定交易、等待或放弃；
- 选择订单类型、入场价格或数量；
- 计算账户风险；
- 推断订单已经触发、成交、撤销或退出；
- 决定持有、加仓、减仓或离场。

图表越过一个价格，只能证明市场发生了越界，不能证明平台权威事实中的订单已经触发或成交。

当市场组织、活动重要区域和当前互动已经明确，但仍不知道怎样形成合理预期或双向路径时，按需查询[常见市场场景](scenarios.md)。场景页不保存第二套区域图、状态或逐 K 生命周期。

## 二、运行卡

盘中只维护这一张卡。首次判断、主问题变化或可靠基线丢失时完整展开；普通新 K 只更新本次新事实及其实际改变的跟随、测试、当前相对优势、控制、组织、路径和下一观察。未变化的结果沿用上次可靠判断。

最小记录保留判断时间、当时最晚可见数据和来源，并在运行卡顶部写“本次新事实”。这里仅引用新增可见事实；对应段落只保存它改变的结论，不复制完整历史。不得用后来的事实改写当时已知内容。

### 观察边界

正常时只显示：

- 品种、数据来源、主周期与 K 线构造；
- 最新可靠完成 K；
- 当前窗口是否足以解释主问题。

只有异常或确实影响判断时才展开：

- 数据问题：数据缺失区间、不可用范围、最后可靠时间、受影响结论和下次检查；
- 来源修订：从最早受影响处重判；
- 获准使用的未完成价格事件；
- 外层周期改变的目标、正常回撤、失效、空间或期限；
- Session、时区或流动性边界造成的实际影响。

### 市场组织

- 市场组织：单边控制 / 双边平衡 / 转换中 / 不清楚
- 控制方向：多头 / 空头 / 双方平衡 / 尚未确认
- 当前阶段：
  - 单边时：启动 / 发展 / 成熟 / 受损
  - 双边时：形成 / 成熟 / 决断中
  - 转换时：旧控制受损 / 新控制尚未接受
  - 不清楚时：隐藏；控制方向使用“尚未确认”，双向路径只能等待形成或当前排除

### 活动重要区域图

只登记当前互动或任一方向路径实际引用的区域；每个区域只保存：

- 区域：
- 价格带：
- 来源：
- 周期：未注明时继承主周期

区域到当前价格或可行参与区的距离属于引用它的互动或路径；期限也由互动或路径保存，不写入区域本身。Pressure、形态、指标关系等来源语言只有改变当前互动、相对优势、控制、阶段、预期或路径时，才还原为事实写入对应结论。一侧削弱不等于另一侧增强，反方向必须有自己的进展和跟随。

### 当前区域互动与价格表现

默认只展开一个主测试：

- 当前尝试：哪一侧正在尝试什么
- 测试对象：引用活动重要区域
- 到达方式：上行 / 下行 / 暂停 / 局部平衡
- 外层作用：延续 / 回调 / 区间段 / 反转尝试
- 互动进程：接近 / 触及 / 反应 / 突破尝试 / 等待跟随
- 合理预期：若当前市场组织、阶段和互动解释成立，接下来应出现什么跟随
- 预期时限：最迟何时应出现
- 实际价格表现，只按需显示会改变当前问题的内容：
  - 初始行为：哪次完成 K、组合或价格事件取得了什么进展，又回吐了什么
  - 实际跟随：这些进展随后被延伸、保住、回试守住、恢复，还是被交还；对手是否取得并保住自己的进展
- 当前相对优势：限定在本周期、当前运动、测试区域和当前问题内，哪一侧更能取得并保住进展；双方接近或尚不清楚时直接写明
- 预期差：符合 / 暂无实质变化 / 弱于预期 / 否定预期
- 测试结果：接受 / 失败 / 未决
- 接受条件：
- 失败条件：
- 下一观察：

第二独立测试只有在测试对象、终局条件、期限和下游影响都独立时才展开。最多保留两个测试；第二测试必须汇入现有向上或向下路径，不能为同一方向建立第二条生命周期。

### 双向路径

没有实际仓位且从未提交本交易相关订单时，向上、向下各填一次同一块；每个方向只保留一条当前路径。一旦提交过本交易相关订单，只有 Account 根据平台权威事实确认[风险关闭](account.md#风险关闭)后才恢复双向搜索。Trade 只是在比较或等待、尚未提交订单时，不改变双向搜索。

#### 每个方向

- 方向：向上 / 向下
- 当前结果：
  - 路径完整：引用活动重要区域图中的当前测试、沿途障碍或检查点、唯一完成区域及其完成条件、失效参照及其失效条件；再显示目标现实性、参与前条件、期限、最强支持与反方事实、本次变化和下一观察；
  - 等待形成：只显示尚缺事实、下一事件和最晚等待时间；
  - 当前排除：只显示缺少目标、空间、时间或形成条件中的一个主因；
  - 实现 / 失效 / 到期 / 替代：只有旧路径已经终局而相关交易风险尚未关闭时显示，保留终局事实并停止建立新路径。

路径完整时，目标、关键区域、失效和本次变化仍使用本页后文的完整条件；这里不另建简化判据。

风险尚未关闭时，只完整维护所选路径，并扫描所有能够削弱、否定或替代它的反方事实。风险关闭后立即恢复双向搜索。

## 三、共同判断语法

### 3.1 五个层次只有一个事实来源

| 层次 | 唯一内容 | 不包含 |
| --- | --- | --- |
| 市场事实 | 来源直接提供的价格、时间、成交资料和修订，以及由此确定性计算的实体、影线、范围和收盘位置 | 支撑、阻力、相对优势、形态职责或交易判断 |
| 结构视图 | 区域、Swing、线，以及 Gap、重叠、越界、回试、H/L 次序等可复核价格关系 | 区域职责、独立路径、概率或订单 |
| 价格表现 | 当前互动中的初始行为、实际跟随，以及由双方表现直接比较出的当前相对优势 | 独立压力、连续性状态、评分、区域职责、订单或仓位 |
| 市场判断 | 组织、阶段、活动区域、当前互动、合理预期、预期差与测试结果 | 账户动作 |
| 市场路径 | 已登记区域在某方向中的职责，以及目标、完成、失效、期限和现实性 | 没有可复核来源的新区域、订单触发、成交或持仓结果 |

同一事实只登记一次。结构名称只保留独有的几何、次序、阶段或重置职责，不复制证据、建立平行流程或增加概率。

价格关系只保存复核所需的最小事实：比较对象、方向、周期、形成或最近改变它的可见事件，以及保持、收窄、重叠、关闭、重新分离、重置或替代等当前结果；不另存生命周期或引用表。当前互动、合理预期、测试或路径需要该关系时，在自己的条件中直接引用唯一事实并写明关系变化后的后果；没有当前结论引用时只留在结构视图，不进入运行卡。

任何新事实、形态、指标关系、行为解释或课程概念只能进入以下一个运行入口：

- 改变 Gap、重叠、越界、回试或其他价格关系：先更新唯一结构事实；只有改变当前表现、测试或路径时才继续传导；
- 改变区域的价格带、来源、周期或是否被当前互动或路径引用：写入活动重要区域图；
- 提出或改变市场正在验证的问题：写入当前区域互动；
- 改变成立条件下的正常后续表现：写入合理预期；
- 改变初始行为或实际跟随：写入当前区域互动，并先与事前合理预期比较；
- 改变本周期、当前运动、区域和问题中的双方相对表现：更新当前相对优势；优势只有持续到足以组织正常回调、预期和路径时，才更新市场组织、控制或阶段；
- 改变某方向的完成目标、参与条件、关键区域、失效、期限或现实性：写入路径。

一条知识可以支持多个结论，但事实只保存一次，每个结论仍由自己的条件完成。无法改变上述任一运行结果的内容只作为结构视图、证据或隔离项，不进入运行卡。

Volume、DOM、新闻或情绪资料可以提示市场组织和尾部风险。只有价格实际表现改变当前测试、相对优势或路径时，才改变方向结论；这些辅助资料不建立独立方向状态。

### 3.2 观察边界与多周期

观察边界说明本次判断适用于哪张图、哪种 K 线和哪段当时可见历史。

- 默认只使用完成 K。未完成 K 只有在方法事先允许的具体价格事件中才能参与，并标为暂时事实。
- 观察窗口不使用固定根数。它至少覆盖当前互动区域、主测试起点、关键结构边界、最近有效转换，以及路径的目标、失效和期限。
- 全天连续交易产品没有天然日内开盘。自定义 Session 只有真实改变流动性、目标可达性或期限时才进入判断。
- 每个活动重要区域、当前互动和路径都绑定周期；未注明时继承主周期，不得无声切换。
- 外层周期只有改变目标、正常回撤、失效、空间、期限或测试解释时才显示。
- 低周期可以提供入场事实，但不能静默改写高周期目标、失效或期限。
- 两个周期不能共享同一目标、失效和期限时，可以分别形成观察边界明确的判断。
- 不得把不同判断中的目标、失效、期限或参与条件拼成一条混合路径。
- 进入 Trade 前，只能明确引用其中一份观察边界下的一条完整路径；其他周期判断只能作为会改变该路径的外层事实。
- 不得因此为同一方向建立第二条活动交易路径。

### 3.3 数据可靠性

| 数据情况 | 市场结果 | 下游边界 |
| --- | --- | --- |
| 可靠 | 正常判断 | 继续运行 |
| 存在数据缺失区间但能证明不影响当前主问题 | 标明限制后继续 | 不把缺失区间解释成价格事实 |
| 数据缺失影响必要事实，或无法证明不影响 | 按不可用处理 | 不猜测缺失区间 |
| 不可用且没有活动风险 | 不形成新路径 | 记录下次检查和最晚等待时间 |
| 不可用且风险尚未关闭 | 冻结最后可靠路径，只报告数据不可用 | Trade 按事前可靠性期限处理 |
| 来源已修订 | 保留旧事实并从最早受影响处重算 | 不静默覆盖历史判断 |
| 未完成 K 且未获允许 | 等待收盘 | 不输出基于该 K 的正式变化 |

市场判断只报告数据状态和最后可靠结论，不因数据缺失自行决定持有或退出。

### 3.4 市场组织、控制与阶段

市场组织先分四类：

#### 单边控制

一侧能够持续扩展极值，并限制对手在正常回撤边界内活动。结构可以表现为 Breakout/Spike、Tight Channel、Broad Channel 或 Trending Trading Range。

#### 双边平衡

双方都能推动、反转和获利，没有一侧持续获得外部接受。结构可以表现为 Trading Range、Breakout Mode、Triangle 或其他双向边界。

#### 转换中

旧控制已经受损，但新方向尚未获得足以组织正常回撤、目标和后续路径的接受。

#### 不清楚

事实不足或解释冲突。此时不显示当前阶段，控制方向为“尚未确认”，双向路径不能标为完整。能够明确测试对象、下一事实和期限时等待形成；否则当前排除。不能靠形态名称强行选择方向；新事实足以重组为单边控制、双边平衡或转换中后，再按对应阶段判断。

阶段决定同一强度事实的意义：

- 启动阶段的强初始行为和良好跟随更可能建立新失衡；
- 发展阶段看正常回调后能否快速恢复；
- 成熟阶段的最大 K、加速和缺口必须同时检查高潮、目标和空间；
- 受损阶段关注旧控制能否恢复，以及反方向能否获得接受；
- 双边成熟后关注边缘反应，决断阶段关注哪一侧获得外部接受。

“成熟”不能只由持续时间、单根大 K 或事后结果命名。单边成熟至少要同时指出：原方向已经持续扩展或长期缺少改变主结构的回调；当前位置已接近事前目标、旧极值或通道外侧，并出现异常延伸、恢复变慢或双向化中的可见变化。双边成熟则要求活动边界在本次到达前已经可识别，双方围绕同一内部区域反复测试，且没有一侧持续获得外部接受。这里不使用固定根数或成熟度评分。

“主要结构破坏”也必须绑定事前参照：控制方向正常回调所依赖的主要 HL/LH、趋势段或有效边界不再约束价格，按观察边界允许的完成事实越界后又获得良好跟随。单次影线、只穿越一条趋势线或一根普通反色 K 只提示受损；结构破坏本身仍不等于反方向已经获得接受。

控制只有在持续能力发生变化时切换。原侧削弱但仍能在正常回调内恢复，且反方没有获得接受，控制不切换。单根普通反色 K 不足以确认转换。

Always In 只是清晰控制的来源别名，不表示账户持仓。Trapped、Disappointment 和 Pain Trade 等叙事必须还原为可见的预期、跟随、失败、接受和空间事实。

### 3.5 活动重要区域图与路径职责

重要区域是 Market 中所有位置判断的唯一基础。目标、障碍、检查点、支撑、阻力、磁吸和失效参照不是独立位置类型，只是已登记区域相对当前方向路径的职责。Reversal Bar 不能修复错误区域、不足空间或已经结束的期限。

当前互动只引用一个当前区域：

- 区间底部、中部、顶部或区间外；
- 趋势或通道内当前真正活动的区域。

重要区域的可复核来源包括：

- 前高低和主要 Swing；
- 区间边界、中部和突破点；
- Gap、趋势线和通道线；
- 端点已固定的比例区域和测量投射；
- 盘前固定参数的 EMA；
- 重要开高低收、整数区域和其他可观察价格带。

这些来源用于识别候选区域；只有当前互动或路径实际引用的区域才进入活动图，并只保存价格带、来源和周期。不分别建立支撑表、阻力表、磁吸表、目标表或止损表。同一价格带只登记一次；接近同价且由同一结构推导的名称不重复增加证据。方向职责直接写在引用该区域的当前互动或路径中，不在区域图预填两套解释。

Gap 首先是两个已明确对象之间的分离关系，不天然是一块重要区域。只有 Gap 区间、中点或由它生成的投射被当前互动或路径实际使用时，对应价格带才进入活动图；关系事实仍只保存一次，不能因为它同时解释当前相对优势、突破和测量而复制成三个区域。

区域职责不是区域的永久属性，而是相对方向、路径、阶段和当前位置的当前解释。同一区域可以同时承担多个职责，也可以对两个方向承担不同职责：

- **支撑 / 阻力**：说明当前哪一侧可能在这里恢复或受阻；突破并接受后可以交换；
- **磁吸**：说明价格有现实理由前往测试，不表示到达后必然反转；
- **障碍**：可能阻止当前完成目标实现，必须进入目标可达性和最强反方事实；
- **检查点**：到达不结束路径，但其正常表现和异常后果会改变后续判断；
- **当前完成目标**：某条方向路径当前要完成的唯一市场结果；
- **失效参照**：帮助定义否定路径的市场事实，不等同于 Trade 的精确保护价。

运行卡只显示当前互动或双向路径直接引用的区域和职责，不要求每个区域填满所有角色。当前价格到完成目标之间，任何会实质改变目标可达性、正常预期或后续市场判断的区域都必须分类；普通情况只显示最近一个，只有多个区域分别改变不同结果时才全部保留。未分类的关键区域意味着路径尚未完整。

职责必须与可观察事件绑定：Market 完成目标是“重要区域 + 完成条件”，路径失效是“重要区域 + 否定条件”。单纯登记一个价带不能证明目标已经实现或路径已经失效。Trade 的精确入场、退出和保护价格引用这些区域及事件，但不写回第二张 Market 区域图；精确保护价可以位于失效参照或入场结构外侧，以容纳正常波动。

#### 路径怎样选择完成区域

候选区域必须在判断时已经可见并具有可复核来源，例如旧极值、区间中部或对侧、突破点、Gap、趋势或通道边界、EMA 测试区、第二段或端点固定的测量投射。MM、前高低和 TR 中部在这里没有不同地位：它们都只说明区域来源。一旦当前互动或路径直接引用候选区域并分配职责，它才进入活动图；不另存候选区域清单。当前路径按同一顺序选择其中一个区域承担完成目标职责：

1. **区域来源**：说明为什么这个区域客观存在，不能只写“想赚到这里”；
2. **路径一致**：当前组织、阶段、尝试和正常预期确实指向该区域；
3. **沿途处理**：更近支撑、阻力或磁吸区域已经归为障碍或检查点，并写明正常与异常后果；
4. **空间与时间**：从当前价格或可行参与区到目标仍有现实距离，期限足以容纳正常路径；
5. **事件明确**：到达、触及、收盘越过或持续接受等完成条件可以被观察并在事前冻结。

“现实空间”不只是图上的价格距离。它要求目标尚未被当前价格消耗，到达前关键区域已经分类，并且按当前组织的正常运动能在期限内到达；若必须跳过未决障碍、依赖异常单根延伸或临时把目标外移，空间就不现实。成本后的回报风险仍由 Trade 判断。

最远、理论回报最高或名称最多的候选不自动成为目标。优先选择当前路径能够现实解释、沿途区域能够完整处理的结果事件。更远投射不能绕过近端障碍来修复空间或回报风险；近端区域无法合理处理时，路径等待形成或当前排除。

每条路径只让一个区域承担当前完成目标职责。其他区域不是并行目标：它们要么被当前测试或路径直接引用为障碍、检查点、磁吸或失效参照，要么隐藏。Trade 可以引用较近区域安排部分或全部兑现，但这不会改变 Market 的结果事件。

EMA 是可选参照。默认参数不等于永久真理；使用其他周期或参数时必须在观察前固定。比例位置必须写明所用区段和周期。

### 3.6 当前区域互动、价格表现与预期差

重要区域回答“在哪里”，初始行为与跟随回答“在那里发生了什么”。两者必须通过当前尝试和合理预期结合；脱离方向、市场组织、阶段、区域和预期，不存在全局通用的“好 K”。当前运动方向和外层作用也必须分开，同一段下行可以是多头趋势回调，也可以是区间向下段。

每个主测试只按一条语法读取：

```text
谁在什么区域尝试什么
→ 若成功应怎样表现
→ 初始行为取得了什么进展
→ 后续是否延伸、保住、回试守住或恢复这些进展
→ 另一侧是否取得并保住自己的进展
→ 实际与预期相差多少
→ 当前相对优势、控制和组织是否改变
→ 测试和双向路径怎样变化
```

任何课程名称或价格行为概念都必须先还原为这条链中的共享内容：

```text
可复核事实或关系
→ 对初始行为或跟随的实际影响
→ 在当前互动中承担的职责
→ 预期差、测试结果和路径变化
```

一个名称可以同时描述几何、行为或职责，但不能跳过中间层直接生成结果。Trend Bar、Gap、Microchannel、Pullback、Breakout、Staircase、Climax、MM、H2 或 Wedge 都遵守同一规则。

#### 事实、表达、职责与结果

- **价格事实与关系**：OHLC、实体、影线、范围、收盘位置，以及带明确比较对象和周期的极值次序、重叠、分离、越界和回试，只保存一次；
- **初始行为**：一根或一组完成 K、组合或价格事件对某个方向产生或回吐了多少进展，是相对当前尝试和周围正常表现的解释，不是固定分数；
- **跟随**：初始行为之后，价格是否延伸、保住、回试守住或恢复其进展，以及对手是否取得自己的进展；它是后续实际表现，不是 K 线永久类型；
- **市场职责**：Breakout、Reversal 和 Signal 说明共享事实在当前互动中承担什么作用，不是价格对象的永久类型；价格关系由预期、测试或路径直接引用，不另取重要性名称；
- **市场结果**：合理预期、预期差、接受、失败、控制和路径变化，必须由事前条件完成；
- **执行职责**：Trade 只引用 Market 已确认的完成 K、组合或价格事件作为边界；订单触发和实际成交仍由平台权威事实定案。

Trend bar 与 trading-range bar 是方向表达的连续谱。实体有意义、回吐较少、收近方向端点并相对周围产生实际位移，通常是较有效的趋势表达；显著影线、重叠、中间收盘或快速反转通常表示更多双向交易。相同外观在强趋势启动、成熟区间边缘、区间中部或既有目标附近可以有不同意义。

高质量趋势 K 在市场组织、阶段、区域和当前路径一致时，可以承担突破、恢复、反转或信号职责；它不因此天然成为好信号。巨大 K 也可能位于成熟阶段高潮、消耗现实空间或使 Trade 的合理保护过远。普通甚至混合外观的 K 在清楚的市场组织和完整路径中也可以提供可用边界。反转与信号可以由多根共同完成，不强迫所有机会拥有一根独立 Signal Bar。

Signal Bar 是当前路径使用某根完成 K 或组合提供参与理由或触发边界时的职责，由 Market 确认。若越过其边界本身能够原子性完成唯一尚缺的市场条件，路径可以交给 Trade；若仍缺收盘、跟随、回试守住或持续接受，就必须等待，不能用订单触价替代。

#### 初始行为、跟随与当前相对优势

价格表现只比较同一周期、同一当前运动或测试中的相关事实，不使用固定最近根数。

初始行为说明一次完成事件取得了什么结果：是否扩展相关极值、有效越过区域、形成新的方向分离、把收盘移向尝试方向，以及影线、回吐和重叠交还了多少进展。实体有意义、方向端收盘、影线较短和实际位移较大，通常说明该次行为表达较好；它仍必须放回当前区域、阶段和合理预期中解释。

跟随读取初始行为之后的全部相关表现。良好跟随可以是继续扩展极值、保持区域外或分离结果、普通回调后快速恢复、回试守住，或者对手尝试后不能保住成果；不要求再出现一根同方向大 K。跟随不足可以表现为停止扩展、明显回吐、分离关闭、重新接受旧区域，或者对手取得并保住反向进展。

一根大趋势 K 和多根较小但方向一致、收盘持续推进、回调有限的 K 都可以建立有效失衡。单根巨大 K 没有后续时只记录强初始行为，不能单独保证接受、控制切换或趋势延续。多次良好跟随可以概括为“具有连续性”，但连续性不另存字段、状态或证据。

当前相对优势是双方初始行为和跟随在同一周期、当前运动、区域与问题中的直接比较。来源中的 buying pressure、selling pressure 只分别表示多头或空头在这次比较中更占优势，不建立两套压力状态。一侧表现减弱只能削弱其优势；对手还必须取得并保住自己的进展，才能支持优势转移。局部优势只有持续到足以组织正常回调、预期和路径时，才支持控制转移。

连续同向 K、微型通道、浅回调、极值推进和多个 Gap 保持可能只是同一段运动的不同描述，只构成一组价格事实，不重复增加证据、概率或风险预算。某段分离关闭时，只重算直接引用它的实际跟随、测试或路径。原结论可以因此削弱或失效，但对手没有自己的初始进展和良好跟随时，不能直接切换优势或控制，市场组织优先检查通道化或双边化。

#### 预期差与测试结果

接受与失败条件必须在终局事实发生前写清。测试结果只有三种：

- **接受**：事前要求的收盘或跟随已经发生；跟随条件可以具体表现为延伸、保持在外、回试守住或恢复；
- **失败**：尝试没有获得应有接受，旧区域或竞争方向重新获得接受并实质否定原目标；
- **未决**：接受和失败的边界明确，但任一终局尚未发生。

没有立即出现良好跟随通常先记为弱于预期，不单独确认失败。普通回调也不会自动确认失败。测试期限结束或主问题被替代后，旧测试关闭。

市场事实、活动区域和阶段只有在这里被转换为“应怎样表现”，再与实际价格表现比较，才取得当前判断意义。H2、Gap、Pressure、突破、第二段、EMA 测试或其他来源名称都不能跳过正常预期，直接完成路径或交易。

#### 预期路径失败

以下顺序用于识别第二段陷阱、强突破后跟随不足、恢复尝试失败和其他“先建立合理预期、随后异常失败”的共同机制：

1. 前一段事实足够强，合理建立明确的后续预期；
2. 预期中的第二段、恢复或再次尝试实际出现；
3. 它发生在会限制延续的区域，例如区间边缘、磁点、测量投射区域或成熟趋势末端；
4. 该尝试未获得本应出现的跟随或外部接受；
5. 旧区域或反方向随后获得接受，才确认原预期失败；
6. 原路径按事实削弱或失效，竞争路径仍须独立具备目标、空间、完成和失效条件。

第二段陷阱不是第一段后的首次反转，也不是“第二段一定失败”。在清楚趋势早期，同样强度的第二段更可能是真实延续；在双边边缘，它可能只是真空测试。

### 3.7 解释名称不建立平行状态

Pressure、形态名称、行为叙事、指标关系和结构频率只解释共享事实怎样改变市场组织、合理预期、初始行为、跟随、当前相对优势、测试结果或路径。它们不保存独立生命周期，不直接生成路径、订单、交易许可或风险预算；无法改变任何当前结论时，不进入运行卡。

### 3.8 双向路径

方向机会就是该方向当前唯一的市场路径，不建立 Opportunity 对象、编号或独立生命周期。

#### 路径完整

路径只有在以下内容全部明确时才完整：

- 当前测试、沿途职责、唯一完成目标和失效参照都引用同一张活动重要区域图；
- 唯一完成区域已登记来源和周期，并绑定可观察完成条件；
- 目标与当前组织、阶段和预期一致，且空间与时间支持其现实可达；
- 参与前市场条件；
- 到达前所有关键区域已有当前职责；其中会改变可达性或后续判断的区域已经归为障碍或检查点；
- 障碍与检查点的正常预期和异常后果；
- 失效参照引用已登记区域，并绑定失效条件、期限、现实空间和时间；
- 最强支持事实和最强反方事实。

参与条件已经完成，或者唯一尚缺条件能由一个精确、可观察的价格事实原子性完成时，路径才可交给 Trade。

要求收盘、跟随、回试守住或持续接受的条件，不能由单纯触价完成，必须继续等待。

#### 等待形成

必须同时存在：

- 真实的当前测试；
- 精确的下一事实；
- 明确的最晚等待时间。

等待形成不是较弱的完整路径，也不能用预挂订单代替缺少的市场事实。

#### 当前排除

只显示一个主因：

- 没有现实目标；
- 没有足够空间；
- 没有足够时间；
- 没有形成条件。

形态名称、单根信号或账户容量都不能修复被排除的市场路径。

### 3.9 首次建立与路径变化

等待形成首次达到路径完整时，只记“首次建立”，不把建立本身称为增强。

路径首次完整时，当前完成目标、完成条件和有效期限共同冻结为一个市场结果事件。之后：

- 仍表示同一事前区域、不会改变该事件是否已经完成、失效或到期的边界精化，可以作为路径更新保留，并记录精化依据；
- 改变目标事件、完成条件或结果期限，属于实质换目标；旧路径先记为“替代”，新目标只能作为新路径“首次建立”，不能写成增强、削弱或对历史字段的覆盖；
- 原目标已经完成时，旧路径先记为“实现”；任何更远延伸都是新路径，不能把原目标向外移动；
- 风险尚未关闭时，旧路径终局后不得建立延伸路径；Trade 按原方案完成退出和撤单，风险关闭后再恢复双向搜索。

障碍、检查点、支持事实或反方事实可以随新事实更新；只要目标事件、完成条件和期限未变，就不因此创建新路径。

已有完整路径先裁决终局：

1. 实现；
2. 失效；
3. 到期；
4. 替代。

多个终局事实先后可知时采用最先发生者。当前数据粒度无法确认先后时，运行上使用“替代”关闭旧路径，复盘保留“先后未知”，不得选择对账户更有利的结果。

没有终局时才判断：

- 增强：实际价格表现继续符合或超过原预期；
- 未变：实际价格表现属于事前允许的正常波动；
- 削弱但仍有效：实际弱于预期，但失效条件尚未完成。

路径实现、失效、到期或替代后冻结终局。若风险尚未关闭，只继续提供保护、期限或退出条件依赖的市场事实，不建立新路径。延伸或反向交易必须在风险关闭后重新建立路径。

## 四、每次市场唤醒

### 4.1 唤醒来源

- 新完成 K；
- 事先允许使用的未完成价格事件；
- 测试、路径或数据可靠性期限；
- 数据恢复、缺失区间确认或来源修订；
- 首次完整分析、接管或完整重建条件。

### 4.2 普通更新

普通新 K 只做六件事：

1. 写入本次新事实；
2. 更新受影响的价格关系、初始行为或实际跟随；
3. 用更新前已经冻结的合理预期裁决预期差和测试结果；
4. 更新当前相对优势；只有持续能力改变时，才进一步更新控制、阶段、市场组织或当前互动，并为下一事件建立新预期；
5. 更新受影响路径的结果或变化；
6. 写明下一观察。

没有下游变化时立即停止，不重新抄写市场组织、活动重要区域、当前互动和路径全文。

不能因为位置未变就忽略直接改变接受、失败、目标、失效或期限的新事实。所有新增事实归入唯一入口后，才允许停止传播。

### 4.3 完整重建

以下情况从观察边界重新建立：

- 品种、主周期或 K 线构造改变；
- 数据缺失区间或来源修订影响旧结论；
- 接管时无法证明旧判断仍可靠；
- 主测试被独立新问题替代；
- 市场组织、关键结构锚点或阶段发生替代；
- 多周期关系改变目标、失效、空间或期限；
- 原路径和风险均已关闭。

## 五、交给交易决策

Market 只向[交易决策](trade.md)交付：

- 观察边界与数据可靠性；
- 市场组织、活动重要区域图和现实空间；
- 当前区域互动、合理预期、实际价格表现、预期差和测试结果；
- 完整的方向路径块，包括已登记区域在当前测试、沿途障碍或检查点、唯一完成目标和失效参照中的职责，对应完成或失效条件、参与条件和期限，以及路径实际使用的 Signal Bar、组合或其他精确市场边界。

尚未提交本交易相关订单且没有实际仓位，或风险已经关闭时交付双向路径；否则，只交付所选路径、最强反方事实和本次变化。

路径完整不表示应当交易。Trade 仍须检查具体入场、计划保护、现实退出、成本后的回报风险和期限；Account 只检查账户限制、执行 Trade 动作，并核对平台权威事实中的订单、成交、仓位和实挂止损、止盈。

市场路径变化不直接决定持仓动作：

- 增强不自动授权加仓；
- 未变不重写原方案；
- 削弱不自动决定减仓或退出；
- 失效只交付市场事实；
- 实现不证明账户已经退出。

## 六、稳定事实附录

本附录用于首次分析、复核和重建，不是每根 K 的检查表。

### A. 结构视图怎样共享事实

同一组 Swing 可以同时形成 H2、Double Bottom、Bull Flag 或 MTR 组件。价格事实只登记一次，各视图只保留独有职责。

| 结构视图 | 共享事实 | 独有职责 |
| --- | --- | --- |
| ii / iii | 连续 inside bars | 压缩范围和边界 |
| ioi | inside–outside–inside | 双边扩张后的再压缩 |
| oo | 连续 outside bars | 双边扩张和不稳定边界 |
| Triangle | 双方反复测试 | 两侧活动边界和成熟度 |
| Expanding Triangle | 双方交替测试并扩张极值 | 扩张边界和测试次序 |
| Double Bottom / Top | 两次运动测试同一区域 | 重复测试区、Neckline 和高度候选 |
| Wedge | 三次可区分的同向推动或测试 | 推动次序、斜率和延伸质量 |
| Flag | 外层方向中的局部结构 | 局部结构对延续或反转的作用 |
| Final Flag | 成熟趋势末端的局部平衡 | 实时候选与事后结果分开 |
| H1/H2…、L1/L2… | 同周期、同恢复对象内的尝试 | 尝试次序、信号边界和重置点 |
| H&S | 旧极值测试、结构破坏和右肩 HL/LH | MTR 组件关系，不建立独立流程 |
| MTR | 成熟趋势后的反向发展 | 从 minor reversal 到控制转移的阶段 |

名称只把共享事实和独有职责写回市场组织、活动重要区域或当前互动，不直接生成路径、概率或交易。

### B. 区间、比例与候选区域投射

区间边界取当前反复组织价格的两个区域。一次影线或轻微越界不会自动改写边界。

设下沿为 `L`、上沿为 `U`、高度为 `R`：

```text
R = U - L
中部 = L + R / 2
底部三分之一区域 = L 到 L + R / 3
顶部三分之一区域 = U - R / 3 到 U
```

当前段从 `A` 到 `B` 的半程为 `A + (B - A) / 2`。

常见投射：

```text
Leg 1 = Leg 2 投射：第二段起点 C + 第一段位移 (B - A)
Range 向上投射：上沿 + Range 高度
Range 向下投射：下沿 - Range 高度
Double Bottom 投射：Neckline + Neckline 到底部区域的高度
Double Top 投射：Neckline - 顶部区域到 Neckline 的高度
```

所有端点必须在判断时已经可见并冻结。投射只产生候选重要区域；只有被当前路径选中后，它才承担完成目标或其他职责。仍须检查更近障碍、剩余空间和时间。50%、三分之一和测量值本身不生成反转或入场。

### C. Double Test 与 Neckline

Double Bottom / Top 的两次测试：

- 不要求精确同价；
- 必须是两次可区分的运动；
- 必须指向同一有意义区域；
- 中间必须有可见的反向 Swing。

Double Bottom 的 Neckline 是两次底部测试之间最高的相关反向 Swing high 区域；Double Top 镜像为最低的相关 Swing low 区域。

高度投射成为现实目标前，至少还需要 Neckline 突破后获得跟随或回试守住之一。Double Test 可以先于 H2/L2 形成，但不能证明 second entry 已触发。

### D. H/L 次序与重置

多头次序：

1. 第一次向上 Trigger 为 H1；
2. 再次回调后，完成 K 定义第二个边界，形成 H2 setup；
3. 越过该高点形成 H2 Trigger；
4. 首根越界 K 为 Chart Entry Bar。

空头完全镜像。严格 second entry 要求第一次 chart entry opportunity 已经触发。Signal Bar 只定义市场边界；是否采用、提交和成交属于后续职责。

H3/L3 可以与 Wedge 共享推动事实。出现更高编号时，应先检查是否已经成为 Triangle、Trading Range 或新的 Pullback 对象。

计数始终绑定周期、恢复对象和重置点。以下情况重置：

- 旧控制已经恢复；
- 新方向获得接受；
- 成熟 Range 切断旧运动；
- 主要结构被替代；
- 观察边界改变。

### E. K 线与运动事实

市场事实由来源直接提供的 OHLC、trade 或 volume、发生时间、最早可见时间和修订关系，以及下列确定性计算组成；不保存当前相对优势、控制、形态职责或路径。

设最高、最低、开盘和收盘为 `H`、`L`、`O`、`C`：

```text
总范围   = H - L
实体     = abs(C - O)
实体占比 = abs(C - O) / (H - L)
收盘位置 = (C - L) / (H - L)
上影占比 = [H - max(O, C)] / (H - L)
下影占比 = [min(O, C) - L] / (H - L)
```

`H = L` 时按零波幅 K 处理，不计算比例。几何关系只描述价格事实：

- Bull body：`C > O`；Bear body：`C < O`；
- Inside bar：high 不高于前高，low 不低于前低；
- Outside bar：high 不低于前高，low 不高于前低，且至少一端严格越过；
- Doji：实体相对周围很小或为零；
- Shaved：实体一端与极值严格相等；使用 tick 容差时须事先声明。

Trend bar 与 trading-range bar 是方向表达的连续谱，不是固定实体占比分类。Breakout、Reversal 和 Signal 是当前区域互动赋予完成 K 或组合的市场职责：Reversal 必须结合区域、当前段、范围、实体、收盘、影线和后续跟随；Two-bar 或 multi-bar reversal 由多根共同形成反向表达，不能被单一吞没几何替代；Signal 只有被当前路径用作参与理由或边界时才显示。跟随是初始行为之后的价格表现，不是另一种 K 线类型。单根 K 不建立趋势、确认反转或许可交易。

Chart Entry Bar 只是首根越过 Signal 边界的图表事实，不能证明平台订单已经触发或实际成交；实际执行仍以 Account 的平台权威事实为准。同一运动在高周期的单根表达与低周期的多根展开只是一组事实，不能跨周期重复增加证据。

- Push / Leg：较大结构中的一段方向运动；
- Pullback：当前方向运动中的暂停或暂时反向；
- Pause：停止扩展极值或横向停顿；
- Actual pullback：当前周期已出现反向高低点运动；
- Implied pullback：当前周期仅暂停，低周期可能已经展开回调。

第二段可以很短、横向、不创新极值或快速失败。它不等于等距投射、second signal、second entry 或第二次成交。

### F. Gap：分离事实、直接引用与后续结果

Gap 比较两个相关价格对象之间的分离或重新重叠程度。正 Gap 表示两者之间仍有未被重新交易的空间；negative / overlap gap 表示相关锚点已经轻微重叠。使用时必须写明方向、周期和比较对象：

- 相邻 K 完整高低范围之间的分离；
- 相邻实体区间之间的 body gap；
- 隔一根 K 比较的 micro gap；
- 突破点与 Pullback 之间的开放、负值或重叠；
- 整根 K 未触及指定 EMA 的 moving-average gap bar；
- 事先固定 Session 的 session gap；
- 本根开盘相对前收盘的单根 opening gap。

这些几何名称不能互换，也不直接决定强弱。关系事实只记录相关锚点和当前是新形成、保持、收窄、轻微重叠、完全关闭还是关闭后重新接受旧区域。长期未触 EMA 后的首次测试与单根 moving-average gap bar 不是同一对象，也不会自动生成入场。

同一次运动可以留下多个 Gap，它们可能在不同时间关闭。运行时不建立 Gap 清单、数量分数、重要性分类或引用注册表：

- 合理预期、价格表现、接受或失败条件、路径完成或失效条件需要某个 Gap 时，直接引用其比较对象、周期和当前关系，并事前写明保持、收窄、重叠或关闭会怎样改变该结论；
- 同一 Gap 被多个结论引用时，关系事实仍只保存一次，各结论分别按自己的条件重算；
- 没有任何当前结论引用的 Gap 不进入运行卡；同一 Gap 在不同周期或问题中的影响由各自结论表达，不得无声跨周期；
- 来自同一运动的 body gap、micro gap、突破回调 Gap、微型通道和极值推进可能只是同一事实组，不能重复增加证据、概率或风险预算。

Gap 只通过初始行为和跟随影响当前相对优势：一次新分离可以构成初始进展；随后保持、扩展、回试守住或普通回调后恢复，可以构成良好跟随；关闭对手分离只有在本侧同时取得并保住进展时，才支持优势转移。某段分离关闭只更新直接引用它的跟随、测试或路径；若对手没有自己的进展和良好跟随，结果优先是原结论削弱或失效以及通道化、双边化，不是自动反转。

Breakout Gap、Measuring Gap 和 Exhaustion Gap 是市场组织、阶段、区域与后续价格表现共同形成的解释，不是出现时即可冻结的几何类型：

- 分离保持、继续获得同向跟随或回试守住，支持突破接受或测量解释；
- 分离关闭、重新接受旧区域并出现反向恢复，支持失败或衰竭解释；
- 跟随减弱但事前要求保持的分离尚未关闭时，仍是未决；
- Gap 区间、中点或投射只生成候选重要区域，被当前路径选择后才取得目标、障碍或检查点职责。

### G. 趋势线与通道线

多头趋势线连接两个相关向上反转低点；空头趋势线连接两个相关向下反转高点。优先使用强段起点、强反转或显著拐点，不用大量小线填满图表。

通道候选来自把趋势线平行复制到另一侧显著极值，或直接连接另一侧两个相关反转点：

- 持续产生反应时保留；
- 新主要极值或失败突破出现时建立重画候选；
- 轻微 overshoot/undershoot 且无良好跟随时不自动失效；
- 强越界并获得良好跟随后失去当前边界职责；
- 长期不再产生响应时休眠；
- 仍是现实回试区时改变职责后保留。

多条线只有在周期、尺度或用途不同的时候并存。
