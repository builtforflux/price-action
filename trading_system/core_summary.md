# 核心知识

## 判断与行动的主线

**观察多空表现 → 判断优势方向 → 决定是否参与及如何参与 → 根据新信息持续修正**

## 市场状态

- 突破：单向推进强，回调浅，价格快速脱离原有区域。
- 趋势通道
  - 窄通道：顺势推进占主导，逆向空间有限。
  - 宽通道：存在双向波段，但整体仍有方向倾向。
- 震荡区间
  - 窄区间：双向空间有限，往往不足以覆盖风险与成本。
  - 宽区间：双向空间充足，可关注区间边缘向内部的运动。
- 状态转换：突破、通道与区间之间会相互演化，也可能发生趋势反转。
- 尺度共存：不同周期上，趋势与区间可以同时存在。

## 多空强弱

结合位置和周期，比较双方：

**推进**：能走多远、多快，突破后是否延续。
**保留**：推进成果能否守住，回吐是否受控。
**恢复**：受阻后能否重新启动原方向。

单根强 K 不代表趋势能持续。一方转弱不代表另一方转强；方向明确不代表当前价格值得参与。

## 形态

- 双底 / 双顶：同一区域的两次测试，中间有反向运动。
- 牛旗 / 熊旗：趋势中的整理。
- 最后旗形：趋势末端可能引出反转的整理；可先顺势突破失败，也可直接反向，事前仅作候选。
- 楔形：三次可区分的同向推动，不要求收敛。
- 抛物线楔形：紧通道内的三次高潮式同向推动。
- 收敛三角形：高点降低、低点抬高，双边范围收窄。
- 扩张三角形：高点抬高、低点降低，双边范围扩大；关注边缘反转或突破延续，不按段数认定结束。
- 上升 / 下降三角形：上沿近水平、低点抬高 / 下沿近水平、高点降低。
- 头肩顶 / 头肩底：三个依次形成的峰 / 谷，头部高于 / 低于双肩，间隔的低点 / 高点连成颈线。
- ii / iii：连续两 / 三根内包 K，范围逐层收窄。
- oo：连续两根外包 K，范围逐层扩大。
- ioi：内包—外包—内包，范围先收窄、再扩大、再收窄。

内外包均相对前一根 K。形态看背景和跟随，局部突破不等于突破外层区间。同一事实不因名称多而更强；嵌套形态看内层表现怎样改变外层预期。

## 计数

- H1：多头回调或区间底部，首次严格越过前一根 K 的高点。
- H2：同一轮计数中，H1 后先出现至少一根高点低于前一根的已完成 K，随后首次严格越过前一根 K 的高点。
- L1 / L2：反向对应，以严格跌破前一根 K 的低点计数。

连续新高／新低不重复计数，相等不触发。原趋势恢复、新方向取得并保住控制，或成熟区间切断旧运动 → 按受影响尺度重计；仅局部触价不重置。

推动按同一运动与尺度计数；强突破改变结构后重计，不跨突破拼三推。第二段运动、第二次测试、H2/L2 触发分别判断。

## 尺度

TBTL（Ten Bars, Two Legs）：用约十根 K、两段估计运动尺度。

| 场景 | 预期与处理 |
| --- | --- |
| 连续高潮或异常持久的单向运动后，有修正依据 | 看横向至反向修正；重评依赖快速恢复的持仓 |
| 楔形、双顶底或主要反转，反向压力与空间支持波段 | 看反向波段，未必成为新趋势 |
| 强突破有跟随、守住进展且有空间，包括成功的顺势通道突破 | 看新波段，允许计划内回调；普通第二段预期不自动套用 |

从该运动起点，按能清楚呈现同一形态的最高相关周期计量。低周期两小段不代表大尺度完成；十根两段不是固定期限或入场、结束信号，也不保证目标到达。持仓按前提与目标管理，不必等满。

## 重要位置

- 结构位置：前高／前低、主要回调高低点，区间上沿／中点／下沿，突破位与颈线。
- 运动起点：趋势段、突破段、通道阶段的起点。
- 趋势参照：趋势线、通道线、EMA20。
- 缺口位置：缺口边界、缺口中点。
- 基准价格：重要时段的开盘价、最高价、最低价、收盘价，以及整数区域。
- 回调与目标：所选运动的价格中点（50% 回调位）、测量目标。

## 测量目标（Measured Move）

固定同一尺度的起点、距离与投射位置，再看障碍和空间。

| 方法 | 怎样投射 |
| --- | --- |
| Leg 1 = Leg 2 | 第一段从 A 到 B，第二段从 C 开始：目标为 C＋(B−A) |
| 缺口中点对称 | 运动起点 S、所引用缺口两边界的中点 M：目标为 2M−S；不把突破 K 的中点当缺口中点 |
| 区间高度 | 区间上沿 U、下沿 L：向上从 U 加一个区间高度，向下从 L 减一个区间高度 |
| 双顶／双底到颈线高度 | 从颈线向突破方向投射一个顶／底至颈线的距离 |

测量值是候选，不保证到达。取点不清可保留少数合理候选，不为扩大目标换锚点。

## 缺口（Gap）

- 类型
  - 突破位置与回调之间的缺口。
  - 实体缺口：比较指定两根 K 的实体，可不相邻。
  - 均线缺口：整根 K 线未触及均线。
  - 时段缺口、开盘相对前收盘的缺口。
- 状态：形成、保持、关闭。
- 突破、测量、衰竭是结合背景与后续的解释。

## 场景

### 趋势延续

- 强突破后有跟随、回吐有限 → 支持延续或回调后的第二段；目标另看前方空间。
- 第二段可短、横向或不创新极值；再次强突破并保持，仍可延伸。
- 窄通道首次反向突破 → 通常先看回调；反向走势持续增强时，再考虑更大修正。
- 出现有意义的回调 → 突破可能转为通道；逆向回调加深、空间扩大时，再判断通道是否变宽。
- 阶梯推进中新高、新低扩展减少，回调加深 → 趋势减弱，但尚不能确认反转。
- 新区间沿原方向逐级移动 → 保留趋势倾向；回到旧区间后能否再次离开，决定延续是否仍有依据。

### 回调恢复

- 回调幅度、耗时接近此前，反向较弱 → 期待原方向恢复，再看实际表现。
- 回调形成强突破或窄通道 → 可能还有第二段回调，首次顺势恢复可能失败；原方向强势恢复并保持则削弱此预期。
- 回调已有两段或多段 → 是否结束看反向走势减弱和原方向恢复，不按段数确定。
- 突破区域回测后守住并恢复 → 支持延续；反复返回、每次离开更困难 → 更可能转为区间。
- 深回调后第二段以弱通道推进 → 可测试旧极值，该段结束后更可能转区间。
- 长期未触 EMA20 后首次触及，包括收于反侧但仍与均线相交 → 先看恢复、测试旧极值；恢复失败再改判。
- 趋势中整根 K 位于 EMA20 反侧，伴随反向走势强、破线或回吐扩大 → 看较大修正；原方向恢复可能只测试旧极值，强突破并保持可支持延伸。

### 区域测试

宽通道有方向倾向，区间偏双向往返；两侧机会不必同强。

- 到达重要位置 → 分别看突破、停顿或反转；能够到达不代表能够突破。
- 区间边缘拒绝价格并向内运动 → 先看沿途障碍，再判断中部或对侧是否可达。
- 区间边缘被突破且有跟随、回吐有限 → 支持向外延伸。
- 未到边缘便反向 → 看能否持续离开，不要求精确触线。
- 第二段先看位置，再决定处理：
  - 趋势中有空间，跟随好、回吐少 → 按延续管理；新入场或加仓另算风险收益。
  - 接近支撑阻力、通道边缘或目标，尤其在区间、宽通道或连续高潮后 → 警惕第二段陷阱，不因强势追单或扩大目标。突破守住可延伸；跟随失败并反向发展则重评持仓，反做另需依据。
- 价格已离开边缘、接近内部障碍 → 按当前位置计算剩余空间。

### 区间演化

- 多次突破后返回 → 支持震荡；双方都有明显波段仍无法离开 → 区间趋于成熟。
- 双方都有较大波段 → 可比较内部机会；双方都走不远、重叠密集 → 可能缺少足够交易空间。
- 一侧反复接近边缘、回调浅、受阻后仍能继续 → 增加该侧突破的依据。
- 区间压缩、双向均可能突破，形成突破模式（BOM） → 转看突破与跟随，不机械反做。首破仍可能失败，方向偏向不等于目标可达。
- 趋势中的短暂整理 → 可保留原方向倾向；整理中双方波段扩大、原方向反复恢复失败 → 更可能转为区间。
- 突破失败回到区间 → 先看向内运动；回测突破处时若再次突破并保持 → 恢复向外延伸的预期。
- 趋势回调加深、恢复受限、重叠增加 → 更可能转为区间；仍持续形成更高或更低波段时，保留宽通道判断。

### 异常运动与修正

- 趋势末端突然加速，或长期缺少回调 → 留意修正；强势仍持续时，不因涨跌过多而判断反转。
- 向支撑阻力快速运动 → 可能是真空；到达后的跟随和回吐决定能否继续。连续高潮会增加衰竭疑虑，次数不决定结束。
- 推进停止、回吐少 → 可能主要以横盘修正；回吐扩大、反向走势持续 → 价格修正加深。
- 长紧通道或连续高潮结束 → 修正可能比局部冲刺后更久、更大；时间与回撤深度分别判断。
- 高潮后原方向恢复 → 可能测试旧极值；测试后继续突破还是再次反转，决定后续预期。
- 顺势突破通道线后继续延伸 → 可能形成更强趋势；失败回入 → 先看通道内部。
- 后期突破缺少跟随并出现反转 → 可支持衰竭判断，不要求 Gap 完整关闭。
- 趋势末端强收盘后缺少跟随，原方向恢复不到该收盘区域，再出现强反向走势 → 更支持反向运动。
- 趋势末端整理后反向发展 → 留意最后旗形。

### 趋势受损与反转

- 趋势线被突破 → 先判断修正是否扩大；局部破坏不等于主要趋势反转。
- 反向突破强紧通道 → 可主要横盘修正；突破较弱通道 → 可研究回测通道起点，仍看反向力量与障碍。
- 反向走势强，原方向测试旧极值后再次反转 → 可研究早期反向波段，不必一律等待 LH 或 HL。
- 首次反向走势弱 → 原方向恢复弱也不足以确认反转，仍需更强反向走势。
- 测试旧极值不到、持平或越过 → 比较测试力度及随后的反转，不按极值位置单独判断。
- 反向突破强且保住进展 → 按实际表现更新方向判断，不必等标准形态完整。
- 原方向重新强势推进并保持 → 原反转依据减弱或失效；后续反转须用新事实判断。
- 反向波段形成后 → 看能否延伸、回调后再恢复，区分区间摆动与新趋势。

强趋势中仍须按反转尝试判断，不能仅凭楔形名称套用 75%；意外突破发生后也不沿用突破前概率。

### 时段影响

仅用于开收盘确实影响走势的产品和 Session。

- 跳空开盘 → 分别比较昨收、昨日收盘区间和昨日高低点；越过昨收不等于突破昨日区间，跳空方向不决定全天方向。
- 开盘范围突破 → 看跟随和回测，不凭首段强势定全天方向；开盘范围不等于 BOM。
- 高周期趋势仍强 → 早期逆向尝试可能失败；昨日处于区间 → 仍需考虑返回区间内部。
- 初始运动相对近期日波幅已很大，随后反向 → 更需考虑宽区间；反向走势极强时仍可能形成趋势，不按固定比例定性。
- 昨日高潮 → 今日可能先延续再修正，也可能较早修正；昨日已开始的整理不从今日开盘重新计时。
- 开盘已有昨日趋势背景，今日强反向且测试或恢复失败 → 短结构也可支持反转，后续展开仍需时间。
- 尾盘新形成的反向通道 → 可能只是区间中的一段，不直接沿用较早建立趋势的延续预期。
- 区间日后段 → 看中部或开盘价，两者可不同；到达后可停留或转向日内极值，仍看剩余时间。
- 临近退出期限，方案依赖快速推进 → 停顿或恢复迟缓会更早损害持有前提。

## 从判断到选择

- **看什么**：期待哪段运动，允许怎样的回调，什么变化会使预期失效；列出最强反方事实，有分歧时明确后续如何区分。
- **值不值**：用当时事实与价格，比较目标、障碍、保护、数量、成本和时间，以及参与或等待、持有或调整。
- **怎么做**：定好方向、入场条件、价格、数量、止损、目标、出场规则和期限，固定损失预算；缺项则等待。

参与后对照这些条件更新判断，区分正常波动与前提受损；等待时明确下一观察。

## 入场

- 候选：H1 / H2、L1 / L2、突破、突破回调、失败突破、边缘恢复；名称本身不授权入场。
- 信号 K 线：提供入场边界，可同时具有趋势或反转作用。
- 确认：按方案选择越界、收盘、跟随或回测守住，不要求每项都完成。
- 强段中逆向参与 → 宜等第二次反转信号或强反向突破；仍要有空间，不按次数入场。
- 低周期可争取更早价格，但不代替高周期确认；按高周期持有，保护与仓位也要匹配。
- Stop 越界触发，仍可能突破失败；Limit 改善价格，但可能缺少确认或不成交；Market 在条件满足后按市价参与。
- 提前反做：走势与空间支持回摆 → 可在弱信号目标附近参与；区间边界仍有效 → 可反做突破收盘。
  须有返回目标、保护和期限；尚无跟随不等于跟随失败，突破持续则重评。
- 等待确认后按新价格重算；普通触价单不能代替其他确认。

## 交易方式与目标

- Scalp：取所选尺度中的短段，通常不穿越明显回调。
- Swing：持有所选波段，容纳计划内回调；按尺度与持有过程区分。
- 近端目标：最近的实质障碍、旧极值或测量目标。
- 后续目标：有延续依据的下一重要区域。
- 分批退出：定数量、余仓保护与目标，核算部分兑现后余仓止损的整笔结果。
- 市场目标不等于出场价，可提前于目标区域退出。滚动投射见 [目标选择与更新](trade.md#目标怎样选择与更新)。

## 止损

按参与依据和允许过程选择参照。下表为做多，做空镜像。

| 本笔要求 | 止损参照 |
| --- | --- |
| 信号低点守住 | 完整信号低点 |
| 允许局部回调，重要上涨段起点守住 | 该段底部 |
| 依赖强突破确认的主要 HL 延续 | 主要 HL 低点 |
| 不容许深回调，半程有恢复依据 | 所选强势段半程 |
| 允许局部信号失败，完整底部守住 | 多次测试的整体低点 |
| 事前允许转区间后恢复，较大结构仍有效 | 能容纳整理的较大结构底部 |
| 允许边缘突破后返回，且有返回依据 | 结构投射或旧极值外可比的历史失败突破幅度投射 |

- **落价**：参照不利侧加缓冲。越过即执行、报价与触发一致且平台允许时，默认外侧 1 tick。
- **数量**：先定止损，再算数量；宽保护须有恢复依据，目标不随止损扩大。
- **移动**：按新确认参照或既定规则，保留正常回调空间；全仓共用止损，只收紧。
- **退出**：前提失败且无及时成立的替代方案，退出，不等止损；市场预期另判。

落价与生效细则见 [保护性止损](trade.md#33-交易前提路径失效与保护性止损)、[移动止损](trade.md#34-移动止损)。

## 收益、仓位与风险

- **门槛**：建仓或加仓的完整计划净回报，不低于全仓止损净损失；仍须有目标可达性和足够时间，通过不证明正期望。
- **预算**：首笔前固定金额或净值比例；分批、加仓、移损和换计划均不重置。
- **数量**：单一入场价的上限＝（最大计划损失−固定成本预留）÷（每单位止损损失＋每单位成本预留）。计入点值，按数量步长向下取整；已有持仓、退出或未决加仓须算完整组合。
- **风险**：初始风险、现价至止损的回吐风险、账户开放风险分别算。止损已在盈利区，仍有回吐风险。
- **整笔核算**：各层分别算到共同止损的损益，计入已实现结果、余仓、可能成交的加仓和全部成本；止损与各出场路径都要算，已实现亏损仍占用原预算。

同一线性产品：

- 整笔净结果＝已实现毛损益＋余仓退出毛损益−全部成本。
- 加权入场价＝Σ(入场价×数量)÷总数量。等量两层的中点只是毛保本；有成本或已退出部分时，另算整笔保本价。

**加仓：须有新的支持依据，新增部分须独立合算。**

- 趋势继续确认 → 在新突破或回调恢复处追加；越晚越要看剩余空间。
- 原前提仍在，支撑阻力附近有恢复或返回依据 → 可按计划在更好位置追加；均价改善不代表恢复更可能。
- 首笔前定各层条件、位置、数量与取消条件，预留后层损失预算。间距要有收益意义，不在几乎同价处堆仓；每次追加重算，不超原预算。

账户还须满足总开放风险、日内损失、保证金、杠杆、清算缓冲和集中度限制；本系统只持单向仓位。复杂组合见 [完整核算](trade.md#37-判断是否值得)。

### 概率与收益的算术

仅有盈亏两种结果时，`p` 为获利概率、`G` 为毛收益、`L` 为毛损失：毛期望＝`pG−(1−p)L`，毛保本概率＝`L/(G+L)`。

| 假设 | 毛期望 |
| --- | --- |
| 40% 赚 2R，60% 亏 1R | +0.2R |
| 60% 赚 1R，40% 亏 1R | +0.2R |
| 80% 赚 1，20% 亏 3 | +0.2 |

这是算术示例，非胜率估计。多种退出结果须分别计概率与成本后的损益。来源：[30A](../reference/course/30A.md)、[30C](../reference/course/30C.md)。

## 持仓、等待与更新

新事实出现，先更新判断，再比较持有、调整或退出的剩余收益、风险和时间；价格与成本变化也要计入。

| 当前情况 | 处理 |
| --- | --- |
| 正常回调，参与依据与承担条件仍在 | 按计划持有 |
| 到阶段目标 | 可兑现部分，有依据才留余仓 |
| 追加所依赖的动能减弱 | 重评该部分；条件失效或风险收益不值时减仓，正常回调不自动触发 |
| 恢复不足、原目标不再合理 | 重评减仓或退出，不执着均价、首笔价格或保本 |
| 走势预期失效或到期 | 重评；无及时成立的替代依据则退出 |
| 空仓 | 明确等待价格、表现与复查时间 |
| 无实质变化 | 沿用原计划；订单、账户及安全期限仍须处理 |

- 减仓前定目标余仓和保护；减仓、平仓或止损进入执行时，终止旧扩仓授权，退出后不自动补仓。
- 延伸目标须有新依据并保留旧记录；入场、退出、目标完成后继续观察，重新参与按当时价格与事实判断。

## 执行与核对

- 启用前核实：价格与数量步长、点值、成本、报价侧、触发与成交规则、账户限制和平台保护能力。
- 提交、接受、触发、成交分别确认；触价不保证成交，申请撤单不等于撤成。
- 成交或订单变化后，核对实际余仓、仍可能成交的订单及足量有效止损；部分退出落实到目标余仓。
- 仓位、订单或保护不清 → 停止新增风险，查询并保护；账户超限、止损执行或安全期限到达 → 先减险。
- 必要数据缺失 → 撤销扩仓授权，保留有效保护；只在事前期限内且确认安全时等待，到期未恢复则按规则退出。
- 仓位归零、相关订单均不再可能成交，才算本笔结束；此前持续管理和查询。异常处理见 [Account](account.md#四平台记录不清时)。

## 后续检验与方法修正

- 只用当时事实；未完成形态、未查看的低周期过程不当确认，动机只作推断。高周期 EMA 用该周期数据，低周期近似不等价。
- 当前预期可更新；纳入评价的原预测仍按原目标、失效和期限检验，不覆盖旧结果。
- 市场判断、交易方案、实际执行、账户结果分开评价；看对不等于合算，盈利不等于方法正确。
- 保留当时依据、授权变化、成交与成本，用连续结果比较参与和管理质量；不凭单笔盈亏或调整少定好坏。
- 来源次数、比例、概率不自动成为规则；有分歧时写明取舍及改判条件。
- 按 [Practice](../practice/README.md)回放检验，按 [Governance](governance.md)调整；文档完整不等于交易优势已验证。
