# 核心知识与选择速查

本页汇总核心知识与选择条件。完整规则和计算见 [Market](market.md)、[场景](scenarios.md)、[Trade](trade.md)、[Account](account.md)及[复盘与治理](governance.md)。

文中“课程概率”均为来源经验，尚非系统已校准数值；按当前表现更新判断。相同数字若事件或期限不同，分别理解，不直接当作本笔胜率。全部已汇总条目及未采用项见[概率清单](../reference/probabilities.md)。

## 判断与行动的主线

**比较双方表现 → 形成条件预期 → 选择运动与参与方式 → 随新事实重评 → 用连续结果检验。**

优先选好值得参与的运动，让价格、目标、保护、数量与允许过程相匹配。持续区分事实与不确定性；依据或承担条件实质变化时行动，否则持有或等待。

## 市场状态

- 突破：单向推进明显，回调有限。
- 趋势通道
  - 窄通道：逆向运动有限，通常缺少逆势交易空间。
  - 宽通道：存在双向波段，仍保留整体方向倾向。
- 震荡区间
  - 窄区间：内部空间可能不足以覆盖风险和成本。
  - 宽区间：可研究边缘向内的运动。
- 状态转换：突破转通道、趋势转区间、区间转趋势、趋势反转。
- 趋势与区间可以在不同尺度共存；先固定产品、周期、Session 和可用数据，再判断。

## 多空强弱

结合位置和周期，比较双方：

- **推进**：涨跌幅度、持续时间、重叠多少，突破哪里，是否有跟随。
- **保留**：回吐多少，突破位置和主要高低点是否守住，Gap 是否关闭。
- **恢复**：回调多深、多久、反向走势多强；回调后能否继续原方向运动。

单根强 K 不代表趋势能持续。一方转弱不代表另一方转强；方向明确不代表当前价格值得参与。

## 形态与计数

形态、Gap、计数和测量按位置、尺度与次序提供信息，说明它们改变哪项预期；同一运动的多个名称不重复增加证据。

- 双底 / 双顶：同一区域的两次测试，中间有反向运动。
- 牛旗 / 熊旗：趋势中的整理。
- 最后旗形：可能出现延续失败的整理，事前作为候选。
- 楔形：三次可区分的同向推动，不要求收敛。
- 抛物线楔形：紧密运动中的连续高潮型三推。
- 三角形：按两侧测试组织边界；收缩与扩张描述边界距离，上升与下降描述边界斜率。
- 头肩顶 / 头肩底：三个相关极值及其间回调构成的结构。
- 主要趋势反转（MTR）：研究趋势受损后的反转尝试；形态成立不等于反向趋势已形成。
- ii / iii：连续两／三根内包 K，每根相对前一根。
- oo：连续两根外包 K，每根相对前一根。
- ioi：内包—外包—内包。
- H1 / H2、L1 / L2
  - H1：同一多头回调或区间底部，首次严格越过前一根 K 高点。
  - H2：H1 后至少一根完成 K 的高点低于前一根，随后首次严格越过前一根 K 高点。
  - L1 / L2 镜像处理。
  - 连续创新高或新低不重复计数，相等高低点不触发新次数；按 [H/L 规则](market.md#d-hl-次序与重置)检查重置。
- 第二段运动、第二次测试、第二次触发分别判断。

## 重要位置

- 前高 / 前低、主要回调高低点。
- 区间上沿 / 中点 / 下沿。
- 突破位置、形态颈线。
- 趋势线 / 通道线。
- 趋势段、突破段、通道阶段的起点。
- 20 周期指数移动平均线（EMA20）。
- 缺口边界 / 中点。
- 重要开盘价、最高价、最低价、收盘价及整数区域。
- 50% 回调位：所选运动的价格中点。
- 测量目标。
- 每个位置注明周期、价格带及作用：支撑阻力、磁吸、障碍、目标或失效参照。

## 缺口（Gap）

- 类型
  - 相邻 K 线完整价格范围之间的缺口。
  - 实体缺口：比较指定两根 K 的实体，可不相邻。
  - 微型缺口：隔一根 K 线比较完整价格范围。
  - 突破位置与回调之间的缺口。
  - 均线缺口：整根 K 线未触及均线。
  - 时段缺口、开盘相对前收盘的缺口。
- 状态：形成、保持、收窄、接触、重叠、关闭。
- 固定比较对象和关闭条件；接触为零宽度，重叠不称为正缺口。收盘到参照的价差另列，不代表中间没有成交。
- 突破、测量、衰竭是结合背景与后续的解释。
- 缺口关闭不单独确认反转；缺口未关闭也不排除修正。

## 测量目标（Measured Move）

| 测量方式 | 候选目标 |
| --- | --- |
| 第一段等长投射：第一段 A→B，第二段起点 C | C + (B−A) |
| 区间、完整突破段或趋势段高度：各取自身最低 L、最高 U | 向上 U+(U−L)；向下 L−(U−L) |
| 双底：底部 L、颈线 N | N+(N−L) |
| 双顶：顶部 U、颈线 N | N−(U−N) |
| 缺口中点对称：中点 M、运动起点 S | 2M−S |
| 突破位置对称：突破位置 P、运动起点 S | 2P−S |
| 突破实体：首开 A、末收 B | 顺向 B+(B−A) |
| 突破失败后的实体反向投射 | A−(B−A) |
| 区间中点对称：中点 M、区间前运动起点 S | 2M−S |

- 固定周期、运动、锚点和投射方向。
- 突破实体取首开至末收的净位移，不逐根相加。
- 测量值只是候选目标，仍须检查可达依据、障碍和期限。

## 场景

六类场景可以同时适用，按位置和尺度分别判断。

### 趋势延续

- 强突破后有跟随、回吐有限 → 支持延续或回调后的第二段；目标另看前方空间。
- 第二段可短、横向或不创新极值；若再次强势突破并保持，仍可继续延伸。分段与投射见[测量目标](#测量目标measured-move)。
- 窄通道首次反向突破 → 通常先看回调；反向走势持续增强时，再考虑更大修正。
- 出现有意义的回调 → 突破可能转为通道；逆向回调加深、空间扩大时，再判断通道是否变宽。
- 阶梯推进中新高、新低扩展减少，回调加深 → 趋势减弱，但尚不能确认反转。
- 新区间沿原方向逐级移动 → 保留趋势倾向；回到旧区间后能否再次离开，决定延续是否仍有依据。

### 回调恢复

- 回调幅度和时间接近此前，反向走势较弱 → 可期待原方向恢复；仍看实际恢复表现。
- 回调自身形成强突破或窄通道 → 反向可能还有第二段，首次顺势恢复可能失败；原方向直接强势恢复并保住进展时，削弱第二段预期。
- 回调已有两段或多段 → 是否结束看反向走势减弱和原方向恢复，不按段数确定。
- 突破区域回测后守住并恢复 → 支持延续；反复返回、每次离开更困难 → 更可能转为区间。
- 深回调后第二段以弱通道推进 → 可测试旧极值，该段结束后更可能转区间。
- 长期未触 EMA20 后首次触及，或收于反侧但仍与均线相交 → 可先期待原方向恢复、测试旧极值；恢复失败时更新预期。
- 趋势中整根 K 位于 EMA20 反侧，且反向走势强、趋势线受损或回吐扩大 → 更支持较大修正；原方向恢复可能只测试旧极值，强势突破并保持时再判断延续。

### 区域测试

宽通道仍有整体方向倾向，区间更偏双向往返；都有双向空间，不代表两侧机会同样强。

- 到达重要位置 → 分别看突破、停顿或反转；能够到达不代表能够突破。
- 区间边缘拒绝价格并向内运动 → 先看沿途障碍，再判断中部或对侧是否可达。
- 区间边缘被突破且有跟随、回吐有限 → 支持向外延伸。
- 未到边缘便反向 → 看能否持续离开，不要求精确触线。
- 第二段在边缘或目标附近停止，随后反向 → 可能是回调，也可能延续失败；按原失败条件判断，反向能走多远另判。
- 价格已离开边缘、接近内部障碍 → 按当前位置计算剩余空间。

### 区间演化

- 双方多次突破后返回区间 → 支持继续震荡；双方曾有明显波段仍无法离开，是成熟区间的依据。
- 双方都有较大波段 → 可比较内部机会；双方都走不远、重叠密集 → 可能缺少足够交易空间。
- 一侧反复接近边缘、回调浅、受阻后仍能继续 → 增加该侧突破的依据。
- 趋势中的短暂整理 → 可保留原方向倾向；整理中双方波段扩大、原方向反复恢复失败 → 更可能转为区间。
- 突破失败回到区间 → 先看向内运动；回测突破处时若再次突破并保持 → 恢复向外延伸的预期。
- 趋势回调加深、恢复受限、重叠增加 → 更可能转为区间；仍持续形成更高或更低波段时，保留宽通道判断。

### 异常运动与修正

- 趋势末端突然加速，或长期缺少回调 → 留意修正；强势仍持续时，不因涨跌过多而判断反转。
- 向支撑阻力快速运动 → 可能是真空；到达后的跟随和回吐决定能否继续。连续高潮会增加衰竭疑虑，次数不决定结束。
- 推进停止、回吐少 → 可能主要以横盘修正；回吐扩大、反向走势持续 → 价格修正加深。
- 长紧通道或连续高潮结束 → 修正可能比局部冲刺后更久、更大；时间与回撤深度分别判断。
- 高潮后原方向恢复 → 可能测试旧极值；测试后继续突破还是再次反转，决定后续预期。
- 顺势突破通道线后继续延伸 → 可能形成更强趋势；失败回入 → 先看通道内部。
- 后期突破缺少跟随并出现反转 → 可支持衰竭判断，不要求 Gap 完整关闭。
- 趋势末端强收盘后缺少跟随，原方向恢复不到该收盘区域，再出现强反向走势 → 更支持反向运动。
- 趋势末端整理后出现反向走势 → 可能是最后旗形；既可先顺势突破再失败，也可直接反向。

### 趋势受损与反转

- 趋势线被突破 → 先判断修正是否扩大；局部破坏不等于主要趋势反转。
- 强紧通道被反向突破 → 可能主要横盘修正；较弱通道被反向突破 → 更需考虑回测通道起点，是否可达仍看反向走势和沿途障碍。
- 反向走势强，原方向测试旧极值后再次反转 → 可研究早期反向波段，不必一律等待 LH 或 HL。
- 首次反向走势弱 → 原方向恢复弱也不足以确认反转，仍需更强反向走势。
- 测试旧极值不到、持平或越过 → 比较测试力度及随后的反转，不按极值位置单独判断。
- 反向突破强且保住进展 → 按实际表现更新方向判断，不必等标准形态完整。
- 原方向重新强势推进并保持 → 原反转依据减弱或失效；后续反转须用新事实判断。
- 已形成反向波段 → 继续区分区间内波段与新趋势；反向能够延伸并在回调后恢复，才增加持续性的依据。

### 时段影响

仅用于开收盘确实影响走势的产品和 Session。

- 跳空开盘 → 分别比较昨收、昨日收盘区间和昨日高低点；越过昨收不等于突破昨日区间，跳空方向不决定全天方向。
- 开盘范围突破 → 看跟随和回测，不能只凭首段强势判断全天趋势；开盘范围与双向突破均有可能的 BOM 分别判断。
- 高周期趋势仍强 → 早期逆向尝试可能失败；昨日处于区间 → 仍需考虑返回区间内部。
- 初始运动相对近期日波幅已很大，随后反向 → 更需考虑宽区间；反向走势极强时仍可能形成趋势，不按固定比例定性。
- 昨日高潮 → 今日可能先延续再修正，也可能较早修正；昨日已开始的整理不从今日开盘重新计时。
- 开盘已有昨日趋势背景，今日出现强反向走势及测试或恢复失败 → 较短的局部结构也可支持反转，但不缩短后续运动所需时间。
- 尾盘新形成的反向通道 → 可能只是区间中的一段，不直接沿用较早建立趋势的延续预期。
- 区间日后段 → 可研究返回中部或开盘价；两者未必同价，到达后仍可能收在附近或转向日内极值，须核对剩余时间。
- 临近退出期限，方案依赖快速推进 → 停顿或恢复迟缓会更早损害持有前提。

## 从判断到选择

- **期待什么**：双方表现支持哪段运动，途中可能经历什么，哪些变化会削弱或否定它。明确最强反方事实；不同解释会改变选择时，说明用什么后续表现区分。
- **是否值得参与**：按当前价格，把目标、障碍、保护、数量和剩余时间一起比较。用同一时点的事实与价格，比较参与与等待、调整与继续持有。
- **接下来看什么**：依据不足时明确等待什么；参与后用新事实检验预期并重评选择。

实际参与前，按 Market 与 Trade 明确完整的[条件路径](market.md#37-条件路径与目标)和[交易方案](trade.md#二运行卡)。

## 入场

- 候选：H1 / H2、L1 / L2、突破、突破回调、失败突破、边缘恢复；名称本身不授权入场。
- 信号 K 线：提供入场边界，可同时具有趋势或反转作用。
- 确认：按方案选择越界、收盘、跟随或回测守住，不要求每项都完成。
- 订单
  - 停止单（Stop）：以越界触发，仍承担突破失败风险。
  - 限价单（Limit）：改善价格，承担确认不足或无法成交。
  - 市价单（Market）：条件满足后按当前可执行价格参与。
- 提前反做
  - 弱信号目标附近：实际走势和空间支持回摆时，押注原方向无法持续穿过该区域。
  - 区间边缘突破收盘：区间判断仍有依据时，可提前反做，预期突破无法获得跟随。
  - 两者均须有返回目标、保护和期限；未出现跟随不等于跟随已失败，突破持续时重评。
- 入场前确定：方向、条件、价格、数量、止损、目标、退出规则和期限。
- 等待确认后按新价格重算；普通触价单不能代替其他确认。

## 交易方式与目标

目标层级、连续强突破的滚动投射及余仓更新，见 [目标选择与更新](trade.md#目标怎样选择与更新)。

- 短线交易（Scalp）：参与所选尺度中的较短运动，通常不计划持有穿越明显回调。
- 波段交易（Swing）：参与所选尺度中的一段运动，容纳计划内回调；与 Scalp 的区别结合运动尺度和持有过程判断。
- 近端目标：最近的实质障碍、旧极值或测量目标。
- 后续目标：有延续依据的下一重要区域。
- 分批退出须明确数量、余仓止损与后续目标，并核算首段退出后余仓回到止损的结果。
- 市场目标与实际出场价分别确定；可在目标区域之前退出。

## 止损

按参与依据和允许过程选择参照。下表为做多，做空镜像。

| 本笔要求 | 止损参照 |
| --- | --- |
| 信号低点守住 | 完整信号低点 |
| 允许局部回调，重要上涨段起点守住 | 该段底部 |
| 依赖强突破确认的主要 HL 延续 | 主要 HL 低点 |
| 不容许深回调，半程有恢复依据 | 所选强势段半程 |
| 允许局部信号失败，完整底部守住 | 多次测试的整体低点 |
| 事前允许转区间后恢复，较大结构仍有效 | 能容纳整理的较大结构底部 |
| 允许边缘突破后返回，且有返回依据 | 结构投射或旧极值外可比的历史失败突破幅度投射 |

- **落价**：参照不利侧加缓冲；越过即执行、报价与触发一致且平台允许时，默认外侧 1 个有效 tick。
- **数量**：先定合理止损，再算数量；宽止损须有恢复依据，目标不随止损机械扩大。
- **移动**：依据新确认参照或既定规则，仍容纳计划内回调；同笔共用止损，只收紧，不放宽。
- **退出**：交易前提失败且没有及时成立的替代方案，退出，不必等止损触发；市场预期失效另判。

参照资格、投射、缓冲和生效要求见 [保护性止损](trade.md#33-交易前提路径失效与保护性止损)；调整条件见[移动止损](trade.md#34-移动止损)。

## 收益、仓位与风险

分层的位置、间距、预算分配与加权损益，见 [分层构造](trade.md#41-位置间距与数量怎样共同构造)；已有退出或未决扩仓时使用 [完整核算](trade.md#37-判断是否值得)。

- 是否值得
  - 同时检查目标可达性、净收益、止损损失、成本和剩余时间。
  - 建仓或加仓时，完整计划净回报须不低于全仓止损净损失。
  - 通过筛选不证明正期望。
- 风险预算
  - 首次参与前固定金额或账户净值百分比。
  - 分批、加仓、移动止损和更换计划不重置预算。
- 数量
  - 单一入场价的数量上限＝（本方案最大计划损失−固定成本预留）÷（每单位止损损失＋每单位成本预留）。
  - 按数量步长向下取整，损失计入每点价值；已有仓位、退出或未决加仓时，按完整组合核算。
- 风险口径：初始入场风险、从当前价格到止损的回吐风险、账户开放风险分别计算；止损进入盈利区域不等于当前无风险。
- 整笔风险
  - 计入已实现不利结果、余仓、可能成交的扩仓订单及成本。
  - 分层按各层入场价至共同止损分别核算。
- 加仓
  - 新增部分有新的正面事实，并独立合算。
  - 首笔前确定各层条件、位置、数量及取消条件；每次新增仍须重新检查，整笔计划损失不超过原预算。
- 账户限制
  - 总开放风险、日内损失、保证金、杠杆、清算缓冲及集中度。
  - 本系统采用单向持仓。

### 概率与收益的算术

仅考虑盈利与亏损两种结果，`p` 为获利概率、`G` 为毛收益、`L` 为毛损失：毛期望为 `pG−(1−p)L`，毛保本概率为 `L/(G+L)`。

| 假设 | 毛期望 |
| --- | --- |
| 40% 赚 2R，60% 亏 1R | +0.2R |
| 60% 赚 1R，40% 亏 1R | +0.2R |
| 80% 赚 1，20% 亏 3 | +0.2 |

这是算术，不是对实际胜率的估计。还须扣除成本；分段退出、小盈小亏等多种结果按各自概率和净结果核算。来源：[30A](../reference/course/30A.md)、[30C](../reference/course/30C.md)。

## 持仓、等待与更新

- 正常回调：参与依据与承担条件仍适用时，按有效计划持有；仍核对当前价格、成本及剩余时间的变化。
- 新事实出现：先更新市场判断，再按本笔前提比较持有、调整或退出的剩余回报、风险和时间。
- 减仓：明确目标余仓及后续保护；减仓、平仓或止损进入执行时，终止旧扩仓授权。退出后不自动补仓。
- 目标延伸：需要新依据，保留原目标记录。
- 走势预期失效或到期：重评持有依据，没有及时成立的替代依据则退出。
- 入场、退出或目标完成后：继续市场判断；重新参与按当前事实和可执行价格评价。
- 空仓等待：明确等待的价格、表现和复查时间。
- 没有实质变化：沿用原计划；订单、账户和安全期限到达时仍按规则处理。

## 执行与核对

- 启用产品前核实数量与价格步长、点值、成本、报价侧、触发和成交规则，以及账户限制和平台保护能力。
- 提交、接受、触发和成交分别核对；图表触价不保证成交，撤单请求不等于撤单完成。
- 每次成交或订单变化后，核对实际余仓、仍可能成交的订单和足量有效的止损；部分退出按目标余仓落实。
- 仓位、订单或保护不清时停止新增风险，按 [Account](account.md#四平台记录不清时)查询与保护；账户超限、止损执行或安全期限到达时先完成必要减险。
- 必要市场数据缺失时撤销扩仓授权，保留有效保护；仅在事前数据可靠性期限内、确认可安全等待时持有，到期仍未恢复则按既定规则退出。
- 实际仓位为零且相关订单均不再可能成交，才确认本笔结束。有效管理和查询持续到执行风险解除。

## 后续检验与方法修正

- 只用当时可得的事实；未完成形态、未观察的低周期过程保留不确定性，对手盘动机标为推断。高周期 EMA 使用该高周期数据，低周期近似不能当作同一值。
- 当前预期随新事实更新；已纳入评价的原预测按原目标、失效和期限检验，不以后来修改覆盖原结果。
- 分开评价市场判断、交易方案、实际执行和账户结果：判断正确不保证交易合算，交易盈利也不单独证明判断或方法正确。
- 保留当时依据、授权变化、实际成交与成本，用连续结果比较参与质量、管理选择和成本后表现；不以单笔盈亏或调整少倒推质量。
- 来源中的固定次数、比例和概率不自动成为运行规则。面对知识分歧，明确采用理由及什么证据会改变取舍。
- 按 [Practice](../practice/README.md)逐步回放与检验，按 [Governance](governance.md)调整方法；文档覆盖不等于已验证交易优势。
