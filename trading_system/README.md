# 交易系统

先判断市场与机会，再决定参与或等待；新事实到来后更新。

## 市场理解主线

```text
定位 → 比较双方进展 → 形成预期 → 找机会 → 决定 → 等待新事实
```

从当前任务进入，跨页沿用已有判断：

- **首次看图或需要重建判断** → 使用 [Market 运行卡](market.md#二运行卡)。
- **已有可靠判断，新事实到来** → 使用 [Market 普通更新](market.md#42-普通更新)；预期落空、参照改变或分歧影响动作时，展开对应比较。
- **已经有机会想法** → 可先到 [Trade 比较候选](trade.md#三构造与比较)；需要评价可达空间时，补充 [条件路径](market.md#37-条件路径与目标)。完整路径与方案是实际授权的要求。

## 盘中决策入口

六问用于查漏，已明确的内容沿用；日常从上方入口继续，处理顺序按[核心闭环](#核心闭环)。启用账户或产品前完成[低频平台检查](account.md#五低频平台检查)，设定风险限制。

| 当前问题 | 决定所需内容 |
| --- | --- |
| **1. 在哪里** | 可靠数据、品种与周期；当前运动、区域及其在较大结构中的作用。 |
| **2. 应该怎样** | 后续预期、正常回调或停顿、主要反证、复查时点。 |
| **3. 实际怎样** | 对照原预期：推进、保留、恢复与对手回应改变了什么；未确认部分继续观察。 |
| **4. 可以去哪里** | 条件、目标、实质障碍、完成、失效与期限；只展开会改变选择的路径。 |
| **5. 是否值得参与** | 用当前可执行价、保护、出场、数量、成本与剩余时间，比较参与和等待，或持有和调整；加仓单独检查新增风险的补偿。 |
| **6. 仓位怎样处理** | 当前动作、目标余仓和订单；账户检查；实际成交、余单与止损；下一复查。 |

## 核心闭环

```text
核对可见事实、实际仓位与订单 → 先完成必须履行的执行与减险
→ 更新市场判断 ↔ 比较参与和管理 → 决定并执行、核对结果
→ 明确下一观察、查询或期限 → 结束本轮，等待新事实
```

仓位、订单或保护不清 → 停止新增风险，按 [Account](account.md#四平台记录不清时)查询与保护。账户超限或安全事件 → 立即减险，不等市场重判。

以下是事件导航。同轮发生的事件分别处理；先处理必须履行的执行与减险，再接续受影响的市场判断和方案。

| 发生什么变化 | 从哪里继续 |
| --- | --- |
| 新完成 K 或允许的盘中事件 | 对照原预期，更新受影响的判断、路径与动作 |
| 价格、成本或剩余时间改变 | 重算当前交换；可达性或失效也改变时更新路径 |
| 订单、成交或保护变化 | 立即核对真实状态；必要时重算方案，未知或安全事件按 Account 处理 |
| 建仓或加仓订单有效期到达 | 结束相应扩仓授权、撤销未成交余量并核对；撤单确认前仍按可能成交处理，原市场路径可以继续观察 |
| 观察或市场路径期限到达 | 按原条件判断截至期限的表现，按本次评价范围留痕；采用中的路径到期时重评持仓依据，没有及时成立的替代依据就退出 |
| 普通出场或交易期限到达 | 执行当前有效的出场规则；有新完整方案时，只按 [Trade 方案更新](trade.md#53-方案更新与尚未成交的退出)处理未成交余仓 |
| 安全期限到达、账户超限或保护性止损进入执行 | 先终止旧扩仓并完成必要减险；随后行情或数据恢复也不取消已触发的安全动作 |
| 背景、重要结构、周期或数据基础改变 | 重建判断，保留先前记录 |

按当前仓位接续管理：

- **空仓且无未决订单** → 缺少机会时保留缺项与复查条件；可等区域互动、新数据或既定时点。
- **持仓** → 原方案适用且无实质变化，沿用管理；未成交或部分成交按实际仓位和可能成交的余单处理。

准备实际授权时，按顺序处理：

1. 补齐 [Trade 运行卡](trade.md#二运行卡)，明确采用的参与条件。
2. 按所选条件决定本次去向：
   - 所需事实已完成 → 按当前价格评价提交。
   - 仍依赖未来条件，平台能准确实施 → 可按完整方案评价预挂。
   - 仍依赖未来条件，平台不能准确实施 → 等待事实；普通触价单不替代收盘、跟随或回试确认。
3. 所有准备提交或预挂的方案，均须通过 Account 检查。等待后按届时价格、成本与剩余时间重算，再检查相应授权。

结束时分别核对：

- **结束本次分析** → 动作明确、操作已落实或可安全等待核对、下一观察已确定，三项均满足；有效订单、保护和查询继续运行。
- **结束本笔交易** → 仓位为零且相关订单均不再可能成交；同品种下一笔先清理旧执行风险。

日常留痕按[最小记录](../practice/README.md#五最小记录)，当前依据、观察条件和有效方案保持可用；实际授权与执行记录按 Account 保留。完整教学过程见[连续示例](examples.md)。

## 方法定位

- **证据**：按当时可见事实判断，预期在结果前确定；动机解释保留为推断，已记录的预测、授权和成交不回写。当前路径及时核对，弃用路径按 Practice 的评价范围处理。
- **交易约束**：执行与保护按 [Account](account.md)；固定目标、单向持仓、共同且不放宽止损、原预算不重置与净回报筛选按 [Trade](trade.md)。方法取舍见[复盘与治理](governance.md#九当前回放重点)。

| 页面 | 负责内容 | 何时查阅 |
| --- | --- | --- |
| [Market](market.md) | 背景、位置、正常与异常表现、双方进展和条件路径；附录保留必要定义 | 建立或更新市场依据时 |
| [场景导航](scenarios.md) | 六类常见问题的适用背景、竞争解释和区分事实 | 不清楚该预期什么或看哪些位置时，按问题查阅 |

| [Account](account.md) | 账户限制、授权执行、真实订单、成交、仓位和止损 | 授权或平台记录改变，或查询与安全期限到达时 |
| [复盘与治理](governance.md) | 分别评价四类结果、连续交易过程及方法变更证据 | 盘后及研究时 |
| [连续事件用例](examples.md) | 检查事实怎样改变动作及实际执行交接 | 学习和验证规则时 |

专项学习、连续练习、正式检验与实盘安排见[训练与实盘运行](../practice/README.md)。选样、重放和留痕按目的确定；已知案例不替代未知检验，执行合规不替代加量所需的经济证据。

[Reference](../reference/README.md) 保存思想来源、证据、解释分歧与核验状态；运行规则由本系统独立表达。当前方法使用定性判断，没有已校准的生产胜率；文档闭环和用例通过不证明盈利能力。
