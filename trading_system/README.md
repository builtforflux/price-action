# 交易系统

这是一套盘中使用的价格行为交易方法。核心任务只有两个：

- 判断市场正在怎样组织价格；
- 只在完整且值得表达的市场路径中寻找交易机会。

系统可以独立于 `reference/` 运行，从市场观察一直走到风险关闭和复盘。它不保证市场一定提供交易，也不承诺固定胜率或盈利；条件不足时，等待或不交易就是完整结果。

## 唯一主链

```text
观察边界
→ 市场组织、结构与位置
→ 当前尝试
→ 合理预期与实际表现
→ 双向路径、区域职责与当前完成目标
→ 选择候选
→ 交易表达与质量判断
→ Account 最终闸门
→ 订单、成交、仓位与保护
→ 新事实更新
→ 风险关闭
→ 复盘
```

前六步是日常重心。场景只在不知道怎样组织双向路径时查询；Account 只在提交动作、Broker 事件、期限或风险关闭时展开。

## 每次需要回答什么

### 一、市场背景

- 当前是单边控制、双边平衡、转换中还是不清楚；
- 控制方向是什么；
- 当前处于启动、发展、成熟、受损或决断阶段。

### 二、位置与空间

- 当前位于什么有意义区域；
- 上下有哪些会实质改变可达性的活动区域；
- 是否有足够价格空间和时间。

### 三、当前尝试

- 哪一侧正在尝试什么；
- 正在测试什么位置或边界；
- 若尝试方有控制，接下来应怎样表现；
- 实际表现符合、弱于还是否定预期；
- 测试是接受、失败还是未决。

### 四、双向路径

向上和向下各自只能得到一种结果：

- **路径完整**：唯一当前完成目标、参与条件、失效、期限、空间和主要反证都明确，到达前关键区域已归为障碍或检查点；
- **等待形成**：真实测试存在，下一事实和最晚等待时间明确；
- **当前排除**：缺少目标、空间、时间或形成条件。

方向机会就是市场路径，不建立 Opportunity 对象、编号或平行生命周期。

### 五、交易表达

只有路径完整时才展开：

- 入场依据、参与方式、价格和期限；
- 市场失效、共同计划保护和 Broker 有效保护；
- 每段退出引用的 Market 完成目标、检查点、障碍、失效或期限；
- 每段退出的授权条件、执行规则和 Broker 成交完成条件；
- 共同保护、首段回退和完整计划三个按数量计算的净结果，以及空间和时间；
- 定性质量：较有利、接近平衡或不值得；
- 风险金额、数量和当前管理动作。

Market 路径完整不等于具体交易一定值得。只有具体表达为“较有利”且 Account 允许时，才选择交易。

### 六、薄 Account 闸门

正常只显示：

- 新增风险允许或禁止；
- 实际仓位和仍可能成交的订单；
- Broker 有效保护是否覆盖全部仓位；
- 是否取消新增风险；
- 唯一主要风险动作。

普通新 K 不唤醒 Account。详细订单竞态、迟到成交、断线和对账规则只在异常或关闭时展开。

## 三种运行状态

### 空仓寻找机会

```text
建立市场背景、位置和当前尝试
→ 比较预期与实际表现
→ 形成双向路径
→ 选择至多一条完整候选
→ 构造入场、保护、退出和交易质量
→ 交易 / 等待 / 放弃
→ 交易时通过 Account 最终闸门
```

分支：

- 只有一边完整：评估该方向；
- 两边都完整：先比较两份最小表达，只选择一边；
- 没有完整路径但下一事实明确：等待；
- 两边都被排除，或无法得到唯一选择且没有下一事件：放弃；
- Account 禁止新增风险：仍可继续观察，但不提交订单。

### 已有订单或仓位

每次新 K 只更新：

1. 本次新事实；
2. 合理预期与实际表现；
3. 所选路径变化；
4. 当前唯一动作。

默认映射：

| Market 变化 | Trade 默认动作 |
| --- | --- |
| 增强 | 继续原方案；增强本身不授权加仓 |
| 未变 | 维持订单或仓位，不重填 |
| 削弱但仍有效 | 取消新增风险；已有仓位按事前规则持有、减仓或退出 |
| 失效 | 取消新增风险并主动退出，不等待更远保护 |
| 实现 | 取消新增风险并执行完整退出计划 |
| 到期 | 取消新增风险并退出全部余仓 |
| 替代 | 关闭原路径交易，风险关闭后再判断新路径 |
| 数据不可用或无法归类 | 取消新增风险、保持保护；期限内不能恢复则退出 |

加仓必须有独立完成事实、共同保护、完整退出、风险预留和新的 Account 授权。价格更便宜、仍未触及保护或还有风险预算都不构成加仓理由。

### 账户异常

出现订单、成交、仓位、保护、资金或连接事实未知或冲突时：

1. 取消新增风险；
2. 查询 Broker 权威事实；
3. 只选择一个主要动作：等待确认、恢复保护、减到安全数量或全部退出；
4. 直到实际仓位、残余订单和保护重新可靠。

Account 可以否决或减少风险，不能创造交易、放宽保护或延长期限。

## 三类唤醒事件

### 市场事件

完成 K 是普通唤醒。只有事先允许的未完成价格事件可以例外。数据恢复、缺口确认和来源修订从最早受影响处重判。

### Broker 事件

订单接受、触发、成交、部分成交、拒绝、撤单确认、更正、仓位、保护和资金变化立即处理，不等待 K 收盘。

### 期限事件

等待、入场订单、出场段、整笔方案、数据可靠性和 Broker 可靠时限到达时，立即执行事前动作，不等下一根 K。

多个事件同时发生时，先按 Broker 权威事实重建风险，再处理到期动作，最后更新市场判断。任何时候保护或账户事实不可靠，都先执行安全覆盖。

## 共同事实与必要区别

H2、Double Bottom、Bull Flag、Wedge 或 MTR 可以共享同一组价格事实。共享事实只登记一次；名称不重复增加证据、概率或风险预算。

但以下职责不能合并：

- 位置说明在哪里以及还有多少空间；
- 结构视图说明几何、次序、阶段和重置；
- 测试说明市场正在验证什么；
- 预期与实际表现说明控制是否兑现；
- 区域职责说明某价格带对当前路径是障碍、检查点、完成目标还是失效边界；
- 市场路径说明某方向当前唯一要完成什么；
- 入场说明怎样参与；
- 市场失效说明观点何时被否定；
- 计划保护说明交易怎样限制尾部风险；
- Broker 有效保护说明账户实际上受到什么保护。

第二段陷阱属于“预期路径失败”：先建立合理第二段预期，第二段实际出现，但在限制延续的位置没有获得应有跟进，随后旧区域或竞争方向重新获得接受。它不是独立场景，也不能在失败确认前事后命名。

## 更新负担边界

### 首次完整展开

- 首次判断或观察边界重建；
- 主测试、市场组织或路径被替代；
- 首次构造交易；
- 提交新增风险；
- Account 异常或风险关闭。

### 普通空仓新 K

- 本次新事实；
- 预期与实际；
- 双向路径变化；
- 下一观察。

### 普通持仓新 K

在上述基础上只增加当前唯一动作。没有变化就结束本轮。不复制 OHLC、订单号、成交号、仓位汇总、费用或版本标识。

## 不能混淆的边界

- 形态名称不等于方向路径；
- 路径完整不等于交易许可；
- Market 路径完整不等于具体交易质量；
- 市场失效不等于计划保护；
- 计划保护不等于 Broker 有效保护；
- 图表触价不等于订单触发或成交；
- Trade 授权退出不等于 Broker 已退出；
- 只有实际成交改变仓位；
- 仓位为零不等于风险关闭；
- 风险关闭不等于财务对账完成；
- 单笔盈亏不能单独证明市场判断或方法正确。

风险关闭要求实际仓位为零、所有仍可能成交或状态未知的相关订单确认终止，并且没有未处理迟到成交。之后再完成费用、现金和账户结果核对。

## Reference 边界

运行所需的定义、条件、例外、失败、重置和安全动作都必须存在于 `trading_system/`。

`reference/` 只保存来源、历史数字、翻译、冲突和研究证据。它可以支持离线校准、审计和方法修改，不能成为盘中临时拼装规则的依赖。
