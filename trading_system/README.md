# 交易系统

在不确定的市场中，识别并参与一段值得持有、能够承担的运动；容纳其正常变化，在参与依据或承担条件发生实质变化时行动，并用连续结果修正方法。成本后正期望是经济评价标准。

系统的判断与行动规则由本页及 Market、场景、Trade、Account、Governance 完整定义。沿本页核心闭环进入负责页，完成市场判断、参与构造、管理、执行与复盘。开始练习时，按 [Practice](../practice/README.md#三历史回放)在 TradingView 随机选历史起点，逐步向前模拟完整交易。

## 判断与行动的主线

**当前在哪里，双方做成了什么？哪段运动值得研究，怎样参与才合算？准备承担什么，什么变化需要行动？连续结果支持保留哪些理解与做法？**

理解市场时，结合状态、位置和尺度，比较双方推进、保住进展和回调后恢复的能力，形成有区分条件的预期。形态、计数与测量为这些比较提供具体依据，按当前问题调用；双向思考无需每轮构造多空两套完整方案。

知识沿着“可见事实 → 比较关系 → 条件预期 → 参与选择 → 后续检验”连接。共同关系帮助理解，位置、尺度、次序和例外决定适用边界；推进、保留与恢复是组织观察的框架，不是已经证明的统一市场因果机制。具体用法见 [Market](market.md#31-事实关系与判断)。

参与前，先让市场预期、入场价格、保护、数量和允许的正常波动相互匹配，说明[发生可能性与收益损失的组合](trade.md#37-判断是否值得)为何有利。后续管理以此为参照；参与质量按当时依据评价，不能用后来盈利或调整少倒推。

优先改善参与质量，是本方法的取舍；是否因此减少无必要调整、改善成本后表现，仍须与既定管理基准比较。理解深入、操作少和收益好分别评价，不用其中一项代替其他项。

新事实可能只补充当前认识，也可能增强、削弱或否定某项预期。预期变化后，Trade 再结合本笔前提、允许的正常不利表现、当前价格与风险收益决定动作。原方案仍适用且无实质变化时，持有或等待就是本轮决定，继续有效管理与下一观察。订单、账户限制和安全期限按各自事件及时处理。

### 必要要求与可选方式

| 内容 | 使用方式 |
| --- | --- |
| 市场判断、机会或等待条件、下一观察 | 每轮明确当前结论，沿用可靠依据，只更新受影响部分 |
| 完整条件路径、交易方案、账户检查与实际保护 | 实际授权及持仓管理按相应规则落实；记录按本次练习、检验与执行范围保留 |
| 场景、术语、补充周期与候选路径 | 取用能帮助解释当前问题或改变选择的内容，无需逐项遍历 |
| 入场方式、分批、加仓、目标延伸与退出重入 | 按所选方案使用；涉及相应操作时才展开其条件、数量与执行细节 |

可以采用有限的机会范围、固定参与方式和简单管理基准，具体见 [Practice](../practice/README.md#1-低频准备)。增加一种参与或管理选择时，说明它相对等待或原方案改善什么、付出什么；是否值得反复采用，按[复盘与治理](governance.md#连续过程与经济表现)比较成本后表现、回撤与负担。

## 核心闭环

启用账户或产品前完成[平台检查](account.md#五低频平台检查)，设定风险限制。每次分析先确认品种、图表周期、数据可靠性和实际仓位、订单。

仓位、订单或保护不清 → 停止新增风险，按 [Account](account.md#四平台记录不清时)查询与保护。账户超限、保护性止损进入执行或安全期限到达 → 先完成必要减险，再接续市场判断。

| 检查点 | 要能说明什么 |
| --- | --- |
| **1. 市场判断** | 识别市场状态、重要位置、尺度和当前运动，比较双方尝试及成果；已有预期时，对照新事实更新。 |
| **2. 预期与机会** | 期待什么后续，允许怎样的回调或停顿，什么事实能区分有依据的竞争解释，什么条件下考虑参与，何时复查。 |
| **3. 交易决策** | 按当前可执行价格、止损、出场、成本和剩余时间，判断可能性与得失的组合是否值得，比较动作并确定仓位。 |
| **4. 执行与核对** | 检查账户限制和平台能力，执行决定，核对实际仓位、未完成订单和止损，明确下次检查的条件或时间。 |

首次建立判断；此后新事实出现，从受影响处接续以上四项。沿用仍有效的背景，对照原预期理解当前运动的变化，明确下一观察。入场、退出或目标完成后，市场判断继续；当前预期可以改变，原预测仍按原条件评价。

没有机会时明确等待条件；实际授权前，须有完整的[条件路径](market.md#37-条件路径与目标)和[交易方案](trade.md#二运行卡)，并通过账户检查。记录按[最小记录](../practice/README.md#五最小记录)，无需重复填写四项；授权和执行轨迹按 [Account](account.md#六最小执行记录)保留。

### 按当前情况查阅

| 当前情况 | 从哪里继续 |
| --- | --- |
| 首次看图或需要重建判断 | [Market 运行卡](market.md#二运行卡)；观察范围或数据基础改变时按[完整重判](market.md#43-完整重判)处理 |
| 新完成 K、允许的盘中事件或市场观察期限到达 | [Market 普通更新](market.md#42-普通更新)，核对原结果、更新判断与机会 |
| 已有机会，或价格、成本、剩余时间改变 | [Trade 构造与比较](trade.md#三构造与比较)或[重评](trade.md#51-重评顺序) |
| 订单、成交、仓位或保护变化 | [Account 核对实际记录](account.md#三提交与平台记录)，再由 Trade 重评受影响的方案 |
| 订单、出场、路径或安全期限到达 | 按 [Trade 期限规则](trade.md#35-出场目标与期限)处理；安全动作优先 |
| 账户超限或平台记录不清 | [Account 硬限制](account.md#二账户硬限制)与[未知状态处理](account.md#四平台记录不清时) |

同轮发生多个事件时分别处理。空仓时可以等待；持仓或存在未决订单时，继续按有效方案管理与核对。无实质变化则沿用原安排。

参与条件已满足，或平台能够准确实施所选未来条件，才可按完整方案评价提交或预挂；否则等待事实。等待后按届时价格、成本与剩余时间重算。普通触价单不能代替收盘、跟随或回试确认，详见 [Trade](trade.md#32-确认程度与订单条件)。

结束本次分析前，须明确动作、落实操作或确认可安全等待查询，并确定下一观察。有效订单、止损和查询继续运行。

实际仓位为零且相关订单均不再可能成交，才由 Account 确认[本笔交易结束](account.md#本笔交易结束)；同品种下一笔先清理旧执行风险。盘后按[复盘规则](governance.md#一复盘时分开四个结果)评价市场、交易、账户与执行结果。

## 方法定位

本系统用于市场判断、机会评价和连续交易管理；最终检验是在可承受风险内能否持续产生扣除成本后的收益。当前使用定性判断，没有已校准的生产胜率；文档完整或执行合规均不证明盈利能力。

- **事实与记录**：只用当时可见信息，动机解释标为推断。当前判断可更新，原预测、授权与成交保持可追溯；路径后续评价按 [Practice](../practice/README.md#路径后续评价范围)处理。
- **方法约束**：条件路径固定目标、失效与期限；单向持仓、全仓共同且不放宽止损、原预算不重置、净回报筛选按 [Trade](trade.md)执行。方法调整按[复盘与治理](governance.md#三方法变更)验证。
- **表达原则**：共用规则只完整定义一次；场景保留会改变判断的背景、位置、尺度和事件次序，优先用具体价格表现说明。

[核心知识与选择速查](core_summary.md)归纳主线、知识和选择条件；具体运行与计算按下列负责页查阅。
