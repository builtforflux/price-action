# 市场模型与机会

> **Owner：市场读取与双向机会**

本页只回答三个问题：价格在哪里，怎样到达，接下来哪些市场结果仍然现实。它不决定是否承担账户风险，也不把图表触发、订单、成交或盈亏写回市场判断。

市场层只有一条更新链：

```text
价格事实 + 观察边界
→ 位置与空间
→ 到达路径与当前测试
→ 响应、分离、压力与控制
→ 当前市场结构
→ 双向机会
```

这里的箭头表示因果顺序，不表示每一步都要单独填表。普通盘中更新只追踪发生变化、并会改变后续结论的最早一环。

## 一、共同原则

市场知识不能因为名称相似而合并，也不能因为名称不同而重复计数。第二次向上恢复可以同时具有以下视图：

| 视图（可同时成立） | 唯一职责 |
| --- | --- |
| H2 | 保存尝试次序和 Trigger |
| Double Bottom | 保存测试区域、Neckline 与投射 |
| Bull Flag 或 MTR component | 保存外层作用 |

这些视图共享底层事实，名称增加不等于证据增加。详细边界见[形状重合](#43-一个事实可以同时满足多个形状)与 [H/L 次序](#44-hl-次序与触发)。

## 二、输入：市场事实与边界

### 2.1 市场事实

底层市场事实只保留判断和复核真正需要的内容：

```text
来源与 instrument
timeframe 与 K 线构造
市场实际发生时间
当时最早可见时间；只有延迟、修订或回看偏差相关时单独记录
原始 OHLC，以及来源直接提供的 trade / volume 等市场数据
修订关系；只有来源更正时保留原值与新值
```

市场发生时间与当时可见时间必须能够区分，防止把事后信息用于当时判断。来源修订不能静默覆盖原判断依据。

市场事实只保存观察，不保存压力、控制、接受、形状、信号或机会等派生结论，也不混入：

- 本账户的 Order、Fill、Position 或 P&L；
- 由观察边界解释的 session、timezone、日程、流动性和可用性；
- 产品报价单位、tick、pip、保证金、rollover 或平台规则。

Volume、DOM、新闻、NYSE TICK 等可作为背景或尾部风险输入，但不能独立保证方向。它们只有通过价格的突破、跟随、回调、接受或失败，才能改变市场路径。

### 2.2 K 线与运动事实

设本根最高、最低、开盘、收盘为 `H`、`L`、`O`、`C`：

```text
总范围   = H - L
实体     = abs(C - O)
实体占比 = abs(C - O) / (H - L)
收盘位置 = (C - L) / (H - L)
上影占比 = [H - max(O, C)] / (H - L)
下影占比 = [min(O, C) - L] / (H - L)
```

`H = L` 时按零波幅 K 线处理，不计算比例。实体、影线、收盘和范围都必须相对附近 K 线及所在位置解释；Trend bar 与 trading-range bar 是连续谱，单根 K 线不建立趋势。

局部几何只描述事实：

- Inside bar：`high ≤ 前高` 且 `low ≥ 前低`；一端相等仍成立。
- Outside bar：`high ≥ 前高` 且 `low ≤ 前低`，并至少一端严格越过；把两端相等也计入的来源口径只留在 Reference。
- Doji：实体相对周围很小或为零。
- Shaved：实体一端与极值严格相等；若采用一跳容差必须另行声明。
- Reversal bar：相对当前 leg 承担反向趋势或拒绝作用；必须结合位置、方向、相对大小、收盘和后续反应。
- Two-bar / multi-bar reversal：多根共同形成反向压力，不能被单一吞没几何替代。

错误位置上的漂亮反转 K 线不能修复目标和空间；强趋势中的普通顺势 K 线也可能属于更可靠的路径。

运动术语只保留各自职责：

- Push / Leg：较大结构中的一段方向运动，不自动成为独立 Trend。
- Pullback：当前方向运动中的暂停或暂时反向运动；反方获得接受并改变外层结构后，不再只是原趋势回调。
- Pause：停止扩展方向极值或横向停顿。
- Actual pullback：当前周期已有反向高低点运动。
- Implied pullback：当前周期只是停顿，较低周期可能已经展开成实际回调。

“通常再尝试第二段”是条件倾向，不是保证。第二段可能很短、横向、未创新极值或快速失败，也不等于 `Leg 1 = Leg 2`、second signal、second entry 或第二次成交。

## 三、位置与空间

位置是市场判断的第一坐标。任何形状、信号或压力都必须回答：它发生在哪里，前方有什么，正常失效在哪里，当前时间内还有多少现实空间。

### 3.1 区域只登记一次

位置地图可以包含：

- 前高低、swing high / low、已形成的日周月 OHLC；
- 区间边界、中部、上下三分之一区域和内部公平区域；
- 端点已固定的当前段半程或其他事先定义的比例参照；
- 突破点、旧结构起点、可见入场区域；
- 趋势线、通道线、EMA、大整数位；
- gap 边界和端点已经固定的 measured-move 区域。

这些对象都是区域，不是保证反转或突破的精确屏障。Support 在当前价格下方，Resistance 在上方；穿越后可以交换角色。

同一价格带只登记一次，并保存来源、距离和汇合关系：

```text
位置地图
├─ 当前互动区域
├─ 上方相关区域：来源、距离、汇合
├─ 下方相关区域：来源、距离、汇合
└─ 向上 / 向下最近障碍、现实目标与可用空间
```

同一区域可以同时服务多条机会，并承担潜在入场区、支撑、阻力、障碍、磁点、目标或失效参照等不同作用。作用属于具体机会，价格带只在位置地图登记一次。

### 3.2 常用位置怎样构造

A. 直接可得的价格参照

前高低、Swing、OHLC、整数位、突破点和 Gap 端点直接绑定来源周期、价格和时间。EMA 由既定周期和参数从价格事实计算，并绑定周期、参数和当前值。不同周期的同价区域可以汇合，但仍只登记一次。

B. 区间与比例位置

区间上下沿取当前反复组织价格的两个边界区域，不因一次影线或轻微越界立即改写。设下沿为 `L`、上沿为 `U`、高度 `H = U - L`：

```text
区间中部 = L + H / 2
底部三分之一区域 = L 到 L + H / 3
顶部三分之一区域 = U - H / 3 到 U
```

当前段从 `A` 到 `B` 的半程为 `A + (B - A) / 2`。比例位置按以下边界使用：

- 绑定明确的段和周期；
- 同一进行中的段创新极值时，当前地图随端点更新；
- 已经引用该位置的交易计划保留当时快照；变化影响空间、目标或保护时重新判断；
- `50%` 或三分之一本身不产生反转、目标或入场。

C. 趋势线与通道线

多头趋势线连接两个相关的向上反转低点，空头趋势线连接两个相关的向下反转高点。优先选择强段起点、强反转或其他显著拐点，不用大量小波动线填满图表。

第二条边界可以从已有趋势线复制平行线并移到另一侧显著极值，也可以在另一侧已有两个相关反转点时直接连接。平行线只是初始候选；实际反应可以支持平行、收敛或扩张通道。

候选线按价格的实际反应更新：

| 条件 | 更新 |
| --- | --- |
| 价格持续对候选线产生反应 | 保留当前职责 |
| 出现新的主要极值、反转点或失败突破 | 建立重画候选；是否采用由后续实际反应决定 |
| 只有轻微 overshoot / undershoot，没有强跟随 | 不自动使原线失效 |
| 强越界并获得跟随，或价格长期不再响应 | 原线失去当前通道边界职责；仍承担突破回试区域时只更新职责，否则休眠或删除 |

多条线只在周期、尺度或当前职责不同时并存，不按线的数量增加证据。

D. 结构投射

只有来源结构和端点已经可见并固定时，才把 measured move 登记为候选位置。具体公式、近端障碍和目标选择由[目标](#八目标)统一负责。

上述构造只提供位置候选。价格到达后的拒绝、突破、跟随、接受或失败，才决定它怎样进入当前测试与双向机会。

### 3.3 区域进入当前地图的条件

以下任一满足，区域才保持活跃：

- 价格正在接近、触及、穿越或离开它；
- 它是当前周期和观察边界内的现实目标或障碍；
- 它会改变当前测试、机会失效、现实目标或可用空间；
- 它是当前市场结构必须保留的外层约束。

其他历史区域休眠，接近或获得新职责时再激活。

多个相对独立的来源在相近价格和时间汇合，可以增强该区域的 magnet 或反应意义。以下情况仍只是一份位置证据：

- 同一组 swing 推导出的多条线；
- 旧高、区间上沿和 Double Top 只是同一价格带的不同名称；
- 同一结构用不同公式得到相近投射。

汇合不直接生成 Entry，也不替代真实的 rejection、breakout、follow-through、空间和概率。

## 四、怎样到达，以及正在测试什么

位置确定后，先读价格怎样到达，再读它正在解决什么问题。

### 4.1 怎样到达

位置确定后，按下面的顺序描述当前运动：

```text
从哪里开始？
现在是上行、下行、暂停还是局部平衡？
它在外层结构中是延续、回调、区间段还是反转尝试？
实体、收盘、影线和相对大小怎样？
同向连续性与跟随怎样？
分离、缺口、重叠和回调怎样变化？
反方有没有形成高质量响应、跟随或失败尝试？
```

当前运动方向和它在外层结构中的作用必须分开。同一段下行在多头状态中可能是回调，在交易区间中可能只是向下的一段。暂停表示尚未形成清楚方向段；局部平衡表示小区间已经比单段更能组织价格。

### 4.2 正在解决什么

通常只聚焦一个真正驱动下一步的主测试。另一项测试只有同时满足以下条件才并行保留：

- 周期或对象不同；
- 有独立的目标与接受 / 失败条件；
- 有自己的期限；
- 会改变下游判断。

共用同一事实和结果条件的形状不另建测试。每项保留的测试分别回答：

```text
正在测试哪个区域、边界或旧控制？
当前运动试图完成什么？
已经进行到接近、触及、反应、突破尝试还是跟随？
同一对象已经完成第几次尝试？
出现了分离、拒绝、突破、重叠还是重新进入？
怎样才算接受，怎样才算失败？
下一项会推进判断的事实是什么？
这个问题最迟何时仍有意义？
```

进行阶段和测试结果不是同一件事。典型先后关系是：

```text
接近
→ 触及或短暂越过
→ 反应或突破尝试
→ 有跟随或无跟随
→ 判断目标被接受、失败或仍未决
```

结果互斥：

- 接受：边界外收盘、跟随、保持在外或回踩守住等事实支持新价格。
- 失败：原目标路径未获接受，并被重新进入旧区域或其他事实实质否定。
- 未决：对象与双向结果条件已明确，但任一终局尚未发生。

测试过程中的证据按因果顺序更新：

- 没有立即 follow-through 会削弱原路径，但尚未确认失败；
- 只有普通回调也不自动确认失败；
- 原目标路径未获接受，并且旧区域重新获得接受或其他事实实质否定该路径，才确认 breakout failure；
- breakout failure 之后，若反向尝试也失败、原突破方向再次获得接受，则形成 failed failure / breakout-pullback 路径。

测试期限是问题边界，不是第四种结果。测试到期、解决或被替代后：

| 剩余内容 | 交接 |
| --- | --- |
| 有新的现实问题 | 建立新测试 |
| 没有新测试，但有明确下一事实 | 交给决策判断是否 `WAIT` |
| 两者都没有 | 形成 `STAND_DOWN` 条件 |

### 4.3 一个事实可以同时满足多个形状

形状是对事实关系的压缩视图，不拥有独立的 `detected → setup → trade` 流程。它只能把结果写入共同链路：

```text
结构锚点与固定投射 → 位置地图
当前互动、次序与响应 → 当前测试
外层价格组织 → 当前市场结构
目标、激活与失效 → 双向机会
是否采用信号、触发或区域 → 交易表达
```

以下视图可以重叠，但各自只保留不可替代的职责：

- ii / iii：连续 inside bars，描述压缩。
- ioi：inside–outside–inside。
- oo：连续 outside bars，描述双边扩张。
- Triangle：成熟双边测试与压缩；Expanding Triangle 逐步扩张两侧极值。
- Double Bottom / Top：保存重复测试区域、Neckline 和可能的高度投射。
- Wedge：保存三次可区分推动或测试、倾斜、推进质量及外层 Flag / Climax 作用。
- Flag：说明局部 pullback、channel 或 balance 在外层 continuation / reversal 中的功能。
- Final Flag、measuring gap、exhaustion gap、confirmed climax：都包含事后结果；实时只能保存候选和所需确认。

它们共同回到一条结果链：

```text
平衡或推进
→ 实际突破或边界反应
→ 有跟随或无跟随
→ 守住外部区域或重新进入原结构
```

Triangle、H/L、Flag、Broad Channel 等来自同一运动时，不能按名称增加概率。

### 4.4 H/L 次序与触发

H/L 编号记录同一周期、Object 与恢复逻辑中的已完成 Trigger 次序，不是 K 线几何，也不是尚未越界时已经完成的交易：

```text
牛向恢复
第一次向上 Trigger 完成 → H1
回调继续，完成 K 线定义第二次向上边界 → H2 recovery setup / Signal Bar
价格越过该高点 → H2 Trigger；越界 K 线是 Chart Entry Bar

熊向恢复
第一次向下 Trigger 完成 → L1
反弹继续，完成 K 线定义第二次向下边界 → L2 recovery setup / Signal Bar
价格跌破该低点 → L2 Trigger；越界 K 线是 Chart Entry Bar
```

Signal Bar 只定义潜在触发边界；Opportunity 判断路径是否现实，Trade Expression 决定是否采用，实际账户记录确认是否成交。Market / close entry 时，同一根 K 线可同时承担 Signal Bar 与 Chart Entry Bar。

H/L 的重合、成立与重置分别处理：

- 重合：H2 与 Double Bottom、L2 与 Double Top、H3/L3 与 Wedge 可以共用事实；
- 成立：严格 second entry 要求第一次 chart entry opportunity 已经触发；
- 时点：Double Test 可以在 Trigger 前形成，不能反向证明 H/L Trigger 已经发生；
- 高阶计数：出现 H4/L4 及更高编号时先重读 Context，不把 Triangle、Trading Range 或 endless pullback 机械延续为同一恢复序列；
- 绑定与重置：计数始终绑定周期、Object 与重置点。

### 4.5 Minor reversal 与 MTR

第一次逆势尝试优先解释为 minor reversal、修正或 Trading Range 路径。升级为更大反转需要先后满足：

```text
成熟趋势
→ 主要趋势线或结构被破坏
→ 原趋势测试旧极值
→ 测试失败或形成 HL / LH
→ 反方 Trigger 并尝试建立 swing
→ 强反向 breakout 与 follow-through 确认控制转移
```

- 约五根强反向 K 线或约十根普通 / 较弱 K 线，只是强度与持续时间启发式；
- 一两根足够强的 surprise 也可能更快改变控制；
- Wedge、Double Top/Bottom、Head and Shoulders、rounding structure、Final Flag 或 Climax 只能描述组件，不能替代结构破坏、旧极值测试和反向接受。

旧趋势重新建立控制、新 breakout 获得接受、成熟 Range 切断旧运动、主要结构被替代或观察周期改变时，旧 H/L、段数和反转组件重置。

## 五、响应、分离、压力与控制

### 5.1 只按事实链更新一次

同一次市场更新依次汇总：

```text
新增区域、运动或测试事实
→ Bars 与 Continuity
→ Separation 与 Pullback
→ Opponent Response
→ Bull Pressure 变化 + Bear Pressure 变化
→ Bull / Bear / Balanced / Unclear Control
→ Context 是否保持、过渡或重构
```

一根强突破 K 线产生的大实体、强收盘、gap、Pressure、Control 和 Acceptance 可以改变多个下游结论，但仍是一条事实链。新的二次测试、独立区域反应、后续 follow-through 或反方尝试失败，才可能增加独立事实。

每根新 K 线或新运动先放回当前问题，而不是先按颜色命名强弱：

```text
它发生在哪里，正在推进还是反对哪项测试？
它只是单根响应，还是延续了此前运动？
它扩大、保持还是关闭了分离？
它使哪一侧更容易继续，哪一侧仍无法获利？
```

然后从最早变化处向后传播。测试仍未推进、两侧压力没有实质变化时，Control、Context 和 Opportunity 都保持，不为每根 K 线制造新结论。

### 5.2 分离与缺口

识别分离必须明确比较对象和边界：

- 完整范围 gap；
- body gap；
- micro gap；
- breakout point 与回调之间的开放、negative 或 overlap gap；
- 整根 K 线未触及 EMA 的 moving-average gap bar；
- session opening gap 或单根 open 相对前 close 的 gap。

这些名称不能互换。完整、实体、微型和 EMA 分离若来自同一次运动，只属于一个 Separation 证据组。

更新分离、重叠、压力与控制：

- 分离扩大或保持 + 良好跟随 → 原方向 Pressure / Control 保持或增强。
- 完整 gap 关闭、body gap 仍保持 → 原方向减弱，但突破尚未因此失败。
- 全部分离快速关闭 + 重新进入旧区域 → 延续路径削弱，通道化或区间化增加。
- 关闭后反方获得跟随 → 原突破路径失败或 Context 重构。
- 当前窗口从未存在相关分离 → 不推导“gap 已关闭”的事件。

Moving-average gap bar 有两种职责：整根 K 线位于 EMA 反侧是严格几何；长期未触 EMA 后的首次测试是时间与趋势背景。两者不能互换，也不机械生成 Entry。

### 5.3 压力、控制与 Always In

Bull / Bear Pressure 分别汇总：

- 顺势 K 线、实体和强收盘的连续性；
- 反向影线和失败尝试；
- breakout、gap、follow-through 与是否快速收回；
- pullback 深度、持续时间和恢复速度；
- 反方能否获得 scalp 或持续路径。

两侧 Pressure 分别得到四种判断：

- 增强：新增的实体、收盘、连续性、分离、跟随或反方失败，使该方向更容易继续；
- 保持：普通回调或单根反色响应没有破坏原连续性，该方向仍能恢复；
- 减弱：实体和延伸缩小、重叠或回调增加、突破缺少跟随，原方向仍可能继续但优势下降；
- 尚未建立：只有单根颜色、影线或短暂响应，没有形成独立连续性或让该侧获得现实路径。

它们不是同一轴的两端。一侧减弱不自动等于另一侧建立；同一根 K 线也可以同时削弱一侧、但仍不足以增强另一侧。两侧汇总后再判断 Control：

A. 原方向 Pressure 保持或增强，反方仍未建立

→ 原 Control 保持

B. 原方向 Pressure 减弱，反方已有响应但没有跟随或尚未否定当前测试

→ 原 Control 减弱或进入过渡；不能提前翻转

C. 反方形成连续响应、关闭原分离，并在关键区域获得跟随或使原测试失败

→ 反方 Pressure 建立；旧结构仍能恢复时先进入过渡，反方在新方向获得接受并阻止旧方向恢复时才切换 Control

D. 两侧都能获得延伸，却都无法保持分离或持续控制

→ Balanced Control 或区间化增强

E. 新事实没有改变测试、连续性或任一侧获利能力

→ Pressure 与 Control 保持

Control 只总结当前哪一侧能够持续推动并限制对手，不直接决定订单。控制足够清楚时才支持 Always In；Always In 不要求必须持仓，也不能替代位置、目标、成本和风险判断。

这些分支规定判断边界，不是按 K 线数量打分。同样的大实体在趋势起点、成熟趋势末端、区间边缘或区间中部可能得到不同结论，必须保留位置、当前测试和此前连续性。

单根异常强反转只有在方向、相对强度、重要位置和对旧控制的否定同时清楚时，才可能直接切换 Control；普通反色 K 线不够。

Trapped in、Trapped out、Disappointment 与 Pain Trade 只能作为对已识别的可见入场路径或触发区域、failure、follow-through 和现实空间的行为解释；它们不新增市场事实、证据或概率，也不能证明真实参与者的身份、仓位或盈亏。

## 六、当前市场结构

Context 保存当前交易周期真正支配正常回撤、目标和管理方式的价格组织。它继承上一份有效结果，再由本次事实确认或重构。

### 6.1 主状态与并存条件

同一交易周期的主状态互斥：Breakout / Spike、Tight Channel、Broad Channel、Trending Trading Range、Trading Range 或尚不清楚。方向为多头、空头、平衡或尚不清楚。只有 Trading Range 额外区分窄或宽、发展中或成熟。

以下条件可以同时成立：Breakout Mode、climactic move candidate、confirmed climax 与 transition。

Conditions 不与主状态并列计数。Context 只从最早发生变化的层次更新：

- 主状态和边界未变，只保持现有 Context；
- 只有 Condition 或运行边界改变，只更新对应内容；
- 主导价格组织、方向、正常回撤、目标或管理方式被替代，才重构 Context。

无需为“变化”另建生命周期。

### 6.2 状态转换

- Breakout / Spike + 第一次可识别回调 + 分离仍好 → Tight Channel。
- Breakout / Spike + gap 缩小或 overlap 增加，但尚无完整回调 → 原状态减弱，标记为过渡，不抢先改名。
- Tight Channel + 回调反复加深、穿回突破点、双边开始获利 → Broad Channel。
- Broad Channel + 相邻突破与回调重叠、延伸缩小 → Staircase / shrinking-stairs 视图，区间化增强。
- Broad Channel + 局部区间经短突破迁移到新区间 → Trending Trading Range 可成为主状态；若仍由方向 swing 支配，只保留同源视图。
- 任一方向状态 + 双方持续在同一公平区域获得接受 → Trading Range。
- Trading Range / Breakout Mode + 强突破、跟随并守住区间外 → Breakout / Spike。
- Trading Range + 突破尝试后重新接受旧区域 → 仍是 Trading Range；该 Active Test 结果为失败。

这些转换没有固定机械根数，也不是不可逆周期。

### 6.3 方向状态

Breakout / Spike 是新区域接受和方向控制已经建立、但几乎没有回调的阶段；第一次可识别回调进入 Channel，不等于整个方向运动结束。

- Tight Channel：回调浅、重叠少、分离保持；第一次逆势尝试通常先按 minor 处理。
- Microchannel：局部没有明显回调，顺势极值持续推进。
- Small Pullback Trend：以浅回调、保留 gap 或反方难以获利维持控制。
- Broad Channel：回调更深更久，常穿回突破点，双边逐渐都能获利。
- Staircase / shrinking stairs：相邻突破与回调重叠，连续延伸缩小。
- Trending Trading Range：局部平衡区通过短突破向新公平区迁移。

Broad Channel 与 Trending Trading Range 可以是同一行情的两个视图；主状态选择真正决定正常回撤、目标和管理的一项，另一项不重复提供证据。

Rising Channel 可以同时具有不同视角：

| 视角（可同时成立） | 适用条件 | 角色 |
| --- | --- | --- |
| 当前周期 | 当前 Channel 仍在组织价格 | 多头趋势 |
| 完整生命周期 | 观察其向下突破后的演化 | 也可提供区间化的 Bear Flag 视角 |
| 外层结构 | 位于外层空头趋势 | 同时承担外层 Bear Flag |

短期恢复旧高与长期向下突破属于不同 Outcome Horizon，不能放进同一交易方程。Falling Channel 镜像处理。位置比例、趋势线和通道线的构造与重画由[位置与空间](#三位置与空间)统一负责。

### 6.4 平衡状态与条件

Trading Range 表示围绕公平区域反复双向测试，双方都能获利且没有一侧持续控制：

- Tight：barbwire 或压缩重叠多，扣除成本后通常缺少空间。
- Broad：边缘可能形成现实路径，中部通常缺少优势。
- Developing：前序方向和初始段仍明显约束测试与目标。
- Mature：已经反复双向测试，前序方向影响减弱，任一方向突破获得跟随的可能性上升。

强区间段可能只是 vacuum test，不因运动强就取得趋势突破后的延续先验。“第二段陷阱”只在以下事实链完成后使用：

```text
第一段合理建立第二段预期
→ 第二段实际出现并吸引延续交易
→ 无法在边界或目标外获得接受
→ 反转
```

条件未完成时不提前使用该解释；完成后也仍只是一条失败事实链。

Breakout Mode 可叠加在成熟 Range、Triangle、ii、ioi、oo 或压缩上，表示两侧突破都可能获得跟进；它不预测方向，也不保证首次突破成功。

进行中的过快、过远或异常强运动只能称为高潮候选；只有后续停止延续并进入区间或反向结构，才能确认高潮。Final Trend Bar、Final Flag、Give-up Bar 同样先保留候选，等待后续结果。

Limit Order Market 是由重叠、影线、反转尝试和双边获利归纳的行为条件，不是新的 Context 状态；价格触及 limit price 也不证明账户成交。

### 6.5 证据不足时的优先覆盖

- 方向状态与 Trading Range 分不清 → 按 Trading Range 管理。
- Breakout / Spike 与 Channel 分不清 → 按 Breakout / Spike 管理，只沿控制方向。
- Tight 与 Broad Channel 分不清 → 按 Tight Channel 管理。
- Broad Channel 与 Trading Range 分不清 → 按 Trading Range 管理。

保守分类只影响市场解释；它不直接决定交易动作或账户风险。

## 七、多周期与观察窗口

每份市场结构、当前测试、机会、目标和概率判断都绑定周期与观察窗口。同一价格在高周期可能是一根突破 K 线，在交易周期是紧密通道，在低周期展开成宽通道或区间；这些视图可以并存。

外层约束只有在改变以下任一项时才进入当前市场判断：

- 当前目标事件或现实目标；
- 正常回调与机会失效；
- 可用空间、计划保护或持有期限；
- 管理方式。

多周期交易按以下边界执行：

- 较小周期可以提前触发，但必须在承担风险前定义；
- 小周期 Entry 追求大周期目标时，Stop、Size 和持有时间必须容纳大周期正常波动；
- 成交后不得因盈亏情绪临时切换周期。

Session 与 Opening 知识按以下边界使用：

- Session、剩余时间、事件和流动性由观察边界提供，只通过目标可达性、持有边界和交易可行性影响市场路径；
- 盘中不能用最终日型回填当时判断；
- Opening、first swing、Opening Breakout Mode、first-18 heuristic 和内部固定 opening window 不是同一对象，使用时必须声明来源边界。

## 八、目标

目标来自已经固定的结构、可见区域和当前问题，不是为修复 reward/risk 而事后挑选的退出价。

| 来源 | 现实目标事件 |
| --- | --- |
| Trend / Channel 恢复 | 测试旧极值、通道边界或下一 magnet |
| Trading Range 边缘反应 | 返回内部公平区域、中部或另一侧 |
| Range / Pattern 突破并接受 | 测试按固定高度投射的 measured-move 区域 |
| 强 Breakout 与回调 | 尝试第二段、旧极值或 Leg 1 = Leg 2 |
| Failed Breakout | 返回旧结构、内部目标、中部或另一侧 |
| 通道反向突破并接受 | 通道起点或更大 Trading Range |
| MTR 路径 | 反向两段、旧公平区域或现实 swing magnet |

常见投射：

```text
Leg 1 = Leg 2：第一段 A → B，第二段起点 C，目标 = C + (B - A)
Range height：H = upper boundary - lower boundary
  向上目标 = upper boundary + H
  向下目标 = lower boundary - H
Double-bottom height = neckline - bottom area
Double-top height    = top area - neckline
Double-bottom target = neckline + Double-bottom height
Double-top target    = neckline - Double-top height
```

Measured move 按以下边界使用：

- 所有端点必须在当时可见并冻结；
- 投射只是 Target candidate，更近障碍、成本和剩余时间会改变现实 Reward；
- 多个相对独立投射形成 target cluster 时，可以增强 magnet 与到达后的反应意义；
- 同一结构的不同量法仍只是一组来源。

市场目标只定义价格触及、进入、越过并接受，或在期限内未发生。账户是否实际退出属于交易结果与账户结果。

第一目标、部分退出和 runner 是交易计划动作，不能改写 Market Outcome Criterion：

- 第一目标只是部分退出或路径里程碑时，Criterion 仍指向原 Opportunity 的主要目标、Invalidation 或 Horizon；
- 原 Criterion 已经实现后，延伸只能引用事前定义的另一条 Opportunity / Horizon，或在当时重新形成延伸机会；具体计划调整由决策页负责；
- 两者都不成立时，按原计划退出。

## 九、双向机会

市场分别检查向上与向下的现实路径，不用一个方向偏见代替双向论证。一条机会由“方向、目标事件、结果期限和判断周期”区分；同方向但目标或期限不同，必须分开。

### 9.1 一条机会必须完整回答

```text
判断时点和交易周期是什么？
它是延续、修正、反转、区间返回还是平衡突破？
市场试图完成什么，怎样判断结果已经发生？
最迟何时仍有意义？
现实目标在哪里？
哪些已发生事实真正支持它？
什么条件使它可以被交易；条件是否已经满足？
什么市场事实真正否定它？
最强反方事实或完整竞争路径是什么？
当前只能作怎样的定性判断；若有同口径数值，来源是什么？
当前仍有效，还是已经实现、失效、到期、被替代或先后未知？
```

机会的目标、结果判定、激活、失效和期限全部由市场判断拥有。交易表达不得用入场、计划保护、账户限制或期望退出反向补写。

数值 Market Probability 只按以下规则消费：

- 目标、条件、周期、期限与判断时点完全相同时才可引用；
- 它只描述市场结果，不描述采用特定 Entry、Stop、Target 和管理后的交易结果，也不能直接代入交易者方程；
- 没有可靠数值时仍可形成完整市场路径，但只能作定性判断；
- 教学区间和理由数量不能改写成精确概率。

数值来源资格与研究边界由[概率与证据边界](probability_and_evidence_boundaries.md)统一负责。

### 9.2 形成结果

每一侧的检查得到以下分支，但不建立额外扫描对象：

A. 路径完整且仍有效

→ 保留或更新机会；激活条件可以已经满足，也可以尚未满足

B. 路径尚不完整，但已有真实测试或明确下一观察

→ 保存下一事实和期限，交给决策判断是否等待

C. 没有现实目标、空间、时间或形成条件

→ 只保留排除原因，交给决策结束当前表达

激活条件尚未满足的完整路径仍然是机会。反过来，只有下一观察时不得伪造目标、期限或到期条件。

向上与向下路径天然竞争，也可以按顺序同时成立。例如空头趋势中先向上修正到 EMA，随后向下延续测试旧低。只有这个顺序会改变当前选择或管理时，才需要保存。

对手尚不完整时，最强反方事实留在当前机会中；一旦形成完整对手路径，就由对手机会自己表达，不能再重复计数。

### 9.3 结果与更新

机会的结束结果互斥：

```text
有效
├─ 目标结果发生                      → 实现
├─ 市场事实实质否定                  → 失效
├─ 结果期限结束                      → 到期
├─ 新市场结构、问题或机会取代        → 被替代
└─ 目标与失效先后无法确认            → 先后未知
```

激活、增强、保持和削弱只是机会仍有效时的属性变化，不形成第二套生命周期。模型更新只记录实际改变的结论；没有变化时不保存额外状态。

竞争路径获得接受时，先更新它自己的 Opportunity，再判断所选 Opportunity 是否失效或被替代。市场原因关闭 Opportunity；账户原因只能拒绝交易表达，不能关闭市场机会。

## 十、唯一更新与交接

市场更新只消费上一份有效判断、当前 Frame 和新增或更正的 Market Facts，并按共同链路更新：

- 位置地图；
- 到达路径与当前测试；
- 压力、控制与市场结构；
- 双向机会；
- 实际发生变化的简短摘要。

若新事实改变了区域、Object、Space、Target 或 Invalidation，就从最早变化处重新传播，不另建 Event、Pattern、Signal 或 Context 流程。

市场只向下一步交付三类内容：

- 一条完整 Opportunity；
- 来自所属环节的 Next Observation 与来源期限；
- 没有现实路径或事件的排除原因。

TRADE、WAIT、STAND_DOWN、Trade Expression、计划和账户动作都不由市场判断直接决定。

盘中最小口述可以压缩为：

```text
位置与空间：在哪里，前方与失效侧有什么？
到达路径：怎样到达，分离、重叠和回调怎样变化？
当前测试：测试什么，怎样算接受或失败，下一事实是什么？
状态：两侧压力与控制怎样，Context 是否真的改变？
机会：Long / Short 各有哪些完整现实路径；目标、失效和期限是什么？
```

只有位置、Test、Context、Opportunity 或下游动作发生变化时才展开记录；完整思考不能遗漏，但不要求逐项抄写未变内容。

## 十一、知识融合、去重与证据边界

任何价格行为知识进入运行方法前都必须能回答：

- 它由哪些可观察事实形成，绑定哪个周期和窗口？
- 它改变位置、到达、测试、状态、目标还是机会？
- 它能直接推出什么，不能越级推出什么？
- 什么事实确认、增强、削弱、否定、替代或重置它？
- 它与哪些名称共用事实，什么才是新的独立证据？

不能回答形成条件、实际作用和更新边界的名称，不进入运行方法。包含最终结果的名称必须区分实时候选和事后确认。不同目标、周期、Horizon 或判断时点不得因名称相同而合并。

证据的一般变化是：出现 → 当前窗口内有效 → 因缺少跟随或重叠增加而削弱 → 因路径被否定而失效 → 因新主导结构、成熟 Range、Control 切换或周期变化而重置。削弱不等于立即失效；重置不否认历史发生，只说明旧事实不再支持当前 Opportunity。

Reference 保存来源主张、原始锚点、冲突、翻译和隔离项；它不拥有运行状态。方法只接受以下证据边界：

- [课程概念索引](../reference/course/concept_index.md)
- [跨讲重复矩阵](../reference/course/repetition_matrix.md)
- [边界与冲突](../reference/course/boundaries_and_conflicts.md)
- [正式来源台账](../reference/official_sources.md)
- [逐讲课程材料](../reference/course/README.md)

本页是市场读取与双向机会的唯一 Owner；Reference 只负责证明、限定或隔离来源知识。
