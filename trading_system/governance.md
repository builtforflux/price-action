# 复盘、证据与方法变更

本页在盘后评价交易过程、知识与方法变更。盘中使用[决策入口](README.md#盘中决策入口)，按需要查阅 Market、Trade 和 Account；研究比较不临时改变当前运行规则。

## 一、知识进入方法前先拆清楚

理解一项思想后，还原适用条件与决策作用，用具体市场过程比较采用它和沿用现状的区别，再决定保留、合并、补充、替换或研究。具体回答三件事：

| 问题 | 必须明确 |
| --- | --- |
| 它是什么 | 对象、产品、周期、比较关系、观察时点、前置、排除、期限，以及确认、削弱、失效和重置事实 |
| 它改变什么 | 位置、预期、进展、路径、交易方案、仓位处理或复盘结果，以及必要的条件顺序 |
| 为什么采用 | 相比当前方法，哪些决定、风险或执行负担得到改善；支持与反对证据是什么，还缺哪些验证 |

概念和流程应服务于可说明的决定。能用已有表达准确说明的关系直接复用；删去有用的尺度、条件或先后次序会损害判断时予以保留。若现有表达妨碍决策，可以调整或替换组织方式，并检查信息是否丢失、判断是否更容易执行。价格行为思想通常通过位置、尝试、预期和实际进展进入判断，其交易价值还须落到参与与管理的取舍。

### 新名称怎样归并

按实际问题维护详细规则，跨环节的思想通过同一连续过程说明其影响：

| 实际改变 | 详细规则位置 |
| --- | --- |
| 可见市场内容、判断或方向路径 | [Market](market.md)；场景只同步导航 |
| 入场、止损、出场、期限、质量、数量或仓位动作 | [Trade](trade.md) |
| 账户限制、订单授权执行或平台订单、成交、仓位与实际止损记录 | [Account](account.md) |
| 尚不改变运行结论 | 证据、研究候选或隔离 |

同一事实登记一次，相关判断直接引用。场景导航按需要合并、拆分或补充；比较它是否帮助识别机会、区分正常与异常表现及选择动作。页面分工和场景数量是组织约定，保留或修改都要说明对使用的影响。

## 二、三类知识分开处理

### 1. 结构关系

不声称精确概率、但条件和例外完整的可复核关系，可以写入相应规则页。多个名称只能合并共享事实；会改变结果的顺序必须保留，例如第二段陷阱不能删除“建立预期—第二段出现—限制位置跟随不足—重新接受旧区域”的先后。

### 2. 条件启发式

`likely`、固定根数、教学比例和无连续样本的经验数字，必须保留来源、产品、周期、时段、目标事件、判断时点、结果期限、例外、冲突和核验状态。信息不完整时只能作为定性参考、研究候选或隔离，不能成为当前交易的精确胜率。

### 3. 已校准的数值规则

数值只有完成完整发布条件，才可以进入生产判断：

- 规则版本和适用范围明确；
- 目标事件与互斥结果明确；
- 产品、周期、时段和判断时点一致；
- 前置与排除条件完整；
- 结果期限固定；
- 样本定义、数量、区间和缺失处理明确；
- 有不确定区间、漂移监控和停止使用条件。

**当前系统中可用于生产的已校准数值概率规则：没有。**

Reference 中的数字仍是证据或研究候选。没有合格数字时使用定性判断，不制造精确胜率，也不因此自动禁止交易。

## 三、三种概率对象

| 对象 | 回答的问题 | 必须匹配的边界 |
| --- | --- | --- |
| 市场结果概率 | 特定条件下，路径目标在期限内发生的可能性 | 产品、周期、判断时点、条件、目标事件和结果期限 |
| 交易结果概率 | 完整交易方案下，各互斥交易结果的可能性 | 入场、止损、出场、数量、成本与全部管理规则 |
| 状态或形态频率 | 某类状态或名称出现的频率 | 形态定义、观察窗口和样本范围 |

每个数值只回答所属对象。H2、Double Bottom、Flag 或 MTR 引用同一事实时按一组事实统计。

## 四、信息处置

每条信息只取一个结果：

| 结果 | 条件与动作 |
| --- | --- |
| 进入方法 | 明确改变运行结论或安全边界，且条件、例外和失效完整；写入相应规则页并同步相关引用 |
| 证据 | 有来源或教学价值但不改变运行状态；留在盘后材料 |
| 研究候选 | 可能有价值但缺样本、定义或校准；写明验证方法，验证前不生产使用 |
| 隔离 | 来源不明、条件缺失、冲突未解或会制造危险确定性；不得伪装成启发式 |

## 五、复盘时分开四个结果

判断与决定发生时保留记录；Account 确认[本笔交易结束](account.md#本笔交易结束)后汇总本笔交易。财务记录未齐时账户结果先标暂定。

| 结果 | 只记录 |
| --- | --- |
| 市场结果 | 原条件下的路径待定、实现、失效、到期或先后未知；停止采用另记时间与原因 |
| 交易结果 | 止盈、止损、主动平仓、到期、scratch、分批出场或无成交 |
| 账户结果 | 实际成交、费用、滑点、持有成本、换算和净结果 |
| 执行过程结果 | 判断和方案是否完整、计划损失与仓位是否合规、提交止损与仓位管理是否遵守规则、平台记录不清时是否先核对 |

本笔交易结束时 Market 可能尚未得出最终结果。其他结果先复盘，原路径仍按事前目标、完成、失效和期限评价；已不影响当前动作的路径可在盘后用可靠后续数据结算。条件未发生导致到期时写明原因，与交易盈亏分别评价。现有数据无法确定目标与失效先后时保留未知，补充更细数据才可确认，不能用“替代”或账户盈亏填补。

**历史预测与当前采用分开。** 新事实可以使执行者停止采用旧判断、形成新路径或修改未来管理。记录新决定的时点、依据和实际余仓；原预测与已有请求、成交继续保留。新目标或期限从新判断开始，旧记录按原条件评价。继续研究市场、采用新判断和授权交易分别按负责页处理。

四个结果不能互相替代：

- 市场到达路径目标，不证明账户捕获收益；
- 赚钱，不证明判断和执行正确；
- 亏损，不自动证明市场判断错误；
- 被止损后市场路径仍可能最终实现；
- 单笔结果不能校准概率。

MAE、MFE、realized R 等事后描述使用预先定义的计算方法。盘中计算保留当时可见的端点、时点和用途；例如已发生回调形成的止盈参照按 [Trade 出场规则](trade.md#35-出场目标与期限)使用。历史止损、初始 R 与旧预测保持原记录，后续统计不反向证明事前优势。

### 连续过程与经济表现

在同一观察窗口中，将等待、参与、持有、退出和重新参与按时间串起来。检查正常不利表现是否被过早当成退出理由、前提改变后是否拖延、反复出入或加仓是否改善未来交换。每笔实际费用只计一次；同一行情的多个交易或重叠路径不能当作多份独立证据。

执行能力和经济表现分别评价。完整、合规且可复核的交易，仍可能持续净亏；成本后净结果、回撤和不同连续窗口的表现决定是否有依据继续采用或增加风险。实际晋级、有限风险的实盘学习及退回规则见[训练与实盘运行](../practice/README.md#晋级与退回)。Brooks 的 [Ask Al #113](https://www.brookstradingcourse.com/ask-al/how-many-points-to-risk-per-trade/) 中“Trading goals”也将小仓位练习、持续盈利与随后加量连接起来；具体评价范围和门槛须按当前方法事前确定。

管理比较按事前风险收益目标评价取舍。例如较早减仓可能减少净收益，同时降低回撤或改善执行稳定性；这些改善须足以补偿收益让渡、成本和负担，并满足经济与风险底线。同一笔获利或某个后续分支不能证明这种取舍值得反复采用，参见[同一前缀下的管理比较](examples.md#同一前缀下的管理比较)。

## 六、最小复盘显示

| 区块 | 最小内容 |
| --- | --- |
| 当时看到 | 原市场判断、预期与实际表现、允许的正常不利表现、当时相关路径和最强反方事实 |
| 当时决定 | 当前动作与等待或维持现有方案的取舍，以及入场、止损、出场、最大计划损失与有时间依据的方案变更 |
| 实际发生 | 订单、成交、仓位、平台实际止损、成本、净结果和最早偏差或新事实 |
| 结论 | 最早需要改变决定的事实；执行是否合规、经济表现是否支持原选择；保留方法、修正问题或形成研究比较 |

等待、放弃、未提交和无成交也可复盘；没有成交时不补造交易收益，账户仍记录实际发生的费用。

一行摘要链接当时判断、历次决定和实际执行记录即可。复杂案例再展开截图与说明；摘要长度不决定原始证据是否保留。

## 七、方法变更

方法研究候选必须说明：

- 当前规则和可复现问题；涉及交易效果时，说明验证对象是执行者的整套裁量还是单项判断的增量；
- 建议修改哪些命题及相关页面，具体会改变哪些决定或记录义务；
- 适用条件、例外，以及对仓位和计划损失的影响；
- 支持与反对证据；
- 怎样连续收集全部命中实例；
- 与变化相应的评价目标、比较基准，以及怎样验收、停止和回滚。

评价整套裁量时，固定执行者、适用范围与选择惯例：同类条件下通常采用什么参与和管理，哪些新事实允许改选，允许的风险及收益让渡是什么。记录实际例外和依据；检验结果适用于这套组合，不能据此认定某项新增判断单独有效，也不能直接外推给其他执行者。

评价单项新增判断时，用同一组当时可见事实比较采用与不采用它的完整方案，固定其余相关选择惯例、取样、成本及风险条件。该判断必然带动的参与或管理变化一并计入；另有变化时明确列出，无法分离影响则只评价整套方案。读取后续后才改变惯例或选择比较对象，属于探索；据此形成候选后另取未知窗口检验，原窗口不充当独立验证。

验证按变化的影响选择：

- **事实、算术或规则缺口**：回查来源或构造可复现反例，核对修正后的动作和交接；这些证据不能证明修正后的交易有正期望。
- **表达与组织**：用相同可见信息检查必要条件是否完整、判断能否调用、记录和操作是否减少。没有发现改善时可保留现状。
- **市场与管理效果**：按上述验证对象固定范围和相关选择，在连续未知行情中与现状或简单基准比较成本后表现、回撤和负荷，按事前风险收益目标判断取舍。

涉及市场与管理效果的发布顺序：

1. 固定验证对象、比较方案、事件、条件、结果和期限；
2. 连续收集样本，不能只收成功案例；
3. 检查重复、镜像、冲突，以及它实际改变的现有结论；
4. 通过场景、计算和必要的独立复核；
5. 发布新版本和生效时间；
6. 新规则只影响生效后的判断，不改写历史记录。

纪律、表达、执行与市场方法都可能产生可复现问题；先定位最早偏差，再决定改变什么。规则难以稳定执行或没有经济表现支持时，不能仅因形式完整就把问题归为执行者未遵守。

## 八、验收用例的地位

[连续事件用例](examples.md)检查当时事实怎样支持或改变动作，以及页面之间的执行交接。

运行行为由规则页定义，用例不另设隐含规则。若用例暴露冲突、遗漏或不合理限制，定位原因后修正规则或用例，并同步两者。用例通过表明给定事实下动作可解释、计算和交接可核对；盈利能力、判断用时和实际负荷另行验证。

## 九、当前回放重点

### 比较中的边界

| 类型 | 当前要求 | 怎样评价变化 |
| --- | --- | --- |
| 事实与记录 | 使用当时可靠信息，未知不填零，历史预测、授权与成交可追溯 | 校正保留原记录和依据；新判断只改变后续决定 |
| 执行与账户 | 核对真实仓位、有效订单和实际保护，遵守账户限制及安全期限 | 平台实现可以更换，替代实现须重新验证相同能力 |
| 方法选择 | 用固定目标、失效与期限表达条件路径；单向持仓、全仓共同且不放宽止损、原预算不重置、净回报筛选 | 按各运行页执行；替代方案在固定条件下研究，通过相应验证后更新规则 |

止损价格不放宽与金额风险不增加有不同含义。原预算不重置用于限制整笔风险，整笔盈利也不能证明新增风险值得承担。比较方法选择时同时检查它保留了哪些保护、限制了哪些可行管理，以及执行者是否能够稳定使用。

### 待验证的交易与使用效果

- **确认与价格的交换**：对同一背景分别回放提前参与、收盘或跟随确认、回试参与；只使用各自当时价格。分别比较强背景下单次完成事件与更多跟随，以及早期反向 Swing 与控制转移后参与的条件和结果。
- **连续管理**：比较计划内回调持有、趋势双边化后的减仓、退出与重入，以及加仓相对不加仓的增量。基准方案在回放前固定，计入费用、未成交和重复出入，检查少数大盈利是否被过早退出破坏。
- **条件目标与后续管理**：比较近端出场、条件测量目标及目标实现后的余仓延伸；保留旧预测与旧请求，计入实际成本和回吐。Neckline 确认前的投射、已发生回调的距离投射及普通退出更新分别检验。另比较按趋势存续条件管理的方案：事前固定正常不利表现、退出与复查条件、风险和期限，检验固定目标预测是否改善决策；该替代方案验证前不代替当前路径要求。
- **判断能否稳定执行**：用同一可见事实检查预期、正常与异常表现及当下决定，保留执行者分歧。比较固定参与与管理基准和多种灵活选择的决定用时、漏做、无必要干预及经济表现，避免把定性语言变成未经验证的评分。

另作研究比较：减仓后采用更远结构止损与先平仓再参与的总风险、成本和执行差异；净回报筛选在不同背景下排除了哪些方案、保留的方案是否仍缺少可达性依据。研究候选按上述方法变更流程验收，验证前继续执行当前限制。
