# 复盘、证据与方法变更

盘后先区分复盘结果、定位问题；需要调整方法或纳入新知识时，再查对应要求。盘中按[核心闭环](README.md#核心闭环)运行，按需要查阅 Market、Trade 和 Account；研究比较不临时改变当前运行规则。

## 一、复盘时分开四个结果

评价对象所需的判断与决定，在发生时留痕；日常练习按[最小记录](../practice/README.md#五最小记录)取用，正式检验事前固定覆盖。真实授权、订单、成交、仓位和保护记录始终按 Trade 与 Account 保存。

- Account 确认[本笔交易结束](account.md#本笔交易结束) → 汇总需要评价的交易。
- 财务记录未齐 → 账户结果先标暂定，待记录补齐。

评价涉及以下结果时分别记录；只研究市场判断的专项不补造交易、账户或执行结果。

| 结果 | 只记录 |
| --- | --- |
| 市场结果 | 原条件下的路径待定、实现、失效、到期或先后未知；停止采用的时间、原因及未继续评价另记 |
| 交易结果 | 止盈、止损、主动平仓、到期、scratch、分批出场或无成交 |
| 账户结果 | 实际成交、费用、滑点、持有成本、换算和净结果 |
| 执行过程结果 | 判断和方案是否完整、计划损失与仓位是否合规、提交止损与仓位管理是否遵守规则、平台记录不清时是否先核对 |

路径结算以原目标、完成、失效和期限为准：

| 情况 | 处理与未决结果 |
| --- | --- |
| 交易已结束，Market 尚无最终结果 | 先复盘其他结果；仍需评价的路径继续结算，不影响当前动作时可在盘后使用可靠后续数据 |
| 条件未发生而到期 | 写明原因，与交易盈亏分别评价 |
| 无法确定目标与失效先后 | 保留未知；补充更细数据才可确认，不用“替代”或账户盈亏填补 |

**历史预测与当前采用分开。** 新事实可以改变后续决定，不能改写已记录的原预测、请求和成交：

- 停止采用旧判断、形成新路径或修改未来管理 → 需留痕时记改判时点与依据；新目标、期限从新判断开始。
- 决定涉及实际仓位 → 另记实际余仓及授权变化。
- 当前采用的路径仍影响动作 → 及时核对；研究市场、采用新判断和授权交易分别按负责页处理。

停止采用后的追踪义务按 [Practice 的路径后续评价范围](../practice/README.md#路径后续评价范围)处理。正式检验仍按事前覆盖结算，缺失如实报告，不事后改成非评价对象。

“未继续评价”表示未继续追踪，不是失败或数据先后未知，不计路径实现率。

四个结果不能互相替代：

- 市场到达路径目标，不证明账户捕获收益；
- 赚钱，不证明判断和执行正确；
- 亏损，不自动证明市场判断错误；
- 被止损后市场路径仍可能最终实现；
- 单笔结果不能校准概率。

- 计算 MAE、MFE、realized R 等事后描述 → 使用预先定义的方法，不据此反向证明事前优势。
- 盘中计算 → 保留当时可见的端点、时点和用途；已发生回调形成的止盈参照按 [Trade 出场规则](trade.md#35-出场目标与期限)使用。

历史止损、初始 R 与旧预测保持原记录。

### 连续过程与经济表现

评价连续管理与经济表现时，按时间连接同一窗口内的等待、参与、持有、退出与重入：

| 出现的情况 | 复查问题 |
| --- | --- |
| 正常不利表现后退出 | 是否过早退出 |
| 前提改变后仍持有 | 是否拖延 |
| 反复出入或加仓 | 是否改善未来交换，整段成本是多少 |

每笔实际费用只计一次；同一行情的多个交易或重叠路径不算独立证据。

- 交易完整、合规且可复核 → 可以评价执行能力，不能据此推定盈利。
- 决定继续采用或增加风险 → 另看成本后净结果、回撤和不同连续窗口表现；按[训练与实盘运行](../practice/README.md#晋级与退回)晋级、有限实盘学习或退回。
- 管理减少净收益但降低回撤或改善执行 → 按事前风险收益目标，检查改善是否补偿收益让渡、成本和负担，并满足经济与风险底线。
- 只有单笔获利或某个后续分支 → 不足以支持反复采用，参见[管理比较](examples.md#同一前缀下的管理比较)。

Brooks 的 [Ask Al #113](https://www.brookstradingcourse.com/ask-al/how-many-points-to-risk-per-trade/) 中“Trading goals”也将小仓位练习、持续盈利与随后加量连接起来；具体评价范围和门槛仍须按当前方法事前确定。

## 二、最小复盘显示

需要完整复核时取下表；专项反馈只取相关内容。已有参数、惯例、判断与执行记录直接引用。

| 区块 | 最小内容 |
| --- | --- |
| 当时看到 | 原市场判断、预期与实际表现、允许的正常不利表现、当时相关路径和最强反方事实 |
| 当时决定 | 当前动作与等待或维持现有方案的取舍，以及入场、止损、出场、最大计划损失与有时间依据的方案变更 |
| 实际发生 | 订单、成交、仓位、平台实际止损、成本、净结果和最早偏差或新事实 |
| 结论 | 最早需要改变决定的事实；执行是否合规、经济表现是否支持原选择；保留方法、修正问题或形成研究比较 |

| 情况 | 怎样显示或评价 |
| --- | --- |
| 完整复核 | 一行摘要链接当时判断、历次决定和实际执行；复杂案例再展开截图与说明 |
| 等待、放弃、未提交或无成交 | 可复盘；不补造交易收益，账户保留实际费用 |
| 缺少完整记录 | 只能判定无法据此复核，不能推定未思考、合规或违规 |

日常留痕、事前选定的完整检查、正式证据覆盖及比率分母统一按[最小记录](../practice/README.md#五最小记录)处理。

## 三、方法变更

先按变化的实际影响选择验证：

| 变化 | 怎样验证 | 结论与下一步 |
| --- | --- | --- |
| 事实、算术或规则缺口 | 回查来源或构造可复现反例，核对修正后的动作与交接 | 不证明交易有正期望 |
| 表达与组织 | 用相同可见信息检查条件完整、判断调用及记录、操作负担；未见改善可保留现状 | 表达改善不证明市场或管理效果 |
| 市场与管理效果 | 按验证对象固定范围与选择，在连续未知行情中与现状或简单基准比较成本后表现、回撤和负荷 | 结论限于验证对象与范围；按事前风险收益目标决定取舍 |

同一修改可以涉及多类影响，分别完成适用验证。纯重排保留原意；表达与组织调整须核对决定、限制及记录义务是否受影响。记录义务改变时，检查可追溯性、正式证据覆盖和执行记录用途；引入或替换参与、管理、风险边界或收益让渡的方法选择时，还须按市场与管理效果验证。

各类候选都说明：

- 当前规则和可复现问题；
- 建议修改哪些命题及相关页面，具体会改变哪些决定或记录义务；
- 适用条件、例外，以及对仓位和计划损失的影响；
- 支持与反对证据；
- 与变化相应的评价目标、比较基准，以及怎样验收、停止和回滚。

涉及市场与管理效果时，还须说明怎样连续收集全部命中实例，并先确定验证对象：

| 对象 | 事前固定 | 结论边界 |
| --- | --- | --- |
| 整套裁量 | 执行者、适用范围、同类条件下的参与与管理惯例、允许改选的新事实、风险及收益让渡 | 只评价这套组合；不证明单项新增判断有效，不直接外推给其他执行者 |
| 单项新增判断 | 同一组可见事实下采用与不采用它的完整方案；其余相关惯例、取样、成本及风险条件 | 必然带动的参与或管理变化一并计入；其他变化列明，无法分离时只评价整套方案 |

- 整套裁量出现实际例外 → 记录例外与依据。
- 读取后续后才改变惯例或选择比较对象 → 归入探索；形成候选后另取未知窗口，原窗口不作独立验证。

涉及市场与管理效果的发布顺序：

1. 固定验证对象、比较方案、事件、条件、结果和期限；
2. 连续收集样本，不能只收成功案例；
3. 检查重复、镜像、冲突，以及它实际改变的现有结论；
4. 通过场景、计算和必要的独立复核；
5. 发布新版本和生效时间；
6. 新规则只影响生效后的判断，不改写历史记录。

纪律、表达、执行与市场方法都可能产生问题；先定位最早偏差，再决定改变什么。若规则难以稳定执行或缺少经济支持 → 继续检查规则及方法，不能仅因形式完整就归为执行者未遵守。

## 四、知识进入方法前先拆清楚

判断一项思想是否进入方法，先还原以下内容，再用具体市场过程比较采用它与沿用现状：

| 问题 | 必须明确 |
| --- | --- |
| 它是什么 | 对象、产品、周期、比较关系、观察时点、前置、排除、期限，以及确认、削弱、失效和重置事实 |
| 它改变什么 | 位置、预期、进展、路径、交易方案、仓位处理或复盘结果，以及必要的条件顺序 |
| 为什么采用 | 相比当前方法，哪些决定、风险或执行负担得到改善；支持与反对证据是什么，还缺哪些验证 |

| 比较结果 | 处理 |
| --- | --- |
| 已有表达能准确说明关系 | 直接复用 |
| 合并会丢失有用的尺度、条件或次序 | 保留区别 |
| 现有表达妨碍决策 | 可调整或替换组织；检查信息是否保留、判断是否更易执行 |
| 尚不能确定改进价值 | 按[信息处置](#七信息处置)保留证据、研究或隔离 |

价格行为思想通过位置、尝试、预期和实际进展进入判断；评价交易价值时，还须比较它改变的参与与管理取舍。

### 新名称怎样归并

按实际问题维护详细规则，跨环节的思想通过同一连续过程说明其影响：

| 实际改变 | 详细规则位置 |
| --- | --- |
| 可见市场内容、共用判断规则、方向路径及其结果处理 | [Market](market.md) |
| 背景相关的正常预期、竞争解释、区分事实与区域作用 | [场景导航](scenarios.md)；共用判据引用 Market |
| 入场、止损、出场、期限、质量、数量或仓位动作 | [Trade](trade.md) |
| 账户限制、订单授权执行或平台订单、成交、仓位与实际止损记录 | [Account](account.md) |
| 尚不改变运行结论 | 证据、研究候选或隔离 |

同一事实登记一次，相关判断直接引用。同一判据的完整定义由所属页维护，其他页保留当前环节所需的条件、提醒与引用。需要合并、拆分或补充场景导航时，比较机会识别、正常与异常区分及动作选择是否改善；保留或修改页面分工、场景数量，都说明使用影响。

## 五、三类知识分开处理

### 1. 结构关系

- 关系可复核、条件与例外完整，且不声称精确概率 → 可以写入相应规则页。
- 多个名称引用同一事实 → 合并共享事实；会改变结果的顺序保留。

例如第二段陷阱的归并，须保留 Market [完整判据](market.md#第二段预期怎样受损或失败)中的预期、第二段、限制位置与后续失败发展的条件和次序。

### 2. 条件启发式

引用 `likely`、固定根数、教学比例或无连续样本的经验数字时，保留来源、产品、周期、时段、目标事件、判断时点、结果期限、例外、冲突和核验状态。

- 信息不完整 → 只能作定性参考、研究候选或隔离；不能成为当前交易的精确胜率。
- 准备用作数值规则 → 按下一节完成发布条件。

### 3. 已校准的数值规则

数值只有完成完整发布条件，才可以进入生产判断：

- 规则版本和适用范围明确；
- 目标事件与互斥结果明确；
- 产品、周期、时段和判断时点一致；
- 前置与排除条件完整；
- 结果期限固定；
- 样本定义、数量、区间和缺失处理明确；
- 有不确定区间、漂移监控和停止使用条件。

**当前系统中可用于生产的已校准数值概率规则：没有。**

Reference 中的数字仍是证据或研究候选。没有合格数字 → 使用定性判断，不制造精确胜率，也不因此自动禁止交易。

## 六、三种概率对象

| 对象 | 回答的问题 | 必须匹配的边界 |
| --- | --- | --- |
| 市场结果概率 | 特定条件下，路径目标在期限内发生的可能性 | 产品、周期、判断时点、条件、目标事件和结果期限 |
| 交易结果概率 | 完整交易方案下，各互斥交易结果的可能性 | 入场、止损、出场、数量、成本与全部管理规则 |
| 状态或形态频率 | 某类状态或名称出现的频率 | 形态定义、观察窗口和样本范围 |

每个数值只回答所属对象。H2、Double Bottom、Flag 或 MTR 引用同一事实时按一组事实统计。

## 七、信息处置

每条信息只取一个结果：

| 条件 | 结果与动作 |
| --- | --- |
| 明确改变运行结论或安全边界，条件、例外和失效完整 | 进入方法：写入相应规则页并同步引用 |
| 有来源或教学价值，但不改变运行状态 | 证据：留在盘后材料 |
| 可能有价值，但缺样本、定义或校准 | 研究候选：写明验证方法，验证前不生产使用 |
| 来源不明、条件缺失、冲突未解或会制造危险确定性 | 隔离：不得伪装成启发式 |

## 八、验收用例的地位

[连续事件用例](examples.md)检查当时事实怎样支持或改变动作，以及页面之间的执行交接。

运行行为由规则页定义，用例不另设隐含规则：

- 用例暴露冲突、遗漏或不合理限制 → 定位原因，修正规则或用例并同步两者。
- 用例通过 → 只说明给定事实下动作可解释、计算和交接可核对；盈利能力、判断用时和实际负荷另行验证。

## 九、当前回放重点

### 比较中的边界

| 类型 | 当前要求 | 怎样评价变化 |
| --- | --- | --- |
| 事实与记录 | 使用当时可靠信息，未知不填零，历史预测、授权与成交可追溯 | 校正保留原记录和依据；新判断只改变后续决定 |
| 执行与账户 | 核对真实仓位、有效订单和实际保护，遵守账户限制及安全期限 | 平台实现可以更换，替代实现须重新验证相同能力 |
| 方法选择 | 用固定目标、失效与期限表达条件路径；单向持仓、全仓共同且不放宽止损、原预算不重置、净回报筛选 | 按各运行页执行；替代方案在固定条件下研究，通过相应验证后更新规则 |

止损价格不放宽与金额风险不增加分别判断；原预算不重置限制的是整笔风险，整笔盈利不证明新增风险值得承担。

比较方法选择时，同时检查保留的保护、限制的可行管理及执行者能否稳定使用。

### 待验证的交易与使用效果

按待解决的问题选择比较，不要求每次全部展开：

| 问题 | 比较对象 | 固定或检查什么 |
| --- | --- | --- |
| 确认是否值得价格让渡 | 同一背景下提前参与、收盘或跟随确认、回试参与 | 只用各自当时价格；比较强背景下单次完成与更多跟随、早期反向 Swing 与控制转移后参与的条件及结果 |
| 连续管理是否改善交换 | 计划内回调持有、双边化后减仓、退出重入、加仓与不加仓 | 回放前固定基准；计入费用、未成交、重复出入，检查过早退出是否破坏少数大盈利 |
| 条件目标及延伸是否改善出场 | 近端出场、条件测量目标、目标实现后余仓延伸 | 保留旧预测与请求，计入实际成本和回吐；分别检验 Neckline 确认前投射、已发生回调距离投射与普通退出更新 |
| 固定目标预测是否改善决策 | 当前路径要求与按趋势存续条件管理 | 事前固定正常不利表现、退出与复查条件、风险和期限；验证前不替代当前路径要求 |
| 灵活选择能否稳定执行 | 固定参与和管理基准与多种灵活选择 | 同一可见事实下比较预期、正常与异常、决定用时、漏做、无必要干预及经济表现；保留执行者分歧，不用未经验证的定性评分 |
| 更远止损是否值得采用 | 减仓后采用更远结构止损与先平仓再参与 | 比较总风险、成本和执行差异 |
| 净回报筛选是否改善选择 | 不同背景下被排除与保留的方案 | 检查排除了什么，保留方案是否仍缺可达性依据 |

研究候选按[方法变更](#三方法变更)流程验收；验证前继续执行当前限制。
