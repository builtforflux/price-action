# 市场场景：按问题查预期

本页只在 Market 已知背景、位置和当前尝试，却仍缺预期或路径时使用。六张卡按因果问题提供候选事实；Market 采用适用事实后立即返回主流程。场景不拥有运行状态，也不定义交易；入场、止损和出场由 [Trade](trade.md) 负责。

## 一、使用边界

按当前主要问题选择一张卡，提取正常预期、竞争分支、关键事实和候选区域，再交给 Market 判断。只有两个测试的对象、最终结果、期限和后续影响相互独立时才临时使用两张；结果仍汇入现有双向路径。

所有卡共享以下契约，不在各卡重复：

- 名称只提供候选视图；测试、优势和路径仍由 [Market](market.md#36-当前区域互动价格表现与预期差) 根据实际进展与跟随判断。
- 一侧失败只结束本侧解释；竞争方向需要自己的进展、跟随和完整路径。
- 候选区域只有被 Market 采用后才用作路径目标、障碍、检查点或失效参照；每条路径只选一个路径目标。
- 触价只有在其本身足以完成事前定义的唯一尚缺条件时才有效；需要收盘、跟随、回试或持续接受时继续等待。固定概率、K 数和产品参数不构成生产许可。

| 原控制正在弱化，稳定双边边界与新控制均未形成 | [单边到平衡的共享过渡](#单边到平衡的共享过渡) |
| 原路径目标已经完成，需要判断目标区域之后的新问题 | [路径目标完成后的共享过渡](#路径目标完成后的共享过渡) |

## 三、导航输出

每张卡只返回正常预期、竞争分支、候选区域和问题改变后的下一张卡。Market 据此判断测试与路径，本页不保存结果。

### 单边到平衡的共享过渡

单边控制逐步双边化时不另立场景，按实际进展转移：

| 新事实 | 候选更新或转移 |
| --- | --- |
| 原方向仍能在正常回调内恢复并继续取得进展 | 保留单边控制；按当前运动使用单边扩展或回调测试 |
| 跟随减弱、分离关闭、重叠或回调加深，反方开始取得进展，但稳定边界和新控制均未形成 | 交给 Market 记为转换中；以原控制恢复、稳定边界形成或反方接受中的下一事实和期限等待 |
| 双方围绕共同区域反复取得进展，稳定边界已经形成 | 到边缘时改查边缘反应；仍在内部时改查成熟平衡的方向决断 |
| 主要结构破坏，旧极值测试或恢复失败成为当前问题 | 改查控制转移 |

Staircase、Trending Trading Range、Gap 关闭和重叠增加只提供上述转移的可见事实，不成为新的运行状态。

### 路径目标完成后的共享过渡

路径目标完成是 Market 对旧路径的最终结果，不是新场景。旧路径先固定为“实现”，该目标作为旧路径磁吸的作用视为已消耗；任何更远目标或反向目标都必须属于重新建立的路径，不得移动或继承旧路径目标。

本笔交易尚未结束时，Market 只继续提供原 Trade 止损、期限和出场条件依赖的事实，不建立新路径。本笔交易从未提交相关订单，或 Account 已确认[本笔交易结束](account.md#本笔交易结束)后，Market 从当前观察边界重新判断；目标区域仍在或再次发生互动时，将其作为新的当前测试并按实际进展转移：

| 新事实 | 候选更新或转移 |
| --- | --- |
| 同向穿越目标区域并获得跟随或外部接受，且下一未消耗区域可达 | 以新目标、完成、失效和期限改查[单边扩展](#四单边失衡继续扩展)；旧目标不外移 |
| 穿越后回试目标区域，原方向仍保持控制 | 改查[回调测试与恢复](#五原趋势中的回调测试与恢复)；恢复成立后再回到单边扩展 |
| 目标同时是事前可识别的双边边缘，触及或越界后被拒绝并回到内部 | 改查[边缘反应与轮转](#六双边结构边缘的反应与轮转) |
| 同向跟随停止或异常延伸回吐，但主要结构仍完整 | 改查[异常延伸与修正](#八成熟趋势的异常延伸与修正) |
| 围绕目标重叠增加，尚无稳定边界和新控制 | 交给 Market 记为转换中；边界形成后改查边缘反应或成熟平衡 |
| 主要结构破坏，反方取得进展并获得接受 | 改查[控制转移](#九趋势破坏后的控制转移) |

触及目标只完成旧路径，不证明目标处拒绝、突破或反方接管；新方向仍须自己的初始表现、跟随、路径目标、失效和期限。

## 四、单边失衡继续扩展

### 因果问题

已建立的单边控制能否保持，并在期限内到达当前路径目标？

### 前提与正常预期

- 一侧已有清楚控制，突破获得跟随或连续同向表现形成有效失衡；
- 延续所依赖的分离、极值推进或结构仍保持，到下一个已知障碍有空间和时间；
- 正常表现是保持分离、扩展极值，或浅回调后快速恢复；第一次逆向尝试通常只形成有限回调。

Breakout、Spike、Always In、Tight Channel、Small Pullback Trend、Microchannel 和已接受的 Range 突破共享这些事实，不各自建立流程。

**候选区域**：下一结构极值、主要支撑阻力、第二段投射区域，以及端点固定的测量区。

### 关键分支

| 新事实 | 候选更新或转移 |
| --- | --- |
| 第一次越界或第一根强 K | 等待事前要求的跟随、分离保持或回试结果；不能宣布新趋势 |
| 突破获得跟随并建立接受 | 支持 Market 判断原方向延伸，并从候选区域中按近端障碍和期限选择当前完成区域 |
| 第一次有意义回调 | 保留原控制、路径目标和失效，改查[回调测试与恢复](#五原趋势中的回调测试与恢复) |
| 跟随不足但尚未重新接受旧区域 | 原延续预期削弱；优先检查通道化或双边化 |
| 重新接受旧区域 | 否定原突破测试；反方向仍须自己的进展与跟随 |
| 晚期异常加速、最大趋势 K 或接近路径目标 | 改查[异常延伸与修正](#八成熟趋势的异常延伸与修正) |

Tight Channel 的第一次逆势信号通常只支持小回调；只有反方向自身的路径目标、失效和期限完整时，才可能形成方向机会。无漂亮 Signal Bar 不否定强趋势，但止损距离和追价质量交给 Trade。

## 五、原趋势中的回调测试与恢复

### 因果问题

当前逆向运动是正常测试、转入平衡，还是开始破坏原趋势？

### 前提与正常预期

- 原控制仍有效，最近主要趋势段或 Swing 尚未被反方向接受；
- 健康回调应在主要结构内停止，并在期限内恢复原方向；
- 首次触及参照不等于恢复，除非事前低确认条件明确允许触及完成唯一尚缺事实；
- 回调越深、越久且原方向反复恢复失败，平衡或控制转移分支越强。

**候选区域**：EMA、固定趋势段比例、趋势线或通道线、旧突破点、前高低、主要 HL/LH、趋势段起点、信号或突破 K 边界及开放突破回调 Gap。参照必须在测试前或到达时明确。

H1/H2、L1/L2、Double Test、Flag、Wedge Flag 和 Breakout Pullback 只保留独有次序或边界。

### 关键分支

| 新事实 | 候选更新或转移 |
| --- | --- |
| 接近或刚触及参照 | 等待拒绝、恢复、继续穿越或参照外接受；不得事后把“需恢复”降为“触及即可” |
| 参照处拒绝并恢复原方向 | 支持恢复；近端候选通常是旧趋势极值，更远区域只有在近端已分类后才考虑 |
| 穿越参照但主要结构完整 | 原方向削弱或测试未决；EMA、趋势线或 50% 的单次穿越不等于反转 |
| 回调加深、延长并双向化 | 已有边界时改查边缘或成熟平衡；无边界时不沿旧趋势建仓或加仓 |
| 主要结构破坏并获得反向接受 | 否定原恢复解释；改查[控制转移](#九趋势破坏后的控制转移) |

### 重要变体

- **长期未触 EMA 后首次测试**：区分触及、收于另一侧、整根位于另一侧和主要结构外接受。整根穿越可增强反方初始表现，但优势转移仍需要跟随；EMA 参数盘前固定，来源根数不作机械许可。
- **深回调但较大 Broad Channel 有效**：短周期可暂时反向；较大主要结构被接受性突破前，不因回调深或价格更便宜改变外层路径。
- **紧密微型通道首次微型趋势线突破**：默认先按正常回调；趋势晚期改查异常修正，主要结构破坏后改查控制转移。低周期只能细化入场，不能改写高周期路径目标和失效。

## 六、双边结构边缘的反应与轮转

### 因果问题

可识别边缘会拒绝并向内部轮转，还是边界外获得接受？

### 前提与正常预期

- 双方已经能反复推动和获利，上下边界在本次到达前可识别；
- 当前位于真实边缘，向内部候选区域有空间和时间，边界外尚无持续接受；
- 普通越界可能只是流动性测试；真突破应在外保持分离、获得跟随或回试守住。

Broad Channel 保留倾斜方向和主要 HL/LH；成熟 Trading Range 更重视公平区轮转。Range Edge、Failed Breakout、Overshoot、Vacuum Test、Double Test 和 Second-leg Trap 共享边缘测试事实。

**候选区域**：当前边界、外部测试极值、内部公平区或中部、对侧边界，以及外部接受后的旧边界回试区。

### 关键分支

| 新事实 | 候选更新或转移 |
| --- | --- |
| 尚未到边缘 | 边缘只是当前段候选路径目标；局部控制清楚时改查单边扩展或回调 |
| 刚到边缘或轻微越界 | 等待回到内部、外部接受或再次测试；Overshoot 不等于突破 |
| 边缘拒绝或外部尝试失败 | 支持向内部轮转；近端通常是公平区或中部，未处理近端前不选更远对侧路径目标 |
| 边界外获得接受 | 否定轮转解释，改查单边扩展；旧边界成为候选回试区 |
| 位于中部或结构太窄 | 当前边缘机会排除；订单类型不能修复空间不足 |

低确认触及只有在成熟边界、向内路径目标、边界外失效、期限和空间均已事前完整，且触及本身足以完成唯一尚缺条件时，才可支持完整路径；它不表示拒绝或成交已经发生。

### 第二段陷阱

必须保留以下顺序：

1. 第一段足以建立第二段预期；
2. 第二段实际出现；
3. 它到达会限制延续的边缘、磁点、测量区或成熟通道外侧；
4. 应有的继续跟随或外部接受没有出现；
5. 价格重新接受旧区域或向内部恢复。

第五步之前只能写延续预期削弱。确认后原外部路径按既有失效条件更新，内部路径仍须独立具备可达的路径目标、失效和期限。清楚趋势早期的强第二段优先按真实延续解释。

## 七、成熟双向平衡的方向决断

### 因果问题

双方继续平衡，还是某一方向完成边界外延伸条件？

### 前提与正常预期

- 双方反复测试、没有持续控制方，有效边界已识别；
- 结构内部尝试继续互相否定，直到一侧完成事前参与条件；
- 第一次越界可能失败；外部接受成立后转入单边扩展，不再沿用内部失败解释。

TTR、Triangle、ii、iii、ioi、oo、Expanding Triangle、大型 H&S 和无尽回调只描述不同几何。若局部方向仍控制当前段、正在回调、已到外层边缘或主要结构已破坏，应分别使用单边扩展、回调、边缘或控制转移卡。

**候选区域**：有效边界、边界外的旧极值或主要支撑阻力、外部接受后的回试区，以及端点固定的测量区。

### 事前参与标准

二选一，并在越界前确定：

- **低确认**：第一次精确越界可以完成参与条件；外部路径目标、回入失效、期限和空间必须已经完整。
- **确认型**：要求边界外收盘、跟随或回试守住；第一次越界仍只是未完成事实。

订单类型由 Trade 决定。看到越界结果后不得临时降低确认标准。

### 关键分支

| 新事实 | 候选更新或转移 |
| --- | --- |
| 仍在结构内部 | 低确认方向在触发、路径目标、失效和期限完整时，可支持 Market 判为路径完整；确认型继续等待形成 |
| 第一次越界 | 低确认标准获得触发事实；确认型仍等收盘、跟随或回试守住 |
| 外部接受完成 | 可支持 Market 首次建立确认型路径；已有低确认路径只更新持续能力；改查单边扩展并保留同一外部路径目标 |
| 越界失败并回到内部 | 支持外部测试失败；边缘有空间时改查轮转，回到中部则等待新的参与事实 |

外部接受只能建立或增强边界外路径，不能同时实现该路径；只有事前路径目标完成才算实现。一侧越界失败不自动完成另一侧机会。

## 八、成熟趋势的异常延伸与修正

### 因果问题

异常延伸会形成新测量段，还是衰竭并进入修正、平衡或主要反转过程？

### 前提与正常预期

- 原趋势运行较久或长期缺少有意义回调，接近事前路径目标、旧极值或通道外侧；
- 出现异常加速、最大趋势 K、连续高潮、MAG 或最后外侧突破；
- 主要结构尚未完成反方向控制转移；
- 真测量段应保持所依赖的分离并继续获得同向接受；缺乏跟随、关闭分离或回到旧区域更支持修正。

Climax、Measuring/Exhaustion Gap、Final Flag、Wedge、Parabolic Wedge、Overshoot 和 Give-up Bar 都只提出竞争问题，不直接许可反向交易。

**候选区域**：下一测量区、主要障碍、高潮起点、异常 K 另一端、突破点、EMA 和公平区。

### 关键分支

| 新事实 | 候选更新或转移 |
| --- | --- |
| 刚出现异常大 K 或加速 | 两边仍缺完成事实；等待跟随、分离保持、再创新极值或回到旧区域 |
| 分离保持并继续同向接受 | 支持最后延伸或新测量段，改查单边扩展；下一测量区或主要障碍进入候选 |
| 同向跟随停止，分离关闭或回到旧区域，并出现反向恢复 | 支持修正，但不自动支持反向趋势 |
| 修正继续展开，主要结构仍完整 | 保留时间或价格修正；原方向恢复时改查回调或单边扩展，形成稳定边界时改查边缘或成熟平衡 |
| 重叠增加、回调加深并形成边界 | 改查边缘或成熟平衡；无边界时只写原方向弱化 |
| 主要结构破坏并测试旧极值 | 改查控制转移 |

### Gap 的竞争解释

- **测量分支**：突破空间保持，普通回调未关闭事前要求的分离，并再次出现同向突破和跟随。
- **衰竭分支**：重新重叠突破点、关闭该分离、同向跟随消失，并出现反向恢复和跟随。

跟随弱但事前要求保持的分离尚未关闭时仍属未决。第一次高潮可以只终止当前段；MAG、Wedge 或超买超卖外观均不证明立即反转。

Reference 中的 TBTL 只提供“修正通常需要足够时间，并常以两段横向至反向运动展开”的来源预期。运行中仍按原方向恢复、稳定边界形成或主要结构破坏选择下一张卡，不建立 TBTL 状态，也不把十根 K 或两段作为机械完成条件。

## 九、趋势破坏后的控制转移

### 因果问题

旧控制能够恢复，市场先进入平衡，还是反方向建立持续控制？

### 前提与正常预期

- 原方向曾有真实控制，当前问题已从普通回调变成旧控制能否恢复；
- 至少出现主要结构破坏、旧极值测试、恢复失败或新 HL/LH 之一；
- 第一次受损后旧方向仍可能测试旧极值并恢复；旧极值测试失败后反方机会才更清楚；反方向突破并获得接受后才完成持续控制转移。

MTR、H&S、Double Test、Wedge 和第一根逆势 Signal Bar 不能单独建立本场景。完整 Tight Channel 中孤立的第一次逆势信号仍留在单边或回调卡。

**候选区域**：旧趋势极值、被破坏的主要结构、新 HL/LH、反向 Swing、两段修正区域和内部平衡区。

### 因果阶段

```text
原趋势弱化
→ 主要结构破坏
→ 旧极值测试或恢复尝试
→ 测试失败并形成新 HL/LH 或第二次反向发展
→ 反方向突破和跟随建立接受
```

### 关键分支

| 新事实 | 候选更新或转移 |
| --- | --- |
| 第一次逆势事实，尚无完整破坏 | 反方向路径仍不完整；等待更强进展、主要结构破坏、旧极值测试或第二信号 |
| 结构破坏但旧极值测试未完成 | 原趋势恢复与反方向接管都未决；趋势线破坏不等于反向趋势 |
| 旧极值测试失败并反向恢复 | 支持早期反向 Swing；仍只选一个当前路径目标 |
| 新方向突破并获得接受 | 支持持续控制转移，改查新方向单边扩展；旧路径仍按事前确定的最终条件判断 |
| 原趋势重新建立 | 否定当前反转路径；旧计数和候选不继续累积，未来反转从新事实开始 |

很多反转先进入 Trading Range；“主要反转”名称不保证永久反向趋势。少数异常强反向事件可以快速切换控制，但仍必须在重要区域否定旧控制。固定 Session 的时间压缩不能照搬到没有对应 Session 的连续市场。

## 十、结束导航

Market 采用候选事实后立即返回主流程。尚缺事实时记录下一事实和期限；没有可达的路径目标、空间、时间或形成条件时记录当前排除。新名称是否值得改变方法由[复盘与治理](governance.md#新名称怎样归并)盘后处理。
