# 市场场景：按问题查预期

本页提供各背景下的正常预期、竞争解释、区分事实与相关区域，供 [Market](market.md) 按问题查阅；共用判断规则引用 Market，参与方式与管理由 [Trade](trade.md) 评价。

## 一、使用边界

- **首次理解或持续更新时，预期、正常回调或相关区域不清楚** → 查对应场景。
- **同一运动涉及多个场景** → 保留各自尺度、参照和条件；无需选出唯一标签，也不逐类检查。

## 四、单边失衡继续扩展

当前问题：已经取得的单向进展能否保持，接下来是继续扩展还是逐步转为双向运动？

### 背景与正常预期

适用背景：突破已获跟随，或连续同向表现形成失衡；分离、极值推进和回撤边界仍有效。此前原方向能扩展并保住进展，逆向尝试难以持续。

延伸预期：继续推进，或浅回调后恢复。更新时比较恢复速度、逆向空间，以及原方向收回失地的能力；对应分支见下表。

Breakout、Spike、Always In、Tight Channel、Small Pullback Trend、Microchannel 和已接受的 Range 突破，可以共享上述进展事实。

**候选区域**：下一结构极值、主要支撑阻力、第二段投射区域及端点固定的测量区。

### 关键事实

| 条件 | 当前含义 | 后续观察或研究 |
| --- | --- | --- |
| 第一根强 K 或第一次越界 | 核对已完成的进展；尚需的跟随、分离保持或回试仍未决 | 观察尚缺的事实 |
| 突破后延伸、保持在外或回试守住，完成事前要求；或浅回调后迅速恢复 | 延伸依据增强 | 结合近端障碍、剩余空间与期限评价下一目标 |
| 第一次有意义回调 | 紧密趋势的首次逆向尝试通常先形成有限回调 | 与原正常边界比较，按[回调测试与恢复](#五原趋势中的回调测试与恢复)找恢复条件 |
| 跟随减弱、分离关闭、重叠增加、回调加深、恢复变慢或反方保住进展，尚未完成失败条件 | 延续削弱；原方向仍可能恢复，也可能通道化或双边化 | 有稳定边界 → 研究边缘与突破；无稳定边界 → 比较原方向恢复与反方发展 |
| 回入旧区域，完成本次突破的失败条件 | 本次突破失败 | 方向路径按自己的失效条件评价；仍可能通过回调恢复 |
| 接近外层边缘或目标 | 当前位置可能限制推进 | 目标已完成 → 按原条件保留结果；再研究该处暂停、回调或后续路径 |
| 趋势晚期在目标或通道外侧异常加速、出现最大趋势 K | 满足异常延伸背景时，修正解释值得比较 | 查[异常延伸与修正](#八成熟趋势的异常延伸与修正) |

逆向机会按 [通道的进展与空间比较](market.md#34-市场结构与持续能力)处理：

- **触发后进展反复被收回，空间不足以支持拟定目标** → 先观察回调、重评顺势仓位。
- **逆向发展扩大** → 再评价新的参与方式；有限回调与反向趋势各用自己的目标和风险。
- **原方向持续能力仍清楚** → 可研究当前延伸或下一次回调后的恢复；Trade 仍按实际入场、止损和剩余空间判断是否适合追价。

Staircase、Trending Trading Range 保留倾斜、重叠、回撤和边界差别，不因共同支持双边化而合并这些关系。

## 五、原趋势中的回调测试与恢复

当前问题：逆向运动是正常测试、转入平衡，还是开始破坏原趋势？

### 背景与正常预期

适用背景：原方向此前有持续能力，主要趋势段或 Swing 尚未被反方向越过并在外保住进展。用此前回调停止的位置、持续时间和恢复方式比较本次逆向运动。

恢复预期：回调在相应结构内停止，并在预期期限内恢复。主要结构完整与本次恢复有力分别判断；边界未破也可以出现持续能力减弱。

**候选区域**：EMA、固定趋势段比例、趋势线或通道线、旧突破点、前高低、主要 HL/LH、趋势段起点、信号或突破 K 边界，以及开放突破回调 Gap。参照和它的预期作用应在对应结果前明确。

H1/H2、L1/L2、Double Test、Flag、Wedge Flag 和 Breakout Pullback 保留各自次序与边界，用来解释恢复发生在哪里、已经经历哪些尝试。

Final Flag 可很短，也可出现在区间内的局部趋势中：

- **旗形接近限制当前段的区域，且反方压力增强** → 考虑顺势突破失败、结束当前段的可能。
- **同时出现成熟、高潮或异常延伸** → 怀疑增加，查[异常延伸与修正](#八成熟趋势的异常延伸与修正)。

后续按实际延续或失败更新候选；反向目标绑定被结束的趋势段尺度。

### 关键事实

| 条件 | 当前含义 | 后续观察或研究 |
| --- | --- | --- |
| 接近参照但尚未触及 | 位置测试仍待发生 | 等待测试，不预记触及 |
| 实际触及参照 | 只完成位置条件 | 停止并恢复、穿越后交还，还是在外保住进展？拒绝、恢复与接受另判 |
| 参照处拒绝并恢复原方向；回调较浅且恢复顺利也提供支持 | 恢复依据增强 | 近端通常看旧趋势极值；更远目标需说明如何通过它 |
| 一次恢复失败，反方仍缺跟随 | 本次失败已发生；旧方向路径仍可能有效 | 观察是否只是较深回调，以及下一次恢复 |
| 穿越 EMA、趋势线或比例参照，主要结构仍完整 | 不自动表示该参照受损 | 按事前作用及允许的复测、恢复条件更新；主要结构独立评价 |
| 回调加深、延长，并伴随恢复反复失败或双向化 | 原恢复预期弱化，平衡或反向发展更有依据 | 有边界 → 研究轮转或突破；无稳定边界 → 比较恢复与反向发展 |
| 主要结构被越过，反方取得并保住进展 | 旧恢复解释受到否定 | 结合各路径自身失效条件，研究[反向发展](#九旧控制受损后的恢复与反向发展) |

### 重要变体

- **长期未触 EMA 后首次测试**：参数事前固定；触及、收于另一侧、整根位于另一侧及主要结构外接受分别判断。整根穿越 → 反方进展增加，继续看能否保住或扩展。
- **深回调而较大 Broad Channel 仍有效** → 短周期可暂时反向；外层主要结构与目标按自身条件判断。
- **紧密微型通道首次微型趋势线突破** → 通常先看正常回调。趋势晚期 → 同时检查异常修正；已有足够反向发展 → 研究旧控制受损，不机械等待固定信号数。

## 六、双边结构边缘的反应与轮转

当前问题：可识别边缘会拒绝并向内部轮转，还是本次能在边界外保住进展并延伸？

### 背景与正常预期

适用背景：双方已能反复推动、反转，上下边界在本次到达前可识别。当前比较本次互动是否改变了边缘此前的作用。

- **此前边缘多次把价格送回内部** → 支持再次拒绝。
- **本次到达前持续推进、回撤有限** → 可能支持向外延伸。

两组依据可以同时成立；结合到达强弱与边缘处已完成的反应判断，尚缺的保持或恢复继续观察。

Broad Channel 仍保留倾斜和主要 HL/LH，成熟 Trading Range 更重视内部轮转。Range Edge、Failed Breakout、Overshoot、Vacuum Test、Double Test 和 Second-leg Trap 使用同一边缘事实，但保留不同次序。

**候选区域**：当前边界、外部测试极值、内部公平区或中部、对侧边界，以及外部接受后的旧边界回试区。

### 关键事实

| 条件 | 当前含义 | 后续观察或研究 |
| --- | --- | --- |
| 尚未到边缘 | 边缘可作为当前段的候选目标 | 局部方向清楚 → 使用延伸或回调预期 |
| 刚到边缘或轻微越界 | 普通越界可能只是测试；两种发展仍未决 | 与此前测试比较，观察回撤位置与恢复 |
| 突破后在外保持、回试守住或继续扩展 | 外部延伸依据增强 | 原轮转失效条件已完成 → 否定原轮转预期，研究旧边界回试；未完成 → 保留待观察部分 |
| 边缘拒绝或外部尝试失败，向内取得进展；回入后向外恢复失败并继续向内 | 向内轮转依据增强 | 先看公平区或中部；更远对侧目标需处理内部障碍 |
| 位于中部或结构太窄 | 边缘假设缺少位置或空间 | 重新寻找有意义的区域与运动 |

成熟边界的向内目标、外部失效、期限与空间可以在触及前评价。Trade 比较：

- **触及参与** → 拒绝仍是尚未发生的假设。
- **拒绝确认后参与** → 使用已经完成的拒绝事实评价当时方案。

### 第二段陷阱

完整次序与未完成阶段按 [Market 的第二段判据](market.md#第二段预期怎样受损或失败)判断。本场景重点看第二段到达的边缘是否限制延续，以及之后向内的进展与向外恢复。清楚趋势早期的强第二段更支持真实延续，不直接套用陷阱解释。

- **应有跟随已缺失，但失败条件尚未完成** → 先记延续偏弱。
- **失败条件完成** → 外部路径按自身条件评价。

内部路径按自己的目标、完成、失效和期限评价。

## 七、成熟双向平衡的方向决断

当前问题：双方继续平衡，还是某一方向能够在边界外延伸？

### 背景与正常预期

适用背景：双方围绕已识别边界反复测试，尚无持续控制方，内部突破容易被对手交还。比较本次与此前失败尝试的进展、交还和受阻后恢复。

- **此前多次尝试不能延续** → 支持继续平衡。
- **本次推进更远、交还更少，并在受阻后恢复** → 为离开平衡提供依据。

第一次越界仍可能失败；压缩或扩张的几何不决定方向，一侧缺少延伸也不代替另一侧的进展。

TTR、Triangle、ii、iii、ioi、oo、Expanding Triangle、大型 H&S 和无尽回调，保留各自压缩、扩张、边界或恢复次序。较小结构位于外层边缘时，同时采用边缘预期。

**候选区域**：有效边界、边界外旧极值或主要支撑阻力、旧边界回试区及端点固定的测量区。

### 参与所用的市场事实

边界、外部目标、回入失效和期限可以在越界前组成条件路径。Trade 比较不同参与时点的价格和风险，授权时明确所用条件：

- **提前参与** → 尚未出现的收盘、跟随或回试保留为假设。
- **等待收盘、跟随或回试** → 所需事实完成后按当时价格评价。

Market 共享同一路径的事实，按事件实际完成程度更新。

### 关键事实

| 条件 | 当前含义 | 后续观察或研究 |
| --- | --- | --- |
| 仍在结构内部 | 继续平衡与外部发展均需比较 | 看双方条件路径及边界外空间 |
| 第一次越界 | 与此前越界比较本次进展 | 尚需收盘、跟随或回试 → 继续观察 |
| 边界外收盘、延伸、保持或回试守住完成事前要求 | 延伸持续能力得到支持 | 重看剩余空间；同根 K 也可能完成事前目标 → 分别核对接受与目标结果 |
| 越界失败并回到内部 | 本次外部尝试失败，内部交易更有依据 | 再次向外恢复失败 → 加强内部交易依据；边缘有向内空间 → 研究轮转；已回中部 → 重看局部运动 |

一侧失败后，另一方向仍需自己的进展、目标与失效条件。

## 八、成熟趋势的异常延伸与修正

当前问题：异常延伸是新测量段，还是当前运动衰竭并进入修正？

### 背景与正常预期

适用背景：趋势持续扩展或长期缺少有意义回调，接近目标、旧极值或通道外侧，并出现异常加速、最大趋势 K、连续高潮、MAG 或最后外侧突破。

- **异常推进取得更多同向进展** → 支持延伸，继续看能否保持。
- **长期单向运动叠加限制位置** → 修正值得比较，继续看进展是否被交还。

两组依据可同时存在；异常 K 大小本身不决定测量、时间修正或价格修正。

Climax、Measuring/Exhaustion Gap、Final Flag、Wedge、Parabolic Wedge、Overshoot 和 Give-up Bar 提供竞争问题。异常外观本身不等于反向趋势。

**候选区域**：下一测量区、主要障碍、高潮起点、异常 K 另一端、突破点、EMA 和公平区。

### 关键事实

| 条件 | 当前含义 | 后续观察或研究 |
| --- | --- | --- |
| 刚出现异常大 K 或加速 | 延伸、停止跟随、回到旧区域仍需比较 | 按背景与空间确定相应观察条件 |
| 分离保持，同向推进继续取得并保住进展 | 最后延伸或新测量段依据增强 | 重看下一目标与障碍 |
| 跟随减弱、重新重叠或回到旧区域 | 修正更有依据 | 比较随后恢复与进展交还 |
| 同向进展停止、重叠增加，但 Gap 仍开放 | 可以是时间修正 | 特定 Gap 关闭尚未发生 → 该诊断仍未决 |
| 分离关闭或回到旧区域，并出现反向恢复 | 价格修正依据增强 | 反向趋势仍需自己的持续进展 |
| 修正展开，主要结构仍完整 | 原方向恢复与双边化均可研究 | 看恢复或稳定边界形成，保留各自目标和期限 |
| 旧方向恢复失败，反方持续发展 | 反向发展依据增强 | 查[旧控制受损后的恢复与反向发展](#九旧控制受损后的恢复与反向发展) |

### Gap 的竞争解释

同次突破留下的多个 Gap 各有比较对象和关闭时点，逐项引用：

- **普通回调保住所引用的分离，随后再次延伸** → 支持测量解释。
- **该分离关闭、旧区域重新交易，原方向失去跟随** → 检查衰竭诊断及之后的恢复。

原方向停止或时间修正不替代特定 Gap 关闭，也不自动说明反向趋势。第一次高潮终止当前段后，仍可能有第二段延伸。

修正常以两段横向至反向运动消化此前单边运动。按当时结构与剩余时间安排观察：原方向恢复、稳定边界形成、反方持续进展分别更新；修正是否完成仍按事前条件判断。

## 九、旧控制受损后的恢复与反向发展

当前问题：旧方向能够恢复、市场先转平衡，还是反方向能够形成 Swing 乃至持续控制？

### 背景与正常预期

适用背景：原方向曾有持续控制，现因反向压力、旧极值测试或恢复失败受到实质挑战。先分清受损的是趋势线、局部运动还是主要结构。

- **旧方向此前有持续能力** → 保留恢复并再次测试旧极值的解释。
- **反方取得进展、旧方向恢复失败** → 原延续预期减弱，研究平衡或反向发展。
- **反向持续能力尚未建立** → 同时研究先转平衡，观察双方推进、恢复与边界形成。

MTR、H&S、Double Test 和 Wedge 保留旧极值、反向运动、恢复次序和边界的区别。

**候选区域**：旧趋势极值、被测试或破坏的结构、新 HL/LH、反向 Swing 极值、两段修正区域和内部平衡区。

### 典型次序与关键事实

典型 MTR 次序：反向压力打破趋势线或通道 → 旧方向测试极值或恢复 → 恢复失败并形成反向发展。

可据此研究早期 Swing；持续控制还需反方延伸并组织正常回调。足够强的事件可使过程很快完成。

| 条件 | 当前含义 | 后续观察或研究 |
| --- | --- | --- |
| 首次逆向进展出现，主要结构仍完整 | 尚不足以判反方接管；完整 Tight Channel 中孤立的首次逆势信号通常先支持有限回调 | 与旧趋势惯性比较逆向规模和跟随，评价有限目标或等待 |
| 通道较宽，有足够反向压力与失败恢复 | 更有意义的反向 Swing 获得支持 | 即使主要结构完整，也可按局部尺度与近端区域研究机会 |
| 趋势线或主要结构受损，旧极值测试未完成 | 旧方向恢复与反向发展仍需比较，尚不能判反方接管 | 看旧极值测试，以及反方能否保住进展 |
| 旧极值测试失败并反向恢复，形成新 HL/LH | 早期反向 Swing 依据增强；旧持续控制仍可能存在 | 先看反向段极值或内部区域；继续看反方回调后能否再延伸 |
| 新方向突破并取得持续进展 | 支持控制转移 | 按新背景研究延伸；旧路径按原结果条件评价 |
| 原趋势恢复，形成新的有效趋势段 | 原反转序列失去当前作用 | 按恢复对象重置计数；新反转预期使用新事实 |

- **主要反转尝试先形成 Trading Range，或 Swing 已达目标** → 不据此断言永久反向趋势。
- **确有对应的固定 Session** → 才使用该时段的时间压缩。
