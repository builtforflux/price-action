# 常见市场场景：按因果问题查询市场知识

> 本页只在 Market 已明确市场组织、活动重要区域和当前互动，却仍缺合理预期或双向路径时使用。

六张卡按因果问题组织知识，不拥有运行状态，不定义交易。提取候选事实后写回 [Market](market.md) 并关闭本页；入场、保护和退出由 [Trade](trade.md) 负责。

## 一、使用边界

```text
明确市场组织、活动区域和当前互动
→ 选择一个主要因果问题
→ 提取正常预期、竞争分支、关键事实和候选区域
→ Market 裁决测试与路径
→ 关闭场景页
```

默认只开一张卡；两个独立测试可以临时使用两张，最终仍汇入现有双向路径。首次分析、主测试替代、组织或控制实质变化，以及旧路径终局后提出新问题时重新选择；普通新 K 只增量更新 Market。

所有卡共享以下契约，不在各卡重复：

- 名称只提供候选视图，不增加证据、概率、风险预算或流程；
- 强初始行为不等于接受；接受、失败、优势和路径完整条件以 [Market 的共同判断语法](market.md#36-当前区域互动价格表现与预期差)为准；
- 一侧削弱或失败不自动完成另一侧路径，竞争方向必须独立取得并保住进展；
- 候选区域写回 Market 后才取得目标、障碍、检查点或失效职责；每条路径仍只选一个完成目标；
- 换卡不自动终结、替代或建立路径；Market 只按可见事实更新；
- 触价只有在事前被定义为能够原子性完成唯一尚缺条件时才可能完成路径；收盘、跟随、回试守住或持续接受不能由订单触发代替；
- 固定概率、K 数和产品参数不是生产许可。

| 当前主要问题 | 使用场景 |
| --- | --- |
| 清楚单边控制，没有有意义逆向运动 | [单边失衡继续扩展](#四单边失衡继续扩展) |
| 原控制仍在，正在发生逆向回调 | [原趋势中的回调测试与恢复](#五原趋势中的回调测试与恢复) |
| 已到可识别双边边缘，判断拒绝还是外部接受 | [双边结构边缘的反应与轮转](#六双边结构边缘的反应与轮转) |
| 双方反复测试且没有持续控制，判断哪侧完成决断 | [成熟双向平衡的方向决断](#七成熟双向平衡的方向决断) |
| 原趋势成熟或异常延伸，主要结构尚未进入控制接管 | [成熟趋势的异常延伸与修正](#八成熟趋势的异常延伸与修正) |
| 主要结构已破坏，判断旧控制恢复还是反方接管 | [趋势破坏后的控制转移](#九趋势破坏后的控制转移) |

## 三、导航输出

每张卡只提供四类候选：

1. 当前解释成立时的正常预期；
2. 竞争结果及其关键支持、削弱或否定事实；
3. 可能进入活动图的区域来源；
4. 主问题改变后应查询的下一张卡。

Market 据此形成接受、失败或未决，以及路径完整、等待形成或当前排除；本页不重复这些运行结构。

## 四、单边失衡继续扩展

### 因果问题

已建立的单边控制能否保持，并在期限内到达当前完成目标？

### 前提与正常预期

- 一侧已有清楚控制，突破获得跟随或连续同向表现形成有效失衡；
- 延续所依赖的分离、极值推进或结构仍保持，到下一现实障碍有空间和时间；
- 正常表现是保持分离、扩展极值，或浅回调后快速恢复；第一次逆向尝试通常只形成有限回调。

Breakout、Spike、Always In、Tight Channel、Small Pullback Trend、Microchannel 和已接受的 Range 突破共享这些事实，不各自建立流程。

**候选区域**：下一结构极值、主要支撑阻力、第二段目标，以及端点固定的测量区。

### 关键分支

| 新事实 | 候选写回或转移 |
| --- | --- |
| 第一次越界或第一根强 K | 等待事前要求的跟随、分离保持或回试结果；不能宣布新趋势 |
| 突破获得跟随并建立接受 | 支持 Market 判断原方向延伸，并从候选区域中按近端障碍和期限选择当前完成区域 |
| 第一次有意义回调 | 保留原控制、目标和失效，改查[回调测试与恢复](#五原趋势中的回调测试与恢复) |
| 跟随不足但尚未重新接受旧区域 | 原延续预期削弱；优先检查通道化或双边化 |
| 重新接受旧区域 | 否定原突破测试；反方向仍须自己的进展与跟随 |
| 晚期异常加速、最大趋势 K 或接近目标 | 改查[异常延伸与修正](#八成熟趋势的异常延伸与修正) |

Tight Channel 的第一次逆势信号通常只支持小回调；只有反方向自身的目标、失效和期限完整时，才可能形成方向机会。无漂亮 Signal Bar 不否定强趋势，但保护距离和追价质量交给 Trade。

## 五、原趋势中的回调测试与恢复

### 因果问题

当前逆向运动是正常测试、转入平衡，还是开始破坏原趋势？

### 前提与正常预期

- 原控制仍有效，最近主要趋势段或 Swing 尚未被反方向接受；
- 健康回调应在主要结构内停止，并在期限内恢复原方向；
- 首次触及参照不等于恢复，除非事前低确认条件明确允许触及完成唯一尚缺事实；
- 回调越深、越久且原方向反复恢复失败，平衡或控制转移分支越强。

**候选区域**：EMA、固定趋势段比例、趋势线或通道线、旧突破点、前高低、主要 HL/LH、趋势段起点、信号或突破 K 边界及开放突破回调 Gap。参照必须在测试前或到达时明确。

H1/H2、L1/L2、Double Test、Flag、Wedge Flag 和 Breakout Pullback 只保留独有次序或边界。

### 关键分支

| 新事实 | 候选写回或转移 |
| --- | --- |
| 接近或刚触及参照 | 等待拒绝、恢复、继续穿越或参照外接受；不得事后把“需恢复”降为“触及即可” |
| 参照处拒绝并恢复原方向 | 支持恢复；近端候选通常是旧趋势极值，更远区域只有在近端已分类后才考虑 |
| 穿越参照但主要结构完整 | 原方向削弱或测试未决；EMA、趋势线或 50% 的单次穿越不等于反转 |
| 回调加深、延长并双向化 | 已有边界时改查边缘或成熟平衡；无边界时不沿旧趋势增加风险 |
| 主要结构破坏并获得反向接受 | 否定原恢复解释；改查[控制转移](#九趋势破坏后的控制转移) |

### 重要变体

- **长期未触 EMA 后首次测试**：区分触及、收于另一侧、整根位于另一侧和主要结构外接受。整根穿越可增强反方初始行为，但优势转移仍需要跟随；EMA 参数盘前固定，来源根数不作机械许可。
- **深回调但较大 Broad Channel 有效**：短周期可暂时反向；较大主要结构被接受性突破前，不因回调深或价格更便宜改变外层路径。
- **紧密微型通道首次微型趋势线突破**：默认先按正常回调；趋势晚期改查异常修正，主要结构破坏后改查控制转移。低周期只能细化入场，不能改写高周期目标和失效。

## 六、双边结构边缘的反应与轮转

### 因果问题

可识别边缘会拒绝并向内部轮转，还是边界外获得接受？

### 前提与正常预期

- 双方已经能反复推动和获利，上下边界在本次到达前可识别；
- 当前位于真实边缘，向内部候选区域有空间和时间，边界外尚无持续接受；
- 普通越界可能只是流动性测试；真突破应在外保持分离、获得跟随或回试守住。

Broad Channel 保留倾斜方向和主要 HL/LH；成熟 Trading Range 更重视公平区轮转。Range Edge、Failed Breakout、Overshoot、Vacuum Test、Double Test 和 Second-leg Trap 共享边缘测试事实。

**候选区域**：当前边界、外部测试极值、内部公平区或中部、对侧边界，以及外部接受后的旧边界回试区。

### 关键分支

| 新事实 | 候选写回或转移 |
| --- | --- |
| 尚未到边缘 | 边缘只是当前段候选目标；局部控制清楚时改查单边扩展或回调 |
| 刚到边缘或轻微越界 | 等待回到内部、外部接受或再次测试；Overshoot 不等于突破 |
| 边缘拒绝或外部尝试失败 | 支持向内部轮转；近端通常是公平区或中部，未处理近端前不选更远对侧目标 |
| 边界外获得接受 | 否定轮转解释，改查单边扩展；旧边界成为候选回试区 |
| 位于中部或结构太窄 | 当前边缘机会排除；订单类型不能修复空间不足 |

低确认触及只有在成熟边界、向内目标、边界外失效、期限和空间均已事前完整，且触及能原子性完成唯一尚缺条件时，才可支持完整路径；它不表示拒绝或成交已经发生。

### 第二段陷阱

必须保留以下顺序：

1. 第一段足以建立第二段预期；
2. 第二段实际出现；
3. 它到达会限制延续的边缘、磁点、测量区或成熟通道外侧；
4. 应有的继续跟随或外部接受没有出现；
5. 价格重新接受旧区域或向内部恢复。

第五步之前只能写延续预期削弱。确认后原外部路径按既有失效条件更新，内部路径仍须独立具备现实目标、失效和期限。清楚趋势早期的强第二段优先按真实延续解释。

## 七、成熟双向平衡的方向决断

### 因果问题

双方继续平衡，还是某一方向完成边界外延伸条件？

### 前提与正常预期

- 双方反复测试、没有持续控制方，活动边界已识别；
- 结构内部尝试继续互相否定，直到一侧完成事前参与条件；
- 第一次越界可能失败；外部接受成立后转入单边扩展，不再沿用内部失败解释。

TTR、Triangle、ii、iii、ioi、oo、Expanding Triangle、大型 H&S 和无尽回调只描述不同几何。若局部方向仍控制当前段、正在回调、已到外层边缘或主要结构已破坏，应分别使用单边扩展、回调、边缘或控制转移卡。

**候选区域**：活动边界、边界外的旧极值或主要支撑阻力、外部接受后的回试区，以及端点固定的测量区。

### 事前参与标准

二选一，并在越界前冻结：

- **低确认**：第一次精确越界可以完成参与条件；外部目标、回入失效、期限和空间必须已经完整。
- **确认型**：要求边界外收盘、跟随或回试守住；第一次越界仍只是未完成事实。

订单类型由 Trade 决定。看到越界结果后不得临时降低确认标准。

### 关键分支

| 新事实 | 候选写回或转移 |
| --- | --- |
| 仍在结构内部 | 低确认方向在触发、目标、失效和期限完整时，可支持 Market 判为路径完整；确认型继续等待形成 |
| 第一次越界 | 低确认标准获得触发事实；确认型仍等收盘、跟随或回试守住 |
| 外部接受完成 | 可支持 Market 首次建立确认型路径；已有低确认路径只更新持续能力；改查单边扩展并保留同一外部目标 |
| 越界失败并回到内部 | 支持外部测试失败；边缘有空间时改查轮转，回到中部则等待新的参与事实 |

外部接受只能建立或增强边界外路径，不能同时实现该路径；只有事前外部完成目标发生才算实现。一侧越界失败不自动完成另一侧机会。

## 八、成熟趋势的异常延伸与修正

### 因果问题

异常延伸会形成新测量段，还是衰竭并进入修正、平衡或主要反转过程？

### 前提与正常预期

- 原趋势运行较久或长期缺少有意义回调，接近事前目标、旧极值或通道外侧；
- 出现异常加速、最大趋势 K、连续高潮、MAG 或最后外侧突破；
- 主要结构尚未完成反方向控制转移；
- 真测量段应保持所依赖的分离并继续获得同向接受；缺乏跟随、关闭分离或回到旧区域更支持修正。

Climax、Measuring/Exhaustion Gap、Final Flag、Wedge、Parabolic Wedge、Overshoot 和 Give-up Bar 都只提出竞争问题，不直接许可反向交易。

**候选区域**：下一测量区、主要障碍、高潮起点、异常 K 另一端、突破点、EMA 和公平区。

### 关键分支

| 新事实 | 候选写回或转移 |
| --- | --- |
| 刚出现异常大 K 或加速 | 两边仍缺完成事实；等待跟随、分离保持、再创新极值或回到旧区域 |
| 分离保持并继续同向接受 | 支持最后延伸或新测量段，改查单边扩展；下一测量区或主要障碍进入候选 |
| 同向跟随停止，分离关闭或回到旧区域，并出现反向恢复 | 支持修正，但不自动支持反向趋势 |
| 重叠增加、回调加深并形成边界 | 改查边缘或成熟平衡；无边界时只写原方向弱化 |
| 主要结构破坏并测试旧极值 | 改查控制转移 |

### Gap 的竞争解释

- **测量分支**：突破空间保持，普通回调未关闭事前要求的分离，并再次出现同向突破和跟随。
- **衰竭分支**：重新重叠突破点、关闭该分离、同向跟随消失，并出现反向恢复和跟随。

跟随弱但关键分离未关闭时仍属未决。第一次高潮可以只终止当前段；MAG、Wedge 或超买超卖外观均不证明立即反转。

## 九、趋势破坏后的控制转移

### 因果问题

旧控制能够恢复，市场先进入平衡，还是反方向建立持续控制？

### 前提与正常预期

- 原方向曾有真实控制，当前问题已从普通回调变成旧控制能否恢复；
- 至少出现主要结构破坏、旧极值测试、恢复失败或新 HL/LH 之一；
- 第一次受损后旧方向仍可能测试旧极值并恢复；旧极值测试失败后反方机会才更清楚；反方向突破并获得接受后才完成持续控制转移。

MTR、H&S、Double Test、Wedge 和第一根逆势 Signal Bar 不能单独建立本场景。完整 Tight Channel 中孤立的第一次逆势信号仍留在单边或回调卡。

**候选区域**：旧趋势极值、被破坏的主要结构、新 HL/LH、反向 Swing、两段修正区域和内部平衡区。

### 因果阶段

```text
原趋势弱化
→ 主要结构破坏
→ 旧极值测试或恢复尝试
→ 测试失败并形成新 HL/LH 或第二次反向发展
→ 反方向突破和跟随建立接受
```

### 关键分支

| 新事实 | 候选写回或转移 |
| --- | --- |
| 第一次逆势事实，尚无完整破坏 | 反方向路径仍不完整；等待更强进展、主要结构破坏、旧极值测试或第二信号 |
| 结构破坏但旧极值测试未完成 | 原趋势恢复与反方向接管都未决；趋势线破坏不等于反向趋势 |
| 旧极值测试失败并反向恢复 | 支持早期反向 Swing；仍只选一个当前完成目标 |
| 新方向突破并获得接受 | 支持持续控制转移，改查新方向单边扩展；旧路径仍按冻结终局条件裁决 |
| 原趋势重新建立 | 否定当前反转路径；旧计数和候选不继续累积，未来反转从新事实开始 |

很多反转先进入 Trading Range；“主要反转”名称不保证永久反向趋势。少数异常强反向事件可以快速切换控制，但仍必须在重要区域否定旧控制。固定 Session 的时间压缩不能照搬到没有对应 Session 的连续市场。

## 十、结束导航

候选事实写回 Market 后立即关闭本页。尚缺事实时记录下一事实和期限；没有现实目标、空间、时间或形成条件时记录当前排除。新名称是否值得改变方法由[复盘与治理](governance.md#新名称怎样归并)盘后处理。
