# 市场场景：按问题查预期

场景用于确定当前背景下的预期、重要位置和改判条件。共用判据见 [Market](market.md#36-区域互动与预期更新)，参与和管理见 [Trade](trade.md)。

## 一、使用方式

先识别市场状态、重要位置和当前运动，再查影响当前判断的场景。同一运动可以同时属于局部趋势与较大区间，分别保留尺度和条件；无需逐类检查或选出唯一名称。状态不清时，按 [Market](market.md#结构不清时的保守处理)限制参与范围。

将相关预期用于当前判断，按 [Market 双向比较](market.md#34-市场结构与持续能力)观察双方实际成果，再用后续区分延续、受阻或平衡。支持到达边界的依据只覆盖所研究的运动，穿过边界后的发展另行判断。随新事实按 [Market 普通更新](market.md#42-普通更新)处理。记录沿用[最小记录](../practice/README.md#五最小记录)，不另写场景摘要。

## 二、场景索引

各场景改变的是正常预期、相关位置或后续区分条件。共用的推进、保留与恢复关系不变，具体含义须放回背景：

| 相似局部表现 | 背景差异怎样改变问题 |
| --- | --- |
| 强势上涨、回调很浅 | 区间内部先研究到上沿；已在上沿则比较拒绝与界外延伸；处于新突破且前方有空间才进一步研究延续 |
| 首次明显下跌 | 紧密上涨中先核对正常回调；较宽通道中可有局部反向空间；旧侧多次恢复失败后还须研究反向持续能力 |
| 停顿、重叠增加 | 保住关键进展时可能是允许的整理；依赖立即推进或剩余时段很短的方案可能已受损 |
| 第二段很强 | 趋势早期可增强延续依据；到达成熟边缘时仍需检验边界限制；两段完成本身不决定退出或反转 |

这些对照用于选择当前问题，不产生独立交易许可。背景尚不清楚时保留缺项；不要为了采用熟悉场景而补画边界或改变所研究尺度。

| 当前情况 | 要判断什么 |
| --- | --- |
| [趋势继续推进](#三趋势继续推进) | 能否延续，还是开始双向波动？ |
| [趋势中出现回调](#四趋势中出现回调) | 回调是否正常，何处可能恢复？ |
| [价格到达区间或宽通道边缘](#五价格到达区间或宽通道边缘) | 返回内部，还是突破后在外延伸？ |
| [区间反复测试边界](#六区间反复测试边界) | 继续震荡，还是有新的突破依据？ |
| [趋势异常加速或持续过久](#七趋势异常加速或持续过久) | 继续延伸，还是开始修正？ |
| [趋势受损后尝试反转](#八趋势受损后尝试反转) | 原趋势恢复、转为区间，还是形成反向运动？ |

### 固定 Session 中的背景与等待

Session 是上述场景的条件修正。仅在产品有明确 Session、开收盘确实影响当前判断时使用：

- **开盘**：昨日清楚趋势可提供主要背景，今日已有强反向压力及测试或失败恢复时，局部反转结构可以较短；这不压缩后续修正或价格目标的发展时间。
- **临近日内退出期限**：剩余时间不足以容纳普通修正后再到目标，且原方案依赖快速推进时，停顿或恢复迟缓会更早损害持有前提。按 [Trade](trade.md#33-交易前提路径失效与保护性止损)重评并执行既定到期动作，不以较大方向未变继续等待。

## 三、趋势继续推进

价格持续创新高（或新低），回调有限，逆向运动难以持续，原有 Gap 与回调边界仍有效 → 先期待延续，或浅回调后继续。依据可以来自突破后的跟随，也可以来自连续同向运动。

强突破后涨跌幅未明显回吐，前方仍有空间 → 可研究暂停或正常回调后的[第二段](market.md#第二段预期与分段尺度)。若这些依据支持新趋势段，并需估计突破 Swing 的持续时间与分段，可参考 [TBTL](market.md#tbtl-与运动尺度)。

紧密趋势的首次有意义逆向运动通常先形成有限回调，可以寻找原方向的恢复条件。其幅度、时间与恢复是否仍正常，按 [回撤与恢复](market.md#回撤与恢复怎样改变原判断)比较；逆向发展扩大时，按 [通道的进展与空间](market.md#34-市场结构与持续能力)重看双向机会，有限回调与反向趋势各用自身目标和风险。

**位置改变预期的地方：**下一结构极值、主要支撑阻力、第二段投射或测量区都只是候选。接近外层边缘或目标时，当前推进可能受限；趋势晚期又在目标或通道外侧异常加速、出现最大趋势 K → 比较[异常延伸与修正](#七趋势异常加速或持续过久)。原方向仍强，也须由 Trade 按当时入场、止损与剩余空间评价是否适合追价。

### 延续方式怎样变化

Staircase 的新极值之后，回调可重新越过此前突破点，形成重叠；Shrinking Stairs 描述每次超越旧极值的新增量缩小。新增量缩小只说明向外扩展减少，不等于回吐增多；回调是否加深、恢复是否变慢分别比较。前者影响继续向远处推进的依据，后两者影响浅回调或快速恢复的预期，各按当前背景与原预期判断。

Trending Trading Range 按区间—短突破—新区间的序列观察。新区间与旧区间分离，说明所选两个范围不重叠；从突破到当前是否曾回入，另按实际过程核对。回到上一区间时，原先依赖界外保持的预期受损；允许回试的预期仍须看能否重新离开并恢复。持续在旧区间内轮转才增加内部平衡的依据，单次回入不确认反向趋势。

短暂停顿中原突破成果仍在、逆向尝试有限时，保留原方向依据；持续双向互动、反复返回旧区域且双方均难在外延伸时，按新平衡研究。持续时间帮助比较旧运动与当前互动的相关性，不以固定棒数自动改判中性。

方向延续与延续方式分别更新。由 [Trade](trade.md#33-交易前提路径失效与保护性止损)核对变化是否触及本笔依赖的推进、回调或恢复条件；市场可能需要更深、更久的回调，不自动扩大原方案允许范围。前提仍成立时，也按[当前交换](trade.md#36-计划损失当前风险与数量)比较剩余回报、到达依据、风险、成本与时间；重评后仍值得持有可沿用，改变方案按[重评顺序](trade.md#51-重评顺序)处理，不按结构名称直接减仓或退出。

## 四、趋势中出现回调

趋势此前能在回调后继续，主要趋势段或 Swing 尚未被反向突破并在外保持 → 仍可期待回调在结构内停止，并在预期期限内恢复。

用此前回调的位置、幅度、时间和后续走势判断本次是否正常。主要结构完整，本次恢复也可能偏弱；具体按 [Market](market.md#回撤与恢复怎样改变原判断)更新。

**回调参照：**此前仍起作用的 EMA、固定趋势段比例、趋势线或通道线、旧突破点、前高低、趋势段起点、信号或突破 K 边界，以及开放突破回调 Gap，可提供回调参照。主要 HL/LH 须按 [主要与次要回调点](market.md#主要与次要回调点)确认，不能用任意局部低高点代替。参照的预期作用须在对应结果前明确；穿越 EMA、线或比例并不自动否定它，仍按允许的复测和恢复判断，主要结构另判。恢复后近端通常看旧趋势极值，更远目标需要处理它的阻碍。

需要区分已经经历哪些恢复尝试时，查 [H/L 次序与重置](market.md#d-hl-次序与重置)；需要判断是否再次测试同一区域时，查 [Double Test](market.md#c-double-test-与-neckline)。它们可以共享回调事实，第二次测试、第二次 setup 与第二次图表触发仍各有自己的条件。

### 哪些背景会改变普通回调预期

- **深回调而较大 Broad Channel 仍有效** → 短周期可暂时反向；外层主要结构与目标按自身条件判断。
- **紧密微型通道首次微型趋势线突破** → 通常先看正常回调。趋势晚期 → 同时检查异常修正；已有足够反向发展 → 研究[旧控制受损](#八趋势受损后尝试反转)，不机械等待固定信号数。
- **旗形接近限制当前段的区域，且反方压力增强** → 把旗形作为 Final Flag 候选，研究当前段是否结束。末端整理可经顺势突破失败后反向，也可未经顺势突破而直接反向；后一过程也可按 HL/LH MTR 研究，不补造突破。旗形可很短，也可出现在区间内的局部趋势；同时出现成熟、高潮或异常延伸会增加怀疑。按实际延续或反向发展更新，反向目标绑定所研究的趋势段尺度；小型局部变化可能只支持有限回调，有意义的反向 Swing 按[反向发展](#八趋势受损后尝试反转)研究。

#### 强回调自身也可能有第二段

外层多头结构完整，本次下跌却形成强空头微通道，反弹很浅 → 局部仍可期待[第二段下跌](market.md#第二段预期与分段尺度)，首次向上恢复可能只是下跌中的回调。外层稍后恢复与局部继续下跌可以并存；空头趋势中的强多头回调镜像处理。

- 首次反弹弱，随后再次下跌并在低位延伸 → 支持第二段下跌。
- 第二次下探未能继续扩大跌幅，随后上涨并获跟随 → 外层恢复依据增强。
- 价格直接强势上涨且涨幅未明显回吐 → 及时削弱局部下跌预期，无需等待第二段。

#### 趋势中的反侧 MAG

EMA 参数与参照周期事前固定。Moving-average gap bar 只说明整根 K 未触均线；反侧 MAG 指多头趋势中整根 K 的最高点低于 EMA，空头镜像为最低点高于 EMA。

反侧 MAG 显示反方已将价格推进至均线另一侧并形成分离，结合反向段强弱、趋势线破坏与保留进展，评价原趋势受损。此后原方向仍可能恢复并测试旧极值，但这次恢复也可能成为更大修正前的最后一段。该关系不要求此前长期未触均线；震荡中反复穿越 EMA，缺少同样的趋势受损语境。

后续按恢复质量判断，不保证最后一段发生、到达或越过旧极值：

| 后续事实 | 怎样接续 |
| --- | --- |
| 原方向恢复并保住进展 | 旧极值测试依据增强；到达前继续核对障碍、空间与期限 |
| 旧极值附近恢复乏力、跟随缺失并反向发展 | 更大修正或双边化依据增强，按[异常延伸与修正](#七趋势异常加速或持续过久)继续比较 |
| 原方向强势越过旧极值并持续保持进展 | 继续评价延伸，不因已有 MAG 就认定该段必为最后一段 |
| 原方向尚未完成测试就恢复失败，反方取得并保住进展 | 按各路径条件更新恢复预期，研究[反向发展](#八趋势受损后尝试反转)，不等待旧极值必被测试 |

触及、反侧 MAG、主要结构外接受是不同事件；均线事件本身不授权入场，也不自动确认反向趋势。

#### 长期远离 EMA 后的首次测试

此前趋势长期未触 EMA、保持在同一侧，首次深入均线的回调另有以下背景：

| 已发生的均线事件 | 当前预期 |
| --- | --- |
| 首次触及 EMA，或收于另一侧但 K 仍与均线相交 | 先看回调停止、原方向恢复并测试旧趋势极值；尚未形成反侧 MAG |
| 首次整根位于原趋势的均线另一侧 | 同时具备长期远离后的首次深回调与反侧 MAG 背景；原方向恢复及后续修正按[上节](#趋势中的反侧-mag)比较，不将两种描述重复计为独立证据 |

## 五、价格到达区间或宽通道边缘

价格反复涨跌，上下边界在本次到达前已经明确，且此前多次在边缘返回内部 → 可期待再次返回。本次若连续强势到达、回调有限，也支持研究突破；仍须按 [Market 边界判据](market.md#边界处是否改变此前作用)核对后续。

**位置决定能研究哪一段：**尚未到边缘时，它可以是当前局部运动的目标；已经向内取得进展时，先看公平区或中部，更远对侧目标须处理内部障碍；外部接受后，旧边界成为回试候选。外部测试极值可供评价边缘尝试。位于中部或结构太窄时，没有相同的边缘位置或空间，不能借用这项机会。

Broad Channel 的双向运动仍保留通道倾斜、主要 HL/LH 和外层方向，成熟 Trading Range 更重视内部轮转；二者有双边空间，不代表双向同强。

有依据的成熟边界可在触及前研究向内目标、外部失效和期限。触及参与时，拒绝仍是假设；拒绝确认后，使用完成事实与当时价格评价。两者按 [条件路径](market.md#37-条件路径与目标)研究，再由 Trade 比较，不把前者误写成已经发生拒绝。

提前反做须明确押注哪项延续不足：

| 候选方案 | 当时依据与尚未确认部分 |
| --- | --- |
| 弱信号的目标区域附近反做 | 背景、实际推进与剩余空间支持回摆，押注原方向无法持续穿过该区域；目标须有价格参照，不能只推测他人会止盈 |
| 区间边缘突破收盘时反做 | 区间边界及返回预期仍有依据，押注后续缺少有效跟随；跟随尚未发生不等于已经失败 |

两者都须独立构造返回目标、保护、期限与数量，并通过 Trade 的参与筛选。后续突破取得并保住进展时，及时更新原假设；不以“区间突破常失败”忽略当前变化。等待失败确认是另一候选，按届时价格比较。

边缘附近的异常强段形成高潮，随后缺少应有跟随并向内发展 → 按[异常修正](#七趋势异常加速或持续过久)评价修正规模；普通边缘拒绝不自动采用同样预期。

### 第二段陷阱

已有第二段接近或到达边缘时，先比较局部强度是否改变此前边缘的限制，再随跟随、返回与恢复更新，按 [Market 的判据](market.md#第二段预期怎样受损或失败)区分陷阱风险与已发生的陷阱。普通边缘机会按自身依据研究，不必等待完整陷阱。

## 六、区间反复测试边界

价格反复测试已识别边界，内部突破经常失败 → 先保留震荡预期。本次若比此前失败尝试走得更远、回调更浅，或受阻后更能继续，突破依据增加。越界与返回按 [Market 边界判据](market.md#边界处是否改变此前作用)判断。

本节从整体平衡看下一段方向，[上一节](#五价格到达区间或宽通道边缘)从已经到达的边缘看向内与向外的空间；两者可以用于同一判断。越界失败后，仍在边缘且有向内空间才研究轮转；已经回到中部则重看局部运动，不能把一次失败直接外推为去往对侧。

压缩、扩张或反复回调都可能维持平衡，几何不决定方向，也不保证马上突破；需要判定这些形态时查 [结构视图怎样共享事实](market.md#a-结构视图怎样共享事实)。较小结构位于外层边缘时，保留外层边缘对方向和空间的约束。

**向外空间的依据：**从有效边界看外部旧极值、主要支撑阻力与测量区，并保留接受后旧边界的回试作用。边界、目标、回入失效和期限可以在越界前组成条件路径；尚未出现的收盘、跟随或回试仍是假设。是否提前参与或等待这些事实，再由 Trade 按当时价格与风险比较。

## 七、趋势异常加速或持续过久

趋势持续扩展或长期缺少有意义回调，接近目标、旧极值或通道外侧，又出现异常加速、最大趋势 K、连续高潮或最后外侧突破 → 修正值得比较。[反侧 MAG](#趋势中的反侧-mag)另按反方进展与原方向恢复评价；长期远离后的[首次测试](#长期远离-ema-后的首次测试)保留其特殊背景。

异常也可来自持续时间：许多小实体 K 长期同向推进、几乎没有回调，相对所选周期此前的持续性已明显异常 → 即使没有末端巨大 K，也比较有意义的时间修正。普通小回调趋势若持续性并未异常、浅回调后仍能恢复并保住进展，不能仅因已走得较久就当作高潮或逆势依据。

异常推进取得更多进展，也可支持最后延伸或新测量段；“运动已久、位置受限”与“本次仍强”可以同时成立。楔形、抛物线、超越或巨大 K 的外观本身不能决定修正，更不能确认反向趋势；后续是否保住进展、怎样恢复，按 [回撤与恢复](market.md#回撤与恢复怎样改变原判断)更新。

真空描述向某个支撑阻力区域的快速运动，使用时说明指全段还是末端冲刺；衰竭判断其后持续能力是否减弱，两者可以共存。单次冲刺重点检验到达后的反应，连续异常冲刺增加维持能力的疑问；仍以跟随、保留和恢复区分延伸与修正，不从次数推定买卖盘已耗尽。

**空间与修正方式：**向前看下一测量区及主要障碍，交还进展时看高潮起点、异常 K 另一端、突破点、EMA 或公平区；这些区域须与当前运动和剩余时间相符。同向进展停止、重叠增加而 Gap 仍开放，可以是时间修正；分离关闭或回到旧区域，并出现反向恢复，会增加价格修正依据。

研究上述运动的修正规模时，可用 [TBTL](market.md#tbtl-与运动尺度)比较时间与分段；受限位置、原向恢复失败、反方进展及足够反向空间增加持续修正依据。三推外观、局部小楔形或强紧通道中的首次反转，不独立提供同样预期。

先明确修正的是局部冲刺，还是长期紧密推进、连续高潮构成的整段运动。局部高潮可先形成小整理；长时间单向运动后的修正，须在能表达该运动的相关尺度上评价，低周期几根停顿不自动代表整体修正完成。时间与深度分开：横向整理可持续较久而回吐有限，少数强反向 K 也可迅速改变价格结构。原运动耗时用于比较修正规模，不按固定棒数或时间比例判定结束。

高潮停止当前冲刺后，旧方向仍可能恢复、再次测试极值，形成双顶或微型双顶等过程，空头镜像。比较再次到达、越过与保留的能力，以及第二次反向是否取得更多进展；不要求精确等高或等低。**反向修正测试高潮起点**与**原方向恢复测试高潮极值**是不同路径；若反方已持续推进，不等待返回补齐双测试。

### 通道突破的方向与目标

先说明越过的是顺势外侧通道线，还是反向一侧的趋势线。通道强弱、突破后的进展与恢复共同决定后续；短暂越线仍按共同边界规则判断。

| 已发生的突破与后续 | 可研究的路径 |
| --- | --- |
| 顺势越过外侧通道线后失败，价格回入并向内推进 | 先研究通道内部，反向力量和空间支持时研究对侧；紧通道的对侧可能太近，不足以支持当前逆势交易 |
| 反向越过趋势线，原通道持续性受损 | 比较旧方向恢复与区间化；回撤加深、双向交易增加且反向进展持续时，可研究通道起点测试 |
| 顺势越过外侧通道线，强跟随及后续保持支持新突破 | 更新为新突破段，研究持续两段及测量候选；这一特定顺势延伸语境按 [TBTL 与运动尺度](market.md#tbtl-与运动尺度)处理，新的回调再按实际正常程度判断 |

通道起点取原突破后开启通道阶段的首次有意义回调区域；很小的停顿被迅速强势恢复时，仍可能属于原突破。先固定通道与尺度，起点不清时保留缺项。它不同于对侧边界或整个 Spike 起点；可达性按[目标选择](market.md#路径怎样选择目标区域)处理。

强紧通道首次反向破线后仍可能主要横向修正、再测旧极值；两段修正预期不保证深回测通道起点。

### Gap 的竞争解释

同次突破留下的多个 Gap 各有比较对象和关闭时点，逐项引用：

- **普通回调保住所引用的分离，随后再次延伸** → 支持测量解释。
- **该分离关闭、旧区域重新交易，原方向失去跟随** → 检查衰竭诊断及之后的恢复。

趋势后期异常顺势突破后失去跟随并出现小反转，也可支持衰竭解释，不要求所引用 Gap 完整关闭。普通停顿不足以单独判衰竭，原方向停止或时间修正也不替代特定 Gap 关闭。衰竭、关闭与反向持续能力分别判断；第一次高潮终止当前段后，仍可能有第二段延伸。

## 八、趋势受损后尝试反转

原趋势受到反向压力、旧极值测试或恢复失败的挑战。此前趋势仍有恢复能力，因此同时观察原方向再测旧极值、转为区间和反向发展的可能。趋势受损、出现反向段与形成反向趋势，按 [Market](market.md#回撤与恢复怎样改变原判断)分别判断。

### 受损位置与恢复次序

先分清受损的是趋势线、局部运动还是主要结构。典型 MTR 次序是：反向压力打破趋势线或通道 → 旧方向测试极值或恢复 → 恢复失败并形成反向发展。只有线或结构受损、旧极值测试尚未完成时，继续对照旧方向的恢复与反方能否保住进展，不能仅凭受损认定反方接管。

旧极值测试失败并反向恢复、形成新 HL/LH，会增强早期反向 Swing 的依据；先看反向段极值或内部区域，持续控制还需反方延伸并组织正常回调。足够强的事件可使过程很快完成，无需固定等待根数。

首次反向段的强弱影响旧极值附近还需要什么确认。以顶部反转为例，底部镜像：

| 已有过程 | 提前参与或等待的依据 |
| --- | --- |
| 首次下跌已有足够卖压，破坏上涨连续性；随后多头测试旧高并出现向下反转 | 可研究 DT/HH 处的早期空头 Swing，不必一律等 LH；仍需比较当前卖出信号、保护与目标 |
| 首次下跌弱，尚未显示足够卖压 | 后续上涨也弱仍不足以补足空头能力；等待更强下跌及之后的 LH，或其他足够强的反向突破与跟随 |
| 首次下跌强，但多头随后重新强势推进并保住进展 | 更新原反转依据，不能继续凭旧卖压提前做空 |

等待应明确要补的事实；DT/HH 或 LH 的位置名称不代替压力与恢复比较。确认增加后，按届时价格重新比较剩余空间和风险，沿用 [Trade 的参与方式选择](trade.md#31-从条件路径开始)。

研究有意义的反向 Swing 时，需要估计持续时间与分段才参考 [TBTL](market.md#tbtl-与运动尺度)；反向压力、恢复失败、跟随与空间增加这项预期的依据。后续可以先形成反向 Swing 或区间，修正完成与持续控制转移仍分别判断。

**同是逆向进展，机会范围不同：**

- **完整 Tight Channel 中孤立的首次逆势信号** → 通常先支持有限回调，与旧趋势惯性比较逆向规模和跟随，评价有限目标或等待。
- **通道较宽，有足够反向压力与失败恢复** → 即使主要结构完整，也可按局部尺度与近端区域研究反向 Swing；不必先确认旧持续控制结束。
- **反转尝试先形成 Trading Range，或 Swing 已达目标** → 不据此断言永久反向趋势。

旧趋势极值、被测试或破坏的结构、新 HL/LH、反向 Swing 极值、两段修正区和内部平衡区，按所研究运动的尺度与当前作用选用。

原趋势恢复并形成新的有效趋势段时，原反转序列失去当前作用；按 [H/L 次序与重置](market.md#d-hl-次序与重置)处理恢复对象，新反转预期使用新事实。
