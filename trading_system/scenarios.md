# 市场场景：按问题查预期

六类场景帮助理解具体背景下的正常预期、竞争解释、关键事实与候选区域。按当前问题取用，写回 [Market](market.md) 的判断；参与方式、止损与管理由 [Trade](trade.md) 评价。

## 一、使用边界

同一运动可以同时是较大趋势的回调、局部突破和某区域的测试。选择最有助于解释当前问题的内容，保留各自周期、比较对象和条件；标签不能唯一确定时，仍可按实际博弈形成条件路径。

本页中的触及、越界、收盘、跟随和回试守住有各自含义。Market 说明这些事实如何改变预期，Trade 决定参与需要哪些条件。具体预期绑定当前产品、周期和剩余时间，并通过回放检验。

## 二、盘中选择器

| 当前主要问题 | 可查内容 |
| --- | --- |
| 一侧已有持续进展，判断能否继续延伸 | [单边失衡继续扩展](#四单边失衡继续扩展) |
| 原趋势中出现逆向运动，判断何处停止、怎样恢复 | [原趋势中的回调测试与恢复](#五原趋势中的回调测试与恢复) |
| 已到可识别的双边边缘，判断拒绝还是外部接受 | [双边结构边缘的反应与轮转](#六双边结构边缘的反应与轮转) |
| 双方反复测试，判断边界外的延伸与失败 | [成熟双向平衡的方向决断](#七成熟双向平衡的方向决断) |
| 趋势异常延伸，判断后续延续、修正与衰竭 | [成熟趋势的异常延伸与修正](#八成熟趋势的异常延伸与修正) |
| 旧控制受损，判断恢复、早期反向 Swing 或持续控制转移 | [旧控制受损后的恢复与反向发展](#九旧控制受损后的恢复与反向发展) |

区间内部的清楚局部段可以使用延伸或回调预期；外层边缘同时约束它的目标与后续。需要解释多个问题时按需取用相关内容，不把场景选择当作路径或交易的额外条件。

## 三、导航输出

从适用内容中取出：当前预期、允许的正常回调或停顿、使它转为异常的表现，以及最近会改变行动的区域。将它们用于 Market 判断与 Trade 的具体交易前提；问题改变时再查相关主题。

同样的回撤，在需要立即跟随的短打方案中可能要求退出，在允许多根回调的延伸方案中可能仍可持有。按事前选定的参与与管理方式解释变化，切换方式时说明新事实及当前交换；场景名称本身不要求换单。

## 四、单边失衡继续扩展

当前问题：已建立的单边控制能否保持，并在期限内到达目标？

### 背景与正常预期

一侧的突破已经获得跟随，或连续同向表现形成失衡；所依赖的分离、极值推进和回撤边界仍有效，到前方区域有空间与时间。正常表现是继续延伸、保住进展，或浅回调后恢复；紧密趋势的第一次逆向尝试通常先形成有限回调。

Breakout、Spike、Always In、Tight Channel、Small Pullback Trend、Microchannel 和已接受的 Range 突破，可以共享上述进展事实。

**候选区域**：下一结构极值、主要支撑阻力、第二段投射区域及端点固定的测量区。

### 关键事实

| 新事实 | 对当前预期的影响 |
| --- | --- |
| 第一根强 K 或第一次越界 | 先核对它在当前背景中完成了什么；尚需跟随、分离保持或回试的判断继续观察相应事实 |
| 突破获得跟随并建立接受 | 延伸依据增强，结合近端障碍与期限评价下一目标 |
| 第一次有意义回调 | 比较回调与原正常边界，按[回调测试与恢复](#五原趋势中的回调测试与恢复)寻找恢复条件 |
| 跟随不足但尚未重新接受旧区域 | 延续预期削弱，可能转通道或双边化 |
| 重新接受旧区域 | 本次突破可能失败；方向路径按自己的失效条件判断，仍可能通过回调再次恢复 |
| 接近或到达目标 | 按事前条件评价目标完成，结合该区域的作用与实际表现，研究正常暂停、回调或后续路径 |
| 趋势晚期在目标或通道外侧出现异常加速、最大趋势 K | 满足[异常延伸与修正](#八成熟趋势的异常延伸与修正)的背景时，比较继续延伸与修正 |

若逆向信号触发后取得的进展反复被原方向收回，按 [通道的进展与空间比较](market.md#34-市场组织控制与阶段)检查其可交易性。不足以支持拟定目标时，这些信号主要用于观察回调、重评顺势仓位；逆向发展扩大后再评价新的参与方式。

反向有限回调与反向趋势有不同的目标和风险。当前控制清楚也可能已经不适合追价；Trade 用实际入场、止损和剩余空间评价。

跟随减弱、分离关闭、重叠增加或回调加深时，原方向仍可能恢复，也可能逐步双边化。Staircase、Trending Trading Range 保留倾斜、重叠、回撤和边界差别；稳定边界形成后研究边缘与突破，尚无边界时按原方向恢复和反方发展的实际条件判断。

## 五、原趋势中的回调测试与恢复

当前问题：逆向运动是正常测试、转入平衡，还是开始破坏原趋势？

### 背景与正常预期

原方向仍有持续能力，主要趋势段或 Swing 尚未被反方向接受性突破。健康回调应在相应结构内停止，并在预期期限内恢复。回调越深、越久且恢复反复失败，双边化或反向发展的解释越强。

**候选区域**：EMA、固定趋势段比例、趋势线或通道线、旧突破点、前高低、主要 HL/LH、趋势段起点、信号或突破 K 边界，以及开放突破回调 Gap。参照和它的预期作用应在对应结果前明确。

H1/H2、L1/L2、Double Test、Flag、Wedge Flag 和 Breakout Pullback 保留各自次序与边界，用来解释恢复发生在哪里、已经经历哪些尝试。

旗形接近会限制当前段的区域、反方压力增强时，同时考虑 Final Flag 候选：顺势突破可能失败并结束这一段。旗形可以很短，也可出现在区间内的局部趋势中；成熟、高潮和异常延伸增加怀疑，按需查[异常延伸与修正](#八成熟趋势的异常延伸与修正)。后续按实际延续或失败更新，反向目标绑定被结束的趋势段尺度。

### 关键事实

| 新事实 | 对当前预期的影响 |
| --- | --- |
| 接近或刚触及参照 | 观察拒绝、恢复、穿越或参照外接受；触及本身只完成位置事件 |
| 参照处拒绝并恢复原方向 | 恢复依据增强；近端候选通常是旧趋势极值，更远目标需说明如何通过它 |
| 一次恢复失败，反方仍缺跟随 | 保留本次失败事实，比较后续是否只形成较深回调；旧方向路径可以仍有效 |
| 穿越 EMA、趋势线或比例参照，但主要结构完整 | 说明该参照受到的影响，继续比较双方实际进展 |
| 回调加深、延长并双向化 | 原恢复预期弱化；已有边界时研究轮转或突破，无稳定边界时保留恢复与反向发展的条件 |
| 主要结构破坏，反方取得并保住进展 | 旧恢复解释受到否定；结合自身失效条件，研究[反向发展](#九旧控制受损后的恢复与反向发展) |

### 重要变体

- **长期未触 EMA 后首次测试**：触及、收于另一侧、整根位于另一侧及主要结构外接受分别判断。整根穿越说明反方进展增加；后续能否保住或扩展仍需观察。EMA 参数在使用前固定。
- **深回调而较大 Broad Channel 仍有效**：短周期可能暂时反向，外层主要结构与目标继续按其自身条件判断。
- **紧密微型通道首次微型趋势线突破**：通常先研究正常回调。趋势晚期同时检查异常修正；出现足够反向发展时研究旧控制受损，而不机械等待固定信号数。

## 六、双边结构边缘的反应与轮转

当前问题：可识别边缘会拒绝并向内部轮转，还是边界外获得接受？

### 背景与正常预期

双方已经能反复推动、反转，上下边界在本次到达前可识别。当前接近边缘、边界外尚无持续接受时，研究向内部运动的空间与条件。普通越界可能只是测试；外部延伸需要能在外保住进展或获得后续跟随。

Broad Channel 仍保留倾斜和主要 HL/LH，成熟 Trading Range 更重视内部轮转。Range Edge、Failed Breakout、Overshoot、Vacuum Test、Double Test 和 Second-leg Trap 使用同一边缘事实，但保留不同次序。

**候选区域**：当前边界、外部测试极值、内部公平区或中部、对侧边界，以及外部接受后的旧边界回试区。

### 关键事实

| 新事实 | 对当前预期的影响 |
| --- | --- |
| 尚未到边缘 | 边缘是当前段的候选目标；局部方向清楚时使用延伸或回调预期 |
| 刚到边缘或轻微越界 | 向内拒绝与外部延伸仍待检验；越界不等于获得外部接受 |
| 边缘拒绝或外部尝试失败，向内取得进展 | 向内轮转依据增强，先评价公平区或中部；更远对侧目标需处理内部障碍 |
| 边界外获得接受 | 轮转预期受到否定，旧边界可成为延伸路径的回试区 |
| 位于中部或结构太窄 | 当前边缘假设缺少位置或空间，重新寻找有意义的区域与运动 |

成熟边界下，向内目标、外部失效、期限与空间可以在触及前评价。Trade 可以研究触及参与与拒绝确认后的参与；选择前者时，预期中的拒绝仍是尚未发生的假设。

### 第二段陷阱

第一段先建立第二段预期；第二段实际出现并到达限制延续的区域；应有跟随缺失；随后重新接受旧区域或向内部恢复。按这个次序评价延续预期为何失败。

尚未完成失败条件时先记延续偏弱。确认后，外部路径按自己的失效条件判断；内部路径仍需自己的目标、完成、失效和期限。清楚趋势早期的强第二段更支持真实延续。

## 七、成熟双向平衡的方向决断

当前问题：双方继续平衡，还是某一方向能够在边界外延伸？

### 背景与正常预期

双方围绕已识别的边界反复测试，尚无持续控制方，内部突破容易被对手交还。第一次越界可能失败；若能在外保住进展、延伸或回试守住，外部路径的依据增强。

TTR、Triangle、ii、iii、ioi、oo、Expanding Triangle、大型 H&S 和无尽回调，保留各自压缩、扩张、边界或恢复次序。较小结构位于外层边缘时，同时采用边缘预期。

**候选区域**：有效边界、边界外旧极值或主要支撑阻力、旧边界回试区及端点固定的测量区。

### 参与所用的市场事实

边界、外部目标、回入失效和期限可以在越界前组成条件路径。Trade 比较提前参与与等收盘、跟随或回试后参与的价格和风险取舍，并在授权时明确所用条件。Market 共享同一路径的市场事实，按各事件的实际完成程度更新。

### 关键事实

| 新事实 | 对当前预期的影响 |
| --- | --- |
| 仍在结构内部 | 比较双方条件路径、边界外空间与内部继续平衡的可能 |
| 第一次越界 | 越界发生；若尚需收盘、跟随或回试，它们仍是待观察条件 |
| 外部接受完成 | 延伸的持续能力得到支持；重看剩余空间，并分别检查原目标是否也已经完成 |
| 越界失败并回到内部 | 本次外部尝试失败；边缘有向内空间时研究轮转，回到中部则重看当前局部运动 |

同一根 K 可以完成外部接受和事前目标，结果分别核对。一侧失败后，另一方向仍要有自己的进展、目标与失效条件。

## 八、成熟趋势的异常延伸与修正

当前问题：异常延伸是新测量段，还是当前运动衰竭并进入修正？

### 背景与正常预期

趋势此前持续扩展或长期缺少有意义回调，接近目标、旧极值或通道外侧，又出现异常加速、最大趋势 K、连续高潮、MAG 或最后外侧突破。测量解释需要继续保住分离并取得同向进展；跟随减弱、重新重叠或回到旧区域，使修正解释更有依据。

Climax、Measuring/Exhaustion Gap、Final Flag、Wedge、Parabolic Wedge、Overshoot 和 Give-up Bar 提供竞争问题。异常外观本身不等于反向趋势。

**候选区域**：下一测量区、主要障碍、高潮起点、异常 K 另一端、突破点、EMA 和公平区。

### 关键事实

| 新事实 | 对当前预期的影响 |
| --- | --- |
| 刚出现异常大 K 或加速 | 结合背景与空间，比较继续延伸、跟随停止和回到旧区域的条件 |
| 分离保持并继续同向接受 | 最后延伸或新测量段的依据增强，重看下一目标与障碍 |
| 同向进展停止，重叠增加，Gap 仍开放 | 可以形成时间修正；依赖特定 Gap 关闭的诊断仍待检验 |
| 分离关闭或回到旧区域，出现反向恢复 | 价格修正依据增强；反向趋势还需自己的持续进展 |
| 修正展开但主要结构完整 | 比较原方向恢复与双边边界形成，保留各自目标和期限 |
| 旧方向恢复失败，反方持续发展 | 研究[旧控制受损后的恢复与反向发展](#九旧控制受损后的恢复与反向发展) |

### Gap 的竞争解释

测量分支关注普通回调能否保住所引用的分离、随后能否再次延伸；衰竭诊断关注该分离关闭、旧区域重新交易，以及原方向失去跟随后的表现。同次突破留下的多个 Gap 各有比较对象和关闭时点。

原方向停止、时间修正、特定 Gap 关闭与反向趋势分别判断。第一次高潮可能只终止当前段，之后仍可能有第二段延伸。

修正常需要时间消化此前的单边运动，常以两段横向至反向运动展开。按当时结构和剩余时间安排观察，比较原方向恢复、稳定边界形成或反方持续进展；修正是否完成按事前条件判断。

## 九、旧控制受损后的恢复与反向发展

当前问题：旧方向能够恢复、市场先转平衡，还是反方向能够形成 Swing 乃至持续控制？

### 背景与正常预期

原方向曾有持续控制，现在反向压力、旧极值测试或恢复失败使该控制受到实质挑战。先说明受损的是趋势线、局部运动还是主要结构。第一次受损后旧方向仍可能测试旧极值并恢复；测试失败、新 HL/LH 和反向跟随会增强反向路径。

MTR、H&S、Double Test 和 Wedge 保留它们对旧极值、反向运动、恢复次序和边界的解释。完整 Tight Channel 中孤立的首次逆势信号，通常先支持有限回调；较宽通道、足够反向压力和失败恢复，可以支持更有意义的反向 Swing。

**候选区域**：旧趋势极值、被测试或破坏的结构、新 HL/LH、反向 Swing 极值、两段修正区域和内部平衡区。

### 典型次序与关键事实

典型 MTR 经历反向压力打破原趋势线或通道、旧方向测试极值或恢复、恢复失败并形成反向发展。此时可以研究早期 Swing；持续控制转移还需反方能延伸并组织正常回调。具体事件足够强时过程可以很快完成。

| 新事实 | 对当前预期的影响 |
| --- | --- |
| 第一次逆势进展，主要结构仍完整 | 比较其规模和跟随与旧趋势惯性，评价有限反向目标或等待更清楚发展 |
| 趋势线或主要结构受损，旧极值测试未完成 | 保留旧方向恢复与反向发展的条件，不把结构破坏等同于反方接管 |
| 旧极值测试失败并反向恢复，形成新 HL/LH | 早期反向 Swing 有更多依据；目标可先是反向段极值或内部区域，旧持续控制此时仍可能存在 |
| 新方向突破并取得持续进展 | 支持控制转移，并按新背景研究延伸；旧路径仍按原结果条件评价 |
| 原趋势恢复并形成新的有效趋势段 | 原反转序列失去当前作用，相关计数按恢复对象重置；新的反转预期使用新事实 |

很多主要反转尝试先形成 Trading Range；Swing 达到目标并不保证永久反向趋势。固定 Session 的时间压缩只在确有对应交易时段时使用。

## 十、结束导航

将采用的预期、区域与条件写回 Market。事实不足时说明待观察的问题和复查时机；有条件路径时交 Trade 比较方案。
