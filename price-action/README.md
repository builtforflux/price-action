# 价格行为

## 判定链路

市场判断 → 条件路径 → 入场与风险 → 持仓管理 → 跟踪更新

判断前提：最后可见 K 线 / 图表周期 / 所选趋势段与摆动尺度 / 实际交易时段。

市场判断：固定位置与尺度，比较双方推进、保留与恢复；形态、时段与市场广度补充条件证据。

新事实出现 → 更新受影响的判断、路径与仓位安排。

概率口径：课程经验，尚未校准；每行对应当时条件与预测事件。本表“未统一”为尚缺的幅度或期限口径，“—”为定性路径。

## 市场判断

### 市场状态与事件

#### 状态分类

| 市场状态 | 子类 | 识别依据 |
| ---- | ---- | ---- |
| 突破 | — | 一根或连续多根趋势 K 线推动价格脱离原结构；观察推进与跟随 |
| 通道 | 窄通道 | 主要摆动点递进，逆向摆动短小 |
| 通道 | 宽通道 | 主要摆动点递进，回调较深、突破点重叠，内部反向摆动较宽 |
| 震荡区间 | 窄震荡区间 | K 线重叠密集，边缘间摆动幅度小 |
| 震荡区间 | 宽震荡区间 | 双向摆动反复被收回，边缘间空间较大，内部可形成趋势段 |

震荡区间简称“区间”；横盘描述价格运动，双边平衡描述多空控制。

#### 趋势结构

| 结构 | 识别特征 |
| ---- | ---- |
| 微型通道 | 多头低点逐根持平或抬高；空头高点逐根持平或降低 |
| 小回调趋势 | 回调短浅、顺势恢复快、突破回调缺口常保持开放 |
| 趋势性交易区间 | 原区间 → 短突破 → 新区间；相邻区间重叠或由缺口隔开 |

#### 状态待定

| 当前条件 | 暂定状态 | 下一观察 |
| ---- | ---- | ---- |
| 趋势 / 区间待定 | 震荡区间，保留双向路径 | 单向推进能否保留 |
| 双向强推进相互抵消，主要摆动点保持 | 震荡区间 | 两侧突破后的跟随 |
| 趋势明确，通道宽窄待定 | 通道 | 回调深度 / K 线重叠 / 顺势恢复速度 |

#### 当前事件

推进 / 回调 / 位置测试 / 突破尝试 / 恢复尝试 / 反转尝试

| 用语 | 口径 |
| ---- | ---- |
| 回调 | 趋势中的暂停或逆向调整 |
| 回撤 | 相对所选趋势段的价格退回幅度 |
| 修正 | 横盘或逆原趋势方向的调整 |
| 延续 | 当前方向继续推进 |
| 恢复 | 回调后重新沿原趋势推进 |

状态关系：突破 ⇄ 通道 ⇄ 震荡区间；可跨阶段转换。

### 重要位置与目标

#### 重要位置

| 类别 | 位置 |
| ---- | ---- |
| 极值 | 前高 / 前低 |
| 时段参照 | 日 / 周 / 月的已知开高低收 |
| 起点 | 趋势段起点 / 突破段起点 / 通道起点 / 最后高潮起点 |
| 线 | 趋势线 / 通道线 |
| 区间 | 上沿 / 中点 / 下沿 / 上下三分之一分界 |
| 比例位置 | 所选趋势段中点 / 深回撤区域 |
| 缺口 | 突破回调缺口 / EMA20 均线缺口 / 开盘缺口 |
| 回测区域 | 突破点 / 强趋势 K 线收盘价 / 信号 K 线与入场 K 线高低点 |
| 目标 | 测量目标 / 通道对侧 / 通道起点 |

#### 位置定义

| 项目 | 定义 |
| ---- | ---- |
| 向上突破回调缺口 | 突破后回调低点与突破前高点之间的缺口 |
| 向下突破回调缺口 | 突破后回调高点与突破前低点之间的缺口 |
| 回撤比例 | 固定趋势段起止极值，按已回撤幅度占该段幅度计算 |
| 原趋势极值 | 所选原趋势段的最高价 / 最低价，包含影线 |
| 强趋势 K 线极值收盘价 | 所选趋势段内强阳线的最高收盘价 / 强阴线的最低收盘价；另记影线极值 |
| 开盘缺口 | 分别以昨日收盘价、昨日收盘区间边界、昨日高低点为参照 |

#### 测量目标

| 测量依据 | 量取范围 | 投射起点与方向 |
| ---- | ---- | ---- |
| 震荡区间 | 所选区间上沿至下沿 | 从突破边界向外等距投射 |
| 双顶 / 双底颈线突破 | 所选顶部 / 底部至颈线 | 从颈线向下 / 向上等距投射 |
| 双顶上破 / 双底下破 | 所选形态上沿至下沿 | 从突破边界向上 / 向下等距投射 |
| 强突破延续 | 首根强趋势 K 线开盘至末根强突破 K 线收盘 | 从末根收盘沿突破方向等距投射 |
| 强突破失败 | 原强突破的首根开盘至末根收盘 | 原突破起点被反向突破后，从首根开盘沿反向等距投射 |
| 等距第二段 | 所选第一段起点至终点 | 从第二段起点沿第一段方向等距投射 |
| 测量缺口 | 所选趋势段起点至突破回调缺口中点 | 从缺口中点沿趋势方向等距投射 |

测量前固定量取范围与投射起点，候选目标按距离排序。第二段起点取回调后的恢复起点；明确区间分隔两段时，第一段止于区间开始，第二段始于区间结束。

#### 位置测试

| 事件 | 定义 |
| ---- | ---- |
| 测试 | 价格接近或穿越指定位置 |
| 回测 | 价格离开后返回原位置 |
| 二次测试 | 同一结构内对指定位置的第二次测试 |

| 结果 | 价格行为 |
| ---- | ---- |
| 接近后反向 | 价格止于测试位置内侧，随后反向离开 |
| 越界后收回 | 短暂穿越测试位置，随后回到原侧 |
| 深度回入 | 突破后大幅回撤进入原区间或通道 |
| 界外保持 | 价格持续位于测试位置外侧；回调守住边界外侧 |

### 多空控制

#### 观察维度

| 维度 | 观察项 |
| ---- | ---- |
| 推进 | 创新极值 / 幅度 / 速度 / 连续性 |
| 保留 | 主要摆动点 / 突破点 / 突破回调缺口 |
| 跟随 | 同向推进 / 立即回入 / 反向覆盖 |
| 回调与恢复 | 回撤比例 / K 线重叠 / 恢复速度 / 原趋势极值测试结果 |

主要摆动点：所选摆动尺度上支撑趋势递进的高低点。局部反转与外层趋势分别判断。

#### 缺口观察

| 类型 | 观察结果 | 强弱依据 |
| ---- | ---- | ---- |
| 突破回调缺口 | 影线间有缺口 | 突破进展保留 |
| 突破回调缺口 | 影线重叠，实体间仍有缺口 | 回撤加深，趋势强度减弱 |
| 突破回调缺口 | 实体缺口也关闭 | 突破强度进一步减弱 |
| EMA20 均线缺口 | 持续保持均线同侧缺口 | 单边推进；同时记录持续时长 |
| EMA20 均线缺口 | 来回穿越均线 | 双边平衡 |

#### EMA20 测试事件

背景：价格长期位于 EMA20 同侧。

| 事件 | 识别条件 |
| ---- | ---- |
| 首次触线 | 价格从原侧首次触及 EMA20 |
| 首次反侧收盘 | 首次收盘落在 EMA20 反侧 |
| 首次反侧均线缺口 K 线（MAG） | 多头趋势后，K 线高点低于 EMA20；空头趋势后，K 线低点高于 EMA20 |

#### 控制权判定

| 当前证据 | 判定 |
| ---- | ---- |
| 单向推进、回调守住主要摆动点、顺势跟随 | 原方向控制 |
| 单向推进暂歇，主要摆动点保持 | 原方向控制待检验 |
| 持续双向重叠、两侧推进反复被收回 | 双边平衡 |
| 反向突破主要摆动点、反向跟随、突破进展保留 | 反方向控制增强 |
| 区间上破 / 下破，跟随与界外保持 | 多头 / 空头控制增强 |

短期方向待定时，以最近仍有效的强突破为方向参照。

### 形态判定

#### 背景与形态作用

| 所处背景 | 形态作用 |
| ---- | ---- |
| 趋势中 | 继续形态 |
| 趋势后期 / 区间边界 | 反转候选 |
| 双向压力平衡 | 突破模式 |

| 观察项 | 具体表现 |
| ---- | ---- |
| 推动结构 | 三推 / 推进增量缩小 |
| 高潮特征 | 抛物线加速 / 异常大实体 / 异常持久的小回调推进 |
| 位置背景 | 到达测量目标 / 测试大周期重要位置 |

#### 形态结构

| 形态 | 构成 / 识别特征 |
| ---- | ---- |
| 牛旗 | 多头趋势中的双底 / 下降宽通道 / 下推楔形 / 三角形 |
| 熊旗 | 空头趋势中的双顶 / 上升宽通道 / 上推楔形 / 三角形 |
| 双顶 / 双底 | 两次极值测试；颈线为两次测试间的摆动点；第二次可越过、持平或止于旧极值内侧 |
| 楔形 | 三次推动及段间回调；第三推可止于第二推内侧；另判通道宽窄、缺口与推进增量 |
| 抛物线楔形 | 三推伴随加速、连续高潮 |
| 三角形 | 收敛：高点降低、低点抬高；扩张：高点抬高、低点降低 |
| 头肩形 | 头部极值、两侧肩部、颈线；右肩为更低高点（LH）/ 更高低点（HL） |
| 圆弧形 | 原方向推进减弱、整理延长、反向高低点逐步递进 |
| 末端旗形候选 | 趋势后期整理、接近目标、反向压力增加 |
| 岛形反转候选 | 岛顶：向上跳空后向下跳空，两侧缺口隔开中间 K 线群；岛底镜像 |
| K 线组合 | ii / iii：连续两 / 三根内包；ioi：内包—外包—内包；oo：连续两根外包 |

内包（i）：高低点位于前一根 K 线范围内；外包（o）：高低点覆盖前一根 K 线范围。组合结合左侧趋势与所在位置判断。

成熟突破模式（BOM）：整理紧密、双向压力接近平衡、上下突破路径均合理。

#### 反转阶段与结果

| 项目 | 口径 |
| ---- | ---- |
| 反转候选 | 当前背景与结构支持反转路径 |
| 反转尝试 | 已出现与原趋势相反的推进 |
| 主要趋势反转（MTR）结构 | 足够反向压力破坏原趋势结构，随后回测原趋势极值；强反向突破可直接启动反向运动 |
| MTR 尝试 | 基于 MTR 结构发生的反转尝试 |
| 反转结果 | 次要反转 / 可交易反向波段 / 强反向趋势，按所选摆动尺度记录 |

#### 形态证据

- 形态待定 → 按位置、推进与跟随判断。
- 嵌套形态 → 记录新增的位置、测试次序与跟随证据。
- 同一价格结构的多个名称 → 合并为一组证据。

### 时段与市场广度

#### 时段条件

课程小时数按原交易时段理解；观察时采用当前市场的实际交易时段。

| 时段与事件 | 候选路径 | 观察重点 |
| ---- | ---- | ---- |
| 开盘第一段 | 延续 / 反转 / 区间 | 实体、收盘、跟随与已运行幅度 |
| 开盘第一段达到平均日波幅约 25%–50% 后失败 | 反向趋势候选 | 剩余空间与反向跟随 |
| 开盘第一段达到平均日波幅约 50%–100% 后失败 | 双向大波动区间 / 大反向趋势 | 两侧推进与主要摆动点 |
| 大周期趋势 / 十字星区间背景 | 开盘测试形成影线后恢复 / 围绕开盘价摆动 | 开盘价测试与跟随 |
| 昨日高潮 | 今日先延续后修正 / 直接修正 | 修正起点、持续时间与段数 |
| 开盘区间反复突破失败 | 边界扩大 / 成熟 BOM | 区间宽度与剩余时长 |
| 昨日高低点外发生开盘反转 | 反向波段 / 反转失败后恢复 | 重复测试、均线同侧保持与跟随 |
| 大幅跳空 | 延续 / 缺口回补 / 区间 | 缺口参照、回调深度与连续推进 |
| 日中整理延长 | 双边平衡 / 原趋势恢复 | 双侧压力、浅回调与缺口 |
| 尾盘测试开盘价、前高 / 前低、日周月价格或测量目标 | 突破 / 回归 / 横盘 | 测试后跟随与剩余时长 |
| 开盘价处于当日动态区间中间三分之一 | 后半日回测开盘价 | 随当日区间扩展更新相对位置 |
| 早段建立的小回调趋势持续至尾盘 | 原趋势延续 | 浅回调、缺口与跟随 |
| 最后一小时才形成的新通道 | 区间内波段 / 再次反向 | 目标空间与剩余时长 |
| 尾盘连续收盘接近各自高点 / 低点 | 重要位置测试后突破 / 修正 | 实体、跟随与目标距离 |

平均日波幅须固定回看期；表内 25%–50%、50%–100% 为运动幅度参照。

| 判断时点与当前条件 | 预测事件 | 课程概率 | 时间口径 |
| ---- | ---- | ---- | ---- |
| 开盘第一段形成 | 初始运动反转 | 约 50% | 开盘阶段；完成期限未统一 |
| 昨日以高潮结束，今日开盘 | 先沿原趋势延续 | 约 50% | 先延续约 1–2 小时 |
| 昨日以高潮结束，今日开盘 | 今日出现横向至反向修正 | 约 75% | 约 2 小时修正；可始于开盘或延续之后 |

#### 市场广度条件

NYSE TICK：NYSE 股票最新成交价相对各自前一笔上涨的家数，减去下跌的家数。课程用于 E-mini 的辅助判断。

| 广度事件 | 配合价格结构 | 路径侧重 |
| ---- | ---- | ---- |
| 首次同向极值 | 强突破与跟随 | 延续 / 原趋势极值测试 |
| 趋势后期重复极值 | 阶梯衰减 / 高潮 | 修正 |
| 价格创新极值、TICK 背离 | 重要位置与反向跟随 | 反向摆动 |
| 空头或区间背景，TICK 持续偏正并多次出现正极值 | 多头压力积累、向上跟随 | 向上突破 / 原空头恢复 |
| 空头或区间背景，TICK 回到自身前高 | 价格上涨受阻 | 回落 |
| 多头或区间背景，TICK 回到自身前低 | 价格下跌受阻 | 反弹 |

TICK 与价格对齐时点，极值阈值按适用市场校准。

## 条件路径

按市场状态检索事件；跨状态的规则列于共用事件，适用条件以各行为准。

概率匹配：判断时点 / 周期与尺度 / 条件 / 预测事件 / 目标与期限逐项对应；同口径事件比较候选路径。

| 方向用语 | 参照 |
| ---- | ---- |
| 反向 | 原趋势方向；另有参照时逐行注明 |
| 均线反侧 | 此前长期保持的 EMA20 一侧的对侧 |
| 向内 / 向外 | 区间或通道边界 |
| 逆倾斜 / 顺倾斜 | 楔形或通道的倾斜方向 |

段数按所选摆动尺度记录；第二段可止于第一段极值内侧，也可横向展开。

TBTL：约十根 K 线、至少两段横盘至逆原趋势方向的修正，按承载结构的相关周期观察。高潮后修正目标：最后高潮起点 / 相关通道区域。

等距目标：从同一现价向上下各取相同距离，比较首次到达次序。

### 信号 K 线

多头实体：收盘高于开盘；空头实体：收盘低于开盘。K 线作用结合背景、位置与相邻 K 线判断。

| 类型 | 典型表现 | 观察重点 |
| ---- | ---- | ---- |
| 多头趋势 K 线 | 多头实体，收近高点 | 实体占比、影线与重叠 |
| 空头趋势 K 线 | 空头实体，收近低点 | 实体占比、影线与重叠 |
| 买入反转 K 线 | 回调或低位测试后向上收回，收于自身中点上方或高于开盘 | 下影、收回幅度与买压 |
| 卖出反转 K 线 | 回调或高位测试后向下收回，收于自身中点下方或低于开盘 | 上影、收回幅度与卖压 |
| 震荡 K 线 | 小实体、明显影线或收盘居中 | 相邻重叠与双向收回 |

买入 / 卖出反转信号均可出现多头或空头实体。

- 强趋势首次回调：顺势信号 K 线形态可较弱。
- 强趋势内逆势强信号：结合回调幅度与反向跟随。
- 突破入场：信号 K 线 → 入场触发 → 跟随；收盘入场时，信号与入场可在同一根 K 线。

### 入场计数

#### H 计数

背景：牛旗 / 区间下沿

1. 突破前一根 K 线高点 → H1
2. 再次出现高点降低 → 再次突破前一根 K 线高点 → H2

#### L 计数

背景：熊旗 / 区间上沿

1. 跌破前一根 K 线低点 → L1
2. 再次出现低点抬高 → 再次跌破前一根 K 线低点 → L2

#### 计数规则

- 同一调整内计数，两次尝试可间隔多根 K 线。
- 同一次连续创新高 / 新低 → 保持当前计数。
- 后续尝试依次记为 H3 / L3、H4 / L4。
- 新一轮调整 / 新强突破后的回调 → 从 H1 / L1 重计。
- 段数 / 测试 / 信号 / 入场尝试 / K 线根数分别记录，注明尺度。

### 风险预算与首仓

整笔风险预算：首仓前固定的本笔计划损失上限，首仓、加仓与调整共用。回吐额度：为当前余仓设定的可接受权益回撤金额。

| 持有前提 | 止损参照 |
| ---- | ---- |
| 信号构成新走势段起点 | 信号 K 线 / 完整反转结构 |
| 强突破 / 趋势波段 | 最近强突破段起点 / 主要 HL、LH |
| 强势段维持浅回撤 | 所选强势段中点 |
| 宽通道 / 区间内反复测试 | 相关通道或区间边界 / 有明确测量依据的投射位置 |

止损置于所选参照的不利侧；参照周期与结构层级对应所参与的运动。

数量上限 =（本笔风险预算 − 固定成本预留）÷（每单位止损损失 + 每单位成本预留）。

每单位止损损失按入场至初始止损计算并换算到账户币；数量按交易单位向下取整。宽止损配小仓位，同时重评目标空间；分层首仓按分配给首层的风险额度计算。

建仓、加仓或调整前，计入已实现盈亏、实际余仓、仍可能成交的加仓与全部成本，按止损退出结果核对原预算。

| MTR 强突破确认后入场 | 获得波段利润 | 约 60% | 利润幅度、期限未统一 |

二元盈亏算例：期望 = 获利概率 × 平均毛盈利 − 亏损概率 × 平均毛亏损 − 平均成本。

## 持仓管理

首仓：首次成交仓位；加仓：增加同方向数量；减仓：减少部分数量；清仓：本笔余量归零。

浮盈 / 浮亏按当前价、实际入场价、余量与成本核算；顺势 / 逆势以所选市场运动为参照；本节同向 / 反向以持仓方向为参照。管理周期与持有依据一致。

按实际成交与余仓核算损益和风险，成本按实际计价口径计入；仓位调整后同步止损数量。

### 持有与止损调整

| 持仓条件 | 管理动作 | 余仓处理 |
| ---- | ---- | ---- |
| 普通回调 / 突破后的首次回调测试，波段前提与主要结构保持 | 持有 | 沿用有效止损 |
| 新强突破与跟随确认主要 HL / LH | 追踪止损 | 多头移至该 HL 下方，空头移至该 LH 上方 |
| 突破入场经历首次回调测试并强势恢复，原入场附近再次面临测试 | 止损可移至保本价附近或新确认结构外 | 关键结构失守时退出 |
| 短线临近目标、退出尚未成交，反向信号出现 | 止盈 / 收紧止损至保本价附近或新确认结构外 | 比较当前价至目标与止损的距离 |

止损调整：多头上移，空头下移；采用新确认结构或既定减损条件。

### 加仓

分层计划：最大入场笔数（含首笔）/ 各层位置或信号 / 间距 / 数量 / 共同止损 / 组合退出 / 期限，首仓前确定。

加仓条件：新增依据成立、目标与时间充足、新增回报与风险相称，整笔风险符合原预算。

| 持仓条件 | 管理动作 | 余仓处理 |
| ---- | ---- | ---- |
| 同向强突破与跟随持续，出现新顺势入场机会 | 按新信号或强趋势收盘加仓 | 首仓可持有波段，后层按短线或波段目标管理 |
| 原趋势 / 第二段前提有效，结构守住；弱回调到计划区域或形成同向恢复信号 | 区域限价加仓 / 多头在反转 K 线高点上方、空头在低点下方突破加仓 | 恢复强时持有；恢复偏弱时按组合退出目标减仓或清仓 |
| 区间边缘，或上下段重叠、回调穿回突破点的宽通道边缘；向内摆动空间充分 | 上沿高处分层卖出 / 下沿低处分层买入 | 向内摆动按目标退出；向外强突破与跟随使前提失效时清仓 |

### 减仓与目标调整

| 持仓条件 | 管理动作 | 余仓处理 |
| ---- | ---- | ---- |
| 趋势延伸，当前回吐风险超过设定额度 | 减仓至符合回吐额度；新结构已确认时可收紧止损 | 按实际余量与有效止损重算风险 |
| 到达阶段退出目标，余仓持有依据仍在 | 按计划部分止盈 | 余仓按后续目标与有效止损持有 |
| 连续加仓后推进减弱，通道变平、重叠增加 | 优先削减依赖持续推进的加仓仓位 | 余仓持有前提有效时保留；前提失效时清仓 |
| 已获趋势利润，接近测量目标或重要区域，出现连续高潮或可信反向信号 | 停止加仓，按预定退出量止盈 | 余仓前提失效或预定全退条件满足时清仓 |
| 趋势转为区间，仍支持区间内摆动 | 调整目标并重评数量 | 以区间对侧 / 近似保本为退出候选 |
| 分层持仓回到预定退出区域：首笔入场价 / 余仓加权入场价 / 组合保本价 | 按组合计划减仓 / 清仓 | 恢复强且目标仍有空间时可保留部分 |

减仓比例注明按原始总量或当时余量计算；余仓保留目标、有效止损与期限。风险倍数目标过近时，比较仍有依据的结构目标。

| 退出口径 | 核算 |
| ---- | ---- |
| 首笔保本 | 首笔按入场价退出为毛保本；净保本计入该笔成本，后层盈亏分别记录 |
| 组合保本价 | 计入已实现盈亏的余仓退出价：整笔毛盈亏为零（毛保本）/ 扣除全部成本后为零（净保本） |
| 近似保本 | 所选分笔或整笔的小利 / 小亏退出 |

保本价注明分笔 / 组合及毛 / 净口径。同一线性产品、同方向持仓：余仓加权入场价 = Σ（各笔未退出数量 × 入场价）÷ 当前总余量。

### 清仓与重新入场

| 当前条件 | 管理动作 | 后续处理 |
| ---- | ---- | ---- |
| 反向信号或强反向推进使持有前提失效 | 清仓并停止加仓 | 清仓后重评入场条件 |
| 保护止损触发 | 按有效止损退出余仓 | 按实际成交核算本笔结果 |
| 到达最终退出目标 | 清仓 | 按原目标记录结果 |
| 日内持仓临近有效期限 | 按剩余时间重评加仓与目标 | 按有效期限清仓 |
| 原仓已清，原交易前提重新成立或逆原持仓方向的新依据成立，独立信号出现 | 重新确定入场、止损、数量与目标 | 新交易单独跟踪；保留原交易结果 |

## 跟踪更新

### 路径更新

| 适用事件 | 新事实 | 更新 |
| ---- | ---- | ---- |
| 突破暂停 / 首次回调 | 突破进展保留，沿本次突破方向恢复并获得跟随 | 跟踪本次突破方向第二段，重评通道结构 |
| 突破 / 边界测试 | 深度回入，逆本次突破方向的大实体与跟随 | 突破失败；重评区间与反转 |
| 回调恢复 / 趋势中的位置回测 | 测试低点或高点守住，顺势实体增大、多头收盘接近各自高点 / 空头收盘接近各自低点 | 原趋势恢复证据增强 |
| 反向窄通道中的恢复尝试 | 恢复受阻，回调方向再推进 | 跟踪回调第二段与二次测试 |
| 回调 / 反转尝试 | 恢复反复受阻，双向重叠持续 | 转为震荡区间 |
| 旗形 / 区间内单向推进 | 一侧突破主要摆动点，强跟随、浅回调 | 突破方向的通道 / 新趋势 |
| 通道边界 / 区间强第二段 | 向边界外的推进受阻，向内反转并获得跟随 | 向内摆动；第二段背景下确认为陷阱 |
| 外侧通道线顺势突破 / 楔形顺倾斜突破 | 界外保持，连续同向跟随 | 跟踪突破方向的新趋势段与测量目标 |
| 楔形逆倾斜突破 | 沿突破方向推进并获得跟随 | 跟踪两段横盘至逆倾斜方向的摆动 |
| 原趋势极值回测 | 回测受阻，反向再推进；后续形成 HL / LH | MTR 证据增强 |
| 趋势后期强趋势 K 线极值收盘价测试 | 成熟通道末端小突破跟随差、失败，随后反向强突破 | 反向第二段证据增强 |
| 头肩 / 双顶底反转 | 强势穿越右肩或反转结构的摆动点，并沿原趋势跟随 | 当前反转结构失效 |
| 突破失败后的回测 | 原突破点或强趋势 K 线收盘价阻挡恢复，逆原突破方向跟随 | 支撑阻力互换，沿原突破反方向延续 |
| 突破失败后的回测 | 收复原突破区域，沿原突破方向推进并守住突破区域 | 原突破方向恢复 |
| 末端旗形候选 | 顺势强突破获得跟随、保留进展 | 跟踪原趋势方向第二段 |
| 单次反转信号失败 | 反向压力保持，新一轮测试与信号出现 | 反转重试 |
| 反转尝试后原趋势恢复 | 强势突破反转结构，恢复窄通道 | 重置此前趋势线突破与原趋势极值测试证据 |
| 趋势后期异常大突破 | 缺口保持、同向再突破 / 反向覆盖、持续跟随 | 测量缺口延续 / 衰竭后修正 |
