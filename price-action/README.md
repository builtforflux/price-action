# 价格行为

## 判定链路

判断时点与尺度 → 市场状态与事件 → 重要位置与目标 → 多空控制 → 形态判定 → 场景路径 → 信号 K 线 → 入场计数 → 订单执行 → 跟踪更新

判断前提：最后可见 K 线 / 图表周期 / 所选趋势段与摆动尺度 / 实际交易时段。

场景组合：市场状态 + 当前事件 + 位置 + 趋势阶段；时段与市场广度作为附加条件。

概率口径：课程经验，尚未校准；每行对应当时条件与预测事件。本表“未统一”为尚缺的幅度或期限口径，“—”为定性路径。

## 市场状态与事件

### 状态分类

| 市场状态 | 子类 |
| ---- | ---- |
| 突破 | — |
| 通道 | 窄通道 / 宽通道 |
| 震荡区间 | 窄震荡区间 / 宽震荡区间 |

震荡区间简称“区间”；横盘描述价格运动，双边平衡描述多空控制。

### 趋势结构

| 结构 | 识别特征 |
| ---- | ---- |
| 微型通道 | 多头低点逐根持平或抬高；空头高点逐根持平或降低 |
| 小回调趋势 | 回调短浅、顺势恢复快、突破回调缺口常保持开放 |
| 宽通道 | 主要摆动点递进，回调较深、突破点重叠、内部反向摆动较宽 |
| 趋势性交易区间 | 原区间 → 短突破 → 新区间；相邻区间重叠或由缺口隔开 |

### 状态待定

| 条件 | 判定依据 |
| ---- | ---- |
| 趋势 / 区间待定 | 暂按震荡区间，保留双向路径 |
| 双向强推进相互抵消，主要摆动点保持 | 震荡区间 |
| 趋势明确，通道宽窄待定 | 回调深度 / K 线重叠 / 顺势恢复速度 |
| 短期方向待定 | 最近仍有效的强突破 |

### 当前事件

推进 / 回调 / 位置测试 / 突破尝试 / 恢复尝试 / 反转尝试

| 用语 | 口径 |
| ---- | ---- |
| 回调 | 趋势中的暂停或逆向调整 |
| 回撤 | 相对所选趋势段的价格退回幅度 |
| 修正 | 横盘或逆原趋势方向的调整 |
| 延续 | 当前方向继续推进 |
| 恢复 | 回调后重新沿原趋势推进 |

状态关系：突破 ⇄ 通道 ⇄ 震荡区间；可跨阶段转换。

## 重要位置与目标

### 重要位置

| 类别 | 位置 |
| ---- | ---- |
| 极值 | 前高 / 前低 |
| 时段参照 | 日 / 周 / 月的已知开高低收 |
| 起点 | 趋势段起点 / 突破段起点 / 通道起点 / 最后高潮起点 |
| 线 | 趋势线 / 通道线 |
| 区间 | 上沿 / 中点 / 下沿 / 上下三分之一分界 |
| 比例位置 | 所选趋势段中点 / 深回撤区域 |
| 缺口 | 突破回调缺口 / EMA20 均线缺口 / 开盘缺口 |
| 回测区域 | 突破点 / 强趋势 K 线收盘价 / 信号 K 线与入场 K 线高低点 |
| 目标 | 测量目标 / 通道对侧 / 通道起点 |

### 位置定义

| 项目 | 定义 |
| ---- | ---- |
| 向上突破回调缺口 | 突破后回调低点与突破前高点之间的缺口 |
| 向下突破回调缺口 | 突破后回调高点与突破前低点之间的缺口 |
| 回撤比例 | 固定趋势段起止极值，按已回撤幅度占该段幅度计算 |
| 原趋势极值 | 所选原趋势段的最高价 / 最低价，包含影线 |
| 强趋势 K 线极值收盘价 | 所选趋势段内强阳线的最高收盘价 / 强阴线的最低收盘价；另记影线极值 |
| 开盘缺口 | 分别以昨日收盘价、昨日收盘区间边界、昨日高低点为参照 |

### 测量目标

| 测量依据 | 投射方向 |
| ---- | ---- |
| 震荡区间 | 双向 |
| 双底 / 双顶至颈线 | 双向 |
| 突破段 | 突破方向 |
| 趋势段 | 趋势方向 |
| 突破点至突破回调缺口中点 | 突破方向 |

强突破高度：首根强突破 K 线开盘至末根强突破 K 线收盘。

### 位置测试

| 事件 | 定义 |
| ---- | ---- |
| 测试 | 价格接近或穿越指定位置 |
| 回测 | 价格离开后返回原位置 |
| 二次测试 | 同一结构内对指定位置的第二次测试 |

| 结果 | 价格行为 |
| ---- | ---- |
| 接近后反向 | 价格止于测试位置内侧，随后反向离开 |
| 越界后收回 | 短暂穿越测试位置，随后回到原侧 |
| 深度回入 | 突破后大幅回撤进入原区间或通道 |
| 界外保持 | 价格持续位于测试位置外侧；回调守住边界外侧 |

## 多空控制

### 观察维度

| 维度 | 观察项 |
| ---- | ---- |
| 推进 | 创新极值 / 幅度 / 速度 / 连续性 |
| 保留 | 主要摆动点 / 突破点 / 突破回调缺口 |
| 跟随 | 同向推进 / 立即回入 / 反向覆盖 |
| 回调与恢复 | 回撤比例 / K 线重叠 / 恢复速度 / 原趋势极值测试结果 |

主要摆动点：所选摆动尺度上支撑趋势递进的高低点。局部反转与外层趋势分别判断。

### 缺口观察

| 类型 | 观察结果 | 强弱依据 |
| ---- | ---- | ---- |
| 突破回调缺口 | 影线间有缺口 | 突破进展保留 |
| 突破回调缺口 | 影线重叠，实体间仍有缺口 | 回撤加深，趋势强度减弱 |
| 突破回调缺口 | 实体缺口也关闭 | 突破强度进一步减弱 |
| EMA20 均线缺口 | 持续保持均线同侧缺口 | 单边推进；同时记录持续时长 |
| EMA20 均线缺口 | 来回穿越均线 | 双边平衡 |

### EMA20 测试事件

背景：价格长期位于 EMA20 同侧。

| 事件 | 识别条件 |
| ---- | ---- |
| 首次触线 | 价格从原侧首次触及 EMA20 |
| 首次反侧收盘 | 首次收盘落在 EMA20 反侧 |
| 首次反侧均线缺口 K 线（MAG） | 多头趋势后，K 线高点低于 EMA20；空头趋势后，K 线低点高于 EMA20 |

### 控制权判定

| 当前证据 | 判定 |
| ---- | ---- |
| 单向推进、回调守住主要摆动点、顺势跟随 | 原方向控制 |
| 单向推进暂歇，主要摆动点保持 | 原方向控制待检验 |
| 持续双向重叠、两侧推进反复被收回 | 双边平衡 |
| 反向突破主要摆动点、反向跟随、突破进展保留 | 反方向控制增强 |
| 区间上破 / 下破，跟随与界外保持 | 多头 / 空头控制增强 |

## 形态判定

### 背景与形态作用

| 所处背景 | 形态作用 |
| ---- | ---- |
| 趋势中 | 继续形态 |
| 趋势后期 / 区间边界 | 反转候选 |
| 双向压力平衡 | 突破模式 |

趋势后期与高潮特征：三推 / 抛物线加速 / 异常大实体 / 异常持久的小回调推进 / 测量目标 / 大周期重要位置。

### 形态结构

| 形态 | 构成 / 识别特征 |
| ---- | ---- |
| 牛旗 | 多头趋势中的双底 / 下降宽通道 / 下推楔形 / 三角形 |
| 熊旗 | 空头趋势中的双顶 / 上升宽通道 / 上推楔形 / 三角形 |
| 双顶 / 双底 | 两次极值测试；颈线为两次测试间的摆动点；第二次可越过、持平或止于旧极值内侧 |
| 楔形 | 三次推动及段间回调；第三推可止于第二推内侧；另判通道宽窄、缺口与推进增量 |
| 抛物线楔形 | 三推伴随加速、连续高潮 |
| 三角形 | 收敛：高点降低、低点抬高；扩张：高点抬高、低点降低 |
| 头肩形 | 头部极值、两侧肩部、颈线；右肩为更低高点（LH）/ 更高低点（HL） |
| 圆弧形 | 原方向推进减弱、整理延长、反向高低点逐步递进 |
| 末端旗形候选 | 趋势后期整理、接近目标、反向压力增加 |
| 岛形反转候选 | 岛顶：向上跳空后向下跳空，两侧缺口隔开中间 K 线群；岛底镜像 |
| K 线组合 | ii / iii / ioi / oo / 震荡 K 线；结合左侧趋势与所在位置 |

成熟突破模式（BOM）：整理紧密、双向压力接近平衡、上下突破路径均合理。

### 反转阶段与结果

| 项目 | 口径 |
| ---- | ---- |
| 反转候选 | 当前背景与结构支持反转路径 |
| 反转尝试 | 已出现与原趋势相反的推进 |
| 主要趋势反转（MTR）结构 | 足够反向压力破坏原趋势结构，随后回测原趋势极值；强反向突破可直接启动反向运动 |
| MTR 尝试 | 基于 MTR 结构发生的反转尝试 |
| 反转结果 | 次要反转 / 可交易反向波段 / 强反向趋势，按所选摆动尺度记录 |

### 形态证据

- 形态待定 → 按位置、推进与跟随判断。
- 嵌套形态 → 记录新增的位置、测试次序与跟随证据。
- 同一价格结构的多个名称 → 合并为一组证据。

## 场景路径

按市场状态检索事件；跨状态的规则列于共用事件，适用条件以各行为准。

| 方向用语 | 参照 |
| ---- | ---- |
| 反向 | 原趋势方向；另有参照时逐行注明 |
| 均线反侧 | 此前长期保持的 EMA20 一侧的对侧 |
| 向内 / 向外 | 区间或通道边界 |
| 逆倾斜 / 顺倾斜 | 楔形或通道的倾斜方向 |

段数按所选摆动尺度记录；第二段可止于第一段极值内侧，也可横向展开。

TBTL：约十根 K 线、至少两段横盘至逆原趋势方向的修正，按承载结构的相关周期观察。修正目标：最后高潮起点 / 相关通道区域。

等距目标：从同一现价向上下各取相同距离，比较首次到达次序。

## 入场计数

### H 计数

背景：牛旗 / 区间下沿

1. 突破前一根 K 线高点 → H1
2. 再次出现高点降低 → 再次突破前一根 K 线高点 → H2

### L 计数

背景：熊旗 / 区间上沿

1. 跌破前一根 K 线低点 → L1
2. 再次出现低点抬高 → 再次跌破前一根 K 线低点 → L2

### 计数规则

- 同一调整内计数，两次尝试可间隔多根 K 线。
- 同一次连续创新高 / 新低 → 保持当前计数。
- 后续尝试依次记为 H3 / L3、H4 / L4。
- 新一轮调整 / 新强突破后的回调 → 从 H1 / L1 重计。
- 段数 / 测试 / 信号 / 入场尝试 / K 线根数分别记录，注明尺度。
- H4 修正候选：核对双重底部、嵌套尝试或连续卖出高潮背景。

### 计数应用

| 背景 | 计数 | 动作 |
| ---- | ---- | ---- |
| 牛旗 / 区间下沿 | H2 | 做多候选 |
| 熊旗 / 区间上沿 | L2 | 做空候选 |
| 区间中部 | H2 / L2 | 等待 |
| 逆势 / 位置条件欠佳 | H2 / L2 | 等待位置测试与反向跟随 |
